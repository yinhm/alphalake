# 原生估值数据门槛

原SQLite的默认10年度／8季度是导出和展示窗口，不是DCF准入要求。此前把窗口内所有收入／EBIT空格列为必需项，是后端门槛错误。本轮按原引擎实际消费纠正，不改变前端、估值公式或引入政策文件。

## 当前原生数据库入口

以下适用于 `POST /api/valuation/from-database` 的默认调整和详细WACC选择；`ready`仅表示这一选择下的数据输入通过检查，不代表预测假设或公司经营口径已认证。

| 类型 | 所需输入 | 缺失处理 |
|---|---|---|
| 基期经营流量 | 最新完整财年FY0收入、报告EBIT | 拒绝；不能把较早年度晋升为FY0 |
| TTM增量 | 若财年后经过K季，使用FQ0…K−1以及FQ4…K+3的收入／EBIT | 仅检查实际参与项；保留季度位置，不把空季度压缩掉 |
| 当前每股股权桥接 | 最新季度（无增量季度时为FY0）的现金和短期投资、有息债务、交叉持股/投资、少数股权、正股数 | 拒绝缺值；明确数值零可用，未知不能当零，也不借用旧年度余额 |
| 默认市场资本权重 | 正的上市币种市值；不同币种时另需正的转换汇率 | 拒绝缺值；TTM不得丢失公司市值快照 |
| 研发资本化 | FY0研发费用为正时原入口自动启用；默认5年寿命需当期及前5个连续年度研发费用，TTM另需相应季度费用 | 作为条件缺项拒绝；不要求这些旧年度的收入／EBIT同时齐全，不压缩研发年份 |
| 租赁资本化 | FY0经营租赁费用为正时自动启用，需未来1—5年和5年后承诺桶 | 作为条件缺项拒绝；显式零与未知分开。现行租赁会计是否重复资本化另行审核 |
| 已知员工期权 | 数量为正时需正行权价 | 缺失时拒绝，不能静默关闭已知稀释；原入口期限等默认假设不冒充事实 |
| 可选历史分析 | 其他年度收入／EBIT，折旧、资本开支、历史税项及资本余额等 | 不阻断使用显式预测假设的DCF；历史FCFF、ROIC等按实际缺项保留空值及警告 |

TTM公式仍为 `FY0 + 本年YTD − 上年同期YTD`。例如2026H1使用2025全年与2026、2025各自Q1/Q2；不要求2016—2019年收入，也不要求八个季度都完整。年度历史行只有收入和EBIT均可用才进入原模型，保留实际年份；研发队列独立读取原年度位置。

财务目标数值与 `export_cells` 审核状态同时检查；手工填入数字不能把未审核映射变为已审核。原来不分字段的“TDX快照永不达标”全局阻断已撤除，改为具体必需／条件项检查。经营租赁、研发、期权未知但未启用时明确警告，不将“默认关闭”表述为“公司没有”。TDX报告EBIT仍需区分非经营／特殊项调整，警告进入成功估值报告。

这里没有认证原生行业回退、国家映射、默认预测增长、无风险利率等假设适用于A股；也不将这组检查推广为所有手工API请求、PATCH方法或困境估值的统一准入。改变方法时须按实际分支重新审查（例如困境账面回收率需要账面权益，合成评级需要利息等）。本轮未增加前端流程。

## 安克当前复验

分母仅 `SZSE:300866` 一家公司；主库schema52，当前SQLite v3，财务截止2026H1、信息截止2026-09-25T00:00:00Z：

- 当前FY0／TTM收入与EBIT缺项 **0**。
- 必需缺项 **4**：2026H1现金和短期投资、有息债务、交叉持股/投资三个目标定义，以及公司市值。
- 条件缺项 **5**：自动启用研发资本化所需2020—2024年度研发费用的标准导出值。缺导出值不证明原始TDX或财报没有。
- 可选历史缺项 **8**：2016—2019年度收入／EBIT，不再阻断当前估值。

所以当前原生请求仍应422拒绝，但理由是实际消费的4项和5项；不再为凑满十年启动招股书补链。下一步应审核并供应上述当前输入；六类原SQL空列不全部属于无条件DCF必需项。额外来源、定义变更及人工假设仍按既有授权边界处理。

## 验证与方法边界

合成回归证明：只有一个财年也能经原引擎计算条件每股值，历史FCFF保持空；不使用的季度可空、实际参与TTM的季度缺失必拒绝；研发只需自己的连续队列；原HTTP路径在当前输入及审核状态齐全时可成功，篡改审核状态后拒绝。合成成功不冒充TDX真实公司成功或估值准确度认证。

相关Python回归156项通过，4项因既有真实工作簿样本缺失跳过；Go全套测试及CLI构建通过。实际8080复验仍422，缺项分类与上述计数一致；复验前后两库SHA256均未变化。实际网页复验与测试日志保存于动态目录 `workspace/derived/valuation-gate-audit/`。没有重建或改写主库、SQLite，没有修改前端，也没有增添依赖。

达摩达兰的[年轻公司估值章节](https://pages.stern.nyu.edu/~adamodar/pdfiles/val3ed/c23.pdf)讨论有限历史下的估值；历史长度影响估计依据与不确定性，不构成统一十年硬门槛。本轮仅纠正输入准入及期间传递，FCFF、再投资、WACC和终值公式均未调整。
