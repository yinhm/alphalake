## 剩余口径与具体补充方案

以下六个原SQL目标目前没有已审核的同义映射；已有相关TDX分量，不等于可以直接填入目标列。

| 原SQL目标 | 已有候选 | 需要解决的边界及补充方案 |
|---|---|---|
| 折旧摊销 | 固定资产折旧、无形/长期待摊、使用权及投资性房地产折旧 | 各期合并/拆分不同；以现金流补充资料审核组成后建立显式派生，不能无条件求和 |
| 剔除特殊项税前利润 | 利润总额、非经常损益及投资/公允价值等分量 | 税前/税后、经营/非经营排除集合不同；先批准目标定义及逐项调整，不能直接使用利润总额 |
| 经营租赁支付 | 租赁负债、使用权折旧、利息等 | 存量和费用不是支付额；需租赁附注支付/到期承诺，确认现行租赁准则下不会重复资本化 |
| 现金和短期投资 | 货币资金、现金等价物、交易性金融资产等 | 需受限、期限、衍生品及重叠分类；先审核附注，再独立提供排除/调整分量 |
| 长期投资 | 长期股权、债权及其他权益投资等 | 需经营/非经营范围、流动重分类与交叉持股边界；不把单一长期股权投资冒充总额 |
| 有息债务 | 短长借款、债券、一年内到期、租赁等 | 需一年内到期拆分及租赁范围，避免其他应付款混入或租赁重复计数；沿用已有样本附注核验再批准派生 |

来源报告EBIT已接入，仍须与原模型经营调整分开。[TDX量化手册](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)提供来源项目定义，不提供完整CIQ特殊项目剔除规则；[达摩达兰租赁表](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/leaseeffect.html)明确区分租赁调整前后经营利润和债务，不能用缺值默认关闭租赁来证明数据完整。

上市前历史可调研[CNINFO招股说明书](https://static.cninfo.com.cn/finalpage/2020-08-13/1208159854.PDF)和[证监会2019年申报稿](https://www.csrc.gov.cn/csrc/c101803/c1005333/content.shtml)。现有关联器要求报告期对应的定期报告，不支持把一份招股书的多个比较期间当成多份年度公告。若补这条链，应显式记录“披露文件—历史期间—报告版本”的审核关联，数值仍来自TDX；不得伪造年报身份或把上市前时期按零填满。该扩展及上述附注补充需作为具体方案审批，不擅自放宽原生准入。
