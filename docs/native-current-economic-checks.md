# 聚焦当前预测的经济一致性

当前暂停为历史回测或补齐比较窗口扩大早年采集。已有历史诊断保留，但不作为当前条件估值准入门槛。本轮复用固定12家公司及其完整输入，核查当前增长、资本效率、折现与终值现金流，不改前端、不补新来源、不改变估值公式或默认政策。

依据：[达摩达兰增长与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)要求关注收入绝对规模和隐含资本回报；[终值超额回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)要求稳定增长与再投资联动。规则切换不自动构成公式错误，也不能因两端都使用教材公式就省略过渡依据。

## 当前输出

现有`tools.review_native_policy`和`tools.evaluate_native_policy`输出`economic_checks`：

- `marginal_return_screen`：复用按投入滞后对齐的增量NOPAT分解，将恒定税后利润率分量/再投资与初始WACC比较，列出低于该参考的年份。该比例不是项目IRR，也不能认证时间变化的风险或因果回报；利润率改善、税率/NOL变化单独保留。
- `terminal_transition`：显式计算终值年度NOPAT、`NOPAT×g/ROIC`再投资及FCFF，并与共享引擎核对；同时列出第10年到终值年的NOPAT、再投资及FCFF变化。
- 同一终值年度继续使用预测期资本倍率的反事实：以同一投入滞后核算收入增量/倍率，与终值规则比较。再投资差額与FCFF差額符号相反，不拿不同投入年度混比。
- `equivalent_sales_to_capital`：在相同增长、利润率和投入时点下，使资本倍率法给出同一终值再投资的等价倍率。仅为代数诊断，不能直接替换行业代理或强迫存量ROIC等于新增ROIC。

目录审阅另输出`growth_duration_effects`：同一利润率场景内比较第3年与第10年收敛，列出第10年收入、前五年再投资及每股值的变化，标记“收入更高而价值更低”。规则、完整请求及同口径已先复验，不按价格选更好看的场景。

检查不使用新增老年份，不设置任意“好公司”阈值。`automatic_approval=false`、`selected_scenario=null`保持。缺历史、回报低或终值发生资本需求变化都不自动删除结果；应解释假设、形成明确过渡场景后再比较。
