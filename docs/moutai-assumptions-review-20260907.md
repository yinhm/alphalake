# 贵州茅台假设复核与研究重算（2026-09-07）

按用户“复合贵州茅台”理解为延续安克的估值复核，检查原假设及条件性重算。信息参考截至2026-09-06已公开材料，财务与股本仍为2026-06-30；不声称已完成9月估值日全部分红、证券和财务状态调整。

本次是研究层计算和文档，未改生产数据、映射、引擎或政策版本。TDX标准输入继续为主，财报与公司说明用于核验及研究政策依据，未用网页摘要覆盖标准数值。

## 主要发现

1. 收入不能套用安克的高增长修正。2026H1营业收入907.0326亿元，同比1.47%，与包含金融利息的营业总收入不是同一概念。网上部分摘要把上年同期893.8935亿元写成本期，原PDF明确两列，应拒绝该摘要取数。[半年报p7、合并利润表](https://static.cninfo.com.cn/finalpage/2026-08-15/1225475868.PDF)
2. 公司8月21日说明会明确：销量增加，产品综合吨价下降，系列酒在二季度减少投放。直销平台高速增长含渠道迁移，不能把i茅台增速当集团新增需求或集团增速。[公司说明会问题三、五](https://www.moutai.com.cn/mtjt/2026-08/21/article_2026082123470131571.html)
3. 预收款下降与直销及代售模式有关，原其他营运资金长期为收入-5%的假设不宜无条件保留。代售物权不转移，渠道收款模式与风险承担发生变化。[同一说明会问题六](https://www.moutai.com.cn/mtjt/2026-08/21/article_2026082123470131571.html)
4. 合并经营现金流706.91亿元仍含财务公司资金波动，不是纯酒业FCFF。沿用原酒业EBIT及金融池分配代理，不把财务公司的受监管资产、集团存款都当上市公司自由现金。

## 资本成本的实际证据与选择

市场参考复用安克本轮已经归档的原始资料：9月4日中债十年国债1.6804%；Damodaran2026年7月工作簿成熟市场ERP4.20%、中国国家风险溢价0.872786%。全球酒类行业2026年1月表中217家，现金修正后的无杠杆beta为0.73。[中债](https://yield.chinabond.com.cn/cbweb-pbc-web/pbc/more?locale=cn_ZH)、[行业beta](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/BetasGlobal.html)、[国家风险工作簿](https://pages.stern.nyu.edu/~adamodar/pc/datasets/ctrypremJuly26.xlsx)

酒业传统有息债务很少，忽略小额租赁权重时，以本币国债为利率代理得到 `1.6804% + 0.73×4.20% + 0.872786% = 5.6192%`。如再按同表0.561459%的主权违约利差调整无风险利率，则约5.0577%。这是同行估计，不是安克的beta，也不是茅台自身回归值。财务公司的存款不能进入酒业WACC的普通借款权重。

本次没有把5.62%直接设为唯一答案。6.5%是对行业beta可迁移性和经营不确定性留有余量的**主观研究情景**，比上述粗估高约0.88个百分点，额外部分并无独立市场校准，不称“观测资本成本”。主表展示6%–8%，另列5.5%及9%压力。未来应该用白酒可比公司、复权回报、市场风险溢价和经营风险分解校准；不能既在经营现金流中大幅打折又重复加入同一风险溢价。

## 实际重算与原模型复现

复用了原研究模型作基准，输入读取 `valuation-chain-2026/inputs.csv` 的TDX标准链数值；少数股权比例恢复自已保存生产原生桥接，避免把CSV展示六位小数当完整精度。

- 原储酒模型中间情景独立重放：**1267.343422元**。
- 现融合统一资本模型已保存结果：**1269.019865元**，并核对现金流现值、终值与原生桥接总额。并未把该合计检查冒充重新执行整个API验收。
- 本轮主要结果采用**五年储酒、两年长期投入的原研究结构**，新增逐年增长路径；没有忽略行业投入周期。

该中心经营价值约16549.37亿元，终值占61.36%。同一新参数若改用统一资本结构（合计增量系数0.40+0.20+0+0.03=0.63，无独立营运余额过渡及提前投入），约1420.10元。这里只作结构差异比较，不声称两种模型语义相同，也未将这个比较实现写入生产。

因此新结果高于旧结果并非经营假设更乐观，主要来自资本成本更低。1116–1555元仅是WACC6%–8%这一维度的条件范围，不是全面风险或概率区间。

以1412.33元为基点，其他条件不变：前五年零增长得到1210.16元（第六年后仍向1.5%过渡，不代表永久零增长）；目标利润率62%/65%得到1375.08/1430.95元；金融池回收95%得到1404.54元；财务公司PB0.8得到1411.35元；少数股权倍率1.25得到1401.59元；终值ROIC=WACC得到1297.79元。这些单变量结果不能当联合悲观情景。

## 验证与保留边界

计算材料在 `workspace/moutai-revaluation-20260907/recalculate.py` 和 `result.json`。研究程序包含原模型重放断言、现有生产桥接合计断言、独立float64一千年逐期终值折现交叉核对（与Decimal经营价值差小于0.1元）、提高WACC及降低金融回收率的方向断言，并保存逐年预测。工作区材料没有纳入默认CI。

没有重跑全套Go或PDF链，因此本轮不声称新增生产链验收。纯酒业历史FCFF仍缺失；金融去合并、逐实体少数股权、实际酒龄和存货管线都没有被本次计算填成事实。新情景也不是已经完成所有期后调整的当前市场目标价。
