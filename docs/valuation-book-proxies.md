# 获准的TDX账面代理：估值输入，不是报表事实

2026-09-26用户明确批准“先允许，但文档明确记录代理条目”。政策版本为`tdx-book-assets-v1`，配置见[`valuation/policies/tdx-book-assets-v1.json`](../valuation/policies/tdx-book-assets-v1.json)。目前只启用安克、苏泊尔，财务报告期固定2026H1；不同公司或报告期不自动延用，茅台不在适用范围内；其金融资产、存款和收益已完成[专项配套诊断](moutai-financial-scope-20260926.md)，剩余受限资金与归母范围不能由合并总额唯一确定。

原TDX标准事实、源零/缺项和SQLite报表列保持原样。后端进入估值时才生成下表的输入；原始查询仍显示现金/投资总额NULL，不能据估值输入反称TDX已经完整披露。本功能依赖AlphaLake后端适配层；单独把SQLite交给未经适配的上游程序，不会自动获得这些代理值。

## 代理条目台账

| 模型输入 | 本版本公式与规则 | 明确的估计与遗漏 |
| --- | --- | --- |
| 现金及短期投资 `cash_and_marketable_securities` | 货币资金＋交易性金融资产；两项都必须有标准值 | 可能漏掉其他科目内存单，可能包含受限资金、套期资产；不是精确总额或价值下界 |
| 长期投资 `cross_holdings` | 长期股权投资、债权投资、其他债权投资、其他权益工具投资、其他非流动金融资产的已知组成小计；至少一项有值 | 缺项是政策未计入，不是源事实为零；账面计价不等于市场价值，不把其他资产整桶加回 |
| 配套经营收益 `ebit` | 营业利润＋利息费用−利息收入−投资收益−公允价值变动收益；五项均须有标准值 | 全部投资收益和公允价值损益按非经营项扣除，可能同时排除经营性套期损益；其余营业项目未作逐项正常化审核，不称公司披露EBIT |
| EBITDA | 不沿用原来源报告EBITDA，估值输入置空 | 避免把未调整EBITDA与政策调整后的EBIT混为同一口径；不因此伪造完整折旧摊销 |

这些规则是输入政策，不改变达摩达兰FCFF、WACC和DCF公式。经营收益与金融资产加回须配套，依据为达摩达兰[股权价值桥接](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/valuepershare.htm)；该资料不证明本政策的混合科目分类或账面值等于公允价值。模型既有投入资本、历史再投资和缺项诊断仍保留，本轮不认证完整历史FCFF或预测准确性。

所有原始分量均从同一SQLite标准事实、同一证券/期间/币种取得，不从PDF取数。单季经营收益由对应累计代理减前一季度累计代理得到，不能用全年除以四；缺任一所需分量、来源冲突、错误单位/身份/期间、非有限值均拒绝，资产分量为负也拒绝。缺利息或投资损益不会回退到未调整的来源EBIT。源码仍使用通用标准名称。

## API、页面与复验

本代理作用于原生数据库Web/API入口；既有AlphaLake CLI的显式估值政策不自动混用本版本。前端文件、选择公司流程和原POST请求不变。`/api/database/company/<ticker>`仍返回报表快照；`/api/database/compatibility/<ticker>`及原生估值响应新增`valuation_proxy`，包含：

- 政策版本、配置SHA256、适用报告期和源快照信息；
- 每项代理的原报表值、估计值、公式、事实ID、归档哈希；
- `estimated`状态、未计入字段，以及适用限制。

原有`warnings`同时呈现中文限制，前端不需要选择或上传JSON。会话保留初始估计依据；用户在原页面修改数值后，后续值属于用户覆盖，不能再称原政策计算值。PATCH重算继续返回初始代理证据和限制，用户修改在既有`source_metadata`中另留痕。

配置不是全市场自动认证。将来扩展公司、报告期或修改公式，需要显式更新政策并重新验证；原始事实或任一必需配套分量缺失，不能因已有代理授权就静默补零。

动态样本、原生200响应、拒绝样本、测试及发布收据位于`workspace/derived/book-proxy/`。代理股票分母仅上述两个获准样本，另以茅台做不适用边界测试；重建既有SQLite快照不等于全市场估值。

本轮发布快照含5,227家公司、825,926条标准事实，上一版687,754条事实及血缘全部保留；报表列双向比对无变化，主库文件哈希不变。8080真实HTTP已验证安克创建成功、用户修改后重算成功，以及苏泊尔/茅台拒绝。Python相关回归56项通过，补充会话与代理回归16项通过；Go全套测试与入口构建通过。首次Go测试误继承真实workspace环境变量导致隔离夹具定位失败，清除该变量后全套通过。重复样本SQLite和旧导出已按路径、哈希、原因留据清理。
