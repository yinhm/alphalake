# 估值用未复权行情观测

迁移 029 新增 `market.daily_observation`，在原单证券／全市场日线写入事务中，保留本次已解析的标准 OHLCV、采集运行和入库时间。`market.ohlcv_daily` 继续作为最新值兼容投影，复权流程不变。新观测、最新投影和原有检查点一起提交或回滚。

这是市值输入的行情基础，**没有完成公司市值或市场资本结构**。仍缺公司／股份类别身份、同日发行与库存股拆分、类别 outstanding 股本和多币种汇总。不能拿 FN238 公司总股本直接乘不同上市类别价格。

## 使用

```bash
go build ./cmd/alphalake
./alphalake sync-daily workspace/market/alphalake.duckdb sh600519
./alphalake export-valuation-quote workspace/market/alphalake.duckdb sh600519 \
  --date 2026-09-08 --as-of 2026-09-09T15:00:00Z
```

日期及截止时点需替换为实际需要；导出只读，不迁移数据库。须先升级并重新采集，迁移不会用现存最新值编造历史观测。`sync-daily-all` 同样保留版本。

输出 `alphalake-valuation-quote-v1`，包括十进制字符串 close、观测 ID、instrument_id、交易日期、采集运行、运行开始／结束时间及 recorded_at；明确 CNY、未复权、市场场所。`market_cap=null` 和 `missing_reviewed_share_class_outstanding` 表示仍缺类别股本，不输出伪市值。可将 JSON 与研究输入一并保存；当前未自动注入估值接口，也未替换目标债务权重。

## 选择与版本规则

- 首批只导出当前元数据为中国大陆 CNY equity 的 TDX 标识，按请求的市场日期解析历史标识；不猜证券身份或跨市场币种。基金、ADR、港股等未开放。
- 精确交易日期，不自动回退前一日。无合格观测时返回错误，调用方须明确另选日期；不把停牌日缺值归零。
- 采集运行必须在交易日期的中国次日零点之后开始。此保守规则用于排除盘中捕获值，无须猜源服务器的收盘更新时间。旧盘中观测不会随查询时间推移自动获得完整收盘资格，需次日重新取得。
- 只选择 `completed` 或 `partial` 运行里的有效观测；`partial` 表示其他行或主数据分区存在问题，本行已通过原日线校验。运行结束和行记录时间均不得晚于 ASOF，进行中／失败运行不进入估值用导出。
- 在合格观测中按 recorded_at、observation_id 选择最后一次取得的版本，价格为空或非正时拒绝，不悄悄回退较早有效值。这是系统观测时点查询，不是交易所原始公开时点历史。
- 同次运行连续写入相同标准内容不增加观测；A→B→A 均保留。同一内容在不同采集运行里再次取得会新增观测，以证明此次取得时间，尤其区分盘中与次日采集。最新日线的数值幂等与采集证据的重复观测是不同口径。
- 不带运行 ID 的旧低层写入保留兼容行为，不生成估值证据。

## 分层及剩余边界

该表保留的是源适配器解析后的标准日线，不是 TDX 网络协议原始字节归档；现有协议路径没有原始稳定文件，不冒充不可变原始响应。未恢复升级前丢失的历史修订，也未回填过去的可用时间。

这一阶段仍按既有 instrument 身份组织，是大陆行情兼容层；ADR 016 的 company／listing 身份、按类别股本和跨市场价格发布仍待落地。当前公司／场所元数据也未版本化，因此不宣称完整多市场双时态支持。参考层的 `meta.dataset_release` 继续用于已有文件型参考发布；本表复用日线采集运行与逐证券原子提交，不将网络增量采集伪装成完整文件快照。

验证覆盖：运行未完成拒绝、旧无版本写入拒绝、截止边界、历史值保留、同次幂等与 A→B→A、盘中记录拒绝、观测与最新投影共同回滚。全套 Go 测试同时覆盖单证券／全市场写入与原有复权行为。
