## 债务和期后资本衔接

选择 `debt_basis=wacc_estimate` 时，合同债务PV上界同时用于WACC权重和DCF股权扣减；不再出现WACC使用现值、股权桥接仍扣账面债务的混搭。转股路径释放的债券负债也改为同一合同现金流现值，选择权账面代理单列，仍比较不转股和全转股取低。

选择 `capital_basis=disclosed_share_scenario` 必须同时提供类别股本、两笔融资发布与明确的现金留存政策。募资现金只加一次：在WACC中抵减经营权益，在DCF中加回股权价值，另同步切换股数；只换股数、只给现金或缺沿用说明均拒绝。

边界没有因此消失：

- 转债剩余面值、108.86元转股价及其他非募资余额仍按六月末附注沿用。新股数可能包含期后转股，旧面值/转股价会误计边际摊薄；这不是已滚动到八月底的证券条款，更不是可转债期权市场定价。
- 公告净额扣除的是预估费用，六月末发行费用资产和应付款的结算重叠未闭合。暂保留原分类并标明该缺口，不自动冲回。
- 预测仍从六月末起算，未将七月至九月的短期间实际现金流和折现时点滚动进来。新股数/现金情景是条件替换，不声称财务、证券条款和估值时钟已全部同日化。
- 六月末对照经营价值约939.89亿元，终值现值占75.48%；结果仍高度依赖长期假设。历史FCFF保持缺失，不把预测当作已披露自由现金流。

## 使用与验收

正式政策文件：

- `valuation/examples/anker-2026H1-revised.json`：复现7.5% WACC、六月末账面债务研究中心。
- `valuation/examples/wacc/anker-revised-forecast-policy.json`：修正预测＋市场WACC＋债务现值、六月末证券口径。
- `valuation/examples/wacc/anker-revised-capital-scenario.json`：再更新已披露股数及明确募资现金情景，须接受其证券条款沿用边界。

例如第二种口径，沿用已有实际财务库和固定版本导出：

```bash
/path/to/python valuation/backend/tools/valuate_alphalake.py FINANCIAL_DB 300866 \
  --period 2026-06-30 --as-of ASOF \
  --policy valuation/examples/wacc/anker-revised-forecast-policy.json \
  --wacc-policy valuation/examples/wacc/anker-contractual-debt-policy.json \
  --wacc-references references.json --market-capital anker-market.json
```

第三种改用 `anker-revised-capital-scenario.json`、`anker-funding-scenario-policy.json` 和包含两个融资发布的市场导出；现金比例在WACC政策的 `market.funding_cash_retention` 明确设置。财务库仍需导入已审核合同债务附注，见[债务及融资事件链](wacc-gap-review-20260909.md)。新版本要求完整十年路径，拒绝同时传入旧的增长/利润率/税率标量，避免参数悄悄被覆盖。

实际验收使用既有隔离财务库 `workspace/wacc-gaps-20260909/financial.duckdb`，通过生产CLI导出并调用真实HTTP服务，五组请求重放均逐字节一致。输出保存在 `workspace/anker-revised-20260909/`；固定输入签名、运行ID、逐年政策和独立结果见[验收摘要](../valuation/examples/wacc/anker-revised-acceptance-20260909.json)。原库和源事实未修改；Go/Python依赖、迁移和80个FN目录不变。

`verify_revised_valuation.py` 从保存请求的标准窗口、附注和政策重建现金/金融资产/少数股权/债务/转股桥接，再用Decimal复算十年预测、终值及最终每股值，并校验市场WACC。它不调用引擎，也不是一套新的财报取数证据。运行：

```bash
python3 valuation/backend/tools/verify_revised_valuation.py 保存的API运行.json [...]
```

CI中的真实Go导出→HTTP测试已覆盖修正研究153.50元复现、逐年公式及现值、少数股权改口径、债务现值衔接、股数/现金同步和非法/不完整输入拒绝。全套Go测试、构建、vet及后端199项测试通过，4项既有外部测试跳过；五组实际结果均经独立脚本复算。
