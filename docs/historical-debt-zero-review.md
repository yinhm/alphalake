# 历史债务源零核对

2026-09-28，核对既有归档中的安克2023、2024年末应付债券。证据核对之后，已实现逐期间余额源零审核及原生批量导出；本轮发布只采用2023年明确披露的真零，2024仍拒绝。发布与验收状态见文末。

## 已确认的根因

两年均已有短期借款、长期借款、一年内到期非流动负债及租赁负债标准值，唯一缺项是`bonds_payable`。不是未同步或字段未映射：本地2023包一份源记录、2024包两份源版本均为零位值，映射的`zero_policy=reject`将其保留为待审核。全部本地版本一致，不等于严格历史PIT。

| 年末 | 原文证据 | 结论 |
|---|---|---|
| 2023 | 年报1219800919，第100页合并表应付债券本期为横杠、比较期3,141,480元；第173页附注明确日本子公司2023年9月提前偿还，年末余额为0；第185页筹资负债变动表期末也无余额 | 明确真实零，已通过独立审核补充进入原生估值供给；标准事实仍为缺项 |
| 2024 | 年报1223379891，第108—109页合并表未列应付债券，六项非流动负债精确加总至1,557,676,104.50元；第100页债券章节不适用；第91页说明拟发行可转债直到2025年2月获注册批复 | 多项证据支持无余额，但未取得同2023年相同强度的直接零余额说明；不能仅凭“不适用”自动放行 |

2023年同样核对六项非流动负债之和为1,194,235,520.75元。加总仅为算术一致性；未列报及“不适用”各自都不足以通用地证明合并范围真零。2023年的日本子公司债券尤其说明，只看上市公司自身发债情况可能遗漏子公司债务。

两年已供给的四项债务分量小计分别为1,016,868,741.7578125元、1,637,795,716.9765625元，保留TDX精度。2023年配合已审核应付债券零值，可形成候选债务输入；2024仍只是部分分量小计。不以PDF小数覆盖源值，也未批准预测资本倍率。

## 接入与失效规则

复用`reviewed_supplement`及追加审核历史，不增加表、不改变标准物化、前端或估值公式。新增`source_zero`绑定标准字段、TDX归档哈希/行序、已发布映射指纹及`explicit_zero_balance`人工审核结论；现有记录同时绑定公司、期间、公告、PDF哈希/页码、审核人和时间。当前范围为合并口径CNY期末余额，不处理流量、不适用或未知值。

`export-financial-source`的独立来源观察提供`source_revision`、`source_row`、`mapping_sha256`，业务调用无需使用源编号。填写完整补充记录后，沿用：

```bash
./alphalake import-supplements CANDIDATE_DB reviewed-zero.json
./alphalake supplement-history CANDIDATE_DB 300866
```

项目名使用`reviewed_source_zero_`加标准字段名；例如`reviewed_source_zero_bonds_payable`，金额必须为0，范围为`consolidated_statement`，期间类型为`instant`，必须填写`reviewed_at`。新增绑定示例（哈希/行序来自实际维护输出，不可照抄占位符）：

```json
{
  "source_zero": {
    "field": "bonds_payable",
    "artifact_sha256": "所审核TDX归档的SHA256",
    "source_row": 1,
    "mapping_sha256": "所审核已发布映射的SHA256",
    "conclusion": "explicit_zero_balance"
  }
}
```

这只是完整补充记录中的新增部分，不能单独导入。结论由人工原文审核作出，枚举、哈希和回归不替代语义审核。没有明确证据时不能填写该结论。系统验证源记录身份、原始零、既有源零拒绝、当前与已发布映射一致性、PDF字节及公告绑定；不能用此通道修补缺文件、源字段缺失、映射/身份不明或其它拒绝原因。

导出保留标准金额优先级，仅在缺标准值时消费有效审核零；不写入SQLite的`standard_facts`。SQLite的`reviewed_source_zeros`按审核哈希保存一份完整证据，`export_cells`记录`available_with_reviewed_source_zero`及审核哈希引用；原生兼容性API额外列出`reviewed_source_zeros`。整个批次仍通过一次财务CLI导出，按归档顺序校验审核，同包复用解析结果，没有逐公司子进程。

撤销、映射指纹变化、更新源记录或原文关联失效后，重新导出恢复缺项，旧审核重放不重新激活；损坏ZIP/PDF直接拒绝候选。既有源冲突也不能由零值审核绕过。已发布SQLite是不可变快照，撤销要经过重新导出、验收和发布才影响网页，不声称即时推送。当前有效审核可用于旧披露时点重算，不能声称严格历史系统时点可用。

SQLite契约为v8，v7需显式重导出，不保留兼容读取。标准三表及CLI专项政策没有自动采用这些审核，原生补充供给不冒称全接口标准事实完整度提升。后续已按同一明确证据标准接入航天电器2024年两项审核零，见[近期债务发布](native-capital-proxy-review.md#原文核验审核接入与发布三步验收)；没有放开字段级零政策。资本范围及公司经济依据仍需核对。
