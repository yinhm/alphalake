# 宏观定期数据：来源、口径与手工维护

宏观数据用于解释需求、价格、产能、信用与财政环境，为公司经营主张提供支持或反证。它们不能替代公司市场份额、产品竞争力、边际资本效率或未来投入证据；不是股价预测器，也不自动成为模型默认。

## 应纳入什么，为什么

| 数据组 | 重要观测与用途 | 官方来源／频率 | 当前接入 |
|---|---|---|---|
| 折现与币种 | 人民币国债曲线、汇率；核对现金流／折现币种 | 中债、SAFE／日 | 复用既有`market`，不另存宏观副本；国债不等于公司WACC |
| 总量与需求 | GDP现价金额、实际同比及季调环比；消费零售、居民收入／支出、失业 | 国家统计局／月、季 | `gdp`、`retail`、`household`、`economy` |
| 通胀与投入价格 | CPI、PPI及工业购进价格；区分名义收入改善和成本压力 | 国家统计局／月 | `cpi`、`ppi`；只接原文提供的分项，不推导未列核心通胀 |
| 经营周期 | 制造业／非制造业PMI、新订单、出口订单、价格、库存；工业增加值、利润、产能利用率 | 国家统计局／月、季 | `pmi`、`industrial`、`profits`、`capacity` |
| 投资与地产 | 固定资产投资及设备／民间投资、房地产投资／销售／新开工／竣工／待售及到位资金 | 国家统计局／月累计 | `investment`、`property`；存量与累计流量分开 |
| 信用与流动性 | M0/M1/M2、官方同比、社融存量／增量及政府债券／人民币贷款等组成 | 人民银行／月 | `money`、`financial_report`、`afre_stock`、`afre_flow` |
| 财政需求 | 全国一般公共预算收入／支出、税收／非税收入、政府性基金收支及同比 | 财政部／月累计 | `fiscal`；不把中央本级当全国，不自行命名财政赤字 |
| 外需 | 货物出口、进口与进出口累计金额及同比 | 国家统计局经济运行稿转述海关／月 | `economy`；保留原统计机构、币种及贸易口径，不冒称海关直连 |
| 供需价格的下一层 | 国内生产资料旬价、国际能源／金属、政策利率／LPR、海外需求与通胀 | 统计局、PBC／CFETS、世界银行、BLS／BEA／Fed等 | 尚未接入新的旬价、国际大宗或海外统计；按具体研究决策扩展，不能称当前已有 |

当前新接口覆盖统计局12组、央行4组、财政部1组发布。详细标准系列以`macro-series`实时目录为准，数量和最新期集中在[项目状态](../implementation-status.md)。宏观的全国范围不等于扩展北交所／金融企业估值范围。

优先官方原文：[统计局发布页](https://www.stats.gov.cn/sj/zxfb/)、[发布日程](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)、[央行统计数据](https://www.pbc.gov.cn/diaochatongjisi/116219/116319/index.html)、[金融统计报告](https://www.pbc.gov.cn/diaochatongjisi/116219/116225/index.html)、[财政统计](https://gks.mof.gov.cn/tongjishuju/)。旧国家数据查询接口本轮返回403，当前采集器使用可访问的官方发布原文，不伪称该API已接通。统计局说明数据库进度更新可能晚于新闻稿约3个工作日，因此不能把数据库尚未更新误判为没有发布。

### 怎样帮助估值研究

| 经营主张 | 可先核对的宏观证据 | 仍需公司证据回答什么 |
|---|---|---|
| 消费企业恢复增长 | 社零、餐饮、居民实际收入／消费、CPI服务价格 | 公司销售是量增、提价、份额增加还是并购；社零不覆盖全部服务消费 |
| 工业公司景气改善 | 生产／订单PMI、工业增加值、产能利用率、工业利润 | 订单能否变收入、行业是否过剩、公司处于成本曲线哪里；PMI不能直接换算成收入增长 |
| 利润率将恢复 | PPI出厂／购进、PMI投入／销售价格、产能利用率 | 原料、售价、产品结构、套保与合同的传导时滞；全国指数不能直接相减得到公司毛利率 |
| 地产链需求触底 | 销售、新开工、施工／竣工、待售及开发资金 | 公司产品依赖哪一环、应收能否回款；开发投资下降不能覆盖所有家居／建材企业判断 |
| 投资需求支持扩产 | 设备购置、制造业／民间投资、财政支出、社融组成 | 公司新增投入对应什么产能及回报；宏观投资增长不是公司的销售资本倍率 |
| 出口与融资改善 | 货物出口、PMI出口订单、实体贷款／企业债融资、既有汇率／国债曲线 | 实际终端地区、币种、客户库存、公司利差与杠杆；人民币计价出口增长不等于美元需求增长 |

这里是取证问题清单，不是自动估值规则、因果模型或情景胜出条件。宏观改善与公司改善可以背离，负证据同样保留；不同时间序列的领先／滞后关系需要验证，不能凭同时上涨认定因果。

### 频率与新鲜度

国家统计局按年度[正式日程](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)公布计划，发布日可能调整；CPI／PPI通常次月上旬、活动数据次月中旬，工业利润较晚，PMI通常在本月末。春节等会改变具体日期，不能按固定一天认证“应有新数”。季度GDP、居民收支和产能利用率按季发布，1—2月合并及1月缺报遵循各自制度。央行和财政也须以实际目录／原文核对，不能给所有宏观组统一一个月度最新期。本轮保留各来源原文已给的历史行，不为补长历史另发批量回溯请求。

## 不能省略的契约

- **金额与增速**：规范金额为元、面积为平方米、人均金额为元／人；百分比增速规范为小数，例如源0.9%存0.009。PMI是0—100量级的扩散指数点，49.8保持49.8；产能利用率同比增减的“百分点”保持百分点值，和比率分开。
- **实际与名义**：GDP现价金额不是不变价GDP；官方实际同比、季调环比和现价金额分别保存。PPI与购进价格是不同篮子，不能直接当某公司的价格／成本弹性。居民收入和支出的名义及实际增速分别取原文，不自行扣CPI。
- **期间**：余额用期末，单月和年初累计分别建系列；GDP季度与累计分开。工业／零售1—2月合并披露保留真实两个月区间，不能补出1月或假称2月单月；其季调月度表仍是普通单月。
- **可比口径**：投资及工业等官方同比依可比口径计算，禁止用异版本金额自行复算；累计同比不能相减得到单月同比。未做任何宏观TTM或同比派生。
- **定义变化**：M1自2025年1月启用包含个人活期存款及非银支付客户备付金的新定义，当前明确使用`cn_money_m1_2025_stock`／`cn_money_m1_2025_yoy`，不拼接旧口径。社融的实体经济人民币贷款与金融统计的金融机构人民币贷款范围也不同。
- **缺项和负数**：原文0是0，负贷款／债券融资是合法净变化；`—`等未列报保留NULL。年表未来月份的空占位只计入跳过数量，不插入0或推进统计期。
- **时点和修订**：每条结果分列统计区间、原文发布时间及精度、首次取得、记录时间。原文没给发布时间就留空，不从URL／报告期推造。当前查询是最新来源版本，不是历史当时可见数据；旧值仍在库内。正文与移动版重复表逐值相同才合并，冲突拒绝。

这些资料不能直接填成公司预测。达摩达兰对[稳态增长的原始说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)要求增长与经营经济体、币种及实际／名义口径一致；不等于用最新一期实际GDP增速当永续增长，或用CPI同比当预期通胀。财政税收也不等于公司边际税率。全球经营公司的外需与风险不能仅以A股挂牌地点决定；当前未接海外宏观时应保留这个限制。

## 存储与刷新

[ADR025](../decisions/025-macroeconomic-observations.md)定义`macro.series`与`macro.observation`，共用已有采集运行、归档和发布版本；不另建宏观数据库，不复制到网页SQLite。来源目录`workspace/nbs`、`workspace/pbc`、`workspace/mof`采用可识别文件名平铺；无需PDF或额外objects层。

下列命令在项目根目录执行；同步／升级及测试须沿[独立1GiB资源约定](fundamental-memory-20260919.md)串行运行。保持手工刷新，不安装调度。

```bash
# 现有官方来源；单独来源可用 --source nbs、pbc 或 mof。
./alphalake sync-macro workspace/alphalake.duckdb \
  --workspace workspace --source all > "$ALPHALAKE_RECEIPTS/macro-online.json"

# 同一已发布原文离线重放；不触网、不推进首次取得时点。
./alphalake sync-macro workspace/alphalake.duckdb \
  --workspace workspace --source all --offline > "$ALPHALAKE_RECEIPTS/macro-replay.json"

# 查标准名称、定义与覆盖；结果中的日期各有含义。
./alphalake macro-series workspace/alphalake.duckdb
./alphalake macro-data workspace/alphalake.duckdb --latest
./alphalake macro-data workspace/alphalake.duckdb \
  --series cn_gdp_real_yoy --from 2025-01-01 --through 2026-09-30
./alphalake macro-data workspace/alphalake.duckdb \
  --series cn_pmi_manufacturing --series cn_pmi_new_orders --latest
```

`alphalake-macro-sync-v1`收据列请求／成功数据集、各运行和发布ID、总观测与新增观测、未来占位及失败；重放新增应为0。目录或正文失败保留partial及诊断，已发布可信数据不清空；不凭HTTP200、退出码或原文取得就认证解析／更新成功。目录有界查找未找到不代表官方没有数据。网络仅对临时错误做一次有界重试，不重试403或换第三方镜像；离线坏归档必须拒绝。

初次schema58→59只在副本上显式执行`upgrade-macro-data`，比较旧表签名、入库与重放、重开后再协调主库／程序切换；正常入口不自动升级。已有schema59直接使用刷新命令。历史财务库、原始证据及研究结果不因新增宏观改写；旧物理库SHA变更不等于财务数值变化。

## 开发验收

来源真实HTML夹具的单位、期别、重复视图、未知／零／负值及篡改拒绝在默认Go组；新宏观全链夹具放`full`组，包含归档→解析→批量写入→重开→零HTTP重放→损坏拒绝及失败行留存：

```bash
go test -tags=full ./internal/ingest \
  -run '^TestMacroRealArchivesReplayAndFailedRunSurviveReopen$' -count=1
```

真实在线接入仍须另验官方目录、主库重开、每组来源状态与版本，不把本地服务器测试说成上游真实可用。不同来源的最新期可以不同，不能统一改成今天或最新月份。
