# 估值行情窗口同步

`sync-valuation-quotes`只取得原生估值实际消费的近期行情窗口。在线`publish_native_valuation`已改用此入口；完整日线同步仍由`sync-daily`/`sync-daily-all`负责，不改变其语义。

```bash
alphalake sync-valuation-quotes workspace/alphalake.duckdb \
  --symbols sh600004,sh600006,sh600008,sh600009,sh600010 \
  --date 2026-09-29
```

本机须在已核验MemoryMax的独立systemd服务中运行，与其他主库写入、大导出及全套测试串行。输出JSON包含运行号、公司数、写入观测数及失败清单；存在失败时退出非零，正常公司可以保留为partial运行，不伪造整批成功。

## 数据边界

- 窗口为指定行情截止日前14个自然日至截止日，含两端。当前估值按信息截止时中国最近已结束收盘竞价的日期选择，15:00之前最多取前一日；实际交易日期由TDX返回，不猜节假日。财报期末和股本基期不截断当前价格。
- 必须已有沪深人民币股票身份，分别核对行情截止日、当前和每根行情所属日；代码复用或身份不明拒绝。此入口不刷新全量证券主数据，身份缺项须另行补链。
- 复用上游SDK分页与既有hosts轮询、每次请求最多三节点。翻页到窗口下界即停止；SDK传输页可能仍包含窗口外及截止日后的行，入库前过滤。不是声称服务端只传输窗口内数据。
- 仅向既有`market.daily_observation`追加观测，运行dataset为`valuation_quote_window`。不写`market.ohlcv_daily`，不修改任何完整历史续传/重试检查点；否则窗口末日会错误成为全历史起始边界。
- 沪深收盘竞价于15:00结束（[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[深交所规则说明](https://investor.szse.cn/knowledge/stock/deal/t20191204_572383.html)）。取得运行须在对应交易日15:00或之后开始；盘中取得不因后来等待而变成收盘证据。仅使用未复权收盘价；市值沿用已批准的价格×报告期总股本代理，明确保留股本基期，不声称股类价格和当前股本已完整。
- 原生导出和精确日期行情查询接受完成/部分完成的窗口运行，并保留原有取得时间、运行结束时间及信息截止条件。失败、取消和未结束运行不作为可用报价。
- 空窗口、非法价格、重复日期、身份或来源不一致显式失败并记录诊断；不补前期价格、不填零。重复在线取得是新的观测证据，不宣称零写入重放。无需新增表、迁移或依赖。

历史样本数值、运行标识及测试收据见[验收记录](../history/valuation-quote-window.md)；当前交付数量统一见[项目状态](../implementation-status.md)。

回归覆盖窗口过滤、时点、身份与来源拒绝、完整日线及检查点不变；五家、20家、40家在线采集均为限定范围验收，不等于全市场最新或完整在线发布周期。后续按[发布手册](system-delivery.md)执行候选核对，不重复全市场DCF。
