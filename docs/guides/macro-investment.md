# 从宏观观测到投资研究

宏观阅读链回答“发生了什么”；投资研究进一步回答“通过哪个经营环节影响谁，哪项证据会推翻判断”。当前以已有沪深非金融研究和数据为范围，不新增行业身份映射、选股评分、宏观择时或参数自动选择器，不改变估值引擎及默认。

## 统一研究链

**固定宏观期次 → 数据变化 → 经营暴露 → 传导机制 → 公司证据／反证 → 显式条件或维持原判断 → 下一次核对。**

1. 引用`/macro/:id`及内容摘要，保留各指标统计区间、单位、来源和版本；当前来源修订版本不认证历史PIT。新宏观取得晚于旧公司报告时，只作为新一轮复核证据，不回写旧报告或声称旧估值已经计入。
2. 先比较实际发布。新统计期、覆盖扩充、历史补入、同期间修订、仅来源更新、区间及定义变化分别解释；点评更新不算又一次经济改善，未取得市场共识时不称超预期。
3. 按公司产品、客户地域、采购及收入币种、融资与资本占用判断暴露。以下是研究机制清单，不是申万／Damodaran新映射，也不把名称相似当公司已受益。
4. 说明支持证据和替代解释，列公司需要核对的正式财务／经营数据。缺暴露或传导证据时保留待核对，不把全国指数换算成公司增长或利润率。
5. 只有经济依据与显式条件齐备，才沿已有年度路径及原生引擎比较现金流和每股条件值；解释收入、利润与再投资的联动，不将宏观叙事直接变为默认预测。

## 六条可重复研究线

| 研究线 | 宏观观察 | 经营机制及反证 | 公司层面下一步 |
| --- | --- | --- | --- |
| 国内消费与服务 | 社零及季调环比、居民实际收入／消费、餐饮、服务价格 | 购买力不等于消费意愿，名义额不等于销量；服务与商品覆盖不同 | 量价、产品与渠道组合、折扣、库存／应收及现金回款；份额提升可使公司偏离总量 |
| 设备与制造 | 设备购置、高技术制造、PMI生产／订单、产能利用率 | 设备需求改善可与总体投资疲弱并存；产量快于订单可能是备库，也可能积压 | 在手订单、交付、产能用途、单位新增资本、应收／库存；不能只上调增长而不审再投资 |
| 资源与成本传导 | 出厂／购进价格、PMI投入／销售价格 | 上游涨价既可能来自需求，也可能来自供给；两类统计篮子相减不是公司毛利率 | 实际售价、原料耗用、合同／套保、库存时滞、竞争；利润率与营运资本一起核对 |
| 地产产业链 | 销售、新开工、竣工、资金与待售库存 | 各环节影响建材、设备、装修及存量服务的时间不同；小幅库存下降不证明需求反转 | 产品所处环节、客户信用、应收账龄／减值、订单和回款；不按整个行业统一正常化 |
| 出口与海外经营 | 人民币货物贸易累计额及同比、PMI新出口订单 | 已完成累计贸易与当月调查不可直接相减；汇率、产品结构、基数及份额都会影响 | 终端地区、销量／外币售价、客户库存、关税与汇兑；国内宏观不替代全球需求或外币WACC |
| 信用、财政与现金流 | 社融余额／当月组成、政府债／实体贷款、财政支出 | 融资不是支出，政府债快增不代表私人需求强；余额、流量及统计月不能混算 | 订单转化、客户付款、贷款到期／利差、资本支出资金；国债及汇率沿现有参考核对 |

每条研究线写清：观察、支持什么、仍被什么约束、哪些公司机制才适用、需要什么反证、影响哪项估值输入及下一次观察事件。可在同一期点评中用不同段落表达，不引入第二套事实或公司预测表。

## 发布比较契约

`GET /api/macro/compare?before=<较早ID>&after=<本期ID>`只读取两个已核验、不可变页面；也可运行：

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.macro_pages compare \
  --before cn-macro-20261021 --after cn-macro-investment-20261021
```

`alphalake-macro-comparison-v1`包含两期ID／内容摘要、点评是否变动、互斥类别计数及逐项差异。网页每页展示10项。新系列首次有观测列为新增覆盖；既有系列晚于基准末期才算新统计期；补入更早缺期是历史补充。NULL、原来无观测、真实零分别显示，移出投影不声称官方撤回。

同一标准系列、期间及定义相同才计算数值修订差，使用Decimal；比率差显示百分点，PMI差显示指数点，不称经济环比。单位、期间口径、实际／名义或季调定义变化停止数值差分。来源比较按URL、内容哈希、原文位置与发布时间，不把库内ID重排、导出时间或重复取得当经济新信息；数值修订同时换源仍以修订为主类，两侧来源都可查。统计区间起点改变单列，未知值不作差。

比较是当前记录规则下的审阅结果；原始历史页面不随规则更新改写。它不提供共识预期、因果识别、显著性或未来收益认证。

## 交付与更新

点评稿与固定期次沿[宏观阅读契约](macro-pages.md)发布。长篇投资专题放`workspace/research/<id>`，kind使用已有`research_note`；登记直接引用`macro/publications/<id>.json`，不再复制全量宏观数据。宏观页允许链接已登记`/research/<id>`及已存在`/knowledge/<id>`，研究报告反向引用宏观固定链接；观点更新用新ID。来源值变动时必须复核点评证据，不沿用与新值不匹配的旧判断。

普通刷新不自动选公司、重算全市场或修改估值；公司研究Skill按实际经营暴露复用本流程。证据按钮可查看指标历史和原文；报告区分本期宏观已复核与旧公司报告仅供后续复核，不把链接数量称公司估值已更新。

## 原始依据与适用边界

达摩达兰说明，真实经济增长、预期通胀和汇率会通过公司现金流及风险影响价值，影响幅度取决于公司特征；这是核对经济暴露及一致性的依据，不是把最新宏观数值直接填入预测的规则。见[The Dark Side of Valuation第1章](https://pages.stern.nyu.edu/~adamodar/pdfiles/DSV2/Ch1.pdf)、[稳态增长条件](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)。以上六条传导链和取证顺序是本项目的研究框架，不能称其规定的选股或参数算法。

国家统计局对[PMI定义](https://www.stats.gov.cn/zs/tjws/tjzb/202301/t20230101_1903972.html)说明50为月度景气分界；指数水平及百分点变化不等于企业收入增速。实际值还须核对[宏观单位、期间及定义](macro-data.md)。核心CPI表格行未接通、PMI季调目录未纠正等现存解析缺口继续披露，不因增加点评宣称覆盖已完备。
