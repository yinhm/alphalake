# 原生估值的来源初值与用户覆盖

2026-10-05用户批准“采用有来源的初始条件，保留用户覆盖”。原生SQLite新会话采用`native-source-initialization-v1`；这是可编辑的条件起点，不是公司预测认证、最优参数选择器或新的DCF算法。完整输入API与上传模板不被此初始化重写。实际金融定义及参数消费见[方法契约](methodology-contract.md)；接口见[数据接入spec](data-contract.md)。

## 本轮替换什么

| 参数 | 原数据库入口 | 新数据库入口与条件边界 |
|---|---|---|
| 首年增长 | 空值由引擎取0% | 合格的同窗收入同比；TTM比上年同截止月TTM，全年比相邻全年。原始窗口及依据留痕，历史观测不认证明年增长 |
| 初期／过渡起点增长 | 空值继承首年，原保持期5年 | 与首年同值，但仅保持首年；第2年起用既有路径向实际稳态增长过渡，默认总预测期仍10年 |
| 高增长保持期 | 5年 | 仅在提供合格增长且期间未显式填写时置1年；本地缩短持平外推的条件，非教材统一要求。**同时提前启动既有税率和WACC过渡**，不能称仅改增长率 |
| 首年／目标利润率 | 空值沿用当前调整后利润率 | 显式保存同一调整后EBIT／同窗收入，目标持平。数值未改，新增来源；负利润率不抬正、不混入未调整行业均值 |
| 初期／过渡期销售资本倍率 | 统一2.5 | 当前匹配行业、原US地域的正有限参考。存量行业统计用于未来新增投资效率是政策代理，非公司边际效率；终值仍按g/ROIC再投资 |
| 稳态WACC编辑按钮 | 开启填9% | 当前**正常税盾基础WACC**起填；最终WACC可能另加税盾不可用调整，不能将已调整结果重复填回。完整融资路径优先 |
| 稳态ROIC编辑按钮 | 开启填10% | 当前终值ROIC起填；默认等于实际终值WACC，只表达无超额回报情景 |
| 稳态增长编辑按钮 | 开启取宏观基础利率 | 当前实际终值增长起填；已有长期利率／增长覆盖仍由引擎消费，不自行改另一个值 |

增长初始化沿用既有条件工具范围`−100% < g ≤ 100%`。同比缺失、分母无效或超界时保留原增长回退与诊断，不截尾；真实零收入不补成正数。负增长虽可计算，却可能隐含资本释放和恢复，需回收、经营期限及生存证据，不能自动认证。没有合格行业倍率时保留原2.5条件并提示，不虚构参考。

初始化只写缺省标量。显式0、已填目标／第二阶段参数、显式期间、完整年度经营／资本路径均保留；完整年度经营路径不执行初始化。数据源财务、研发往期队列、行业／国家选择及WACC算法不变；本轮原生参考升级v4，融资输入政策另按批准更新。`source_metadata`按字段记录来源初值；引擎`forecast_parameters`说明实际消费分支，不能仅凭其`explicit_input`标签认定是谁填写了参数。

## 没有随之替换的条件

| 条件 | 当前保留值／行为 | 原因及下一步依据 |
|---|---|---|
| 总预测期／利润率过渡 | 10年／5年 | 成熟过程和目标成本变化是公司判断；不能统一换另一个常数。初值利润率持平时过渡年数不制造改善 |
| 研发寿命 | 原5年 | 是费用未来收益寿命，不按公司可得历史或上市年数缩短；未来费用／税务桥仍显式提供 |
| 投资领先期 | 原1年 | 原引擎使用未来收入增量估计先行投入；不是所有行业建设周期已经验证 |
| 无风险率／债务成本 | 同发布CNY国债扣主权利差、重基准行业债务利差 | 人民币融资初值已获批接通，信用/地域及跨市场利差仍是可编辑代理，详见[人民币政策](native-cny-policy.md#当前数据库默认人民币融资2026-10-05)；观察日保留，等待手工刷新 |
| 稳态增长／WACC／ROIC | CNY利率边界增长、持有本次正常税盾WACC、无超额回报 | 币种、通胀、经济增长及竞争优势须一致；利率上界不是必然增长，ROIC高于WACC需持续优势依据 |
| 税率／NOL | 原参考及现有可选路径 | 有效税率不是法定未来税率；NOL未知不宣称不存在。无到期／上限、单一税基及部分税盾比例仍是条件 |
| 失败概率／回收 | 0／50%，原按所选价值基础 | 0表示持续经营情景，非真实失败风险为0；50%在失败概率0时不影响估值，启用后须补处置依据 |
| 现金受限／员工期权／转债 | 既有事实、代理和显式开关 | 未开启调整不证明不存在；转债市场索偿仍需合同现金流、含权市值及收益率，不能因初始化顺带猜填 |

这些尚未认证的条件在KB逐项解释。当前授权包括人民币来源融资初值，不包括新税法、经营选择器、公司信用/地域自动认证或未知研发队列估计。

## 用户修改与导出

原页面双击输入、PATCH及敏感性调整继续使用同一引擎。显式0保留；清空经营单项恢复该引擎的原回退，不重新取行业参考；人民币来源Kd／稳态WACC清空则恢复来源联动，避免回退美元利率；敏感性Reset恢复该面板本次进入时保存的输入（含已提供的来源初值及之前的手工修改）；离开再进入会重新保存，不能把它当全局恢复出厂值；重新加载公司重新建立来源初值。已有会话和旧完整请求不自动迁移。完整年度路径覆盖的标量只读，不允许编辑制造假生效。

Excel仍保留13张表，但DCF和融资结果导出**当前共享引擎快照**；删除原固定5年／10年和独立WACC公式，避免税务、年度路径、实际期间及股权桥失配。编辑Excel不会重新运行估值；请在网页/API修改、重算、再导出。附表交叉引用不驱动DCF。

## 方法出处与本地选择

达摩达兰的[增长企业价值驱动](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)支持历史增长作为近端参考、竞争限制增长、利润率可持续性及增长需要资本；[高增长持续期](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/highgrowthperiod.htm)要求考虑规模、增长惯性和竞争优势；[稳定增长率](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)要求长期经济及币种／名义基础一致。原文**不规定**保持1年、过渡9年、±100%边界或跨公司统一合理倍率。

行业倍率的存量／新增效率差异、负增长释放、税率与折现联动及未闭合融资必须单列。来源可追溯、公式一致、预测有效性是三项判断；新估值更接近股价或更高不能证明更准确。中文学习材料入口：`/knowledge/initial-valuation-assumptions`；回归及数值影响见[本轮交付](../history/source-defaults-20261005.md)。

2026-10-05人民币融资初值与其编辑联动见[数据契约](data-contract.md#人民币数据库默认与编辑联动2026-10-05)。来源Kd／稳态WACC随依赖更新；显式覆盖分别优先，不重新初始化用户经营参数。跨币种教学入口为`/knowledge/currency-wacc`，本地规则为`/knowledge/cny-wacc-default`。
