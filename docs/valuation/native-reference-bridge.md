# 原生参考输入与版本契约

已接入的Damodaran参考存于主库，随财务导出SQLite，并绑定到原生会话。保留原生默认US口径和用户显式覆盖；Global行业数据不静默替代US数据。当前版本、截止和交付数量见[项目状态](../implementation-status.md)。

## 原生实际消费输入及适用性（2026-10-02核验）

调用链为SQLite财务/参考→`api.database._db_record_to_company_input`→共享引擎。来源发布与内容签名随会话绑定，用户显式参数优先；`prepared_ttm`只解决期间转换，不替代经济假设。网页及API未指定无风险率时沿用4.25%，不是从主库自动选出的人民币利率；原页面实际提交同一默认值。

| 实际输入 | 来源与消费 | 性质及未闭合边界 |
|---|---|---|
| 收入、报告EBIT、研发、利息、税费及股本 | TDX标准事实经SQLite；半年TTM为上一全年＋本半年−上年半年，余额取期末 | 公司披露值及确定性转换；报告EBIT不自动认证已剔尽非经营收益 |
| 无风险率 | 请求值优先；原请求/前端默认4.25% | 用户/继承假设，无市场观察日或人民币来源认证。主库已有2026-09-24人民币10年国债1.6738%，不是自动采用值；截至本次截止已8个自然日，需保留年龄及国债/无风险口径选择 |
| 去杠杆Beta | 绑定US行业`beta_unlevered_cash_adjusted`，再按输入D/E和边际税率加杠杆 | 同行业参考代理；不是公司回归Beta，US业务可比性和单业务选择仍需依据，不静默切Global/China |
| 股权风险溢价 | 公司参考国家的源总ERP；Macro保留总ERP−CRP，默认CAPM再加一次CRP | 已排除重复叠加；注册国与实际经营风险暴露不同，默认不是地理收入加权，也不是独立Lambda模型 |
| 税前债务成本 | 默认直接用US同行`cost_of_debt_pretax`完整利率 | 行业参考代理，不是公司借款利率或人民币信用定价；没有随请求无风险率重基准的步骤，不能据来源正确认证币种一致 |
| 信用评级/利差 | 默认没有评级，故不走评级分支；可选原引擎评级表单独锁版本 | 主库大企业信用档已存在，但不进入默认债务成本；统一BBB不是已核实公司信用，不替换冻结表 |
| 边际税率及债务税盾 | 公司参考国家税率；本轮122家均China=25%。DCF另按亏损/抵扣可用性调整税盾 | 国家法定参考不自动等于公司税收优惠到期后的边际税率；常数初始债务分量及终值正常化是既有本地政策，见TODO |
| 预测初始有效税率 | 81家供给合格最近全年所得税费用/利润总额；41家未供给合格比率，模型使用国家边际税率 | 前者是会计有效税率，后者是模型假设，不冒充公司实际税率；后续过渡至边际税率不是现金税预测证据 |
| 权益、债务及资本权重 | 最近合格A股收盘×披露期总股本；默认不启用债券定价，用五分量账面债务代理 | 使用市场权益与账面债务的混合代理；已批准的B/H股A价代理保留，结果字段`market_values`不认证两侧都是可成交市值 |
| 现金、投资及少数权益 | 标准事实组成的已批准账面代理进入股权桥 | 不等于全部超额现金、非经营投资市值或少数权益市值；与EBIT经营范围的配套仍需审阅 |

默认初始计算为`βL=βU×[1+(1−t)×D/E]`、`Ke=Rf+βL×总ERP`、`Kd税后=Kd×(1−t)`、`WACC=E/(D+E)×Ke+D/(D+E)×Kd税后`。本轮独立十进制复算与来源定位对照均通过；算术正确与代理、币种及经营范围依据分别判断。

达摩达兰要求无风险率与估值现金流币种匹配，债务成本也基于同一无风险率及公司违约风险；行业Beta可用于自下而上估计，但应反映业务和杠杆；资本权重以市值为原则，债务账面代理应明确。依据：[折现率课程](https://pages.stern.nyu.edu/~adamodar/pdfiles/eqnotes/dcfrates.pdf)、[债务成本、Beta与权重](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/discountrates.htm)、[行业变量定义](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/variable.htm)。这些原则不授权直接采用统一人民币利率、US/Global切换或信用档。

### 增长、利润率、再投资及终值

| 输入 | 原生默认实际行为 | 经济性质 |
|---|---|---|
| 前五年收入增长 | 第一年未填为0%，第2–5年沿用第一年；没有自动消费历史增长或行业预期增长 | 原模型待编辑假设，非公司预测 |
| 经营利润率 | 第一年为调整后EBIT/TTM收入；目标未填沿用，默认不收敛至行业利润率 | 基年派生加持续性假设；行业调整后利润率虽然已交付，没有自动作为目标 |
| 销售/资本倍率 | 未填使用2.5，稳定阶段沿用；投入默认领先所支持收入1年 | 原模型政策，非公司存量倍率、边际投资效率或行业同步值 |
| 研发资本化 | 120家启用默认5年经济寿命，2家未启用；连续费用来自TDX | 费用事实与经济寿命选择分开；数据齐全不自动证明5年适合全部行业 |
| 稳态增长 | 无显式覆盖时采用请求无风险率，本轮4.25%；第6–10年向此过渡 | 本地条件假设，不是达摩达兰要求全部公司长期增长4.25% |
| 稳态WACC/ROIC | 基准WACC=请求Rf＋基础ERP；无ROIC覆盖时ROIC等于实际终值WACC | 无超额回报的条件政策；本轮28家终值税盾不可用，WACC另加初始债务税盾分量，94家无此调整 |
| 稳态再投资 | `g/ROIC`，与稳态税后利润配套 | 公式一致不证明增长、竞争优势或过渡期资本需求合理；122家既有审阅均保留资本过渡依据缺口 |
| 期权、可转债、优先股、困境和税损 | 原模型默认及用户显式输入；不因TDX未提供就认证为不存在 | 不自动补事实，不用可算结果证明无稀释或无生存风险 |

增长应与再投资及未来投资回报相联系；历史存量资本回报不自动等于新增项目回报，行业均值也需判断可比性。依据：[达摩达兰增长基本面](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)。0%增长、2.5倍率、5年持续期/研发寿命均是本地选择，不是教材统一阈值。无风险率更改同时影响初始折现、增长路径及终值，不能称只更新WACC。

### 本轮证据与停止条件

使用现行126家已发布范围，财务/股本2026H1、信息截止2026-10-02T07:00:20.774867+00:00，行情9月30日。默认参考、请求Rf=4.25%下原生API122成功/4拒绝；122份报告保存输入及五项审阅并重放，独立核对Beta、ERP、债务成本、边际税率、资本权重及初始WACC。分别篡改WACC和重复叠加CRP，各122项被独立断言捕获。8080省略Rf的安克/茅台请求与本轮输入及结果相同；另用3%仅验证显式参数优先，Beta/ERP/Kd及权重不变，不能将测试值视为获批利率。

例：安克默认条件WACC10.8833%、茅台7.4358%、苏泊尔7.5091%、中国神华9.9989%；均使用4.25%请求假设、China总ERP5.0727858398%，不称当前公司市场WACC。上轮正式发布器验收请求为4%，本轮为原API默认4.25%，不能直接比较价格或宣称同输入不变；与上轮4.25%条件验收比较时，明确排除两条显式行业/国家政策请求，仅124家默认请求可比，其状态与122份成功结果一致。

证据在`workspace/derived/native-input-audit/`：`native/`保留逐公司原生报告与审阅；`input-sources.json`保留参考单元格、来源定位、复算及请求控制；`wacc-references.json`显示已入主库但未进入默认路径的人民币国债、利差和参考。主库与网页快照哈希未变，本轮未刷新来源上游、修改引擎、前端或默认政策。一次性汇总曾漏计终值税盾、混用显式代理/不同利率基线及候选物理哈希，修正核验口径后完成；失败日志保留，未因此放宽原生准入或修改模型。

当前结论是**数据与参考确已进入模型，经济假设自动化尚未闭合**。币种一致的初始/稳态参考选择、公司信用、税率/税盾及预测依据列入[待审批](../../valuation/TODO.md)，沿用现有显式输入审阅；不以本次核验自动替换网页默认。

## ERP语义

源`total_equity_risk_premium`已含国家风险溢价。原生`MacroInputs.equity_risk_premium`以源总ERP减源CRP得到基础分量，引擎只加一次CRP；国家目录与地域分部直接使用源总ERP。缺分量不填零，不以统一成熟市场ERP覆盖国家源行。

依据为[Damodaran国家风险说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/ctryprem.html)。这一口径修复和参考版本更新须分别比较，不混称单因素估值变化；完整纠错金额与原始验收见[历史记录](../history/native-reference-bridge-20260927.md)。

## 接口与数据边界


- `upgrade-native-references <db>`：当前显式schema54→55，增加研发/租赁调整后利润率指标；原schema53→54转换按原提交执行；先备份，重开并比较后清理回滚副本。
- `sync-native-reference <db> --file betas --local workspace/damodaran/betas.xls --python .venv/bin/python`：导入已有原文件。`--local`、`--offline`互斥；前者按此次导入记首次取得，不猜早期下载时间；后者只重放已注册且哈希合格的发布。省略两者才访问该工作簿原官方URL。支持清单见解析器及离线证据`internal/source/damodaran/testdata/native/sources.json`。
- `export-native-references <db> --as-of <RFC3339>`：在同一事务选取已完成发布，导出发布ID、源定位、SHA256、观察日、取得日、数值与缺项；归档缺失/坏哈希拒绝。
- 当前SQLite导出契约为v10、原生参考契约为v2，包含`reference_release`、`reference_value`、`reference_company`、`reference_issuer_association`及内容签名。默认财务与参考同一截止；`--reference-as-of`可显式选择不同参考截止，必须分别报告，不能冒称严格历史PIT。旧契约必须显式重建，不作运行时回退。
- 原生默认仍是US；最近验收US/Global各94行业、21指标已解析，共3,948行业观测（其中两项调整后利润率为schema55新增）。来源金额按既有DECIMAL12规范存储，逐格复核允许最多半个末位量化误差，不声称恢复源Excel浮点无限精度。原生股票波动率读取WACC表同名字段；EVA债务资本比独立为`debt_capital_ratio`，不再覆盖Beta表`debt_equity_ratio`。
- 国家风险复用主库CN/HK/US/IL已审核发布；国家税共4项，其中CN=25%、HK=16.5%、IL=23%，US为空且状态`ambiguous`。源表B217、B246分别为25.63%、25.886141%，没有依据选择其中一条，禁止最后一行覆盖。US税自动选择和未接入国家须拒绝，用户全量显式参数API仍保留；当前目标仍是沪深普通企业，不宣称全球国家覆盖。
- 合成评级、区域/分位数等原引擎冻结参考JSON暂保留原方法版本，并在快照中单列`model_reference_hashes`。这些**不是同步的当前市场参考**；不拿主库大企业信用档替换不同边界的原表，不把默认WACC称公司已核验市场WACC。用户无风险利率、方法与显式参数优先，不强制自动替换为人民币国债。
- 新会话携带`reference_snapshot`，PATCH和敏感性计算继续使用创建时的参考对象；新发布只影响新会话。原页面不改、不要求用户上传参考JSON；未知行业不猜、不静默改Global或任意占位行业。

同发行人参考按[审核和发布流程](../guides/system-delivery.md#同发行人参考的默认关联)接入：人工核实同一法人及A股/港股证券标识后，复用官方同发行人港股原行的行业/国家；不猜集团关系、不增加H股价格，精确A股条目和用户覆盖优先。关联随快照版本绑定会话，撤销及工作簿更新不会静默回退旧审核。

源证据补充：税率表重复美国行、Beta去杠杆税率选择、EVA的D/(D+E)与Beta的D/E均锁定为离线回归；21个字段按精确表头/出现序提取，缺失保持NULL。在线更新的文件如改版不通过这些门槛，不发布替代可信历史。

## 消费和发布

财务准入与参考准入分别返回；缺公司行业/国家、歧义税率或失效发布不能靠任意占位值转为自动就绪。用户显式选择属于假设，不写回公司分类。冻结模型参考、同步市场参考、用户覆盖分别留痕，默认WACC不冒称公司已核验市场WACC。

日常同步、导出、候选API核对和原子发布使用[系统交付](../guides/system-delivery.md)；底层字段及快照契约见[SQLite导出](../guides/valuation-sqlite-export.md)。验收须检查原生创建会话、修改参数和敏感性计算仍绑定同一参考版本；仅入库成功不算消费链路通过。

身份表示、非H股上市角色及招股目录代码的确定性核验见[数据契约](data-contract.md#同发行人参考的身份取证)，不增加模糊匹配或改变参考地域。
