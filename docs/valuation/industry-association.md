# 国内行业分类与估值参考关联

核对日期：2026-10-01。退市身份链和短历史估值方案当前暂缓，优先行业分类及参考关联。本轮同步TDX转发的申万行业，并核对达摩达兰原始方法；默认估值政策与引擎保持冻结。同步验收状态见下文。

## 三个问题分别处理

| 问题 | 来源/规则 | 与其他问题的边界 |
|---|---|---|
| A股公司属于哪个国内行业 | 建议以申万行业作为国内主分类，保留TDX原生行业及概念体系 | TDX转发的申万归属是来源观测，不自动认证官方版本或生效日期 |
| 是否属于当前非金融估值范围 | 国内行业及业务口径明确后作范围判断；金融冲突单列 | 缺达摩达兰证券条目不等于没有申万行业，也不证明是金融企业 |
| 使用哪组估值行业参考 | 达摩达兰公司精确条目/已审核同发行人关系优先；其他须显式跨体系映射政策 | 申万行业名称不能直接充当达摩达兰行业；国家风险参考另有来源，不由上市市场猜测 |

申万与达摩达兰可以同时保留：前者支持国内分组、筛选及同业查询，后者支持当前模型的行业Beta、资本效率等参考。达摩达兰[Bottom-up Beta原始说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/TenQs/TenQsBottomupBetas.htm)按实际经营业务选择风险及权重；一项上市公司行业标签不能证明全部经营风险已闭合。多业务权重不得从标签个数或同业票数推算。本阶段不扩展引擎的分业务计算。

## 达摩达兰方法：分类体系与参考地域分开

**A股国内分类使用申万更合适；估值参考继续按业务匹配达摩达兰行业，不作二选一。**这是项目设计建议，不是达摩达兰指定的中国分类标准。

1. **他的行业并非只用于美股。**[数据说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/databreakdown.html)说明这是依来源分组整理的自有分类，约100类，并承认粗细分类与样本量的取舍。[当期数据目录](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datacurrent.html)同时提供US、Global、Emerging Markets及Just China等行业Beta、资本成本和经营参考。分类名称与统计地域是两个维度；项目原生后端仍用US，是现有接入政策，不是他的普遍要求。
2. **行业用于识别经济业务和可比公司。**[Bottom-up Beta说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/TenQs/TenQsBottomupBetas.htm)先识别经营业务，估计无杠杆业务风险，按业务价值加权，再按公司杠杆调整。公司只有一个主行业标签，不等于全部业务均同质；申万一级过宽、三级样本不足时都不能机械使用。
3. **跨市场是否可比取决于业务。**[新兴市场估值论文，PDF第18–20页](https://pages.stern.nyu.edu/adamodar/pdfiles/papers/emergmkts.pdf)允许全球同业用于跨市场经营风险相似的行业；对消费需求及发展阶段显著不同的行业，可能更适合新兴市场同业。他以全球钢铁与新兴市场汽车作不同选择，未规定A股全部用China或全部用Global。Beta无货币单位；现金流与折现率的币种仍须一致，国家风险另行处理，不能靠地域Beta替代或重复计入。
4. **同业参考不能直接成为公司WACC。**[官方全球Beta表](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/BetasGlobal.html)同时给出杠杆Beta、无杠杆Beta和剔除现金后的业务Beta；需区分这些字段、公司债务及税率。地区选择也不自动决定利润率或资本倍率：当地竞争、经营模式及财务调整范围仍需相应依据。
5. **国家风险不能由行业标签决定。**[国家风险原文](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/CountryRisk.htm)区分收入来源、生产所在地和风险管理；在A股上市不等于全部业务风险在中国。当前国家参考及已批准代理保留，复杂分业务风险计算不借此绕过引擎冻结。

### 项目应采用的分层

| 层 | 交付内容 | 采用原则 |
|---|---|---|
| 国内分类事实 | 申万层级、证券归属、TDX来源及观测时间 | 国内分组、查询和同业发现；不覆盖其他源标签 |
| 跨体系关联政策 | 申万业务类别→达摩达兰行业，允许一对多/无法对应 | 核对业务定义及适用范围；精确公司条目优先，不能按名称相似或同业票数自动认证 |
| 估值参考地域 | US/Global/China/Emerging、源版本、样本数及选择依据 | 按业务可比性与样本质量审核；不设置无据的统一优先级或静默回退 |
| 公司估值输入 | 已选业务风险、公司杠杆/税率、独立国家风险及显式覆盖 | 复用现有引擎；用户输入优先，代理与事实分开 |

当前源标签的两个例子：安克创新申万为“品牌消费电子”，达摩达兰公司表为`Computers/Peripherals`；贵州茅台分别为“白酒”和`Beverage (Alcoholic)`。这是来源分类的实际差异，不是已批准的映射政策。公司证券精确匹配证明参考关联对象正确，不独立证明行业经济适配正确；前者也须在通用业务类别审核中审阅，不能只审缺条目的公司。不得自动把安克改成另一个英文行业，或把所有白酒公司默认参数等同于全球全部酒类公司。

现在先补齐国内分类事实。跨体系映射与参考地域选择按类别提出明确政策后审批，不把“接入申万”扩展成默认算法修改；不另建本地同业Beta引擎。

## TDX已有接口与本地链路

上游[injoyai/tdx接口说明](https://github.com/injoyai/tdx/blob/master/README.md)，本地依赖v0.0.87核对：

- `GetTdxHy()`下载`tdxhy.cfg`，一次返回逐证券的通达信行业`TdxHy`及申万行业`SwHy`，无需逐家公司请求。
- `GetZHBFiles()`取得`zhb.zip`，其中`incon.dat`提供行业代码、名称及可解析层级。不能只拿代码当行业名称，也不猜缺失的中间层。
- `GetBlockData`/`GetBlockDataWithIndex`提供概念、风格、指数等板块；它们常多重重叠，不作为主营行业替代。
- `GetFinanceInfo()`有基础行业编号，但不是同一份申万分类目录；未核实编号词典前不能替代`SwHy`。

`sync-industries`现在只刷新行业，按主库已有证券身份关联；需要新证券身份时先单独运行`sync-instruments`。未知成员留诊断，部分快照不关闭旧历史。既有链路为`sync-industries`→`classification.taxonomy/node/membership`，TDX与申万分别成体系，成功体系可独立提交。`valuation-readiness`已有行业成员及来源输出，`audit_reference_coverage`可检查关联与候选；无需再建第二套行业采集器。原生估值默认仍从已核验的达摩达兰参考取数，没有因为数据库存在申万就自动使用它选Beta。

[申万官方2021版说明](https://wxweb.swsresearch.com/swsreport/2021_08/328340.pdf)给出一级31、二级134、三级346个分类。这是该版标准，不是当前TDX归属的版本证明。此次官方PDF请求403、官网分类页面/工作簿请求失败，检索可见其官方说明，但未取得新的官方完整目录用于逐项核对。本地TDX归属的代码及层级仍使用源体系标识；不能把内部`X...`代码冒称申万官方指数代码或直接改标签为已认证SW2021。新版本、官方目录与TDX转发口径匹配须另行验证。

## 推荐执行顺序与审批边界

1. 国内分类同步已拆清主数据耦合；将来源partial、1家并列归属、估值参考缺关联和双向金融冲突分别报告，未知身份不以默认值填充。
2. 建立申万叶行业→达摩达兰行业的显式版本化映射候选，核对业务定义、正反样本及适用范围；优先审核业务清楚且单一候选的类别。源版本、两端代码/名称、依据、审核与撤销分别留痕，复用现有分类目录，不先扩建假想多市场表。
3. 国家来源单独闭合；行业映射不顺带填China、改变US/Global口径或覆盖公司精确参考。多候选与金融冲突继续列出，必要时仅接受既有用户显式输入。
4. 审批后的映射才进入主库→SQLite→原生API默认链路，按固定样本及适用全范围验收，保留拒绝与数值影响。没有审批前不修改`company_scope`、默认行业选择或估值准入政策。

“国内主分类优先申万”是此次调研建议，尚未作为新默认政策上线；已有申万事实与查询继续可用。估值行业代理与默认关联改变仍见[待审批](../../valuation/TODO.md)。
