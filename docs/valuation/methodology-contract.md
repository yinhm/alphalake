# 非金融企业估值方法契约

主线是通用的输入选择和经济一致性规则，固定样本只检验规则，不逐公司追求转绿。适用于沪深非金融企业的持续经营条件DCF；金融模型、多市场和严格历史回测不在本轮范围。原网页不变，复用原生引擎、输入门槛与政策审阅工具。

## 五项交付

| 层次 | 已实现的统一检查 | 不由检查自动证明的内容 |
|---|---|---|
| 输入选择 | 原生兼容API的`input_contract`逐项列出准入检查实际读取的值、来源状态、用途、必需/条件/可选角色，以及缺失处理；历史FCFF不设为预测DCF门槛 | `usable`是所选入口可消费，不是完整经济口径认证；显式输入也不自动成为公司事实 |
| 经营利润与资本 | 审阅输出`methodology.operating_scope`列出实际调整利润、研发资产、租赁资本、少数股权及金融投资，并明确五项范围核验任务 | 报告EBIT未必是经营EBIT；合并利润与归母资本不能直接认证经营ROIC；代理授权不等于已完成分类 |
| 增长、利润率、再投资 | 复用逐年收入、利润率、投资滞后、收入增量/资本倍率及NOPAT分解；汇总收入绝对扩张、收入倍数、总投入、资本释放年份及低于初始WACC的回报诊断 | 持续期、市场空间、利润率目标、资本可收回性需要依据；不设统一“合理增长”阈值，不把利润率改善全部归因于新增资本 |
| 终值与WACC | 输出实际终值增长、税率、WACC、ROIC及再投资率；标记增长超过无风险率参考、永久税率差异、超额回报及资本规则跳变 | 单行业Beta、目标权重、信用档、税盾和国家风险暴露仍属政策；注册地不证明经营风险地域，币种和名义/实际基础仍须来源支持 |
| 适用边界与不确定性 | 保留亏损、收缩、资本释放、非正股权及终值亏损提示；计算只改变终值ROIC至终值WACC的对照，缺项公司仍在批次分母 | 对照不代表概率或置信区间；差额为0可能只是基线已采用ROIC=WACC，不表示估值稳健。计算通过不代表经济依据充分或预测有效；不按最高/最低估值自动选场景 |

后三项在`tools.review_native_policy.review_report`统一生成`methodology`，原目录审阅和自动选择调用复用同一实现。`automatic_adoption=false`；无公司证据不因多了一份检查报告就自动批准。适用边界提示不在网页新设阻断，原有必需项与公式有效域拒绝保持。

## 输入与缺项规则

来源优先顺序为TDX标准事实→同口径派生→已批准并标注范围的代理。CNINFO用于身份、披露时点、范围核验，不替换为PDF金额主源。预测、有效税率、风险参数等假设与事实分别解释。准入检查的结构化明细见`GET /api/database/compatibility/<ticker>`的`input_contract.inputs`；不把它冒称预测参数及全部可选报表字段的完整目录。

- 基期收入/EBIT、实际参与TTM的期间、股权桥接及所选调整缺项，按[准入契约](valuation-input-gates-20260925.md)处理。
- 现金/投资和市值的既有获准代理继续可用，来源状态及限制随值返回；不增加旧年度静默回退。
- 可选历史、季度未披露的现金流补充资料保留缺项，不推算季度金额，不阻断不消费它们的收入增量法DCF。参见[披露期间边界](../guides/tdx-offline-sync.md#披露期间边界与停止条件)。
- 当前接口缺少独立的通用“最新期估计”输入政策，故本轮不自动启用旧年替代或插值；达摩达兰允许估计，不等于系统已实现且已获授权的估计。

## 方法依据与公式纠错

依据达摩达兰[增长、利润率与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)：资本倍率可参考公司或行业，但需检查规模、利润率及隐含回报；成熟阶段再投资与增长/资本回报联动。既有`economic_checks`逐年算术验算保持，不能重复扣研发和营运资本。经营范围参照[非现金营运资本](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/noncashwc.htm)的现金/投资/有息负债区分；WACC另按[国家风险暴露](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/CountryRisk.htm)和[税率](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/taxrate.htm)核对经营地域与长期税率，不由上市地点或当前有效税率替代。

依据[稳定增长](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)与[终值回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)，负稳定增长可以描述部分清算，稳态再投资率为`g/ROIC`。本轮修复原引擎在`g<0`时把再投资截成0的偏差：改为有符号的`NOPAT*g/ROIC`，正增长与零增长结果不变；`g<=-100%`拒绝，不作为持续经营终值。负再投资表示资本释放假设，不证明资产必能按账面金额收回；终值亏损则另提示需要复苏或有限寿命路径。

回归以负/零/正增长核对独立公式，并验证在`ROIC=WACC`时终值等于下一期NOPAT/WACC。不能由这个恒等式认定增长完全不影响整家公司价值，因为收入基数、显式期投入等也会随情景变化。

## 复验入口

在[独立1GiB硬限额服务](../guides/fundamental-memory-20260919.md)内，使用已有SQLite，不重采数据：

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.check_native_sqlite \
  --database workspace/derived/valuation.sqlite \
  --output workspace/derived/methodology-contract/new-check \
  --risk-free-rate 0.04 --review-methodology
```

4%为本次默认入口验收的显式假设，不是当前人民币无风险率。逐公司结果保存完整报告、输入契约及方法审阅；摘要区分财务/API准入、方法审阅数、未计算数和各类经济依据缺口。统一条件情景仍走[已有入口](native-uniform-scenarios.md)，固定原名单及政策，不按结果替换公司。

验收同时检查现行SQLite哈希不变、原成功结果不变、缺项分母保留、负增长公式和篡改拒绝。范围核验、代数一致性和预测有效性分别报告。下一步应推进通用的经济依据选择规则，不能把本页检查项数量当成估值准确度。

## 本轮验收（2026-09-29）

- 同一100家SQLite（财报2026H1、财务截止2026-09-27T08:12:14.060804+00:00、参考截止2026-09-28T10:57:05.699379Z）默认财务90准入、API89成功保持；全部既有输入及最终值相同。89家审阅、11家原拒绝保留；数据库哈希未变。
- 89家中23家当前及终值经营亏损、35家非正股权剩余、1家涉及资本释放；89家均有默认假设和终值资本规则过渡须说明。类别可重叠，不等于89家计算错误，更不是准确率统计。
- 原固定12家按相同规则重建：10家可运行、2家输入阻断；其中7家选出24个条件场景，3家选择拒绝。全部场景审阅通过，不自动选最高估值；原冻结运行不覆盖。
- 77项针对性回归通过。Python全量首跑567通过、2失败、4跳过；两项失败是旧测试缺少既有空研发队列与可空年度资本倍率的契约预期，修正后相关3项通过，未重写冻结证据。Go全套与构建通过；4项skip仍为缺上游测试数据，不能称全证据零跳过。
- 测试串行运行于独立1GiB服务，完整测试组峰值896.5MiB；100家与12家离线验收共6.07秒。8080加载当前后端后100家真实API复验通过；首次请求早于服务监听就绪的失败日志保留，确认就绪后复验，未再次重启。动态协议、版本、逐公司报告、失败日志及真实8080复验收据均在`workspace/derived/methodology-contract/`。

这轮交付的是可执行的方法检查与公式修复，尚未建立所有非金融企业的自动经济假设选择，也未证明预测准确度改善。下一轮以盈利恢复、利润/资本口径和终值政策的通用依据为主，不以样本转绿替代方法工作。
