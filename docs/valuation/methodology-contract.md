# 非金融企业估值方法契约

本页区分现有实现、显式条件与待审批方法，不能作为对全部修改的符合性认证。逐提交依据及架构边界统一见[引擎调整台账](engine-change-ledger.md)；其中转债取低、税盾比例/固定融资及无研发桥的终值正常化仍列为待处置，本地政策不因测试通过而追认为达摩达兰原文规定。

主线是通用的输入选择和经济一致性规则，固定样本只检验规则，不逐公司追求转绿。适用于沪深非金融企业的持续经营条件DCF；金融模型、多市场和严格历史回测不在本轮范围。原网页不变，复用原生引擎、输入门槛与政策审阅工具。

## 五项交付

| 层次 | 已实现的统一检查 | 不由检查自动证明的内容 |
|---|---|---|
| 输入选择 | 原生兼容API的`input_contract`逐项列出准入检查实际读取的值、来源状态、用途、必需/条件/可选角色，以及缺失处理；历史FCFF不设为预测DCF门槛 | `usable`是所选入口可消费，不是完整经济口径认证；显式输入也不自动成为公司事实 |
| 经营利润与资本 | 审阅输出`methodology.operating_scope`列出实际调整利润、研发资产、租赁资本、少数股权及金融投资，并明确五项范围核验任务 | 报告EBIT未必是经营EBIT；合并利润与归母资本不能直接认证经营ROIC；代理授权不等于已完成分类 |
| 增长、利润率、再投资 | 复用逐年收入、利润率、投资滞后、收入增量/资本倍率及NOPAT分解；汇总收入绝对扩张、收入倍数、总投入、资本释放年份及低于初始WACC的回报诊断 | 持续期、市场空间、利润率目标、资本可收回性需要依据；不设统一“合理增长”阈值，不把利润率改善全部归因于新增资本 |
| 终值与WACC | 输出实际终值增长、税率、WACC、ROIC及再投资率；标记增长超过无风险率参考、永久税率差异、超额回报及资本规则跳变 | 单行业Beta、目标权重、信用档、税盾和国家风险暴露仍属政策；注册地不证明经营风险地域，币种和名义/实际基础仍须来源支持 |
| 适用边界与不确定性 | 保留亏损、收缩、资本释放、非正股权及终值亏损提示；计算只改变终值ROIC至终值WACC的对照，缺项公司仍在批次分母 | 对照不代表概率或置信区间；差额为0可能只是基线已采用ROIC=WACC，不表示估值稳健。计算通过不代表经济依据充分或预测有效；不按最高/最低估值自动选场景 |

## 研发预测税务契约

2026-10-04核对准确上游`c4b86e5`及调整前`10d567d`，用户随后明确批准共享引擎调整并选择“显式路径＋具名条件”。已实现下述研发税基桥，保留网页用户基线；本轮授权不解冻其他算法、默认政策或复杂税法。上游原文件、差异见[模型复核](../history/valuation-model-review-20261004.md)，批准及实施登记为台账E28。

实际调用链为`orchestrator → M1 → M3 → M4`。M4不直接外推基期FCFF；E28将所选历史研发队列传入M4，并消费显式未来费用/扣除。代码位于`module_1_adjustments.py`、`module_3_cashflow.py`及`module_4_dcf.py`，完整提交定位沿台账。

### 必须分开的语义

以下是语义清单，实际字段见本节末尾。为隔离研发，本节公式假定经营范围相同，无额外租赁/融资及其他纳税差异；复杂条件须另加明确桥接，不能套简式认证。

| 符号 | 含义与供给边界 |
|---|---|
| P | 未做经济研发资本化的同范围经营EBIT；历史取标准事实，未来为经营假设 |
| R | 计入该期间损益、拟重新资本化的研发费用；未来R是显式预测，不是TDX事实 |
| A | 所选经济寿命下历史及未来费用队列的当期摊销；不是税务摊销，不能用当前A复制十年 |
| E=P+R−A | 经济调整后EBIT；利润率、资本回报须与该范围匹配 |
| D | 当期税法允许的研发总扣除，包含适用的额外扣除/税务摊销；与R、A不必相等 |
| τ、L | 对应税基的适用税率及可利用期初税务亏损；会计有效税率、法定/边际税率、现金税比例分开 |
| C、I | 不含重复利息税盾的现金经营税及同范围总净再投资；不是把所得税费用当现金税，也不是将实际含融资税项直接当无杠杆税 |

已在报表资本化的开发资产及摊销不能再全额加入研发费用队列；如需重估，须按原报表到经济口径的差额处理。未来费用和税务假设由AlphaLake交付并留依据；税基、抵扣、NOPAT及FCFF由共享valuation规则计算，不能在适配器自动改税率绕过冻结。

### 应采用的关系及适用条件

经济资本化只改变利润/资本分类，不自行改变税法。在上述简化范围内：

```text
经济EBIT E = P + R − A
税基（抵亏前）B = E + A − D = P + R − D
现金经营税 C = max(0, B − 可利用期初亏损L) × τ
经济NOPAT = E − C
FCFF = 经济NOPAT − 总净再投资I
```

这只是无到期/抵扣上限、无其他差异且不计税收抵免的简式，不是中国企业完整申报算法。L须按B及税法可利用条件滚动，不能按E判断亏损；有真实抵免、退税或多法人范围时分别留证据，不因简式max(0)清空来源事实。融资税盾与经营现金税配套，不能在FCFF重复加入利息税盾。

当D=R、没有亏损限制且P足以当期缴税时：

```text
NOPAT = P×(1−τ) + (R−A)
      = E×(1−τ) + (R−A)×τ
```

例如P=200、R=100、A=40、τ=25%，E=260、现金经营税50、NOPAT210；直接260×75%=195会多计税15。若非研发净投入50，总投入=50+60=110，FCFF=210−110=100，与未重分类的150−50一致。恒等式只验证同一经营/税务/投入预测的重分类，不表示所有未来估值必然不变。

**未来差额必须滚动。** 当前R=100，过去五年各40，采用五年直线寿命；假设以后R仍100、P仍200、普通当期扣除且税率25%，得到下表。总投入需另按同范围生成；本表只核对税后利润，不声称现行收入增量模型已经表达相应投入路径。

| 未来年度 | R | A | E | 应有NOPAT（现金税50） | 调整前M4同E按25%税率计算 |
|---|---|---|---|---|---|
| 1 | 100 | 52 | 248 | 198 | 186 |
| 2 | 100 | 64 | 236 | 186 | 177 |
| 3 | 100 | 76 | 224 | 174 | 168 |
| 4 | 100 | 88 | 212 | 162 | 159 |
| 5 | 100 | 100 | 200 | 150 | 150 |

差额不是固定15；R下降、R<A时方向也可反转。上述未来费用/P保持不变只为独立虚构算例，不是公司预测规则。

**经济盈利不等于税务盈利。** P=−10、R=100、A=30时E=60。普通当期扣除、无既有L及其他差异时，现金税0、NOPAT60，产生税务亏损10。调整前M4按E计算得NOPAT45、亏损余额0；调整前基期helper若传25%税率会得62.5，隐含了未有证据的即时亏损税收利益。E28已约束基期负税基不自动退税，显式预测按B滚动L；“调整后EBIT为正”也不证明能纳税或利用债务税盾。

### 再投资、终值及中国税收边界

1. 收入增量/资本倍率给出的I须与含研发资产的利润/资本范围一致；R−A是解释总投入组成，不在I之外另扣。若详细拆分，I=非研发净投入+R−A；研发和营运资本均不能重复计算。
2. 稳定期税务边际税率应用于稳定税基。零增长且费用队列已完全稳定、D=R时，R=A可使研发税差消失；尚在替换历史队列时不能提前假定归零。
3. 正增长稳态下，R与收入同速增长、寿命n年时，A=(1/n)ΣR/(1+g)^i，i=1..n，因此R−A通常仍为正。五年、g=3%、当期R=100的虚构稳态中A约91.5941，净调整约8.4059；这是队列公式推导，不是教材规定所有公司g或研发费用率。不能将终值E直接乘法定税率就认定税务正常化；g/ROIC使用匹配的NOPAT和总再投资，不再加一份研发。
4. 中国普通扣除、加计扣除与开发资产税务摊销分别解释。国家税务总局公布的2023年第7号一般政策，对符合条件的费用化研发规定据实扣除后再加计100%，形成无形资产按成本200%税前摊销，并有企业/活动/归集范围条件；不能把全部TDX研发费用都乘200%，也不能据通用政策认证具体公司。历史有效税率若已包含该优惠，另减加计扣除会重复计算；采用独立扣除模型时须说明适用税率和扣除范围。

原始依据：[达摩达兰研发重分类、现金流及预测](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/R%26D.htm)、[无形投入与利润/再投资一致性](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/intangiblevaluedriver.htm)、[税率与NOL](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/taxrate.htm)、[国家税务总局研发扣除条件](https://www.chinatax.gov.cn/chinatax/c102419/c5204648/content.html)。原文的方法、上述代数推导和本地预测假设分别留痕。

### 当前输入、输出与终值处理

未提供`research_tax`的用户输入仍使用经济EBIT税项代理，响应明确`operating_tax_basis=economic_ebit_tax_proxy`及研发提示；不猜未来费用、不自动降低税率。正E且没有NOL等复杂状态时，原`annual_forecast.tax=C/E`仍可算术复现现金税情景，但该比例不是法定税率，也不能与研发税基桥重复使用。

完整API的`valuation_assumptions.research_tax`现接受：

| 字段 | 契约 |
|---|---|
| `policy_id` | 非空政策/用户路径标识；不是公司税务资格证明 |
| `expenses`、`deductions` | 各覆盖全部预测年度，非负有限金额；分别为损益费用R及税务总扣除D，与报表同金额单位 |
| `terminal_expense`、`terminal_deduction` | 预测期之后第一年的R/D；此后与终值收入按g增长 |
| `tax_rate_basis` | `taxable_profit_rate`为显式税基税率条件；`reported_effective_rate_proxy`明确原会计税率是代理，后者只允许D=R，禁止再次叠加优惠 |
| 既有研发输入 | 选择研发资本化，寿命n≥1，完整n年历史队列及当前费用非负有限；未知队列不补零、不扩采 |
| 既有税率路径 | 提供研发桥时，原税率/逐年tax作用于B，须在[0,1]；不再是C/E。税率依据显式记录，债务税盾率仍独立 |

金额单位沿完整输入：本项目原生SQLite为百万元。费用是已费用化的部分，不重复加入报表已资本化的开发支出。经济利润E仍取原收入×调整后利润率；由E、R、A推导P，不在适配器偷偷修改利润率。显式抵亏仍采用既有`override_nol/nol_amount`，本路径限定无到期/上限、无抵免、无跨法人差异条件，不能认证真实可利用亏损。

M4输出逐年`research_amortization_projections`、`tax_base_projections`、`cash_tax_projections`、`nopat_projections`和`nol_projections`。融资比例代理改按B/期初L判断，而非E；固定初始债务分量与不可拆分WACC的限制保留。API拒绝无效路径，PATCH失败保留旧会话。

终值区分长期稳态与旧队列/亏损的过渡：先按R随g增长推导稳态A/B，计算正常化NOPAT及总投入`NOPAT×g/ROIC`；逐年替换剩余旧研发cohort，再解析计价无限期抵亏尾部，不截断年份。临时税收利益不自动形成额外经营再投资。实际尾部现金税与既有税盾融资代理配套，默认稳态ROIC随实际长期WACC。

`terminal_nopat/reinvestment/fcff/tax_base/cash_tax`是**正常化稳态金额**；`terminal_first_year_tax_base/cash_tax`是预测期之后首年含旧队列和剩余NOL的实际条件值。`terminal_value_firm = terminal_fcff/(terminal_wacc−g) + terminal_tax_transition_value`；过渡差额同时包含队列、抵亏及折现时序，不单独称“研发税盾价值”。`unused_nol_at_terminal`仍指预测期末余额；`terminal_nol_treatment`表明已在税务尾部考虑，不等于全部余额都有正价值。非研发桥分支的剩余NOL正常化边界仍在TODO。

`tools.evaluate_native_policy --research-tax`只附加一个`research_tax_current_ratio_ordinary_deduction`条件：R/收入保持当前比率，D=R，复用原税率代理、增长、经济利润率和总再投资。费用率持续是本地条件，不是达摩达兰规定或公司事实；不声称中国加计扣除、不替换显式路径/原基线、不自动选值、不与全部增长/资本情景交叉组合。

调整前Decimal反例保留于`workspace/derived/valuation-upstream-review/rd-tax-contract-check.json`；E28代码回归及固定12家同输入影响见`workspace/derived/research-tax-bridge/`。主库、财务SQLite、默认用户输入未改；方法原文、代数推导、实现假设及条件数值分别记录，不声称提升了预测准确率。

## 输入与缺项规则

来源优先顺序为TDX标准事实→同口径派生→已批准并标注范围的代理。CNINFO用于身份、披露时点、范围核验，不替换为PDF金额主源。预测、有效税率、风险参数等假设与事实分别解释。准入检查的结构化明细见`GET /api/database/compatibility/<ticker>`的`input_contract.inputs`；不把它冒称预测参数及全部可选报表字段的完整目录。

- 基期收入/EBIT、实际参与TTM的期间、股权桥接及所选调整缺项，按[准入契约](valuation-input-gates-20260925.md)处理。
- 现金/投资和市值的既有获准代理继续可用，来源状态及限制随值返回；不增加旧年度静默回退。
- 可选历史、季度未披露的现金流补充资料保留缺项，不推算季度金额，不阻断不消费它们的收入增量法DCF。参见[披露期间边界](../guides/tdx-offline-sync.md#披露期间边界与停止条件)。
- 当前接口缺少独立的通用“最新期估计”输入政策，故本轮不自动启用旧年替代或插值；达摩达兰允许估计，不等于系统已实现且已获授权的估计。

## 方法依据与公式纠错

依据达摩达兰[增长、利润率与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)：资本倍率可参考公司或行业，但需检查规模、利润率及隐含回报；成熟阶段再投资与增长/资本回报联动。既有`economic_checks`逐年算术验算保持，不能重复扣研发和营运资本。经营范围参照[非现金营运资本](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/noncashwc.htm)的现金/投资/有息负债区分；WACC另按[国家风险暴露](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/CountryRisk.htm)和[税率](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/taxrate.htm)核对经营地域与长期税率，不由上市地点或当前有效税率替代。

依据[稳定增长](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)与[终值回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)，负稳定增长可以描述部分清算，稳态再投资率为`g/ROIC`。本轮修复原引擎在`g<0`时把再投资截成0的偏差：改为有符号的`NOPAT*g/ROIC`，正增长与零增长结果不变；`g<=-100%`拒绝，不作为持续经营终值。负再投资表示资本释放假设，不证明资产必能按账面金额收回；终值亏损则另提示需要复苏或有限寿命路径。

回归以负/零/正增长核对独立公式，并验证在`ROIC=WACC`时终值等于下一期NOPAT/WACC。不能由这个恒等式认定增长完全不影响整家公司价值，因为收入基数、显式期投入等也会随情景变化。

### 合并资本与亏损税盾实现及边界

原生适配只在SQLite声明`annual_bv_equity=parent_attributable`且两项账面值齐全时，以归母权益＋账面少数权益构造`consolidated_book_equity`；最新季度取同期期末值。字段与股权桥接的`minority_interests`分离，后者即使改成市场价值也不能改写账面资本。未知范围不猜、缺项不补零。公司指标不再自动扣除整项投资；只有利润与资产分类配套后才能采用此项调整。历史租赁期初资本未知时不计算相应ROIC或增量资本倍率。

亏损税盾使用一个公开的估计：年度可利用比例=`max(0, EBIT−期初结转亏损)/EBIT`，亏损或税率为零时取零；从所选WACC中撤销未能利用的初始债务税盾分量。分量按初始债务权重×税前后债务成本差保持不变，**不是**公司未来融资、税法限额或税务亏损认定的预测，也不自动重估Beta和信用档。这是依据官方税盾原则的本地比例代理，不是教材指定的唯一算法。直接输入整体WACC缺分量时仅报告边界。

终值沿用正常化税率，不计尚未使用亏损的额外资产价值；负终值EBIT不产生自动税收抵免，无应税利润/税率时撤销债务税盾。默认终值ROIC随实际终值WACC保持一致；显式ROIC覆盖仍为独立政策。输出保留逐年可利用比例、WACC调整、实际终值WACC/ROIC及估计依据。永续亏损不因可算而获得持续经营适用认证。
