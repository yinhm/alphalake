# 显式估值政策清单

本文统一WACC及经营输入的选择、交付和验收顺序。AlphaLake提供事实、参考及显式假设，复用现有完整`POST /api/valuation`，不增加接口或修改页面。字段路径相对于请求中的`inputs`；具体单位、期间和缺项规则以[数据接入spec](data-contract.md)为准。

**可表达、可复算、经济依据充分、允许自动采用是四件不同的事。** 当前已有条件请求可执行；公司信用、经营持续性和成熟期依据仍有缺口，自动选择与默认替换见[待审批](../../valuation/TODO.md)。本文不构成采用授权。当前数量及数据库范围只在[项目状态](../implementation-status.md)维护。

## 计算前固定输入

每次交付绑定证券范围、财务/股本基期、信息截止、价格观察日、SQLite/参考版本及完整请求；保留同一快照的默认基线。事实、来源参考、已批准代理、继承默认和用户覆盖分别标记，用户显式输入优先。缺项保留原因，不借其他情景或默认值静默补齐。

请求旁保存来源版本、定位、哈希、期间、单位、政策理由及批准范围，沿用已有运行证据格式；这些证据不是新增typed字段。动态请求、结果与收据放`workspace/derived/`，不写进源代码或标准财务事实。

## 折现与融资选择

选择`methodology_choices.cost_of_capital_approach=reference_snapshot`时，下表组件位于`methodology_choices.reference_capital_inputs`。Macro中的币种、无风险率、风险和边际税率假设须同步解释，不能只换初始WACC、保留另一币种的终值参数。

| 输入字段 | 来源与显式选择 | 验收边界 |
|---|---|---|
| `risk_free_rate` | CNY同币种长期利率；国债扣所选主权利差的估计，与直接国债代理分别命名 | 留期限、观察日和参考年龄；过期不能改时间戳放行。归档条件分析不称当前市场参考 |
| `beta_u` | 有业务可比性依据的去杠杆Beta；保留US/Global等实际地域 | 人民币不强制China样本；资本倍率地域不继承Beta地域，不能自动切换 |
| `mature_market_erp`、`country_risk_contribution` | 成熟ERP与已按显式暴露政策加权的国家风险分别供给 | 不重复叠加总ERP中的CRP；注册/上市地不证明经营暴露，λ=1仅为条件代理 |
| `debt_cost_pretax`、`debt_cost_basis` | 同币种完整债务成本；公司债券/评级证据优先，合成估计次之，不足则命名信用情景 | `analyst_credit_reference`可标参考情景，不证明真实评级。US完整债务利率不能重标为CNY；信用分母须正、同期间同范围 |
| `capital_structure_basis`、`market_equity`、`estimated_debt`、`debt_weight` | 当前路径选`market_equity_estimated_debt`，权益/债务金额以百万元人民币供给 | `debt_weight=D/(D+E)`匹配金额；A股价格×总股本及账面债务仍是批准代理，不称完整市场价值 |
| `tax_shield_rate` | 对应所选边际抵税率；会计有效税率另用于经营预测 | 国家税率不证明公司优惠期限或足额抵税；保留既有亏损税盾计算，不改变算法 |

已入表租赁债务不再加一次付款PV，已含租赁利息不重复加入分母。报告EBIT与研发调整后EBIT分别保存，不能在适配层自动更换信用分子。报表信用附加条件已批准并接入显式入口，不替换原用户请求；正式评级、自动推荐和默认替换仍未批准。缺/零/负利息和官方区间缝隙保留，不填AAA或插值。具体原始依据及选择顺序见[人民币政策](native-cny-policy.md#已批准规则与依据)和[组成审计](native-cny-policy.md#利润利息与租赁组成审计)。

## 经营与稳态选择

下表字段位于`valuation_assumptions`。率用小数比例，资本倍率无量纲；历史收入、利润和资本只是选择依据，预测请求不是新事实。

| 输入字段 | 必须明示的选择 | 联动验收 |
|---|---|---|
| `revenue_growth_next_year`、`revenue_growth_years_2_5`、`high_growth_years`、`projection_years` | 同窗收入观测、未来起点、持续期及收敛期限 | 看预测收入绝对规模；一年高增长窗口仍可能有十年渐变，不把最近同比称长期预测事实 |
| `operating_margin_next_year`、`target_operating_margin`、`margin_convergence_year` | 报表→研发/租赁调整桥、未来利润率目标与过渡 | 历史/行业利润率按相同范围和税前后口径比较；正利润不证明持续性，亏损不等于无估值方法 |
| `sales_to_capital_high`、`sales_to_capital_stable` | 公司存量或明确地域的行业资本代理，用于预测新增投入 | 分开存量/新增效率；再投资已是合计净投入，不另加研发或营运资本。资本释放需可回收依据；隐含回报不等于项目IRR |
| `override_reinvestment_lag`、`reinvestment_lag_years` | 是否覆盖投入到收入的时间差 | 不把一年当统一经济规律；沿用现有路径并解释建设/周转假设 |
| `effective_tax_rate_override_years_1_5`、`override_tax_convergence` | 与`macro_inputs`有效/边际税率对应的经营税路径 | 字段名不能代替实际时序：高增长窗口影响税率过渡。分别看税率、NOL、税盾和税后利润，不称纯增长变化 |
| `cost_of_capital_stable_override`、`stable_growth_rate`、`roic_stable_override` | 成熟风险/融资、同币种增长与新增资本回报 | 检查实际终值WACC大于g、ROIC有限且正；`roic_stable_override`留空按现有引擎使用实际终值WACC，是无超额回报情景，不是公司必然状态 |

已有`annual_forecast`可逐年交付`growth/margin/tax`，长度必须覆盖`projection_years`，覆盖两阶段增长/利润率/税率路径，最后一年利润率和税率延续至终值；已有`annual_sales_to_capital`逐年覆盖两阶段倍率，要求全程有限且正。两者不覆盖终值的`g/ROIC`再投资规则。显式零值按其实际语义处理，不当作“未填写”；基期收入为零的商业化路径仍属[引擎待审批](../../valuation/TODO.md)。

研发寿命/队列及租赁调整继续由`adjustment_inputs`交付，现金、投资、债务、少数股权等保留原股权桥。更换利润率或资本代理不能顺便覆盖这些输入。缺研发历史不自动补零、缩短经济寿命或禁用调整；不为此次清单扩采早年。

原始方法见[增长、可持续利润率与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)、[增长与资本回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)、[终值超额回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)。具体本地选择及未闭合依据见[经营输入审阅](native-assumption-selection.md#当前经营输入联动审阅2026-10-02)，不能把2%、一年、十年、样本30或五年研发寿命称为教材统一要求。

## 跨公司有序对照（2026-10-02）

已按清单完成既有12家固定样本的参数分解；沿用原2026H1财务/股本、9月30日价格、同一SQLite与参考截止。基线是已保存人民币归档参考条件，候选是已有v2经营条件，均不是最新市场WACC或获批默认。1家亏损候选继续保留拒绝；其余11家分别按“增长及持续期→利润率→资本倍率→终值ROIC”和反向顺序计算，共99次真实原生API调用，全部通过既有审阅器重放。

所有步骤的财务、研发/租赁调整、初始资本成本与股权桥输入保持相同；两种顺序的最终DCF及每股值均精确复现保存候选，各步差额之和闭合。只替换预先固定的8个现有参数，没有更换源值、选信用或寻找更好的价格。FCFF加1的篡改仍被拒绝；原证据文件哈希全部不变。

| 审阅项 | 实测结论 | 对下一步的意义 |
|---|---|---|
| 利润率及终值ROIC | 两组参数在全部11家、两种顺序中的数值贡献均为0 | 此次显式值与实际继承结果等价；不能把填写参数说成新方法改善，也不外推所有公司的覆盖均无影响 |
| 增长与持续期 | 同时替换增长起点和高增长窗口，贡献依赖资本倍率采用顺序 | 优先审核最终收入规模和持续性；这是参数组的条件贡献，不称单一增长率的因果影响 |
| 资本倍率 | 康弘、华电的贡献在两种顺序中甚至变号 | 增长/收缩与再投资存在交互，不能单独给某倍率固定“增值贡献”或以其值较高证明更合理 |
| 税率与折现时序 | 本次11家逐年折现因子均未改变；增长组仍可改变经营税率过渡 | 本次没有观察到折现路径变化，保留一般联动边界，不凭初始WACC相同泛称任何候选的全路径相同 |
| 终值权重 | 候选终值现值/经营资产价值约53.8%–181.8% | 仁智大于100%对应显式预测期现值为负，保留真实条件结果；不是解析错误，不据此认证终值或删除公司 |

例如安克增长及持续期组的有序贡献约210.2793–210.6159元/股，资本组约−0.3408至−0.0042元/股；这两项区间不是置信区间，不能任意取端点相加。安井资本组约−14.6365至−0.3271元/股，说明有序分解的差异可很大。完整请求、两种路径的逐步FCFF/终值及闭合结果在`workspace/derived/policy-bridge-attribution/`；这些是归档条件对照，不作为当前目标价。

本轮停止于复现与差异解释：没有证明最近同比可持续、行业存量倍率代表未来新增效率或终值资本过渡具备公司依据。下一轮先针对通用增长持续期/规模选择提出具体方案与证据要求，再讨论资本代理及稳态采用；不继续重复审计数值等价的利润率/ROIC填写，不扩大历史和个股取证。自动采用仍进入[TODO](../../valuation/TODO.md)，现有基线与条件请求保留。

## 增长持续期与规模选择方案

**方案供后续采用审批，本轮只补依据并验证既有条件路径。** 达摩达兰的[持续期说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/highgrowthperiod.htm)关注公司相对市场规模、当前增长/超额回报及竞争优势持续性；[增长驱动](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)要求检查收入绝对增量、历史与成熟同行。没有统一的3/5/10年规定，也不能由公司上市年限或一年的高同比直接推出持续期。

### 选择顺序与数据边界

| 优先级 | 可复用依据及处理 | 未闭合时怎么办 |
|---|---|---|
| 1 用户显式路径 | 原有`annual_forecast`，或明确增长起点/持续/过渡参数；保存理由及实际消费路径 | 可计算不自动认证经济合理；缺税率/利润率等完整输入仍按原契约处理，不能在适配层填事实 |
| 2 已有公司与行业证据 | 同窗收入、连续年度规模、利润/资本范围与同口径成熟同行分别呈现；用它们检验增长起点和规模 | 历史同比不是未来增长，行业统计不是可服务市场；缺年度不压缩历史，缺ROIC不妨碍独立收入诊断 |
| 3 市场与竞争证据 | 明确产品/服务、地域、市场基年与未来规模，份额/渠道/产能及竞争优势期限，解释所选持续期与成熟状态 | 当前标准财务和行业资本参考不直接供给这些证据；缺项标未知，不自动赋3/5/10年、不新增来源逐个股补证 |
| 4 证据不足的条件比较 | 复用现有3/5/10年路径，保存全部结果、缺项和共同假设，`selected_scenario=null` | 保留可用条件估值，不把未知经济依据变成财务缺项；不按价格、估值高低或区间中点选择 |

这里的持续期是收入增长过渡的参数，不等于已经核实的竞争优势期，也不代表该期间必然创造价值。研发支出是可能的增长投入，既有队列用于利润/资本调整；不能把研发费用率直接转换成未来增长率或延长持续期。

### 可计算检查与经济判断

1. **收入规模。** 输出每年的收入、绝对增量、相对基期倍数及第3/5/10年规模。若有可比市场假设，按各业务/地域的同期间名义金额计算隐含份额；不同货币、价格口径、范围及重复市场不能直接相除或相加。大于同口径完整市场规模属于该市场假设下的冲突，不单凭“十年超过5倍”或公司规模大拒绝估值。市场规模本身若是预测，也须另标假设。
2. **持续性。** 市场空间与竞争/产能证据需支持增长路径和到达成熟状态的时间；有历史增长仅能说明曾经实现，不证明未来订单、市场份额或竞争优势。缺这些依据时保持条件状态，不能将固定压力路径改名为自动合理预测。
3. **投入与回报。** 同时审阅净再投资、资本释放、隐含回报和FCFF。增长创造价值需有新增投入回报依据；历史存量ROIC或税后利润率×倍率的筛查不能替代项目回报，亏损/收缩不删除原数据。
4. **稳态。** 收入增长、利润率、资本效率、风险及终值回报共同解释成熟状态，保留`g/ROIC`再投资；同币种名义终值增长受长期经营经济体约束，无风险率是实务参考而非公司增长事实。见[稳定增长原文](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)。暂缺公司/市场依据不擅自改现有终值算法。

### 既有路径的纯增长验证

沿用原12家及同一人民币归档参考条件，复用`scenario_payloads`的持平利润率路径和`tools.compare_native_growth.compare`，11家生成33个既有3/5/10年场景，1家保留亏损选择拒绝。全部真实API与共享引擎结果精确一致、既有审阅器重放通过；财务/研发调整、初始资本成本、逐年折现因子和股权桥均不变。比较工具先验证将原基线写成逐年路径的等价性，再只改变增长；缺理由及不完整路径均拒绝。未通过改`high_growth_years`联动税率，故本次可与上节组合参数对照区分。

| 示例（固定跨行业样本） | 第3年收敛：第十年收入/基期 | 第5年收敛 | 第10年收敛 |
|---|---:|---:|---:|
| 安克 | 1.623倍 | 2.094倍 | 3.954倍 |
| 达梦 | 1.767倍 | 2.422倍 | 5.305倍 |
| 安井 | 1.484倍 | 1.800倍 | 2.914倍 |

较短收敛不一定更保守：起点低于稳态增长时，它意味着更快恢复，康弘等收缩样本的规模与条件值反而更高。不自动选择3年、不赋概率，也不为解释差异更换税率或信用。完整11家公司三种路径的收入增量、资本需求、FCFF及终值保存在`workspace/derived/growth-runway-review/`，这里只列规模诊断；没有公司市场空间/竞争期限就不称哪条更贴近现实。
