# 选股页面 spec

状态：**已实现并在既有8080发布验收**。2026-10-21用户批准实施；本文维护选股结果表的当前契约，实际范围与测试见[首版验收](../history/screen-delivery-20261021.md)和[全部覆盖总览／单行布局验收](../history/screen-overviews-20261021.md)。入口与模型边界沿用[研究交付契约](../guides/research-delivery.md)、[数据契约](data-contract.md)及[引擎冻结约定](../../valuation/TODO.md)。

## 1. 目标与页面位置

新增独立页面 **`/screen`，导航名称“选股”**，用于从已覆盖公司中按估值、实际采用的预测假设和审阅边界筛选研究候选，再进入完整研究。表格展示已经计算并保存的结果；无需先加载估值公司，不创建计算会话。2026-10-21用户确认该入口命名及选股用途。

三个入口分工：

| 入口 | 用户要解决的问题 |
| --- | --- |
| `/screen` | 按行业、估值差异、假设和审阅边界筛出哪些公司值得进一步研究？ |
| `/research`（已有） | 找公司研究、历史修订、独立DCF或专题报告 |
| 原生估值各页（已有） | 编辑公司输入和假设，执行交互计算 |

首版涵盖选定批次的完整证券分母，未计算、缺项和范围外公司也有行。单公司一行仅适用于该批次规定的一套条件；不同情景、研究版本和独立DCF不拼成同一家公司“最佳估值”。

选股流程是“限定范围 → 设置筛选条件 → 比较结果与假设 → 阅读公司报告”。筛选条件来自用户，结果只表明满足这些条件；不引入自动推荐分数、买卖评级或新的合理参数选择器。

## 3. 页面内容

页面自上而下为：

1. 标题、批次选择、研究日期、财务期、输入信息截止、报价日期分布；股本基期与报价日分别显示。
2. 总数与状态计数：全部、已计算、缺财务输入、待范围审核、产品范围外；明确“已计算不等于预测获得经济认证”。
3. 搜索、状态／行业／审阅提示筛选、数值范围筛选、重置及“显示关键假设”开关。
4. 结果表、匹配数量、分页；链接到同批次完整CSV和研究总览。

默认列如下；每股值与报价单位均为**人民币元／股**：

| 默认列 | 内容与交互 |
| --- | --- |
| 公司／代码 | 公司名和规范证券代码合为一列，固定在左侧；公司名链接到该行研究报告 |
| 估值参考行业 | 原有Damodaran行业，未知明确显示；不新增跨体系映射 |
| 计算状态 | 已计算／缺财务输入／待范围审核／产品范围外；可展开中文原因和缺项 |
| 每股条件价值 | 已保存结果，两位小数显示，保留底层精度；负值和极端值保留 |
| 来源收盘价 | 该批次保存的未复权收盘价，悬浮显示实际交易日，较旧报价带“旧”字；不是实时股价 |
| 每股差额 | 条件价值减来源收盘价，带正负号；仅在来源保存价差且允许比较时显示，不重新开放不可比行 |
| 描述性价差 | 已保存百分比，带正负号；悬浮显示完整比较口径，不可比时显示原因；不称上涨空间、目标收益或买卖建议 |
| 首年增长／调整利润率 | 默认可见的两列，读取实际预测第一年，不将其认证为公司预测 |
| 初始WACC | 该次实际采用的初始资本成本，未知不补参考平均值 |
| 审阅提示 | 单行显示第一项及其余项数，悬浮显示全部，点击展开；不是综合风险评分 |

首年增长及调整利润率默认可见；“显示更多假设”增加资本倍率、永续增长、稳态WACC及终值占比，默认关闭，避免表格过宽：

| 可展开列 | 显示口径 |
| --- | --- |
| 预测第1年收入增长 | 实际年度预测路径，不拿历史同比替代 |
| 预测第1年调整后营业利润率 | 与实际模型调整口径一致，不当作报表营业利润率 |
| 预测第1年资金安排的收入／资本倍率 | 读取该年 `capital_funding`；显式净再投资路径未提供倍率时显示“不适用／未提供”，不反推 |
| 永续增长／稳态WACC | 两列或组合单元格，区别于初始WACC |
| 终值现值占经营价值 | 读取已有审阅结果，分母为经营资产价值，不是股权价值 |

行内“详情”展开财务期、股本基期、信息截止、研究冻结时点、条件类型、模型／参考版本、run ID、完整审阅原因及报告链接。共同日期可在页首集中展示，但不同日期必须在行上显式体现。详细历史报表、年度现金流及全部图表继续去公司报告阅读，不复制成几十列表格。

## 4. 搜索、筛选与排序

- 搜索支持公司中文名、完整证券代码和六位代码，例如“安克”“SZSE:300866”“300866”。统一空白、全半角和英文大小写；不承诺拼音、模糊纠错或公司旧简称，除非来源明确提供别名。
- 搜索长度最多160字符；停止输入约250毫秒后请求，取消过时请求，旧响应不得覆盖新关键词。Enter立即提交，清空可恢复全表。
- 状态、估值参考行业、审阅提示和价格比较状态支持筛选。不同维度取交集，同一维度多选取并集。提示的筛选计数按当前其他条件计算，重叠提示不能相加当公司总数。
- 数值范围支持描述性价差、初始WACC、预测第1年增长率／调整后营业利润率及资金安排的收入／资本倍率；上下限可单独填写，包含端点。未知值不满足已设置的数值范围，显示“该条件排除的未知值数量”，不将未知当0。未设置范围时仍保留未知行。
- 数值筛选示例：“已计算＋指定行业＋描述性价差大于20%＋初始WACC低于10%”。页面仍展示资本基期代理和经营假设，说明这是指定条件下的研究候选，不把较大价差等同于较高预期收益。
- 默认展示全部公司，规范证券代码（含市场前缀）升序；“只看已计算”是显式筛选，不删除未计算分母。
- 支持代码、条件价值、收盘价、描述性价差、WACC及已展示数值假设排序；按未舍入的数值排序，未知始终排最后，同值按证券代码稳定排序。先筛选、再排序、最后分页。
- 价差排序由用户选择，不默认展示“最便宜股票榜”，也不按价差选择或替换条件。
- 默认每页50行，可选25／50／100行；服务端最多返回100行。筛选变化回第一页，页码越界回最后有效页；空结果有重置入口。
- 批次、关键词、筛选、排序、页码及关键假设开关写入URL，支持刷新、分享和浏览器返回。URL显式带批次，不让“当前批次”切换后同一分享链接变成另一组数据。

## 5. 值、价格及可比性

以下均为展示契约，不修改已存结果、输入或估值公式：

| 情况 | 必须如何显示 |
| --- | --- |
| 来源值为0 | 显示 `0.00`；不能用真假判断当成未知 |
| 缺值／不适用 | 显示 `—`并提供原因，不能填0或从别批次补值 |
| 未生成估值但有报价 | 保留报价，估值及价差显示 `—`；计算状态解释缺项 |
| 条件权益非正 | 原负值及已保存的描述性价差保留，突出“条件权益非正”；不解释成股票可交易的负价格或确定亏损幅度 |
| 极端正值 | 不截断、不隐藏；保留可见审阅提示，不能标成高置信机会 |
| 期后融资／股数未衔接 | 估值和报价可并列，价差沿来源保持空值；不得由前端自行补算 |
| 股本基期代理比较 | 显示“资本基期代理”，与完整可比状态分开；不声称已审查全部资本变化 |
| 旧报价 | 显示实际交易日和相对本批次报价基准的差异，不冒称最新；是否旧价依据批次日期，不猜交易日历 |

已存价差定义为 `(每股条件价值 / 来源收盘价 - 1) × 100`，但**是否输出以来源比较状态和已保存结果为准**；网页不因两个数存在就重新生成价差。`descriptive_difference_pct` 已是百分数，13.75显示为13.75%，不得再次乘100。增长、利润率、WACC等 `*_rate` 使用小数率，0.08显示为8.00%。

没有估值时，当前源行即使保留 `capital_date_proxy`，页面也应优先显示“未计算／未比较”，同时保留原比较状态供追溯。未知比较状态显式标记“不支持的比较状态”，不能默认认作已可比。

每股差额仅作上述可比结果的金额展示，按未舍入的价值和报价相减；百分比仍读取已保存结果，不重新估值。差额／百分比两列以浅红到浅绿区分七个数值区间：≤−50%、(−50%,−20%]、(−20%,0)、0、(0,20%)、[20%,50%)、≥50%。这是固定的视觉分组，不是经济阈值、置信度或选股政策，保留数字正负号及图例。条件权益非正单独用琥珀色，未知／不可比用灰色；不把模型负值当成股票可交易负价。

审阅提示复用既有汇总条件：条件权益非正、预测利润率超出±100%、资本释放缺可回收依据、研发资本化但未供未来税务路径。资本释放同时核对总净投入与非研发分量：总额非负仍可能隐含非研发资产释放，两类金额不相加、同一公司只计一项提示。来源缺项和资本变化单独呈现，不新设分数、经济阈值或买卖评级；没有标签也不表示经济依据全部通过。

## 6. 数据交付与批次

### 一次提取，查询只读摘要

采用“**已登记研究 → 一次生成紧凑结果摘要 → 只读分页API → 表格**”。不向财务SQLite增加结果长表，不建立第二权威研究数据库，也不要求网页连接DuckDB。

工具 `valuation/backend/tools/valuation_results.py` 显式接收已登记总览ID，复用现有路径、登记及哈希校验。先读总览结果；按公司顺序逐个读取该批次明确登记的模型，提取实际参数与提示，及时释放模型，不同时保留全市场响应。核对冻结批次自身的一致性，不要求其计算版本等于当前HEAD，不为读取历史结果重估。不下载数据、不启动Go、不创建会话、不调用估值引擎、不重新取最新报价。不得为拼一页表扫描所有旧报告。

摘要字段对应如下；字段不存在即保留未知及原因，不推导新经营假设：

| 摘要内容 | 已保存来源 |
| --- | --- |
| 公司、行业、准入、每股值、报价、价差、日期、报告和run ID | 总览 `results[]` |
| 初始WACC | 公司模型 `response.cost_of_capital.wacc` |
| 首年增长／调整利润率／资本倍率 | `review.forecast[0].growth`、`adjusted_operating_margin`、`capital_funding.sales_to_capital` |
| 稳态增长／WACC／终值现值占比 | `review.terminal.growth`、`wacc`、`value_share` |
| 逐行审阅提示 | 复用 `tools.initial_coverage_report.catalogue` 现有判断及其模型来源；必要时抽出共享提取函数，不另建判断词典 |
| 模型及参考版本 | 同一请求／响应及冻结协议实际记录；缺失明确标注，不以当前HEAD或现行参考版本补造 |

首年是“预测第1年”，不能只凭LTM的 `fiscal_year` 推出日历年份。已核对 `tools.review_native_policy`：终值占比为 `dcf.pv_terminal_value / dcf.value_of_operating_assets`，分母为0时未知；摘要只读取其已保存的 `review.terminal.value_share`，不另算或误用股权价值作分母。

摘要放在 `workspace/derived/valuation-results/<dataset_id>/index.json`；`valuation-results/`目录下另放一个 `current.json`，以 `current` 记录明确选定的dataset ID，`datasets`记录已发布ID到摘要哈希、分母及轻量批次元数据的映射。发布共用`publish.lock`，不增加逐公司文件。摘要包含轻量元数据和所有行，不复制财务事实、年度完整响应、正文、图表或参考全集。该目录属于**可重建但正在发布时须保留**的消费派生物，纳入[workspace清理规则](../guides/workspace-layout.md#清理与迁移)。

dataset ID绑定来源总览、证券集合、条件类型和冻结版本；发布后摘要不可原地改写，内容修订另建ID并保留来源总览ID。记录契约版本、摘要构建版本、源总览登记及结果哈希、消费SQLite哈希、参考版本、条件／计算版本及构建时间；构建时间不是信息截止。每行保留其报告ID和已登记模型的哈希定位，不重复全份文件登记。

**全部估值覆盖总览统一在`/screen`交付**：包括全市场、指定证券池、初次覆盖及故事批次，批次选择器分别读取明确发布的摘要，不按文件名最大值、最高估值或每家公司最新报告自动拼表。一个总览包含原生基线、故事或诊断条件时分别发布，同一公司不在单批中重复，也不由页面选优。原报告继续保存方法、来源和完整研究；公司详报与独立DCF不因该规则被混为全市场批次。

历史冻结格式不进入HTTP运行时。先显式转换成当前`alphalake-valuation-results-v1`摘要，再用`import-snapshot`核对登记来源哈希、模型定位（若有）、证券／状态／日期分母及有限数值后发布；未知假设、模型哈希、参考版本、冻结时间留空，不能用当前事实或研究发布日期补造。未设置或不适用的特定情景标`not_calculated`（本情景未计算），与财务缺项分开；范围外及失败仍留在该批次分母。发布不默认替换当前批次。原文保存的价格比较若已有明确资本变化证据，导入摘要停止比较并保留原文件定位，不改旧文件或借此改估值结果。

### 发布与错误

构建后核对完整证券集合、重复代码、状态／数量、逐行条件值／报价／日期／run ID、模型关联、提示统计及摘要大小。普通财务缺项、无报价、范围外和未提供可选假设是合法行，不能阻断发布；源哈希冲突、串批或已记录数值不一致属于完整性错误，保留诊断且不切换。先小批验证，再串行完成本地全批摘要；全批过程使用项目规定的独立1GiB服务并记录耗时、内存及体积，不继承真实库的测试环境。

完整摘要就绪后原子写入 `current.json`，失败继续保留上一份有效指针。首版手工构建／切换，未来可接研究批次发布末尾；不安装调度或在HTTP请求中自动构建。已发布财务SQLite更新不会改写旧结果批次；页面明确“此表尚沿原研究快照”，需另外生成并发布新研究结果才更新估值。

### 手工构建与切换

在项目根目录执行，解释器按本机环境明确。全批命令必须按[资源隔离](../guides/fundamental-memory-20260919.md)放入独立1GiB服务，下面只列业务命令；不直接与全套测试并行启动：

```bash
ALPHALAKE_PYTHON=.venv/bin/python
PYTHONPATH=valuation/backend "$ALPHALAKE_PYTHON" -m tools.valuation_results check \
  initial-coverage-all-20261021 --ticker SZSE:300866 --ticker SZSE:301718
PYTHONPATH=valuation/backend "$ALPHALAKE_PYTHON" -m tools.valuation_results build \
  initial-coverage-all-20261021 --dataset-id initial-coverage-all-20261021 --activate
# 回到仍保留且校验通过的已发布摘要：
PYTHONPATH=valuation/backend "$ALPHALAKE_PYTHON" -m tools.valuation_results activate \
  initial-coverage-all-20261021
# 只导入已显式转换成当前消费契约的摘要；历史原文件不是该命令的输入
PYTHONPATH=valuation/backend "$ALPHALAKE_PYTHON" -m tools.valuation_results import-snapshot \
  workspace/derived/valuation-results-candidate.json
```

`check`只读指定样本，不发布缩小分母的摘要。`build`沿完整证券集合写入摘要；不加`--activate`只登记批次，保留当前选择。重跑相同ID须先重新核对来源及摘要内容，一致则复用原字节／构建时间；内容变化或原摘要被改写须明确修订，不重签旧ID。

## 7. 只读API

与现有 `/api/valuation` 计算接口及 `/api/research/{id}` 分开：

```text
GET /api/valuation-results/datasets
GET /api/valuation-results/{dataset_id}?q=&admission=&industry=&flag=&comparison=&sort=ticker&direction=asc&offset=0&limit=50
```

数值范围参数分别为 `difference_min_pct/difference_max_pct`、`wacc_min_rate/wacc_max_rate`、`growth_min_rate/growth_max_rate`、`margin_min_rate/margin_max_rate`、`capital_ratio_min/capital_ratio_max`。界面百分比转换与字段单位一致：价差20%传20，WACC 10%传0.10；资本倍率使用倍数。上下限须为有限数，下限大于上限返回422；不因负值、0或超100%的真实已存结果而私设经济过滤阈值。

第一接口返回有效批次的ID、标题、日期、条件类型、来源总览和当前指针，不携带全部行；批次数量超出现有规模时再按实测补分页。第二接口返回固定契约 `alphalake-valuation-results-v1`：

- `dataset`：ID、内容哈希、来源报告／版本、财务期、信息截止、研究时点、报价日期分布及全局适用边界。
- `universe_count`、`filtered_count`、`admission_counts`：分别为完整分母、当前筛选匹配数和全批互斥状态计数；不能让过滤后数量冒充覆盖率。
- `facets`：行业／提示／比较状态的选项及交叉筛选计数；另提供各已设置数值范围的未知值排除数量，按其他条件匹配范围分别计算，重叠数量不相加。
- `offset/limit/rows`：当前页的轻量字段、行详情所需元数据和标准化展示原因；无完整模型或图表。
- `issues`：可定位的摘要发布／可选字段诊断，不返回文件系统绝对路径。

`rows`沿用总览中的 `ticker/name/reference_industry/admission/financial_admission/missing_fields/reason/report_id/url/mode/condition_value_cny_per_share/close_cny/close_date/descriptive_difference_pct/price_comparison_status/price_comparison_reason/financial_period/share_date/information_as_of/research_frozen_at/run_id`。另外增加 `assumptions`（`initial_wacc_rate/first_year_growth_rate/first_year_adjusted_margin_rate/first_year_funding_sales_to_capital/terminal_growth_rate/terminal_wacc_rate/terminal_pv_share_rate`）、`review_flags`及独立于原始状态的 `comparison_display_status/reason`。假设均可为null，缺项原因由对应字段说明提供；不得返回NaN或Infinity，未知保持null。中文标签由统一字段／状态词典提供，来源编号不出现在业务列中。

多选参数使用重复查询参数，排序及枚举字段白名单校验，未知字段报明确参数错误，不执行用户表达式；未知批次404、非法参数422、已发布摘要缺失或哈希异常503。没有摘要时显示“尚未发布估值结果表”并提供研究入口，不自动计算或回退另一批。

服务按实际workspace、dataset ID和摘要文件签名缓存已验证的紧凑索引；新版本、替换或原地篡改须失效并重新校验摘要哈希。每次查询只做内存筛选／排序及分页，不读取数千份公司模型、正文、图片或源文件。进程缓存最多保留两份最近使用的摘要，避免选过多个批次后持续涨内存；响应不能修改缓存对象。批次列表只读已发布元数据，所选摘要在查询时核验内容，不为下拉框加载全部历史行。

批次目录与 `current.json` 变化下一请求可见；列表响应带内容版本／ETag。前端缓存按dataset ID及内容哈希隔离；一次响应内所有行属于同一摘要。下载首版直接链接现有已登记完整CSV，明确“完整批次”，不误称下载当前筛选结果。

## 8. 前端与可访问性

复用现有React、路由、API客户端和配色，原生HTML表格足以支撑每页最多100行，首版不引入新表格库或全表虚拟滚动。公司列横向滚动时固定，表头随页面正常滚动；表格容器只按需横向滚动，**不设高度上限或内部纵向滚动，当前页所有行和展开详情随页面完整呈现**。分页仍限定每页25／50／100行，不一次渲染所有公司。默认每家公司严格单行：代码、公司名和展开按钮并列；长名称、行业及提示省略，原文留在DOM并提供原生`title`悬浮提示，键盘／触屏可展开完整详情。关键数值不截断，每股条件值突出，差额及百分比保留符号和分组底色。窄屏默认收起行业、首年假设、WACC和提示细节，行详情仍可访问全部内容与报价日期。报告返回保留筛选位置。

排序表头使用按钮，当前排序列提供 `aria-sort`，焦点清晰；搜索和筛选有真实标签，加载／匹配数量通过状态区域提示，错误有重试。颜色不能作为正负值、状态或提示的唯一标识。交互依据[W3C可排序表格说明](https://www.w3.org/WAI/ARIA/apg/patterns/table/examples/sortable-table/)，实际验收覆盖键盘与窄屏，不直接复制示例当作已完成可访问性测试。

加载、首次未发布、筛选无结果、请求失败及摘要损坏分别展示。切换批次／关键词后不能把旧行显示成新查询结果；可以保留旧表位置，但必须显示其批次及正在更新状态，防止错误配对。
