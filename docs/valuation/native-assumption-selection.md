# 自动选择条件估值假设

当前入口在基础选择之后按统一规则生成增长持续期×利润率目标情景，并保存历史一步预测诊断；不再把单一候选视为自动推荐。当前跨公司验收见[统一方法](native-uniform-scenarios.md)。早期固定五家及重建数字保存在历史验收，按原提交复验。

## 达摩达兰方法核验

2026-09-28核验结论：**尚不能确认所有自动假设具有公司层面的经济依据，不能批准为自动合理估值。** 下述公式可用于条件情景，但数值有来源不等于预测合理；最近同比、持平利润率和行业倍率均不能由公式正确性获得背书。核验范围为当前 `select_native_assumptions.select` → `evaluate_native_policy.prepare` → 原生M4调用链，包括继承的WACC、税率及调整开关；不是对仓库所有专项模型重新认证。

| 自动选择/继承项 | 原始资料要求与允许方法 | 本项目结论及采用前缺口 |
|---|---|---|
| 最近可比同比作为未来增长 | [增长驱动](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)要求结合市场空间、竞争、公司历史及成熟同行，检查收入绝对规模 | 历史观测是真实输入，但直接外推仅是基线；缺公司增长空间与规模检验 |
| 一年后线性过渡、第十年进入终值 | 同上，增长持续期和衰减速度依公司特征 | 一年、十年及线性路径均为本地情景参数，不是理论统一规定；低于终值增长的公司实际会向上收敛，不能一概称“衰减” |
| 当前调整后TTM正利润率永久持平 | 同上，只有可持续时才能持平，目标和过渡需竞争及成本结构依据 | 正值不证明持续性；未完成调整口径一致的同行、历史及竞争优势核验 |
| Global行业销售资本比 | 同上，允许公司或行业倍率估计收入增量对应投入，需监测隐含资本回报 | 行业存量比率可作代理，不能认作公司新增资本效率；研发/租赁调整一致性和隐含ROIC仍需核验 |
| 一年投入滞后 | 同上，允许按投资到收入的时间差设置滞后 | 继承原引擎默认或显式覆盖；一年不是所有公司的通则，缺建设/周转周期依据 |
| 税率过渡 | [税率](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/taxrate.htm)允许有效税率渐变，但终值应使用适用边际税率 | 共享高增长期参数使税率也从第二年开始过渡，没有公司时间依据；现拒绝继承“永久保持不同于边际税率的有效税率”覆盖，不擅自改写用户税率 |
| 终值增长min(2%,人民币无风险率) | [稳定增长](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)要求币种/名义实际一致、长期经济约束；无风险率是实务上限参考 | 上限约束符合方法；2%不是指定值，也不保证公司具备该增长能力 |
| 终值ROIC=WACC、再投资率=g/ROIC | [终值超额回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)要求增长与再投资联动，允许竞争消除超额回报 | 公式有据，ROIC=WACC是无长期超额回报情景；并非所有公司必须相等，也不能单独证明整套估值保守 |
| Global无杠杆Beta、行业D/E、恒定WACC | [课程估值说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/eqUGemail.html)强调业务Beta和资本结构匹配 | 行业目标权重允许作为显式政策，但不等于公司市场权重；单行业、成熟期风险及目标杠杆未逐公司闭合 |
| 全中国风险暴露 | [国家风险暴露](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/CountryRisk.htm)应考虑经营地域，不由注册/上市地点直接决定 | 仅是情景；尤其安克海外业务，不能据A股身份自动采用全中国暴露 |
| 统一BBB债务利差 | [合成评级](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/syntrating.htm)可用近期借款或财务比率估计信用风险 | 利差表有来源不证明公司是BBB；必须有适用评级或偿息能力/借款证据后才可作为公司参数 |
| 25%债务税盾 | 税率资料要求考虑可利用税盾及亏损抵扣；跨国业务可能有不同适用税率 | 统一25%是情景；不能由国家法定税率推出公司立即足额享受税盾 |
| 研发摊销、租赁、NOL、失败概率、现金/投资与股权桥接 | 沿用原生输入及已有[方法审计](../history/damodaran-method-audit-20260911.md)、[输入审计](../history/native-input-policy-audit.md) | 本选择器没有重新估计这些项目；五年研发寿命、无NOL/零失败概率等默认设置不证明实际状态。代理授权允许计算，不等于经济核验通过；每次完整请求保留这些输入 |
| 样本30、有效期370天、增长有效域及正利润准入 | 数据治理和本工具能力边界 | 均非达摩达兰规定；他的方法可以处理收缩和亏损；v2允许盈利收缩的条件恢复路径，亏损仍需独立扭亏政策 |

当前审计输出增加 `economic_basis.status=not_established` 及八类未闭合依据，和 `predictive_validation` 分开。`selected_conditional` 只表示条件输入可生成，不能被解释为方法适用性通过；`automatic_adoption=false`保持。缺项不会被文字免责声明变成合理参数，现阶段只允许显式条件计算，不能自动发布为公司合理值。过去冻结结果按原提交复验，本次不修改其文件。

当前推进增长/利润率持续性、资本口径与隐含回报的输入审阅；公司信用/经营地域/税盾审计见[人民币政策](native-cny-policy.md)。历史预测扩采仍暂停，既有失败结论保留。不能只通过回测挑出一组数字就宣称遵循理论；不因候选值更高改网页或默认选择。

## 计算前固定的规则

当前以固定12家及相同SQLite/参考截止验证统一规则，不搜索阈值或按股价选参数；保留旧三年CAGR联合候选和原冻结结果，所有拒绝留在分母。不打开历史研究留出集，不声称预测误差改善。

选择政策见[配置](../../valuation/examples/native-assumption-selection.json)。这是本地明确政策，不是达摩达兰指定的统一参数。

- 增长起点：最新可比YTD收入同比；只有年度报告窗口才使用最近完整年度同比。同窗累计证据缺项时拒绝，不静默退回年度CAGR；标准prepared TTM读取累计组成，外部季度输入读取原季度窗口，见[数据接入spec](data-contract.md)。v2接受−100%<同比≤100%的有限值；负同比不裁成零，按显式收缩政策生成趋稳恢复情景。上下界是当前工具能力与收入正值约束，不是教材的预测区间。
- 增长路径：高增长窗口一年，此后沿用原引擎向终值增长收敛至第十年；不把最近同比恒定延续五年。不证明公司衰减速度已校准。
- 利润率：明确采用当前已调整TTM正利润率持平情景，不混用未调整行业利润率；亏损需要扭亏路径，本规则拒绝。维持当前利润率仍是未经预测验证的假设。
- 资本：按原生公司已解析行业选Global销售资本比，要求样本不少于30、报告值有限且为正、来源日期与可用日期在参考截止内、观测不超过370天；无跨地区备用或2.5兜底。它是行业存量资本效率代理，不冒充公司新增资本效率。
- 终值：增长取2%与人民币无风险代理较低者；新增资本ROIC=WACC、不假设永久超额回报。沿用明确WACC情景（行业资本结构、BBB信用档和全中国暴露等仍非公司事实），政策边界必须随结果保留。

政策依据是达摩达兰的[增长、利润率和再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)与[终值再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)。原生引擎的现金流、折现及股权桥接公式保持不变。

自动选择不等于自动证明合理。输出须记录每项选择依据、明确政策、参考样本与缺项；未通过规则的不产生该候选。既有失败的增长研究继续有效，本轮不以机制通过或价格变化替代预测验证。

现有审阅工具会重新执行选择，比较政策、证据决定、原始请求及API返回输入；API自动更新的公司比较用资本成本单独核对为本次计算WACC，不把这项派生更新误当作用户输入篡改。原生目录查询404现归为 `outside_snapshot_scope`，与财务缺项区分。

## 同口径输入门槛

选择器会从基线报告读取增长及调整后利润率，再把候选假设写入显式情景输入。因此，两份输入不能只有证券代码相同：财务年度/季度、期间、币种、研发与租赁调整、股权桥接、期权和行业输入等必须一致，否则明确拒绝`selection financial or adjustment basis differs from baseline`。

比较使用当前模型的完整规范化输入，避免只检查EBIT而漏掉现金或研发队列。只允许宏观情景、预测假设、派生公司比较指标，以及方法中的参考WACC选择/参考组成不同；这些是已有情景路径，不表示其经济依据已审核。既有税率与终值条件继续单独检查。检查不修改传入对象，不从独立SQLite历史补齐模型缺项。

这是共享选择入口的输入一致性修复，不改变达摩达兰方法、获批代理、原页面或默认估值。此前同代码的另一套财务输入可能通过身份检查并混用基线利润率；现在在生成候选前拒绝。改换会计或代理口径时，必须先形成该口径的完整基线，再选择假设。

## 合法变更：重建基线并重新估值

同口径门槛只阻止混用，不能把旧方法或旧数据固化为准入条件。现已在同一工具提供显式重建入口：

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.select_native_assumptions \
  --rebuild workspace/derived/assumption-rebuild/request.json \
  --output workspace/derived/assumption-rebuild/result.json
```

实际运行仍须遵守独立systemd硬内存限制。请求JSON包含：

| 键 | 内容 |
|---|---|
| `baseline` | 旧完整报告，原样保留作为历史证据 |
| `inputs` | 当前模型契约的完整新输入；包含显式参考WACC |
| `reason` | 数据、口径或方法变更理由，不能为空 |
| `evidence_files` | 可读取的依据文件路径列表，保存路径与SHA256 |
| `reference_rows`、`reference_cutoff` | 行业资本参考及带时区截止 |
| `policy` | 当前自动选择政策，仍执行参考有效性、增长/利润率和终值等检查 |

程序首先用新输入和共享引擎重建完整基线，再从新基线读取增长/调整利润率，选择候选并重算DCF。旧利润率不会被借入新口径。结果`native-assumption-rebuild-v1`同时保存旧报告、新基线、候选完整输入/报告、逐项输入变化、重建与选择两阶段的结果差异、引擎版本、实现哈希及内容派生`run_id`；输出只允许新建于workspace/derived，不覆盖旧运行。

旧输入会尝试按当前引擎重放：一致记为`reproduced`；不一致或当前契约/公式无法接受时分别记录未验证状态和原因，不因此否决合法新输入。无法重算旧输入时，前后基线差额留空，旧报告不冒充当前公式下的可比结果；不建立旧运行时兼容层。不能借此隐瞒历史失败或伪造旧报告可信性。

依据文件存在及哈希只保证留痕，不自动认证新经济假设。`economic_approval=not_inferred_from_rebuild_or_evidence_hashes`；新增来源、政策或方法是否适用仍遵守现有约定。改进方法以达摩达兰原始资料为准。选择不通过时也保存已经重建的新基线及明确拒绝原因，不回退旧假设。此入口不更新原网页默认或主库数据。

历史样本数值、运行标识及测试收据见[验收记录](../history/native-assumption-selection.md)；当前交付数量统一见[项目状态](../implementation-status.md)。

## 盈利收缩的条件路径（v2）

`native-assumption-selection-v2`要求显式`contraction=conditional_recovery_with_implied_capital_release`。收入同比为负且当前调整利润率为正时，复用共享引擎及既有3/5/10年路径，将负增长逐步推向同一非负稳定增长；这是假设恢复的持续经营情景，不是从一次收入下降认定公司结构性衰退，也不证明恢复必然发生。固定持平/历史利润率规则不变，不为亏损公司自动填正利润率。

达摩达兰[增长基本面](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/growth.htm)允许负再投资，并要求区分暂时减少投入与逐步清算；[衰退企业](https://pages.stern.nyu.edu/adamodar/New_Home_Page/littlebook/decliningvaluedrivers.htm)区分持续经营、困境概率与处置回收，并警示直接套健康企业条件会高估价值。这里采用的是条件恢复路径，未建立困境概率或资产处置定价。

`selection.decisions.growth.path`区分收缩恢复与非负增长；收缩时`economic_basis.unresolved`必须列出恢复时点/存续及资本释放可收回性。收入增量为负时仍按所选倍率和投入滞后计算负再投资，不截零；原方法审阅逐年列出释放金额和年份。此金额不是已实现现金、资产出售价格或已核实的折旧回收。没有回收证据不得自动采用，`automatic_adoption=false`及无场景概率保持。

v1冻结运行按原提交复验，当前工具只接受v2；不保留旧政策别名。既有正增长公司的完整输入与DCF结果必须不变，新增可计算情况单独计数。网页默认、主库与SQLite不变。
