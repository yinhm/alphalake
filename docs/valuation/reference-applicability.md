# 估值参考的经济适用性

官方参考准确入库、公式可复算与适合本公司是三项判断。公司研究沿[现有显式入口](../guides/company-valuation-entry.md)采用有据条件；统一默认及新参数选择算法仍受[冻结约定](../../valuation/TODO.md)约束。

## 采用前核对

| 核对项 | 判断与处理 |
|---|---|
| 来源与样本 | 绑定发布版本、原表单元格、样本量及去杠杆/现金修正口径；US、Global和China分别核对，不把另一份统计样本数贴到实际采用的Beta上 |
| 业务与资本结构 | 样本是否覆盖公司产品、需求及成本风险；检查高杠杆是否使去杠杆Beta依赖少数特殊公司。上市地、计价币种和业务风险分别判断 |
| 跨地域差异 | 同行业不同地域参考用于交叉核验；差异大只触发人工审阅，样本更多不自动胜出，不能按股价或估值高低选来源 |
| 融资与稳态 | Beta、ERP、债务成本和权重分别留痕；初始参考改变后明确终值WACC是否联动、ROIC是固定数值还是关系，不把漏改终值当修正完成 |
| 结果解释 | 固定经营、税务、年度投入及股权桥比较；若ROIC随WACC改变，终值必要投入也改变，不能称纯折现单因素贡献 |

低Beta不等于原文错误，总波动也不等于市场Beta；高终值占比、资本释放及非正权益不自动归零或拒绝。ROIC=WACC时，增长与必要投入相互约束，不能固定FCFF只改Gordon分母来夸大增长影响。

## 已审核的显式研究修订

2026-10-23用户要求举一反三修正异常，本轮审核后沿既有接口重建以下研究条件。它是人工审核清单，不是自动选择器，也未更改原生网页默认。

| 已有参考分类 | 本轮显式选择及理由 | 边界 |
|---|---|---|
| Rubber& Tires | 同版Global业务Beta；US仅3家且行业杠杆极高，Global覆盖更广的轮胎/橡胶制造竞争与供应链 | 保留宽行业代理，橡胶汽车部件与轮胎差别继续披露 |
| Chemical (Diversified) | 同版Global业务Beta；US仅4家且高杠杆，已读公司为受全球价差、能源及装置投入影响的多产品化工制造 | 不用行业均值改写公司利润或资本效率 |
| Oil/Gas (Integrated) | 已有明确上游、炼化和销售一体化业务证据的公司采用同版Global业务Beta；US仅4家 | 燃气分销/管网不因分类名称纳入 |

以上均保留现有行业分类。国新能源的已读业务主要为燃气分销/管网，不据分类名称套用一体化油气修订；原数值保留为诊断，新的业务关联方案另审。公用事业、广播等低Beta参考尚未形成充分修订依据，不扩大采用范围。

后续研究复用本清单时仍核对业务和来源版本，明确继承或例外；不得把未审公司自动回退旧基线并当主研究。Beta地域变化不自动带动利润率、资本倍率、债务利差或ERP地域切换。
