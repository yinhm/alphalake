# 估值参考的经济适用性

官方参考准确入库、公式可复算与适合本公司是三项判断。公司研究沿[现有显式入口](../guides/company-valuation-entry.md)采用有据条件；统一默认及新参数选择算法仍受[冻结约定](../../valuation/TODO.md)约束。

## 采用前核对

| 核对项 | 判断与处理 |
|---|---|
| 来源与样本 | 绑定发布版本、原表单元格、样本量及去杠杆/现金修正口径；US、Global和China分别核对，不把另一份统计样本数贴到实际采用的Beta上 |
| 业务与资本结构 | 样本是否覆盖公司产品、需求及成本风险；检查高杠杆是否使去杠杆Beta依赖少数特殊公司。上市地、计价币种和业务风险分别判断 |
| 跨地域差异 | 同行业不同地域参考用于交叉核验；差异大只触发人工审阅，样本更多不自动胜出，不能按股价或估值高低选来源 |
| 融资与稳态 | Beta、ERP、债务成本和权重分别留痕；初始参考改变后明确终值WACC是否联动、ROIC是固定数值还是关系，不把漏改终值当修正完成 |
| 结果解释 | 固定经营、税务、年度投入及股权桥比较；若ROIC随WACC改变，终值必要投入也改变，不能称纯折现单因素贡献 |

低Beta不等于原文错误，总波动也不等于市场Beta；高终值占比、资本释放及非正权益不自动归零或拒绝。ROIC=WACC时，增长与必要投入相互约束，不能固定FCFF只改Gordon分母来夸大增长影响。

## 已审核的显式研究修订

2026-10-23用户要求举一反三修正异常，本轮审核后沿既有接口重建以下研究条件。它是人工审核清单，不是自动选择器，也未更改原生网页默认。

| 已有参考分类 | 本轮显式选择及理由 | 边界 |
|---|---|---|
| Rubber& Tires | 同版Global业务Beta；US仅3家且行业杠杆极高，Global覆盖更广的轮胎/橡胶制造竞争与供应链 | 保留宽行业代理，橡胶汽车部件与轮胎差别继续披露 |
| Chemical (Diversified) | 同版Global业务Beta；US仅4家且高杠杆，已读公司为受全球价差、能源及装置投入影响的多产品化工制造 | 不用行业均值改写公司利润或资本效率 |
| Oil/Gas (Integrated) | 已有明确上游、炼化和销售一体化业务证据的公司采用同版Global业务Beta；US仅4家 | 燃气分销/管网不因分类名称纳入 |

以上均保留现有行业分类。宽行业内部仍须看公司实际业务，不能把同版Global当作审核终点。2026-10-25沿既有显式`direct_unlevered`入口完成以下研究修订：

| 已读业务类别 | 显式业务Beta代理 | 本次适用及限制 |
|---|---|---|
| 汽车橡塑零部件 | Auto Parts／Global，现金调整去杠杆Beta 1.353472；797家 | 朗博、中鼎、川环的客户、产品和需求主要为汽车配套，不继续套轮胎参考；新领域贡献仍按原故事，不改收入或资本条件 |
| 天然气分销／管网 | Oil/Gas Distribution／Global，0.461154；186家 | 国新能源采用输配业务风险，不冒称油气一体化；顺价、信用及债务期限未闭合，继续仅作诊断 |
| 有线接入网络 | Cable TV／Global，0.590830；42家 | 江苏有线、湖北广电区别于节目广播；政企业务等混合暴露仍披露，湖北广电恢复／融资条件继续仅作诊断 |

这是业务可比性审阅后的显式风险代理，**不是修改官方公司行业事实或批量分类关联**。采用工作簿的业务Beta后按本公司资本结构重新加杠杆，不移植行业债务权重；利润率、资本倍率、债务利差及ERP继续沿原条件。Global在此是分散地域样本的研究选择，不是因为样本数大就必然正确。其他未审公司不自动采用。

用户随后要求其余应更新的也更新。本轮扫描全部3,399套已计算研究的笔记及来源分类，详细审阅45项，沿同一既有接口处理40项：

| 类别 | 处理 | 不能省略的区别 |
|---|---|---|
| 同类有线／燃气 | 5家有线接入、5家燃气供应采用已审Global同类参考 | 东方明珠的内容／文旅组合、广州发展的煤电气组合不因原标签纳入 |
| 承运／资源／服务 | 油运2家→海运；恒通→物流；卫通→通信服务；中海油服→油田服务 | 运输油气不等于经销油气，提供油田服务不等于拥有储量 |
| 公用事业／材料 | 4家供热热电→综合公用事业；东华能源／万邦达→基础化工 | 水务标签不能代表供热或已占主体的化工装置；综合参考仍是宽代理 |
| 制造／设备 | 自动化及专用装备4家→Machinery；汽车内饰／配件2家→Auto Parts；PCB→电子制造；功率芯片→Semiconductor | 给某行业供应设备不等于自己拥有该行业产出；卖芯片不等于卖制芯设备 |
| 其他可识别主营 | 铁路物流、医院运营、物业管理、防务、网络优化／工业检测及通航分别采用对应宽参考 | 保留剩余业务、客户集中、资本及地区差异，不把更贴近理解为精确复制 |
| 复杂混业 | 广州发展、东方明珠、蔚蓝锂芯、冠城新材保留原数值，仅作诊断；另5家既有诊断保持 | 缺组合依据不虚构单一Beta或分部权重，也不把未知填0、拒绝全部公司估值 |

36个风险输入修订均保留原经营路径并成套更新稳态；另4项用途纠偏保持完整请求和原值。不是把扫描后的其他公司都认证为适用，也不是完成所有公司的重新研究。分部收入、毛利与业务价值权重不同；尤其原料过手、内部抵销、地产存量和参股投资并存时，不能按一个半年的收入直接加权Beta。详细公司清单、仍保留的混业边界及前后数值见[扩展验收](../history/reference-scope-corrections-20261025.md)。

后续研究复用本清单时仍核对业务和来源版本，明确继承或例外；不得把未审公司自动回退旧基线并当主研究。Beta地域变化不自动带动利润率、资本倍率、债务利差或ERP地域切换。
