# 周期企业：正常化与显式回落路径

周期企业仍使用FCFF、再投资、WACC及股权桥接。区别在于未来经营输入：景气高点的增长和利润率不能直接当成长期水平，低点亏损也不能直接当成永久状态。行业标签、历史波动或估值极端都不足以独立确定周期位置。

## 原始方法及适用条件

达摩达兰的[《Ups and Downs: Valuing Cyclical and Commodity Companies》](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/commodity.pdf)给出两条DCF路径：正常化各项输入，或从当前经营状态显式过渡至正常水平。第9–10页提醒不能只正常化利润而忽略回报、再投资与融资；第13–17页讨论正常化与丰田实例，第22–24页讨论逐年回落／恢复及情景分析。

[正常化利润说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)强调：规模变化明显时，平均利润率比平均利润金额更合适；观察窗应覆盖周期。教材中的历史年数不是本系统准入硬门槛，也不证明固定五年一定覆盖完整周期。直接替换基期隐含立即正常化，缓慢恢复／回落须另列期间路径。

| 路径 | 适用依据 | 必须保留的边界 |
|---|---|---|
| 正常化估值 | 有跨周期、同范围的经营利润、资本和融资依据 | 同时正常化收入／价格、利润率、再投资、回报及风险；已经正常化后不再叠加周期恢复增长 |
| 当前基期＋显式路径 | 当前财务可信，能够声明短期景气与长期经营条件 | 保留当前基期，逐年供给收入、利润率、资本效率、税及风险；回落年限是经济判断，不是统一规则 |
| 行业正常水平辅助 | 公司历史不足或经营范围变化，有真正可比的跨周期同业数据 | 单年行业均值不是跨周期均值；业务、资产轻重和经营效率差异不能略去 |

商品价格驱动企业还须核对[正常价格、供需及市场价格路径](https://pages.stern.nyu.edu/adamodar/New_Home_Page/littlebook/commodityvaluedrivers.htm)。存储产品也受需求、供给和价格周期影响，但不能直接照搬油矿耗竭或原材料价格回归模型。江波龙同时销售存储产品、采购存储晶圆，采购成本滞后及存货周转影响价差；只看一种晶圆报价不足以决定利润。

## 数据与假设如何分工

1. **保留事实。** TDX标准收入、EBIT、研发、资本及存货保留原期间、范围和来源；周期高利润、亏损和减值不按异常数删除。年度正常化不能把单季金额当全年，也不能以平均值回写事实。
2. **声明周期证据。** 原文说明价格、供需、采购成本、销量或存货的传导机制；区分价格周期与销量、产品结构和市场份额增长。没有价格／销量拆分时明确收入尚未正常化，不声称识别到精确峰谷。
3. **确定利润口径和窗口。** 利润与收入同范围；资本化研发、租赁及非经营收益须分别处理。报表利润率均值与调整后利润率均值不混用。算术均值赋各年度相同权重；收入加权均值赋大规模年度更高权重，属于另一个显式政策，不能悄悄互换。亏损年保留；旧经营范围不可比另留诊断。
4. **联合供给未来输入。** 收入路径须分清周期变动和结构性增长；利润率路径可以回落或恢复。未来研发费用、摊销、现金税、资本需求和融资使用同一经营条件，不另外重复扣研发投入。资本效率不能仅因利润率降低就宣称已正常化。
5. **检查成熟期。** 永续增长、边际税、ROIC与WACC及再投资联动。ROIC=WACC是无超额回报条件，不是所有周期企业的统一事实；终值不能继续保留景气峰值。接近股价不能证明周期中枢或回落年限选对。

现阶段复用[数据契约](data-contract.md)、[显式政策](explicit-policy.md)及共享引擎：

| 既有输入 | 周期条件的表达 | 核验 |
|---|---|---|
| `valuation_assumptions.annual_forecast` | 每年收入增长、调整后EBIT利润率、税率 | 完整覆盖预测年数；末年利润率、税率延续至终值 |
| `research_tax` | 年度研发费用、普通／有依据的税务扣除及终值 | 滚动原经济寿命队列；税基=经济EBIT＋研发摊销−税务扣除 |
| `annual_sales_to_capital` | 各投资年的资本效率条件 | 沿原投入领先期计算总净再投资；不是新增研发扣款 |
| `annual_net_reinvestment` | 各实际投资年的显式总净投入 | 与年度倍率互斥；包含资本化研发净投入，零／负值保留，不按销售领先期移动 |
| 现有参考融资／`debt_tax_shield` | 所选正常融资条件，或明确保留既有融资代理 | 不把当前市场权重／行业信用代理自动称跨周期公司WACC |
| 现有稳定增长／ROIC条件 | 成熟期增长、风险及再投资 | 再投资率=g/ROIC；预测末期与稳态经营范围一致 |

增长衰减及利润率路径复用既有分支；直接总预算按本轮明确批准接通，不自动填入已有条件。初次验证只学习方法、生成完整显式输入并经现有`POST /api/valuation`验收；2026-10-06用户恢复通用周期框架目标，已进一步接入下述行业条件批次。行业候选筛选不改变公司来源分类；未来自动默认采用仍须先闭合周期、窗口、经济证据及缺项政策，不能以数值可得替代审核。

## 通用框架与行业范围

交付单位是经济机制和完整证券分母，不能只给少数高估值样本改参数。框架分为三层：来源事实与收益组成；有经济依据的正常化／过渡输入；既有共享引擎及独立审阅。长期目标仍是所有周期性行业公司，当前行业筛选只是候选入口，不把没有命中的行业认定为无周期。

| 暴露类别 | 必须回答的经济问题 |
|---|---|
| 资源价格与储量 | 正常价格、产量／品位、成本；储量能否补充、投入与有限寿命是否匹配 |
| 材料供需与价差 | 产品与原料价差、成本位置、产能利用率、库存及维持投入 |
| 农业供给与价格 | 品种价格、产量、天气／生物周期与投入成本；不把供给冲击全归因宏观周期 |
| 技术供需与产能 | 价格和销量、产品升级、市场份额、产能／库存与研发寿命分别处理 |
| 资本开支与订单 | 客户投资、订单交付、建设领先期和维护投入；收入回落不自动释放生产资本 |
| 耐用品需求 | 替换销量、产品结构、产能与金融兼营；实际规模变化不能只用平均利润金额 |
| 地产建设与信用 | 开工／交付、合同和存货资本、融资、困境与存续；不把账面存货等同可释放现金 |
| 运价与运力 | 运价和运输量、载运率、运力、租赁和燃料；保留资产与利润同范围 |
| 可选消费与商业需求 | 客流／客户需求、价格、租赁、品牌及结构增长；公司可能比行业更稳定 |
| 受监管能源／混合业务 | 监管回报、合同保护及业务分部先核实；行业名称不足以统一正常化 |

实现中的逐行业名单为`tools.cyclical_valuation.PROFILES`，它是显式筛选政策，不是达摩达兰发布的周期行业表，也不修改申万或官方公司行业关联。金融和北交所范围外；没有精确来源关联的公司单列未解析，保留原发布分母。财务、参考或窗口缺项逐类留痕，不删亏损公司，不自动缩短历史或研发寿命。

## 收益与资产组成的来源审核

达摩达兰的[经营资产与其他资产说明](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/a22.htm)要求收益口径与资产桥一致：经营DCF未计入的资产收益，对应资产才在桥接中另估；[持股估值说明](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/valcrosshold.htm)进一步区分独立持股与合并子公司。保留持股收益的预测同时再加持股价值，存在重复计价风险；全部剔除投资收益也可能移除经营套保或其他业务收益。不能只凭科目名称统一减利润、加资产，更不能将账面余额认证为持股市场价值。

复用`tools.derive_tdx_capital`，按原公司／期间宽行增加八项标准上下文，不改变六项既有核算公式，不写回事实或估值输入：

| 组成 | 经济边界 |
|---|---|
| 累计营业利润 | 中文报表标签不自动等于纯经营EBIT，仍须核对报表组成 |
| 联营／合营投资收益 | 投资收益子项，不能与投资收益再次相加；其他分量反向抵销时，子项绝对值可以大于合计 |
| 投资收益现金流 | 收款时点和应计收益不同，不能替代或重复加进当期利润 |
| 净敞口套期收益 | 只是特定列报项目，不代表全部套保；性质由被套期风险及业务决定，零值不证明没有套保 |
| 长期股权投资 | 核对持股及合并范围；对应收益与资产须一并处理 |
| 债权、其他债权、其他权益工具投资 | 期末账面余额保留，不仅凭名称认定全部非经营或已完成价值估计 |

## 条件批次与数据契约

`tools.cyclical_valuation`读取当前SQLite同版参考及主库范围审核，用原生`from-database`准备基线，复用`cycle_conditions`和共享引擎生成四个观察条件。证券范围及源／实现哈希在计算前冻结，完整报告流式写压缩包；每家公司完成后删除该次验证会话，不保留全量报告对象或逐公司启动进程。未指定证券时检查整个发布分母，只有已确认非金融中的行业候选及混合业务候选进入条件计算。TDX金融分类与达摩达兰关联冲突时沿原口径待定，不能仅靠原生行业标签重判为非金融。

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.audit_native_coverage \
  --database workspace/valuation.sqlite --source-database workspace/alphalake.duckdb \
  --output workspace/derived/cyclical-industry-framework/current-coverage.json

PYTHONPATH=valuation/backend .venv/bin/python -m tools.cyclical_valuation \
  --database workspace/valuation.sqlite \
  --scope workspace/derived/cyclical-industry-framework/current-coverage.json \
  --output workspace/derived/cyclical-industry-framework/new-run
```

按[资源隔离](../guides/fundamental-memory-20260919.md)在独立1GiB服务中串行执行；输出目录须为新的derived子目录。范围报告必须与SQLite／主库哈希、报告期、信息截止及完整证券清单匹配；过期、重复、缺证券或范围计数矛盾均拒绝。小范围复验可重复添加`--ticker SHSE:600019`等，不改变默认全发布分母的口径。未刷新报价或数据；行情价格和股本仍为原输入时点。

- **观察条件**：最近完整财年的连续五年，报表EBIT利润率算术／收入加权均值，保持亏损；收入前三年持平后沿原稳定增长。报表利润观察不是已审核的经营利润，更不是正常价格／销量预测。
- **研发与税**：复用当前研发费用率／普通扣除及滚动队列；已填未来研发、预测或倍率路径的用户输入保留，不自动覆盖。没有选择研发资本化的原输入也不擅自开启。
- **资本**：只附加年度倍率路径；稳态NOPAT、ROIC与税务读取共享引擎。考虑原投入领先期L，等价倍率为`ROIC×(1+g)^(L−1)/稳态NOPAT利润率`，末年净投入按稳定增长扩大后与终值投入闭合。负NOPAT不能编造正倍率；资本释放逐年及终值分别列出，未证实不自动采纳。研发税基恒等式还原稳态摊销后，明确总再投资减研发净投入的非研发残余；正增长下永久释放非研发资本不能仅靠终值算术通过认定可持续。
- **收益范围**：批量读取标准投资收益、公允价值收益的完整累计三分量，核对期间、CNY及范围；分别显示占报表EBIT比例。源零保留0，缺项留空，不把两项全当非经营并直接减掉，也不更改资产桥。
- **融资与终值**：保留原人民币融资／年度税盾条件，不因利润回落自动改债务、Beta或现金。资源寿命、成熟经营回报及生存风险另审；算术衔接不是经济认证。
- **输出**：`protocol.json`、`summary.json`及`api-evidence.tar.gz`。每公司保留基线、来源和场景状态；`selected_scenario=null`、`automatic_adoption=false`。run ID为摘要内容签名，属于该条件批次，不冒充主库估值运行ID。

状态分别表示行业候选、混合候选、范围外／未解析、原输入阻断、观察条件无法表达、条件计算成功及逐场景拒绝。预测缺年、零收入不能构造利润率、终值需要恢复等均是所选条件的边界，不泛称公司无法估值。完整经济正常化仍须补收入、收益范围、资本和融资证据；本入口不会只凭历史均值自动生成合理参数胜出者。

### 历史资本分量与接口表达核验

2026-10-06仅复用当前来源核算及周期归档，未扩采早年、运行新估值或改变政策。候选4,090家、FY2021–2025共20,450个年度位置：现金资本开支减来源隐含D&A为正13,254、负7,178、零1、缺17；4,077家五年分量完整，2,699家至少一年为负。这一减法仍受D&A范围、并购及非现金增加限制，不是已分类净再投资。负值可能表示账面资本消耗或投入时点差异，不能等同于出售资产取得现金，也不能一律判错。

2022–2025的贸易营运资本小计变化共16,360个可比较位置，正9,253、负7,097、缺10。2021年的4,090个位置因观察窗没有2020年而不计算变化，不把它们转报为源缺失或据此扩采；小计不含其他经营往来，余额变化还可能含并购、汇率或非现金影响，不冒充经营现金回收。达摩达兰[非现金营运资本说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/noncashwc.htm)允许负余额／负变动，同时要求未来变化与收入及经营机制配套；不能把当年释放无限延续，也不能以通用0下限替代判断。

当前条件中有1,081家在完整五年中未出现上述负差额，却有预测非研发资本释放；这只是应查组成的线索，既不证明未来不能释放，也不证明其他公司释放已获支持。历史负差额、未来预算及资产可回收性分别留痕，不按符号或行业自动审批。

逐份回读全部12,947个已算条件，2,330家、9,184个条件存在“投入所对应的收入增量为0，但研发净投入为正”：第1年9,028项、第2年8,674项，条件间有重叠。现有正资本倍率无论取多大／小，`0／倍率`仍为0；**只有当用户明确采用非研发净投入不为负的条件时**，总净投入才至少须覆盖研发净投入。现状不自动采用该条件或R&D下限，也不追加一遍研发扣款；需要下述显式预算接口才能准确表达。17,702个具体年度位置与原预测逐一定位，未重新估值，详细协议、CSV及源码在`workspace/derived/cyclical-capital-observations/`。

### 显式年度净再投资：已批准并接通

现有正销售资本比不能在收入持平时表达正净投入，因而不能仅靠调倍率解决研发资本积累或转型投资。这是输入表达边界；扩展目的不是自动估计维护投入或改变正常化利润。达摩达兰[周期论文](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/commodity.pdf)第23页表3直接列示恢复期年度再投资，第24页保持终值g/ROC；[研发论文](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/R%26D.pdf)第20–21页要求资本支出与摊销包含研发的对应分量。年度字段、互斥和实际投资年对齐是本地输入设计，不是教材规定的接口。2026-10-06用户明确批准“落实方案调整”，已接通后端显式契约及共享计算，不改变网页、数据库新会话或四个已有观察条件。

| 输入约束 | 行为 |
|---|---|
| `annual_net_reinvestment` | 显式提供与预测期等长的有限数值列表，单位百万元报表币种；缺省沿现有销售资本比路径，显式0保留 |
| 投资时点 | 按实际投资预测年对齐；直接预算不再按销售领先期位移，领先期只解释业务证据及原倍率对照 |
| 路径互斥 | 与`annual_sales_to_capital`同时提供则拒绝；直接预算启用后不再计算`Δ收入／倍率`，标量倍率只保留为原输入、不消费 |
| 总投入范围 | 已包括资本开支−折旧＋非现金营运资本变动＋研发费用−研发摊销；不得再叠加研发净投入 |
| 净释放 | 负值可表示有依据的资产／资本释放；没有证据仍只标条件，不能统一截为0或按行业判真 |
| 现金流与账面资本 | 同一预算参与`FCFF=NOPAT−净再投资`及既有未来资本／ROIC诊断，不另建DCF或只修改最终价格 |
| 终值 | 继续使用g/ROIC，不从年度预算自动推永久投入或自动改ROIC；末期衔接和终值研发／非研发组成单列核验 |
| 会话安全 | 长度错误、非有限值及双路径在计算前拒绝，原会话与用户基线保留 |

例如前轮江波龙收入持平首年总净投入为0、研发净投入约7.263亿元。若用户另给“非研发净投入为0”条件，该年总预算应为7.263亿元，原利润与税不变时FCFF减少7.263亿元；这是预算条件的算术影响，不是公司事实、完整重估或已推荐的资本预算。不能简单在原总预算上全年重复加研发，尤其原总预算已经足以涵盖研发的增长年。

验收固定有／无研发、收入持平／增长／下降及不同投入领先期的跨公司基线，核对来源输入不变、显式0、负预算、双路径／长度／非有限拒绝、税务及股权桥不变和FCFF逐年差额。终值若隐含无依据的永久资本释放继续待审，不为转绿自动降低ROIC或抬高利润率。当前尚无该字段或实施代码；完整条件仍按既有接口提交。

## 首轮显式验证：规则先冻结，结果不选优

完整动态协议、请求、实际8080响应、共享引擎审阅、来源及检查放在`workspace/derived/cyclical-valuation/`。沿用已发布2026H1财务及参考快照；数值和分母见[当前状态](../implementation-status.md#前轮七家公司显式验证2026-10-06)。原沪深300批次及生产默认基线保留，没有用更接近行情的条件覆盖它们。

- 观察窗固定为既有2021–2025五个完整年度，保留亏损；不认证已覆盖完整周期、不扩采更早年份。采用报表EBIT利润率，因为更早年度的完整研发调整队列不可得，不补造队列或缩短寿命。
- 固定四个条件：算术利润率均值分别于第1／3／5年到达；收入加权均值于第3年到达。第一年已开始线性过渡，年份指预测年的末点；四个条件无概率、无胜出者。
- **收入条件**为当前TTM收入保持三年，随后按原稳定增长率增长；这是剥离近期高增长外推的条件，不是销量或晶圆价格预测。没有正常化当前收入中的价格因素，也没有判断公司实际不会扩大业务。
- **利润／研发条件**为报表利润率向目标过渡，再按已有“当前研发费用率不变、普通当期扣除”条件供给未来研发，使用共享五年队列摊销。经济EBIT=报表EBIT＋研发费用−摊销；税基核对回报表EBIT。不把费用率或普通扣除条件说成公司真实税务预测，TTM与年度cohort的既有近似仍保留。
- **资本条件**从原行业倍率渐变，于第5年达到与无超额回报稳态一致的倍率：`稳态销售资本比=终值ROIC/稳态NOPAT利润率`。其推导是固定利润率下“新增NOPAT/净再投资”一致；这是未来资本需求条件，不能冒充实测公司倍率。沿原一年投入领先期，末年投入供给下一年收入增量，核对末年投入按稳定增长扩大后等于终值投入。
- **资本组成未认证。** 前两年收入持平使原销售资本比路径的总净再投资为0，但研发费用仍存在。江波龙相应隐含非研发净再投资为−7.263／−5.001亿元，必须有折旧、资产或营运资本释放依据才能采用；本轮没有此依据，不把这个算术残差称已核实库存释放。研发净投入与总再投资的负残余已由现有审阅逐年列出，也不能为消除此残差再扣一遍研发。
- **融资、税和资产桥**保留原人民币WACC、原年度税路径、现金／投资／债务及股数代理。保持这些条件便于复验，不代表融资或库存去化后的债务已正常化；不能从利润回落擅自推算存货释放、减债或现金增加。

江波龙原默认把当前调整利润率及近翻倍增长长期外推，不能用于认定周期企业合理价。本轮条件值消除了这种外推，但正常收入、产品升级后的中枢、融资／库存资本释放仍未闭合。**条件可算与周期合理估值已完成是两件事。** 天赐材料使用同样规则检验接口复用；天齐锂业因报表EBIT投资收益范围尚未审核保留边界，不强塞入经营利润均值模型，也不清空其报表事实。
