# 周期企业：正常化与显式回落路径

周期企业仍使用FCFF、再投资、WACC及股权桥接。区别在于未来经营输入：景气高点的增长和利润率不能直接当成长期水平，低点亏损也不能直接当成永久状态。行业标签、历史波动或估值极端都不足以独立确定周期位置。

## 原始方法及适用条件

达摩达兰的[《Ups and Downs: Valuing Cyclical and Commodity Companies》](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/commodity.pdf)给出两条DCF路径：正常化各项输入，或从当前经营状态显式过渡至正常水平。第9–10页提醒不能只正常化利润而忽略回报、再投资与融资；第13–17页讨论正常化与丰田实例，第22–24页讨论逐年回落／恢复及情景分析。

[正常化利润说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)强调：规模变化明显时，平均利润率比平均利润金额更合适；观察窗应覆盖周期。教材中的历史年数不是本系统准入硬门槛，也不证明固定五年一定覆盖完整周期。直接替换基期隐含立即正常化，缓慢恢复／回落须另列期间路径。

| 路径 | 适用依据 | 必须保留的边界 |
|---|---|---|
| 正常化估值 | 有跨周期、同范围的经营利润、资本和融资依据 | 同时正常化收入／价格、利润率、再投资、回报及风险；已经正常化后不再叠加周期恢复增长 |
| 当前基期＋显式路径 | 当前财务可信，能够声明短期景气与长期经营条件 | 保留当前基期，逐年供给收入、利润率、资本效率、税及风险；回落年限是经济判断，不是统一规则 |
| 行业正常水平辅助 | 公司历史不足或经营范围变化，有真正可比的跨周期同业数据 | 单年行业均值不是跨周期均值；业务、资产轻重和经营效率差异不能略去 |

商品价格驱动企业还须核对[正常价格、供需及市场价格路径](https://pages.stern.nyu.edu/adamodar/New_Home_Page/littlebook/commodityvaluedrivers.htm)。存储产品也受需求、供给和价格周期影响，但不能直接照搬油矿耗竭或原材料价格回归模型。江波龙同时销售存储产品、采购存储晶圆，采购成本滞后及存货周转影响价差；只看一种晶圆报价不足以决定利润。

## 数据与假设如何分工

1. **保留事实。** TDX标准收入、EBIT、研发、资本及存货保留原期间、范围和来源；周期高利润、亏损和减值不按异常数删除。年度正常化不能把单季金额当全年，也不能以平均值回写事实。
2. **声明周期证据。** 原文说明价格、供需、采购成本、销量或存货的传导机制；区分价格周期与销量、产品结构和市场份额增长。没有价格／销量拆分时明确收入尚未正常化，不声称识别到精确峰谷。
3. **确定利润口径和窗口。** 利润与收入同范围；资本化研发、租赁及非经营收益须分别处理。报表利润率均值与调整后利润率均值不混用。算术均值赋各年度相同权重；收入加权均值赋大规模年度更高权重，属于另一个显式政策，不能悄悄互换。亏损年保留；旧经营范围不可比另留诊断。
4. **联合供给未来输入。** 收入路径须分清周期变动和结构性增长；利润率路径可以回落或恢复。未来研发费用、摊销、现金税、资本需求和融资使用同一经营条件，不另外重复扣研发投入。资本效率不能仅因利润率降低就宣称已正常化。
5. **检查成熟期。** 永续增长、边际税、ROIC与WACC及再投资联动。ROIC=WACC是无超额回报条件，不是所有周期企业的统一事实；终值不能继续保留景气峰值。接近股价不能证明周期中枢或回落年限选对。

现阶段复用[数据契约](data-contract.md)、[显式政策](explicit-policy.md)及共享引擎：

| 既有输入 | 周期条件的表达 | 核验 |
|---|---|---|
| `valuation_assumptions.annual_forecast` | 每年收入增长、调整后EBIT利润率、税率 | 完整覆盖预测年数；末年利润率、税率延续至终值 |
| `research_tax` | 年度研发费用、普通／有依据的税务扣除及终值 | 滚动原经济寿命队列；税基=经济EBIT＋研发摊销−税务扣除 |
| `annual_sales_to_capital` | 各投资年的资本效率条件 | 沿原投入领先期计算总净再投资；不是新增研发扣款 |
| 现有参考融资／`debt_tax_shield` | 所选正常融资条件，或明确保留既有融资代理 | 不把当前市场权重／行业信用代理自动称跨周期公司WACC |
| 现有稳定增长／ROIC条件 | 成熟期增长、风险及再投资 | 再投资率=g/ROIC；预测末期与稳态经营范围一致 |

增长衰减及利润率路径不需要增加估值引擎分支。本轮只学习方法、生成完整显式输入并经现有`POST /api/valuation`验收，没有新增自动选择器、周期分类规则或默认替换。未来若要求自动默认采用，须先按[valuation TODO](../../valuation/TODO.md)审批周期识别、窗口选择、经济证据及缺项政策。

## 首轮显式验证：规则先冻结，结果不选优

完整动态协议、请求、实际8080响应、共享引擎审阅、来源及检查放在`workspace/derived/cyclical-valuation/`。沿用已发布2026H1财务及参考快照；数值和分母见[当前状态](../implementation-status.md#周期方法显式验证2026-10-06)。原沪深300批次及生产默认基线保留，没有用更接近行情的条件覆盖它们。

- 观察窗固定为既有2021–2025五个完整年度，保留亏损；不认证已覆盖完整周期、不扩采更早年份。采用报表EBIT利润率，因为更早年度的完整研发调整队列不可得，不补造队列或缩短寿命。
- 固定四个条件：算术利润率均值分别于第1／3／5年到达；收入加权均值于第3年到达。第一年已开始线性过渡，年份指预测年的末点；四个条件无概率、无胜出者。
- **收入条件**为当前TTM收入保持三年，随后按原稳定增长率增长；这是剥离近期高增长外推的条件，不是销量或晶圆价格预测。没有正常化当前收入中的价格因素，也没有判断公司实际不会扩大业务。
- **利润／研发条件**为报表利润率向目标过渡，再按已有“当前研发费用率不变、普通当期扣除”条件供给未来研发，使用共享五年队列摊销。经济EBIT=报表EBIT＋研发费用−摊销；税基核对回报表EBIT。不把费用率或普通扣除条件说成公司真实税务预测，TTM与年度cohort的既有近似仍保留。
- **资本条件**从原行业倍率渐变，于第5年达到与无超额回报稳态一致的倍率：`稳态销售资本比=终值ROIC/稳态NOPAT利润率`。其推导是固定利润率下“新增NOPAT/净再投资”一致；这是未来资本需求条件，不能冒充实测公司倍率。沿原一年投入领先期，末年投入供给下一年收入增量，核对末年投入按稳定增长扩大后等于终值投入。
- **资本组成未认证。** 前两年收入持平使原销售资本比路径的总净再投资为0，但研发费用仍存在。江波龙相应隐含非研发净再投资为−7.263／−5.001亿元，必须有折旧、资产或营运资本释放依据才能采用；本轮没有此依据，不把这个算术残差称已核实库存释放。研发净投入与总再投资的负残余已由现有审阅逐年列出，也不能为消除此残差再扣一遍研发。
- **融资、税和资产桥**保留原人民币WACC、原年度税路径、现金／投资／债务及股数代理。保持这些条件便于复验，不代表融资或库存去化后的债务已正常化；不能从利润回落擅自推算存货释放、减债或现金增加。

江波龙原默认把当前调整利润率及近翻倍增长长期外推，不能用于认定周期企业合理价。本轮条件值消除了这种外推，但正常收入、产品升级后的中枢、融资／库存资本释放仍未闭合。**条件可算与周期合理估值已完成是两件事。** 天赐材料使用同样规则检验接口复用；天齐锂业因报表EBIT投资收益范围尚未审核保留边界，不强塞入经营利润均值模型，也不清空其报表事实。
