## 官方目录是否对得上

本轮取得用户提供的[通达信专业财务数据项](https://help.tdx.com.cn/gspt/docs/markdown/redword/Profinance/profinancedatalist.html)，与已冻结的另一份[官方量化目录](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)逐编号比较。没有发现编号语义冲突，不能认为两个页面内容完全相同。

- 公式页面424行、422个唯一位置；源位置401和402各重复一次，192明确为“暂无”。重复与空定义保留在原文，不算新增字段。
- 它补足源位置74–97的24项官方名称依据。此前这批只引用portfolio；现在462项命名依据中461项有官方来源，只有源位置165仍仅参考词典。参考词典的credit及原始文件保留。
- 量化页面另有40项本页未列出的定义，包含后续新增与金融类指标；不因较短页面缺行删除这些已有证据。
- 去空白与全半角标点后，13处标签差异来自“账/帐”、注释详略及百分号括号。逐项记录双版本原文，不覆盖更详细的日期格式、未来期间及股本范围注释。
- 页面定义支撑名称与部分单位，不独自证明某家公司某期的取值正确，更不能证明源零是真实零、来源EBIT/ROIC符合估值政策或每股指标可直接加总。

[原文压缩归档及比对收据](../internal/source/tdx/financial/testdata/official-profinance-fields.receipt.json)锁定SHA256、重复位置、标签差异及40个缺行；默认Go回归同时检查两份官方页面。未增加网络测试依赖。

## 新增12项

| 通用字段 | 含义与边界 |
| --- | --- |
| cashflow_reconciliation_net_income | 现金流补充资料的净利润起点，独立于利润表来源 |
| cashflow_asset_impairment_provisions | 资产减值调节项，不与信用减值混为一项 |
| credit_impairment_cashflow_adjustment | 信用减值调节项；TDX以万元编码，落库换成元 |
| cashflow_long_lived_asset_disposal_loss | 长期资产处置损失调节，负数表示收益，不是处置现金流 |
| fixed_asset_retirement_loss | 固定资产报废损失调节 |
| cashflow_fair_value_loss | 公允价值变动损失调节，保留有符号金额 |
| cashflow_finance_costs | 现金流调节财务费用，不等于利润表总费用或现金付息 |
| cashflow_investment_loss | 投资损失调节，收益保留负数 |
| deferred_tax_asset_decrease_cashflow | 递延所得税资产减少调节，不等于期末余额或余额简单差 |
| deferred_tax_liability_increase_cashflow | 递延所得税负债增加调节，不等于期末余额或余额简单差 |
| operating_cash_flow_indirect | 间接法经营现金流总额，独立保留附表血缘，不和主表相加 |
| net_cash_increase_reconciliation | 补充资料现金净变动，不与主表重复加总 |

全部为合并口径、人民币元、年初累计，映射从2025-01-01起生效；零值拒绝。原文范围为安克一家公司的2025H1、2025FY及2026H1，36个当期非零源位与原文一致，另36个比较列只作原文保护。

[原始台账](../internal/ingest/testdata/cashflow-reconciliation-2026/evidence.json)复用已有三份PDF及裁剪包。既有三表校验器支持第二个封闭审核批次，默认CI执行；共用Go测试完成归档/关联、物化、当期值、TTM窗口、公告次日边界、错误倍率撤除、恢复及重开幂等。原64项批次仍保持独立分母。

这些报表调节项提供净利润到经营现金流的解释证据，不直接补成已分类营运资本或历史FCFF，不改变达摩达兰定义及估值预测政策。
