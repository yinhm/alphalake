## 不能照搬的部分

1. 配套解析器 `to_dataframe` 第140–152行固定上限580并删除后续列。AlphaLake按包内`ReportSize/4`动态读取，真实样本已有584项；必须保留该机制和float32源位，不按旧词典截断。
2. `np.float64`是目标列类型，配套二进制解包仍是32位浮点。转64位不能恢复源精度，更不能据此恢复财报小数。
3. 金额、每股指标、比例和日期混在同一字典；万元、元、单季度、累计及期末语义主要在注释/章节中，缺少有效期、审核范围和证据约束，不能直接成为标准表DDL。
4. 英文键存在实际问题：无形资产摊销键尾部带制表符，非流动资产处置损失英文误写为liability。业务字段继续使用AlphaLake通用标准名，不另建英文别名或原始编号接口。
5. 词典不能证明零值表示真实零，也不能识别受限资金、关联方融资性质或到期债务的附注拆分；这些缺口仍须显式补充和核验。
