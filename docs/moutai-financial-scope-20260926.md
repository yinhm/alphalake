# 茅台金融兼营口径：TDX可计算分量与估值边界

本轮范围：贵州茅台一家公司，2025H1、2025年末、2026H1，信息截止2026-09-26 08:00 UTC；当前主库只读查询。结论是**已把笼统的“兼营金融不适用”推进为可计算分量与具体缺口，但尚未批准原生Web估值**。没有把茅台整体认定为金融企业，也没有新增PDF数值到模型、扩大现有代理白名单或修改前端。

2025H1经营收益诊断606.6037亿元；三期组成TTM为1098.0907亿元。公式为：

`营业利润 − 金融净利息及手续费 + 财务费用项下利息费用 − 财务费用项下利息收入 − 投资收益 − 公允价值变动收益 − 信用减值收益 − 资产处置收益`。

金融业务利息与财务费用里的利息是两套标准字段，不能互相替换。整体剔除信用减值和资产处置仍是诊断政策，可能移除非金融业务损益；金融管理费、税项及内部抵销也未完整拆开。2025H1资产池因其他债权投资源零歧义明确返回缺项，未以另外两期齐全推断该期为零。

“一年内到期非流动资产”并非通用投资字段；本样本2026H1原文第59页证实本期及2025年末比较列均为到期债权投资，才支持此处的样本解释。诊断工具不把这一解释推广到其他公司。

## 现金差额有了原文解释

已归档的[2026H1原文](../internal/ingest/testdata/moutai-valuation-2026/1225475868.pdf)第82页现金构成：库存现金0.000095亿元、可支付银行存款441.1810367368亿元、其他货币资金0.0074680407亿元、可支付央行款项8.3263774776亿元、存放同业款项1398.5959775711亿元，精确相加为1848.1109548262亿元。TDX现金余额为1848.11094016亿元，差异为源精度。

货币资金只有535.1879897908亿元（TDX为535.18798848亿元）。第53页另将存放同业、拆出资金及减值合并为资产负债表“拆出资金”；第82页还披露83.5533725297亿元法定存款准备金不属于现金及现金等价物。**不能相加“现金等价物＋拆出资金”，也不能把两个现金口径的差额解释为一种受限资金。** 本轮重提取现金五个分量并验证精确求和，不只是检查文件哈希。

## 剩余阻碍具体是什么

1. **受限与必要经营资金**：TDX总额未提供本轮所需的完整拆分。法定准备金是金融业务必要资产，不是可立即分配的闲钱；全额剔除与以持续经营价值计量也不是同一政策。原文受限资产账面口径与现金流口径自身还有差异，不能混用。
2. **金融子公司的权益与归属**：合并数据不等于财务公司独立数据。既有风险报告2026H1列示财务公司权益约119.41亿元、税前利润8.02亿元；而TDX合并金融净利息及手续费约14.9804亿元。不能用后一项替代前者，亦不能把合并金融资产全部乘51%。少数股东权益还包含销售公司等主体，不存在仅靠合并总额唯一解出的拆分。
3. **税、费用与投入资本配套**：上述收益公式尚未分摊金融费用和税，资产池又含贷款和债券。若将1753.19亿元直接塞进原SQL的现金列，引擎还会用它扣减投入资本，制造新的口径问题。
4. **行情（后续已解决）**：[100家验收](valuation-100-market-20260926.md)已补齐茅台报告期价格及市值代理；财务范围问题仍独立保留。

这不是“TDX完全没有数据”，而是**合并总额无法唯一反推出子公司和内部抵销明细**。已有标准字段支持资产负债配对与收益诊断，但未支持完整归母股权桥接。

## 下一步方案及批准边界

达摩达兰对金融企业强调直接估计股权价值，因为债务、再投资和现金的含义不同于工商企业；依据为[《Valuing Financial Service Firms》](https://stern.nyu.edu/~adamodar/pdfiles/papers/finfirm09.pdf)第14页起。对本样本，优先方案是白酒经营DCF与金融子公司股权分开，再处理内部抵销和少数股东，而非把茅台整个企业切到银行模型。

- 完整分部路线需要财务公司独立权益/利润、监管资本及内部往来。既有原文可作核验，但按当前TDX-only取数约束，不能自动导入这些PDF值。没有发现TDX合并三表能提供其独立范围；若采用结构化补充来源，须先明确批准来源和契约。
- 若继续TDX-only，可研究“合并金融资产净额按账面计价”的独立股权桥接代理，显式选择受限/经营资金处理、少数股东计价及配套经营收益政策。它需要单独的净资产桥接位置，不能冒充现金列或直接套现有安克政策。以上三组财务选择尚未获批，本轮仅交付可复算底稿，不产生茅台估值数值。

## 复验与实际交付

新增工具只做诊断，没有数据库写入：

```sh
./alphalake financial-statements workspace/alphalake.duckdb 600519 \
  --period 2026-06-30 --as-of 2026-09-26T08:00:00Z --include-evidence \
  > workspace/derived/moutai-scope/2026-06-30.json
PYTHONPATH=valuation/backend .venv/bin/python -m tools.derive_financial_scope \
  workspace/derived/moutai-scope/2026-06-30.json
PYTHONPATH=valuation/backend .venv/bin/python -m tools.verify_moutai_financial_scope \
  workspace/derived/moutai-scope/2026-06-30.json
```

后一个命令依赖`pypdf`，复用既有冻结PDF、定位台账及完整字段目录；PDF不参与前一个命令的计算。2025年末和2026H1各21项、2025H1利润分量10项，共52项完成原文重提取和源精度核对。允许目录单位下的直接float32编码或万元先保留两位再编码，并记录具体匹配方式和金额差；这不恢复源值丢失的小数，也不等于完整分部语义审核。2025H1另10项可用资产值没有本轮对应原文定位，明确列为未核验。

真实负向验证将存款负债缩小1000倍，原文核对拒绝；单位/时点/证券污染、单季混入累计、非有限值和存款源零由单元测试锁定。单元测试随既有后端CI执行；本轮主库快照的PDF复验为上述显式本地命令，不声称CI拥有动态workspace。动态输入、输出及收据均留在`workspace/derived/moutai-scope/`。

验收：相关Python回归3项通过，`go test -p 1 ./...`及`go build ./cmd/alphalake`通过；Go未修改，无需格式调整。`git diff --check`及文档相对链接检查通过。主库和已发布SQLite哈希与上一轮发布收据一致；临时构建程序已删除，没有新增数据库副本。
