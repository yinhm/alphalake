# ADR023：未映射来源差异不阻断等价标准报表

状态：按当前数据分层约定实施；不调整估值方法、零值政策或默认行业。

同一归档中相同证券、报告期、市场标记及记录长度的重复行，原规则因任一来源位置不同而拒绝整家公司。真实4个期间显示：仅未审核期间口径的来源股利支付率不同，标准报表字段全部位级相同。该比率没有标准映射，整行拒绝无助于保证已审核字段正确。

- 只忽略官方目录中有明确定义、未审核、无名称歧义且当前数据库没有映射的来源比率位置差异；判断由完整目录和实际映射驱动，不建估值字段白名单。
- 所有其他元数据及来源位置仍须一致；金额、公告日期及其他元数据、身份、记录长度、市场标记、已映射字段或未知位置不同继续整条拒绝。不能仅因某字段暂未被当前估值消费就忽略它。
- 原ZIP及全部轻量行定位保留。等价标准字段按既有单行规则物化，未审核字段不选值、不写标准事实；独立来源核验保留不同值及哈希。同步与库重建采用同一排除规则。
- 某位置后来加入映射时，自动退出排除集合，须重新核验原重复记录；来源与规则变更应重同步、重算和重导出，不能沿用旧准入结果。

独立核验必须逐归档版本绑定哈希、原文行序、代码和市场标记；不同版本不能按某一个版本的行序互相读取。哈希与位比较证明本规则所需的等价边界，不证明来源比率的经济口径。

回归包括未映射比率差异可通过、新增映射后恢复拒绝、金额与市场标记差异继续拒绝。真实比较及失败核验记录放`workspace/derived/remaining-financial-gaps/`，当前发布范围和剩余缺项维护于[项目状态](../implementation-status.md)。
