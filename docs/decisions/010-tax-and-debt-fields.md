# ADR 010——税项、利息、债务明细与万元换算

状态：已接受，2026-09-06。扩展 ADR 009 的映射与单位规则，标准字段由 29 个增加到 38 个。

迁移039后，FN86、FN305、FN306、FN83、FN82、FN301的累计人民币元映射有效期扩至2024-06-30，依据[安克三期原文与18个源值](../../internal/ingest/testdata/anker-cash-history-2024/README.md)。零值歧义与原倍率规则不变；这不是逐公司历史语义审核或全市场估值适用性证明。主库发布状态与代码迁移版本分别报告。

## 单位与精度

迁移 019 增加 `provider_field.value_multiplier`，默认 1，FN439/FN581 为 10000。物化先将源值乘以倍率，再转 DECIMAL(38,10)，标准单位统一为 CNY。倍率仅接受已支持的 1、10000；未知倍率拒绝并记录 `canonical_scale_unknown`，不保留失去依据的旧标准事实。原始 float32 位不变。

两项万元字段在本样本中已舍入至 0.01 万元，无法恢复百元内的原始精度；不能将财报金额直接转 float32 后与源位比较，也不能只改单位标签而漏乘倍率。测试保留 PDF 原值、源编码值和倍率三者，并分别核对。

FN581也可能用零表示未单列补充资料，加入 `provider_zero_ambiguous` 规则。[中邮科技2025年报](../../valuation/research/tdx-growth-expanded/depreciation-review-688648/evidence.json)实证使用权资产折旧合并在FN136对应行，FN581为零但实际折旧非零；不能将零值只解释为无业务或未披露全部折旧。实际为零的值同样保守留下缺口；源证据不删除。

## EBIT 与债务的使用边界

新增字段允许从同一证券、报告期、源版本和公告的利润总额及利息费用计算基础的税前息前收益；这仍包含可能需要剔除的非经营损益，不直接等于达摩达兰估值中的经调整经营 EBIT。财务费用包含汇兑等项目，不能替代利息费用；利息收入保留为单独调整证据。没有把 TDX FN207 直接映射成已审核的估值 EBIT，也没有自动确定边际税率。

[海航2021/2022历史研究反例](../../valuation/research/tdx-zero-calibration/earnings-review/README.md)进一步明确：两期半年主表利息行空白、FN305/FN306为零，但附注有非零金额；2021年报FN305匹配主表借款利息，未包含附注单列租赁利息，下一年比较列又包含两者。源零不代表经济零，同名字段跨期也须核对包含范围。本补证不扩展标准映射有效期、不以PDF覆盖TDX、不将过去主表缺项直接外推为所有公司的现期缺数。

债券和非流动租赁负债补入后，仍需从附注拆分一年内到期的借款、债券、租赁及其他负债，避免漏项或重复相加。当前报表余额不自动等于估值所需债务市场价值。本轮不生成未经核实的总债务或净债务。

## 升级与验收

执行 `alphalake init DB` 后再 `alphalake materialize-fundamentals DB`。物化版本为 `pit-fundamental-v4`、标准化规则为 `tdx-float32-decimal-v2`，从本地源事实重建，无需重下财务包。

验收覆盖原文重提取、16 个源值、倍率转换、税项累计期间、非零债券、公告/PIT、错误倍率拒绝及恢复、零值折旧诊断、迁移及幂等重放。移除万元换算后，真实租赁负债回归按预期失败。


## 非流动债券与一年内到期部分

[2021/2022研究补证](../../valuation/research/tdx-capital-inputs/five-debt/README.md)明确FN56对应样本主表的非流动应付债券行，不能独自代表全部未偿债券。湖北宜化2021年末FN56为零，但FN52对应附注明确包含2,000万元一年内到期应付债券；既不能由FN56零推断没有债券，也不能在已计FN52总额后再次加入该债券。FN52另含长期应付款、租赁及利息，需按研究/估值口径分别分类。本补证不扩展标准映射有效期或批量确认源零，也不声称全部公司的FN52都已完成分类。
