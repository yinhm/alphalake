# ADR 019：按报表成批审核标准财务字段

## 决策

源解析已完整覆盖584位置，但上一轮仅81项有标准审核。本轮继续使用同一源目录，以已归档的合并资产负债表、利润表、现金流量表为单位核验，不为每项需求另写解析器。标准目录增加64项至145项；新映射从2025-01-01起有效，单位统一人民币元，全部拒绝无法区分缺失与真实零的源零。

证据分母是安克创新一家公司的2025H1、2025FY、2026H1三份原报告。本次主表候选盘点194个源位置（193个业务名称，其中贷款有同名歧义），64项获准，其他130位置保留未定位、源零、附表待审或期间不适用的结果。它不是全462项定义或全市场公司的逐项原文验收。

| 分组 | 新增数 | 主要内容 |
| --- | ---: | --- |
| 资产负债表 | 19 | 投资性房地产、使用权资产、长期待摊费用、衍生资产/负债、应付票据、实收资本、留存收益及其他余额 |
| 利润表 | 17 | 累计收入/成本、销售/管理费用、税金及附加、联营合营投资收益、营业外收支、综合收益等 |
| 现金流量表 | 28 | 客户回款、采购/职工支付、经营/投资/筹资流入流出、借还款、股利及利息、汇率影响等 |

完整通用名称、源映射、逐报告原文行与源位见[证据](../../internal/ingest/testdata/statement-expansion-2026/evidence.json)，包括192个当期位置：188项非零逐位匹配、4项原文横线且源零；另核对192个比较列单元格，但不将比较列作为本期来源。旧准入有效期及旧事实不扩大或重写。

## 语义边界

- 新`retained_earnings`表示未分配利润；累计营业利润仍是`operating_profit_cumulative`，两者不得混淆。
- `paid_in_capital`是账面资本金额，单位元；`total_shares`是股数，不因两者数值近似而互换。
- `revenue_cumulative`与`total_operating_revenue`分别保留营业收入与营业总收入；本公司数值相同不证明金融兼营公司也相同。
- 资产减值收益采用当前利润表有符号金额，旧格式资产减值损失源零仍未获新批准；不得将旧损失口径与新收益口径固定叠加。
- 使用权资产、投资性房地产及衍生金融工具只是合并报表余额。经营/非经营分类、租赁调整和股权加回须另有政策，不能由新增余额自动决定。
- 股利及利息支付的合计不当作纯利息，借款收到现金不当作债务期末余额；累计现金流不替换单季或已推导TTM。
- 来源期初现金余额修正为`opening_instant`，从普通经营窗口中排除；不以报告期末标记期初余额。现金流补充表的现金变动即便与主表数值匹配，也不能仅凭主表同值批准附表取数。

## 实现与校验

schema48只维护当前定义；完整目录版本为`tdx-financial-20260919-v2`，共145项标准定义及审核映射。物化函数支持显式源字段批次，候选、计数及撤除使用同一筛选，限定批次不刷新身份或公告关联。无字段限制的日常物化仍处理全部已审核映射。

原PDF和裁剪包复用已有归档，不重复下载。校验工具放在`valuation/backend/tools/verify_tdx_statement_expansion.py`，证据目录只有数据与说明；不引入依赖。新增离线CI步骤强制执行三份PDF重提取和源位比较。

真实隔离链复用两公司六期原始包与公告关联：恢复64项后新增670条事实、98项拒绝，旧810条事实保持不变；这不是670项原文金额核验。安克三期188项非零全部取得标准事实，4项歧义零不物化。标准估值出口64个新窗口中61完整、3缺项；TTM按源值复算并以4 ULP检查聚合误差，不依赖float64精确相等。中国次日零点边界、错倍率整批撤除、恢复重建、重开后零变更重放均有断言。

原文金额、源位、倍率、期间或把横线伪造成零的篡改均被拒绝。早期年报/季度/更正/TTM固定样本继续固定其原映射分母，新字段由本轮完整标准链验收，不把历史覆盖数改成新样本声明。

本轮不更改达摩达兰公式、增长、利润率、资本倍率或WACC。新增标准供给不等于缺失的经营资本分类和FCFF已经闭合。

## 本地库接入结果

[接入收据](../acceptance/statement-expansion-20260919.json)记录了财务主库和参考库的schema48接入及最新备份。主库对2,084,416个候选新增1,657,953条事实，426,463项均因源零歧义拒绝；原2,048,273条事实及无关表内容摘要不变，现有标准事实总数3,706,226。新增事实覆盖2025Q1至2026H1六个报告期，逐期证券数见收据；这些是本地主库批量供给数量，不是新增逐公司原文审计数量。

第一次64字段一起写入在1GB限制下发生OOM，事实写入事务回滚，运行5379的失败信息保留。随后以同样1GB、单线程、每批8字段完成8批；运行5380–5387因包含明确拒绝项，状态均为partial，不报全候选成功。没有扩展身份或公告关联，也不重复追加原始包。

重开后在2026-09-19信息截止下比较安克和苏泊尔：原81字段的事实、窗口、血缘及补充导出内容逐项不变；新64字段分别有61、51个完整窗口。使用现有已审核资产政策、在原输入上绑定一次相同证据后，仅替换为扩充字段的输入，两份完整引擎报告均不变。这是新供给的计算回归，不是重新提出目标价或证明估值准确度提高。

最初尝试把当前主库输入送入更早的历史政策快照，曾分别因WACC截止不一致、后来原文审核时间超出旧截止而被拒绝；没有放宽检查。正式比较采用两份2026-09-19同截止的前后导出与已审核政策。历史系统审核时点的既有边界继续保留。

`go test ./...`、CLI构建、`go vet ./...`及新增真实窗口回归通过；Python对应7项回归通过，无跳过，使用既有Python3.12/pypdf，CI有独立原文校验步骤。本轮不改依赖。一次性接入工具和临时种子库已删除，备份在重开及完整比较后轮转，保留最新一份。
