# ADR 018：源字段编号与标准财务消费分离

## 决策

FN是TDX的数据源标识，不是应用财务字段。标准事实已有`canonical_field`，但旧导出将FN放入`field`，TTM与估值又按FN取数，导致语义标准化未贯穿消费链。本次修正业务契约，不只改显示名；不改变达摩达兰公式或公司政策的经济假设。

| 层级 | 职责与字段约定 |
| --- | --- |
| 原始归档、`provider_fact` | 原件、源字段编号、float32位、下载版本与身份；保留未审核和歧义数据 |
| `provider_field`与物化 | 来源特有映射、倍率、有效期、零值判定；核对单位、期间及标准定义，不匹配拒绝并撤除失效标准事实 |
| `fundamental.field` | 独立通用字段目录：字段名、单位、数值类型、`instant/quarter/ytd`期间语义；新增语义须审核后迁移 |
| `fundamental.fact` | 通用字段、数值、期间、范围及证据血缘；`source_provider_field`仅追溯，不作业务取数键 |
| 年度／TTM | 读取标准目录与标准事实，按通用期间语义计算；不读取源映射目录决定算法，不按FN分支；缺期保留NULL |
| 查询导出、准入、估值及政策 | `field`使用通用名称，例如`long_lived_asset_disposal_cash`；FN仅允许出现在来源证据中 |

业务查询、计算、政策及对外API/CLI参数、输出、文档和说明必须使用标准目录名称，禁止以源编号代替或另设编号别名。源编号仅在必要的源处理、校验、独立来源证据和明确标注的源维护操作中出现；不默认向业务使用者暴露，也不要求其理解编号。原始证据、历史迁移及冻结归档不改写。

当前标准目录81项。`revenue`等原单季度标准字段名称不改，目录明确`quarter`；累计营业利润仍为`operating_profit_cumulative`，不与单季度营业利润或留存收益混淆。来源编码及报表组合范围核验继续保留，独立目录不意味着所有字段都适用于每家公司。

## 数据与契约迁移

迁移046明确原八项单季度映射为`quarter`、股本为`instant`，建立通用目录，并将非legacy股本标准事实的旧Q1/H1/Q3/FY标签改为`instant`。金额、股数、源位、事实ID、公告与原始证据不改。已有错误来源映射不能单独改写标准期间定义。

`export-valuation`升级为`alphalake-valuation-v2`，就绪度为`alphalake-readiness-v2`。事实及窗口的`field`等于`canonical_field`；事实另保留`source`、`source_provider_field`。标准窗口只将源事实ID用于血缘，应用不通过源编号选择分量。API拒绝旧v1或把FN冒充v2字段；只读财务出口要求schema46，不能静默迁移原库。

旧冻结证据不重写。显式迁移请求：

```bash
PYTHONPATH=valuation/backend python -m tools.migrate_standard_contract old-request.json new-request.json
```

工具仅依据旧请求已经携带的标准字段名转换键及股本期间标签，同步已审核资产政策的业务字段；缺失或歧义拒绝。新文件独占创建并输出前后哈希，不覆写旧请求，也不直接迁移带run ID的完整运行。压缩归档在复验工具内先核对原哈希、解压，再显式迁移。源编码与标准含义已矛盾的输入不能靠重命名修复。

完整旧运行及索引仍保留；v1请求需要显式转换后重新估值，生成新run ID和增量索引。历史运行的严格重放可使用原实现版本，不能把旧run ID移植给新契约。当前可执行审核政策示例已改为通用字段；经济政策ID不变，新输入契约及引擎签名区分本次迁移。

## 验证与适用边界

- 标准TTM测试移除整个源映射目录、更换来源与源字段编号后仍取得相同结果；期间、缺口及更正血缘回归保留。
- 真实处置现金链将源期间映射篡改为单季度，必须拒绝并删除事实；恢复累计语义后重建，其他字段保持不变。
- 应用契约拒绝源编号，旧快照显式迁移后复算；来源编号变化不改变DCF。应用目录/API/统一入口有禁止FN依赖的回归检查。
- 主库发布须对全部既有表比较，只允许046定义的目录和股本期间标签变化；财务数值与来源证据不变。两公司报告仅桥接分量键从源编号改为通用名称，其余报告内容逐项比较。
- 简化研究的共享源适配集中解码、披露日期、字段映射和单位换算；金融兼营四字段按已审核映射从万元转元。经营窗口、收入（含多年增长及渐变利润率预测）、资本开支及现金流计算使用通用名称；替换源编号后经营预测不变，直接传FN给经营窗口拒绝。冻结源证据保持原编号，新运行收据包含适配器代码哈希。

源解析、物化校验、历史源位取证仍可使用源编号。已授权的简化TDX回溯通过独立源适配器提供通用字段，经营计算不得直接使用FN；源证据序列化保留原编号，不冒充标准事实或严格PIT。共享经营窗口、收入预测、在建工程分组及研发历史/预测已转用通用字段，原文核验中的经济计算及当前文档复验示例也已迁移，见[收口核查](../standard-fields-consumption-audit-20260918.md)。冻结研究文件与历史迁移中的FN不批量替换。该修正不增加新财务字段、不补齐未分类经营资本，也不证明估值预测准确度提高。

研发链路以`research_and_development_expense`取数，冻结单字段源位由适配器解码；经济计算不构造FN键。更换源编号后整份研发利润试验输出不变；1,800个真实冻结候选复算与原结果完全相同，候选未通过的结论保留。研发源零歧义、缺年、时点隔离和金额篡改回归通过，不扩大字段历史适用范围或生产准入。

再投资共享分量、营运现金预测/分项诊断及经营现金流范围检查改用通用字段和期间语义；研究适配目录42项，与既有生产映射一致。源零歧义继续阻断，万元字段在适配层换算。旧研究源分量和金融信号的归档格式由显式序列化保留（金融信号仍以源编码单位展示），不回流作为经营计算键；该兼容格式不是生产标准事实契约。新增原始编号拒绝、换编号结果不变和元字段不截断源精度的回归。

债务小计、账面资本现金扣减情景、营运余额比例候选和利息源零训练过滤已按通用字段计算；租赁负债倍率归源适配器管理，不在应用重复乘万元倍率。1,800个资本盘点位置与原冻结结果一致，六家两年度债务/资本核验保留缺口、现金扣减符号差异和历史重述。经营回溯模块不再提供原始`value`解码器；源位核验直接导入`tdx_research_source.source_value`，研究窗口只接受通用字段。

原文核验工具也区分证据与计算：安克资本分量先按源编号逐位核对，再将金额字典转换为通用字段计算折旧、营运现金和再投资小计；保留原冻结Decimal表示，不改写2022年冲突。中邮折旧现金桥接、研报利润/资本开支比较及经营异常诊断的金额计算改用通用字段；FN仅留位比较、原文映射与源证据。六份当前文档复验片段和全仓库应用边界已完成核查；源验证中的编号保留范围见收口记录。
