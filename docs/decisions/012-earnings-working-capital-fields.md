# 012：非经营损益与营运资本组成字段

状态：已实现，迁移 022；2026-09-06。

本批把安克、茅台估值中可由 TDX 供给的项目推进到标准层，而非继续增加 PDF 专用计算。审核字段由 38 增至 45，字段有效期从 2025-01-01 起。

| FN | 标准字段 | 含义 | 期间/单位 |
| --- | --- | --- | --- |
| FN12 | prepayments | 预付款项 | instant / CNY 元 |
| FN13 | other_receivables | 其他应收款账面列示金额 | instant / CNY 元 |
| FN46 | payroll_payable | 应付职工薪酬 | instant / CNY 元 |
| FN47 | taxes_payable | 应交税费 | instant / CNY 元 |
| FN82 | fair_value_change_income | 公允价值变动收益 | 年初累计 / CNY 元 |
| FN83 | investment_income | 投资收益 | 年初累计 / CNY 元 |
| FN301 | asset_disposal_income | 资产处置收益 | 年初累计 / CNY 元 |

四个余额名称与 [TDX 官方目录](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)一致。该在线页缺少 FN74–97 段，不能仅凭目录宣称 FN82/FN83 已审核；本批三个损益字段均由两家公司合并利润表本期列及三个原始 gpcw 包逐位核对。数值搜索只用于发现候选，正式证据仍要求原文项目、章节、列序及期间相符，不能用一次数值碰巧相等定义字段。

证据复用已归档完整财报：安克 2025H1/FY2025/2026H1 七字段各三期；茅台三个损益字段各三期、四个余额字段 FY2025/2026H1。合计 38 个金额，见 [证据清单](../../internal/ingest/testdata/earnings-working-capital-2026/values.csv)。父验证器先逐项重提取 PDF，再核验本清单与源 float32 位，Go 独立解码同一源包并核对 PDF 哈希。没有新增 PDF 解析特例，也没有将验证范围扩大宣称为全市场逐公司对账。

所有倍率为 1，不恢复 float32 丢失的小数。损益流量沿用 Q1/H1/9M/FY 和既有 TTM 规则，与现金流量表的调节项、收现金额区别对待。其他应收款是列示账面余额，不能直接认定全部属于经营营运资本；应交税费包括多种税，不能替代应交所得税。投资收益、公允价值及资产处置收益仍需在估值政策层判断剔除哪些分量，不自动改写成经调整 EBIT。

迁移仅增加映射，已有 38 字段的规则不变，不提升 materializer 版本来制造全库更新。升级后运行 `materialize-fundamentals`：从已有源事实发现新增映射。真实两公司测试构造 v21 映射状态，先导入形成 432 条事实，再执行生产迁移及物化，新增 84 条且旧事实零更新；关闭重开、重放及 PIT 检查保留。将七个倍率改成 -1 会撤销 84 条，恢复后从原始证据重建 84 条。

估值链对应分量切换为标准查询优先，PDF 继续独立核验。已配置字段缺失或冲突必须失败，禁止退回原 PDF 金额。新字段本身没有解决财务公司去合并、经营营运资本完整归因或借款/租赁到期附注拆分。

后续按需求继续审核：交易性金融资产及现金流收支/调节项可优先从现有台账找候选；研发费用与更多历史期间需补字段和原文证据。候选尚不计入 45 个完成数量，不把“已有源字段”写成“已标准化”。
