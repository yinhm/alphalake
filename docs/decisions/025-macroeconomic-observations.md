# ADR025：宏观统计独立成域，共用来源发布版本

2026-10-21接受。用户授权调研并接入重要定期宏观数据；当前业务仍为沪深非金融公司的条件估值，不增加预测参数自动选择器。

## 决策

增加`macro.series`与`macro.observation`，纳入同一权威DuckDB，schema59。全国经济统计不是公司报表，也不等同于达摩达兰行业／风险估计；不塞入`fundamental`或复制为公司事实。国债曲线与汇率继续归`market`，已有达摩达兰数据继续归`reference`，不为宏观查询再存一份。

- `series`保存稳定业务名称、来源数据集、地域、频率、期间基础、规范单位、价格基础、季调状态和经济定义；没有来源编码作为业务名称。
- `observation`只保存系列／期间／版本、规范值、明确缺项状态和必要原文定位。共享取得时间、原文哈希和发布时间通过`meta.dataset_release`与归档关系引用，不逐点复制源文件／BLOB或大JSON。
- 沿已有归档、采集运行、版本和检查点机制原子发布。原文、解析实现及归一化决定版本；网络重试代码不成为财务或宏观数值失效依据。DuckDB不支持跨schema外键，发布事务核对发布版本、运行与归档关系，同域系列外键由数据库约束。
- 新版保留旧观测；同一原文／解释重复导入不新增值。当前查询逐系列／期间选较新来源版本：已知发布时间优先用于版本排序，未知时用来源快照的最新统计期，其后用记录时间。后下载的旧版本不因此胜出。显式缺项覆盖旧值时仍为NULL，不复活旧数字。

## 边界

当前接正式统计观测；政府预测、机构预测和市场预期不能冒充实际值。期间、发布时间与首次取得分别保存，历史表中的旧年度值仍属本次取得的修订版本，不宣称严格PIT。当前可用的宏观观测不因无法证明早年可用时间而拒绝。

GDP现价金额／实际增速、PMI指数点／百分比、百分比／百分点、单月／累计／余额、名义／实际及季调／未说明分别建明确系列。保留合法零、负值和未列报；未来占位月份不补零。不用分项机械相加、累计同比作差、不同口径金额重算官方增速。

源文件按`nbs`、`pbc`、`mof`平铺归档，同哈希版本复用；目录与正文分别留证。首次接入先在副本上显式升级58→59，核对原有全部表内容签名；验收、重开后切换，清理临时回滚副本并留收据。正常入口不静默兼容旧库。

宏观资料供研究和显式假设审阅，不自动修改增长、利润率、税率、终值或WACC。SQLite不复制宏观库；本轮不改valuation引擎、网页默认或财务发布快照。指标来源、用途、手工刷新及查询见[宏观数据指南](../guides/macro-data.md)。
