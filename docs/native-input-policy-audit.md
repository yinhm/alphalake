# 原生网页输入与政策审计

本轮核查对象为原生`POST /api/valuation/from-database`，不是将历史CLI研究政策推广到网页。本文件说明实际实现，不为既有默认值补造达摩达兰出处或公司证据。用户仍可在原页面手工修改。

## 实际调用链

`api/database.py::from_database` → SQLite准入与`fetch_valuation_company` → `_db_record_to_company_input` → `engine/orchestrator.py::run_full_valuation` → 六个原模块 → 原序列化与可编辑会话。

显式政策CLI经`tools/company_valuation.py`、`data_sources/alphalake.py`构造另一个明确的输入契约，再进入同一共享引擎。共享公式不保证输入/估值相同；比较时先固定政策、参考、财务、股本和时点。

## 当前输入来源

| 输入 | 原生网页初始行为 | 性质与不足 |
|---|---|---|
| 收入、报告EBIT、研发、税费、股本 | SQLite宽表，由TDX标准事实供应；模型按实际完整窗口使用 | 报告EBIT不自动等于完整调整后经营收益；缺研发年度不补零 |
| 现金、长期投资 | 已批准已知组成的账面代理，配套警告保留 | 受限、经营属性和非经营收益配套可能不完整 |
| 市值 | 合格A股价格×报告期总股本；多股类沿用显式代理 | 不等于B/H各类别价格及汇率加总 |
| 第一年增长 | `revenue_growth_next_year`未填时为0 | 模型默认，不是TDX预测，也不是证明公司将零增长 |
| 第二至第五年增长 | 未填时沿用第一年 | 同为假设，不是估计好的五年增长 |
| 初始利润率 | 未填时用调整后EBIT/收入 | 基年衍生；是否可持续需要经营判断 |
| 目标利润率 | 未填时沿用初始利润率 | 恒定利润率假设，不自动收敛至行业合理水平 |
| 销售/资本倍率 | 未填时高增长期2.5，稳定期沿用 | 代码默认；没有本轮公司审核或普适参数的来源认证 |
| 初始有效税率 | 最近完整年度所得税费用/利润总额，符合约束才供给 | 会计有效税率，不是现金税或未来边际税 |
| 预测税率 | 原模型高增长期有效税率、后续向边际税率过渡 | 边际税来自绑定参考；缺国家税或源歧义拒绝自动选择，不再填21% |
| 无风险利率 | 请求提供，原请求默认0.0425 | 验收显式使用0.0425，不冒称人民币当前市场利率 |
| 行业、Beta、ERP等 | 主库发布→SQLite参考快照→会话绑定 | US口径保留；缺少公司行业/国家选择时拒绝，用户显式选择另层留痕 |
| 终值增长 | 默认关联无风险利率，显式覆盖按原引擎规则 | 条件假设，不是长期中国增长预测 |
| 终值WACC/ROIC | 默认WACC为无风险利率+ERP；ROIC等于该WACC | 无持续超额回报的默认情景，不是公司已测定资本回报 |
| 期权、困境等 | 原默认与用户编辑 | 未披露输入不能反向证明没有稀释或困境风险 |

默认解析具体见`engine/module_4_dcf.py`与`engine/data_dictionary.py`。该审计轮没有改变公式和默认参数；后续[参考桥接核对](native-reference-bridge.md)发现并修正国家ERP重复计数，原生默认条件值会变化，必须按实际输入区分纠错与参考版本更新。

## 两条参考消费路径的边界

主库已补US/Global行业输入和国家税率，原生网页通过SQLite v7绑定参考发布与内容签名，详见[参考桥接](native-reference-bridge.md)。US不改成Global，请求无风险利率仍由用户决定。

显式政策CLI与原生网页复用主库来源，但选择的数据集和估值政策不同，不保证相同数值。原网页不再读取workspace散落工作簿；同步主库后仍需导出并发布SQLite。已有会话保留其创建时参考，PATCH不偷偷换成新发布。原引擎可选方法中的冻结参考单列版本哈希，不声称已更新成当前市场数据。

## 已完成的修复与历史范围

历史审计中100家公司87家财务准入；003816中国广核未匹配公司行业，原实现使用Advertising占位，随后已提示用户。参考桥接进一步拒绝这种默认计算，保留显式行业/国家选择，不能把占位估值计作自动准入。000917电广传媒的Advertising匹配保留，两者不能混为同一问题。

原PATCH接口改选行业/国家只更新名称、未同步参考数值；已修正为加载对应参考再重算。用户显式覆盖优先，无风险利率保留用户值，有效税率编辑进入实际模型；未知选择拒绝且不改旧会话。回归验证Beta、ERP和有效税率实际进入输入。该历史审计轮原前端文件、公式和初始默认数值未改，87家初始条件值保持一致；后续ERP纠错的影响独立记录在参考桥接文档，不能把历史不变结论沿用到当前程序。

## 下一轮经济输入优先级

1. 将已提示的未匹配行业变为可审阅的行业映射；明确国家/行业/参考版本与默认假设，保持原页面可编辑。
2. 无风险利率、币种、ERP、Beta、资本结构组成统一可追溯WACC输入，不能把主库有参考数据称为整条供给已完成。
3. 对增长、利润率、资本效率进行联合政策审阅，以通用公司能力及既有基线为依据；不从股价反推一组“更准确”参数。
4. 资产加回和非经营收益剔除配套审计；优先解决对估值影响大且可通用的口径。

上述为明确待办，不是本轮已改变的生产政策。当前交付是“数据和已批准代理准备好、原模型可复现、用户可编辑”的条件估值，不是无人审核的自动投资结论。
