# 公司与行业资本倍率核对

本轮复用当前12家公司、2026H1财务及既有信息/参考快照，不采集早年数据，不改变默认估值或已批准代理。沿用[资本过渡基线](native-capital-transition.md)，在已有`tools.review_native_policy`增加`capital.proxy_comparison`，不增加第二套估值入口。

## 方法及用途

达摩达兰[增长与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)允许参考公司数据和行业销售资本倍率估计再投资，同时要求关注隐含资本回报。官方[行业资本支出表](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/capex.html)的倍率标为销售收入/投入资本（LTM），不是已观测的公司项目边际效率。

新审阅固定最新完整财年及此前四年。本批为2021—2025；缺年不向更早扩展，不因缺项删除年度分母。模型历史倍率复用共享引擎：年度收入除以期末“权益＋债务−现金＋研发资产”。这仍带原有代理和范围限制，不据此宣布经济口径已闭合。

每年度并列输出模型倍率、独立SQLite倍率、独立资本范围桥接、行业倍率及模型/行业相对比值。两条历史路径不混合；缺模型年、重复年、缺资本输入、非正倍率分别标记。保留缺余额与缺研发队列原因，负资本不当作数据错误删除。

对正模型存量倍率，额外量化一个反事实：保持预测前五个投入年度的收入增量及滞后，分别除以该年度历史倍率，与实际情景再投资比较。负收入增量原样保留。此结果只说明资本倍率选择会改变多少投入，不自动采用，不是完整DCF、置信区间或未来项目效率估计。没有改变增长、终值、WACC或股权桥。

## 当前发现

同一“增长五年收敛、调整利润率持平”场景，前五年再投资差额单位为亿元；正数表示使用公司2025年存量倍率将需要更多投入：

| 公司 | 已用Global行业倍率 | 模型2025年倍率 | 2021—2025正倍率可算年度 | 前五年再投资差额 |
| --- | ---: | ---: | ---: | ---: |
| 安克创新 | 2.484 | 2.288 | 1/5 | +8.42 |
| 贵州茅台 | 0.843 | 1.419 | 1/5 | −51.97 |
| 扬农化工 | 1.087 | 0.963 | 1/5 | +2.07 |
| 天富能源 | 0.566 | 0.444 | 1/5 | +3.00 |
| 航天电器 | 2.465 | 0.768 | 1/5 | +13.89 |
| 安井食品 | 1.709 | 1.361 | 1/5 | +13.44 |

这六家模型2024年均缺`bv_debt`；不能从本次输入缺项推断TDX无数据，更不能以单年倍率冒充稳定五年水平。安克独立SQLite的2025倍率是1.861，模型是2.288，主要涉及已记录的现金专项口径差异；其独立历史2021—2023可算，模型缺整年输入，不可把独立比率直接拼入模型序列。详见[EBIT与投资范围核对](ebit-investment-scope-audit.md)。

当前结果支持**保留行业代理并明确公司偏离，不自动批准替换**。特别是航天电器行业倍率约为模型存量倍率的3.21倍，行业分类、资产范围及新增项目效率需要解释；茅台方向相反，不能统一把降低倍率称为更真实。两者均非公式错误，也不撤销现有条件估值准入。

最近年度债务缺口已核实为10项源零待审核，详见下节；后续按既有逐期间证据通道处理，并核对资本范围对倍率的影响；复用已有TDX和已归档证据，不把缺2024余额转为继续追采2018年前数据。只有可比范围及持续性有据，才另立明确政策重建估值。
