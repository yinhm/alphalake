# 财务消费分层收口核查（2026-09-18）

目标是让应用按通用财务含义取数，源编号留在解析、映射、校验和血缘层。生产库发布记录见[正式发布](standard-fields-publication-20260918.md)，设计依据见[ADR 018](decisions/018-standard-financial-consumption.md)。本轮不增加标准财务字段、不改变估值方法或经济政策。

研究适配沿用已授权的简化回溯范围，不发布标准事实，不扩大生产映射有效期，也不声称严格PIT。42项是研究实际消费字段数，81项是生产标准目录数，两者不是全市场数据覆盖率。

## 保留FN的位置

- Go源解析器、源记录结构、物化源零校验及数据库历史迁移；`materialize-fundamentals --field FN110`是限定源字段的修复操作。
- 数据库发布检查中的源映射/血缘白名单，用于限定迁移允许改变的内容。
- `tdx_research_source`中的映射、源位解码和FN314日期解释；金融业务、租赁与折旧的万元编码在适配层处理。
- 原文核验中的源位比较、精度界限、固定原文项目映射、来源版本差异和空白/源零证据。例如FN34只作为未升级为标准事实的源存量核验。
- 冻结源归档、证据标签和历史说明。经营计算模块不再转导出原始`value`解码器，源核验直接导入适配器。

上述位置按职责核查，不能仅凭搜索未出现FN就认定完成。生产应用层有编号禁用回归；研究模型有字段键检查，实际输出另由真实重放和篡改测试验证。
