# 六项余额历史供给

本轮复用 `extend-capital-history`，补齐流动资产、流动负债、应收账款、存货、应付账款及交易性金融资产的历史映射。依据既有官方财务目录审核：六项均为元、倍率1、期末余额。标准字段仍为346个，审核区间365→371；已有19项历史规则和2025年以后的规则不变，历史源零仍拒绝。

这解决映射有效期造成的供给缺口，不批准非现金营运资本分类，也不把历史余额差额直接作为FCFF的营运资本变动。公告未关联、未单列和混合范围继续单独处理。
