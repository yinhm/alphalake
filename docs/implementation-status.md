## 数据供给现状与保留边界

1. **资本效率的公司经济依据。** 已实现最近连续三年公司资本代理的完整DCF对照，单独量化选择公司/行业代理造成的估值影响；当前v3直接使用共享引擎的显式合并账面权益，匹配合并收入，不再另加一次少数股权；现金/投资等经济适用依据仍需判断，不继续扩展早年历史。现有五分量债务代理、现金/长期投资代理、研发资本化和少数股权范围必须分别说明。
2. **字段级零值规则。** 官方定义、全局分布和小样本核验明确后统一放行，不再逐公司重复审批。应付债券上轮已完成，此前新增17项历史资本字段及4项投资/研发字段，主库新增139,373个标准零值，100家SQLite新增4,946个零值、611个财务输入单元格由缺失变为有值；既有非空值不变。六家2024年十项债务源零已全部闭合。8项补充资料字段当前仍保留原规则；审核已区分6项季度披露缺口与2项年度/半年也存在的合并列示反例，尚未发布分期间零策略，其他权益工具投资待补非零样本核验。航天电器长期应付款仍缺可靠计息分拆，与源零放行分别处理。见[字段扫描与发布](guides/tdx-offline-sync.md#字段零值审核)及[资本效率](valuation/capital-efficiency.md)。
3. **经营预测适用性。** 保持达摩达兰公式，以现有公司证据校准增长、利润率和再投资；只做有决策价值的定向取证。统一情景可重复，不代表自动假设已通过预测有效性认证。
4. **供给与运维。** 按通用缺口类别推进研发披露、身份/源零审核；维持固定样本发布验收、性能门槛和来源新鲜度说明。线上完整更新及自动调度尚未作为当前交付验收，不先扩建调度平台。

## 不应混淆

- 已批准现金、长期投资和A股价格×总股本代理可用于条件估值，但不代表完整资产范围或真实分股类市值。

- 行业参考齐备不等于公司市场WACC已自动确定；默认US参考与显式人民币政策分别展示。
- 多市场、金融专项模型、严格系统时点回放及个案长期深挖暂不推进。既有来源、失败结果和审核证据保留。
