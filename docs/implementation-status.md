## 参考与分类

既有申万事实与Damodaran参考分开，准确发行人其他股类关联优先于行业代理；不得按行业名称或地域静默换口径。分类／新增关联和多市场当前暂停，118家待定不自动归类。世盟Transportation/China等已批准显式条件仍可用；盛龙年度研发缺项保留，不靠行业覆盖放行金融证据或补零。详见[行业关联及历史审核](valuation/industry-association.md)。

原生参考与SQLite、会话绑定；人民币融资来源初值沿已批准政策，保留US行业、信用及目标权重代理。用户覆盖优先，CNY币种一致不等于公司市场WACC已认证，见[人民币与数据契约](valuation/data-contract.md#人民币数据库默认与编辑联动2026-10-05)。

## 估值能力与冻结边界

原生网页／API、具名条件CLI、运行追踪／比较、显式年度经营路径、研发税务、债务及可转债处理均已接通。当前公式冻结；仅有复现和回归的明确BUG可修，方法、默认算法及新必要输入先列[valuation TODO](../valuation/TODO.md)待审批。全部模型变动查[引擎台账](valuation/engine-change-ledger.md)，不把本地实现当原始理论。

来源增长同比、当前调整利润率及匹配行业资本倍率是可编辑初始条件；完整显式年度路径优先。公司经营范围、可持续利润、未来研发／税务、资本预算及终值过渡仍需证据；没有经济参数自动胜出者，不按股价选优。当前研究入口见[故事契约](valuation/narrative-valuation-plan.md)、[周期条件](valuation/cyclical-valuation.md)及[原生输入审阅](valuation/native-assumption-selection.md)。独立`alphalake-dcf`只复用数据，校验结果不自动回写或发布。

## 数据缺口与下一步

1. **提高经营与资本证据的可用度**：[通用盘点](history/economic-input-evidence-20261017.md)已接入4989家收益与资产组成，4985家四项可得、4家不足；非零不等于错误，也不自动剔除。继续按类别核对收益组成、现金／投资资产、合并资本与少数权益范围，复用既有显式年度再投资／研发税务入口；不得把“金额齐全”当经营口径已闭合，也不自动整桶扣除投资收益。
2. **稳定当前手工刷新**：清楚交付来源状态、缓存回退、实际消费窗口、规范收据和网页版本；新源候选单列验收，保留完整发布分母。性能用同范围实测，不把网络等候说成存储退化。
3. **保持当前准入边界**：15家已分类非金融缺项以短历史研发、上年同期或整期源记录不足为主；未知不补零，不按上市年数缩短研发寿命。历史不足方法、退市身份链、金融专项、多市场及新分类扩展继续延期。
4. **改善经济输入后再讨论预测认证**：公司量价／份额、竞争及资本预算约束应能改变显式条件；只读审阅、算术闭合与统计预测有效性分别报告，不重新启动已延期自动选择器或深挖个股异常。

## 性能与开发

日常Python默认约25秒；真实建库、PDF批量与跨语言验收使用`--full`／Go `-tags=full`，不强塞日常迭代。Go整仓库还包含大量真实存储夹具，耗时与Python分开报告；默认组不称全局验收。独立systemd服务硬限额1GiB，大任务串行，禁止再触发同scope杀终端的OOM；见[测试分层](guides/testing.md)和[资源隔离](guides/fundamental-memory-20260919.md)。

同5227范围v13暖缓存导出37.92秒、候选API160.29秒；已验证同条件4974结果不变，同截止重放复用导出和计算。历史60秒／3秒不是发布硬阈值。最近报价在线阶段2127秒主要受网络／源接口约束：固定256家、2560报价的本地基线4.29秒，不能以此承诺在线全量耗时。[日K限窗、归档与状态输出](history/refresh-efficiency-20261017.md)已完成真实样本验证，不增加连接节点或抬高资源上限来掩盖问题。
