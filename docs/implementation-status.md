## 验证、性能与整理

默认／全局验收及资源配置见[测试约定](guides/testing.md)与[内存隔离](guides/fundamental-memory-20260919.md)，大任务串行置于独立1GiB服务。本轮Go默认及构建通过；Python默认728通过、4跳过、156重型未选择（34.32秒），相关真实来源链4项通过。真实5,227家新旧候选及网页复验通过，三张财务宽表值与原快照一致；报价／参考更新后4,973家条件每股值变化，不是公式或假设算法改动。原研究不随新快照重写，完整PDF、历史研究及无改动前端未重跑。

同5,227家本轮导出36.56秒，完整双组API、归档及网页切换538.62秒；同截止重放49.38秒，源投影核对后复用SQLite及计算，5,227次真实GET通过，不替换网页文件。18个来源简称更新造成首次重放范围文件变化，规范ID／ticker不变；不称完全跳过源核对。整组峰值960.50MiB，主要高水位来自文件缓存，运行中无OOM且最终退出成功。已退役8份重复前版／预检展开产物约320.50MiB，保留当前完整候选归档及研究引用。详细来源、测量、失败与收据见[本轮交付](history/partial-financial-publication-20261021.md)；历史秒数不能脱离范围、缓存及资源直接比较。
