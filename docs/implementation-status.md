2. **字段级零值规则。** 官方定义、全局分布和小样本核验明确后统一放行，不再逐公司重复审批。应付债券上轮已完成，本轮新增17项历史资本字段及4项投资/研发字段，主库新增139,373个标准零值，100家SQLite新增4,946个零值、611个财务输入单元格由缺失变为有值；既有非空值不变。六家2024年十项债务源零已全部闭合。8项补充资料字段当前仍保留原规则；审核已区分6项季度披露缺口与2项年度/半年也存在的合并列示反例，尚未发布分期间零策略，其他权益工具投资待补非零样本核验。航天电器长期应付款仍缺可靠计息分拆，与源零放行分别处理。见[字段扫描与发布](guides/tdx-offline-sync.md#字段零值审核)及[资本效率](valuation/capital-efficiency.md)。

## 不应混淆

- 已批准现金、长期投资和A股价格×总股本代理可用于条件估值，但不代表完整资产范围或真实分股类市值。
- 历史FCFF仍缺已审核的完整折旧/非现金营运资本出口口径；它不是当前基于收入增量的预测DCF的统一准入门槛。
- 行业参考齐备不等于公司市场WACC已自动确定；默认US参考与显式人民币政策分别展示。
- 多市场、金融专项模型、严格系统时点回放及个案长期深挖暂不推进。既有来源、失败结果和审核证据保留。
