## 性能基线与观察

- 数值规模2.28倍、宽行规模3.49倍。139.71秒包含完整范围规则重算及新增1,086.69万个标准值；旧少数股权补链29.73秒和早期60秒目标均不是相同工作负载，不能直接判定回退。当前缺少可比旧实测，不能把全部时间变化简单归因于数据增长。
- 同一扩大后数据集，本轮优化从260.54秒降至139.71秒（耗时减少46.38%）；这是单次测量，不冒称三轮稳定中位数。无变化重放3.28秒、数值增改删0，可作为现行观察基线，不因超旧3秒目标而列为故障。
- 100家重导出/API、全市场导出及盘点合计407.99秒。后续有实际慢任务或存储放大迹象时，先拆分SQLite写入、完整性校验及盘点耗时，再判断是否需要优化；本轮不追加仅为赶旧秒数的重建。
- 比较按[性能基线](guides/financial-storage-redesign-20260925.md)固定工作量和资源，记录吞吐、体积、RSS及冷热缓存；正式对照至少三次。1GiB硬限额、正确性、证据与幂等约束继续保留。合理规模增长不要求性能例外审批。

## 数据供给现状与保留边界

1. **资本效率的公司经济依据。** 已实现最近连续三年公司资本代理的完整DCF对照，单独量化选择公司/行业代理造成的估值影响；当前v3直接使用共享引擎的显式合并账面权益，匹配合并收入，不再另加一次少数股权；现金/投资等经济适用依据仍需判断，不继续扩展早年历史。现有五分量债务代理、现金/长期投资代理、研发资本化和少数股权范围必须分别说明。
2. **字段级零值规则。** 官方定义、全局分布和小样本核验明确后统一放行，不再逐公司重复审批。应付债券上轮已完成，此前新增17项历史资本字段及4项投资/研发字段，主库新增139,373个标准零值，100家SQLite新增4,946个零值、611个财务输入单元格由缺失变为有值；既有非空值不变。六家2024年十项债务源零已全部闭合。8项补充资料字段当前仍保留原规则；审核已区分6项季度披露缺口与2项年度/半年也存在的合并列示反例，尚未发布分期间零策略，其他权益工具投资待补非零样本核验。航天电器长期应付款仍缺可靠计息分拆，与源零放行分别处理。见[字段扫描与发布](guides/tdx-offline-sync.md#字段零值审核)及[资本效率](valuation/capital-efficiency.md)。
3. **经营预测适用性。** 保持达摩达兰公式，以现有公司证据校准增长、利润率和再投资；只做有决策价值的定向取证。统一情景可重复，不代表自动假设已通过预测有效性认证。
4. **供给与运维。** 按真实剩余缺口推进行情、身份/源零审核；维持固定样本发布验收、性能基线观察和来源新鲜度说明。线上完整更新及自动调度尚未作为当前交付验收，不先扩建调度平台。

此前少数股权历史补链的存储验收：复制＋规则重建＋落盘29.73秒，重放2.26秒且增改删均0，100家导出4.68秒；独立服务硬限额1GiB，未重测全市场导出和标准查询性能。首次宽表集合校验触及DuckDB查询内存上限，改为记录键＋其他列SHA-256签名后通过，未提高内存或缩小范围；失败日志保留。主库新增6,928个历史少数股权值，SQLite新增706个单元格，其他标准列签名及既有少数股权值不变。

## 不应混淆

- 已批准现金、长期投资和A股价格×总股本代理可用于条件估值，但不代表完整资产范围或真实分股类市值。
- 历史FCFF仍缺已审核的完整折旧/非现金营运资本出口口径；它不是当前基于收入增量的预测DCF的统一准入门槛。
- 行业参考齐备不等于公司市场WACC已自动确定；默认US参考与显式人民币政策分别展示。
- 多市场、金融专项模型、严格系统时点回放及个案长期深挖暂不推进。既有来源、失败结果和审核证据保留。
