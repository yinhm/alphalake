最近全市场估值实测见[2026-09-10验收](a-share-automation-acceptance-20260910.md)：当时主库schema37，5,569家均有处理结论，5,304家核心输入齐全，2,461家条件估值，零执行异常。当前主库已发布schema38，新增安克30条历史事实；本次未重跑全市场估值。后文历次样本数字按当时口径保留，不代表当前累计覆盖。

预测准确度研究已完成2023H1、2024H1两起点复验：[半量乘性利润校准](../valuation/research/tdx-growth-expanded/README.md)在固定新增120家公司、171/240可评价组合中通过预定门槛，利润误差改善约10.2%，收入未改善。此前失败及样本不足结果保留；另做60家公司逐一删除训练后重拟合，最小改善约7.14%；[一年期校准政策](forecast-calibration.md)已接入统一CLI/API，安克主库对照验证差额仅来自第一年利润折现；追加2025起点85/120个组合改善约1.9%，未达5%效果门槛；未自动推广全市场，完整DCF有效性仍未证明。

[现金预测不确定性复核](../valuation/research/tdx-operating-cash-forecast/uncertainty.md)已完整重现原120家、331/360组结果；整体OCF主误差下降6.84%的分层95%百分位区间约2.08%–11.36%，不分层敏感性约1.40%–12.48%。2024单期及现金代理整体WAPE区间跨零，未证明每期稳定改善；固定三起点、17个单公司行业层及共同冲击限制保留，不扩大DCF准入。[既定输入子组](../valuation/research/tdx-operating-cash-forecast/scope-uncertainty.md)另重现244/255组：OCF主误差下降6.70%的分层区间约1.68%–11.62%，现金代理及两项WAPE区间跨零；沿用全部120家公司抽样，不冒称完整DCF准入或新留出，两套新区间现已加入统一现金检查的`evidence.research_uncertainty`，显式返回分母、单位、源哈希与当前公司适用性未知的限制；现金公式及估值不变。

状态含义：

- **已实现**——存在可执行的生产路径，且有测试覆盖。
- **部分实现**——已有可执行行为，但尚未完成已接受的设计。
- **仅有结构**——已有表或模型，但缺少完整采集或处理路径。
- **计划中**——仅为已接受的方向，不代表已有实现。
