# workspace 顶层清理与 SQLite 迁移

按用户要求，网页财务发布库移至`workspace/valuation.sqlite`；顶层只保留它和唯一主库`alphalake.duckdb`。候选、回滚副本、锁和当前发布收据统一放`derived/system-delivery/`，原始证据仍按来源归档，知识库位置不变。当前规则见[布局](../guides/workspace-layout.md)及[发布契约](../guides/system-delivery.md)。

12个哈希ZIP／`.held`是旧测试模拟包，合计1,984字节，其中两份内容分别是`corrupt`和`tampered second package`。财务测试曾继承真实`ALPHALAKE_WORKSPACE`，共享测试辅助函数因而写入顶层；主库14,843条原文记录均未引用这些文件，已删除。两处测试包入口取消继承workspace，测试内仍可显式设置自己的临时目录；生产取证与归档逻辑不变。另以一个空临时目录模拟继承workspace，分别运行两包真实ZIP物化测试，均通过且该目录保持为空。

SQLite通过同一文件系统重命名迁移，没有复制第二份财务库或保留旧路径别名。旧位置的发布锁已清理，当前收据移动，切换日志显式更新目标及回滚位置；原切换日志另存审核目录。冻结历史收据不改写，迁移清单记录新旧位置。8080重启读取新路径；原进程内临时会话不持久化，既有运行证据不受影响。
