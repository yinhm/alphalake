# 公司研究Skill的基本面与图表增强

本轮改进报告完整度与研究表达，不改估值公式、默认参数、数据发布或页面。`alphalake-valuation`继续用既有AlphaLake数据与估值引擎；尚无合理参数自动选择器，不把新模板称作预测准确度提升。

## 改了什么

原入口已有论点与假设，但基本面只给简短维度，报告模板偏模型说明且没有可执行制图。现要求首次覆盖让不了解公司的读者认识业务、客户／渠道、行业竞争、财务质量、管理层与资本配置；重要判断串联观察、机制、替代解释及估值影响。历史阅读优先已有近3—5年及可比中期，不扩早年、不把展示长度设为模型门槛。

主研究条件由研究者算价前提出理由，首页给明确每股点值、币种及资本基期，备选条件不赋概率；证据不足时仍如实交付已有条件，不编中心值或当前目标价。新模板把内部版本细节放附录，避免掩盖公司分析；短问题不强制整篇研究。

继续参考同一固定Anthropic提交，补看首次覆盖的公司研究及制图细则；吸收业务／竞争／治理覆盖和先有研究、数据、估值再绘图的依赖，不沿用固定字数、管理层履历配额、25—35图或分五次确认。具体文件、改写及许可证见[来源记录](../../skills/alphalake-valuation/UPSTREAM.md)。

`tools.research_charts`支持趋势、分组柱、价值桥、已有敏感性矩阵四种图。仅展示给定数组，来源文件及哈希实际核对、null保留空缺、预测与事实区分、价值桥组成核对；不算DCF、不选参数、不下载来源、不覆盖登记报告。中文PNG、数据、manifest和图注统一进workspace研究目录，沿原登记及图片白名单显示。可选依赖`research`增加Matplotlib，CI显式安装并提供中文字体；普通网页启动不导入制图依赖。见[图表契约](../../skills/alphalake-valuation/references/charts.md)。
