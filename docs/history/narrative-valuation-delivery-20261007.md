## 明确条件及机械交付

每家公司两条显式故事：经营机制条件和竞争／价差压力条件。五家周期样本沿既有三年算术调整路径；其他样本人工给前三年增长并向原长期增长过渡，持有当前调整利润率。非研发净投入比例、5%收入规模压力和1个百分点利润率压力均为人工验收判断，不是披露事实、达摩达兰规定或公司推荐预测。完整比例、路径、反例及证据状态均在冻结协议与故事文件中。

研发采用既有当前费用率／普通扣除条件，以原历史队列滚动计算研发净投入，再与人工非研发预算合成完整年度总净投入；不重复扣研发。人民币风险、原融资／终点及索偿输入明确继承。主张统一保留`insufficient`，不能因为已算出价格而改为证据充分。末年预算和稳定期g/ROIC的转换、资本释放及融资依据继续在报告中提示，不自动平滑或认证。

链路为：同版原生基线 → 中文故事／证据／反例 → 人工年度绝对收入、调整利润率、税率及原生覆盖 → 相邻收入生成增长 → 原生完整请求／实际8080 → 年度现金、经营／股权每股结果 → 归档核验及修订。没有故事评分、概率或胜出者，也没有自动附加3／5／10年条件；事实及默认不变。
