## 调整类别与合理性

| 类别 / 台账项 | 实际改动及判断 | 适用边界 |
|---|---|---|
| TTM与缺项；导入前、E18/E20/E23 | 完整TTM可直接输入，保留独立年度研发；缺值不再用零、旧年度或一股替代，合理 | 不伪造季度，不把历史FCFF缺项扩成所有DCF必需；缺来源仍拒绝对应计算 |
| 研发；E10/E11 | 基期税收重分类、净再投资、历史cohort及资产/利润一致性修正有据 | 五年寿命是原应用默认；基期/历史修正不能证明预测税务已处理 |
| 回报及资本；E12/E13/E15/E17/E26/E27 | 真财年间隔、匹配期初、当年税项、合并权益及不重复少数权益等修正合理 | ROIC诊断缺项不借另一口径补；账面资本与桥接公允价值不同 |
| WACC；E02–04/E06/E07/E19/E21 | 显式Beta、资本权重、参考融资组件；总ERP不重复叠CRP，修正合理 | 行业权重、合成利差及跨市场Beta是代理；风险币种和经营地域须单独论证 |
| 来源语义；E14/E22 | 行业EBIT增长与收入增长、调整前后利润率分开，正确 | 不能把交付了行业数据等同于公司预测已采纳 |
| 参数定义域；E08/E09/E16 | WACC≤g、非正ROIC/资本倍率不再静默返回零，合理 | 明确非法值拒绝不等于保证其余参数经济合理 |
| 逐年路径；E05/E24 | 显式增长/利润率/税率与资本效率沿原FCFF公式计算，合理的条件接口 | 最后一年必须真的达到稳定状态，末年税率不能自动冒充正常化税率 |
| 收缩终值；E25 | 负g仍按g/ROIC计算净再投资，代数一致 | 负再投资意味着可回收资本，不适合自动外推所有衰退/永久亏损；有限经营期另论 |
| 专项股权桥；E01 | 明列现金、投资、债务等索偿及范围，有助避免隐式覆盖 | 转债终局取低不是完整期权估值；权益比例须匹配利润/资产/索偿范围 |
| 亏损税盾；E27-T | 无应税利润不凭空获得当前税收利益，原则正确 | 按应税EBIT比例、恒定初始债务分量及立即正常化终值是本地近似，未获完整方法认证 |

目录外亦会改变输入及估值：原生SQLite/参考版本接入，标准报表EBIT直通，曾按公司覆盖EBIT/现金的政策撤销，具名增长/资本/信用条件生成等，均由台账列明。数据来源修正有理由，但不自动证明`reported_ebit`已剔除所有非经营投资收益；与投资资产加回的收益范围仍须配套。现金/投资组成不完整、账面债务/少数权益及A股价格乘总股本代理仍是条件输入。

原页面曾被专项入口修改后恢复；随后累计TTM展示BUG修复与用户授权KB也改变前端源码，但不改变DCF。不能用“不应修改前端”的架构目标抹去已经发生的历史。

## 独立算例与发现

全部为虚构币种的百万元，不是安克或其他公司的新估值。共享基准：收入1,000、报表EBIT200、税率25%、初始WACC10%、一年显式预测；除个别条件外终值g=0、WACC8%、ROIC12%。在准确上游与当前同输入执行，再按原始定义独立计算预期。

### 1. 普通盈利路径与明确修复

无研发、无亏损抵扣的例子，两版预测FCFF150、终值1,875、经营价值1,840.909091和每股30.818182完全一致。不存在全引擎统一乘数或更换DCF主公式。

WACC=g时上游终值静默为0，当前明确拒绝；资本倍率0时上游将再投资归零，当前明确拒绝。负g=−2%且可回收资本时，终值NOPAT147、净再投资−24.5，当前终值1,715，上游因把再投资归零得1,470。最后一例仅证明所选回收条件下关系闭合，不证明企业一定能释放资本。

### 2. 研发税收修正未贯穿预测

当期研发100、摊销40，净调整60；研发当期全额税前扣除，且存在足够应税利润时：

```text
调整后EBIT = 200 + 100 − 40 = 260
调整后NOPAT = 200 × (1 − 25%) + 60 = 210
            = 260 × (1 − 25%) + 60 × 25%
```

原基期错误NOPAT195、净再投资110、FCFF85；当前基期NOPAT210、净再投资110、FCFF100，与未重分类现金流100一致。E10修复正确。

但是[M4预测](../../valuation/backend/engine/module_4_dcf.py)仍用调整后EBIT及税率，经`_apply_nol_and_tax`计算现金税，不调用研发调整函数。在额外明确“次年仍为报表EBIT200、净研发调整60且可当期扣除”的条件下，当前预测NOPAT195，应为210，差15。这条预测逻辑也存在于上游；问题是既有修复未闭合整个预测链，而非本轮新改坏。

未来研发与摊销未在当前预测接口逐项表达，因此不能把当前60或15恒定外推，更不能把总再投资之外再次扣一遍研发。现有逐年税率路径可表达经审核的现金税情景；是否足够、是否需要输入扩展，以及NOL、研发优惠/加计扣除等公司税收条件，须另列方案后审批。此例不构成中国企业税务事实。

依据：[研发盈利、现金流与未来估值](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/R%26D.htm)，特别是After-tax Operating Income及Effects on Cash Flows；[教材第10章](https://pages.stern.nyu.edu/~adamodar/pdfiles/valn2ed/ch10.pdf)。重分类不应自行改变现金税；税收待遇必须独立保留。

### 3. NOL和债务税盾仅部分闭合

隔离融资影响，将债务权重设0，期初可抵扣亏损NOL=1,000、每年EBIT200、g=0。一年显式预测后剩NOL800；两版终值都立即按25%税率得150/8%=1,875。若不考虑到期/法定限额，余下四年各有税收节省50，终值时点现值为：

```text
Σ（50 / 1.08^j），j=1..4 = 165.606342
含该条件税收利益的终值 = 2,040.606342
```

不应凭NOL余额直接加800×25%，也不应当作0。需要盈利时点、使用限制及可利用性证据。旧上游已遗漏终值外这段抵扣，当前增加余额/警告但没有计价。

E27-T另增加债务税盾撤销：初始债务权重×初始税前/税后债务成本差，按可征税EBIT比例加回每年WACC，融资分量一直保持初始值。达摩达兰支持抵扣期间现金税与债务税盾配套，但并不指定上述比例及固定融资路径。默认未提供NOL也不等于公司实际NOL为0。

依据：[有效税率、正常化及亏损抵扣](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/taxrate.htm)，The Effect of Net Operating Losses；两条可选思路是逐年税率处理，或独立计量可实现的抵扣现值。

### 4. 转债取低与亏损终值

专项桥中经营价值1,840.909091，债务扣300、50股；转股释放100、增10股。不转股每股30.818182，全转股27.348485，当前选27.348485。模型没有期限、波动率或转股权利价格，因此“取低”不能证明已计量期权或给出公允价值下界。完整方法应区分纯债及权益索偿，再扣权益索偿价值；依据：[转债及期权处理](https://pages.stern.nyu.edu/adamodar/New_Home_Page/lectures/eqshare.htm)。

永久EBIT−100例中，上游终值−937.5，当前取消虚构税收抵免并调整税盾后为−1,204.819277。负值保留了假设的经营代价，但不是具有有限责任的普通股公允价格；持续经营/复苏/失败或清算边界不能只由Gordon公式认证。不因希望转绿而强制改为正数。

## 原默认与当前使用情况

逐字段AST比较原字典已有输入默认值，未见`ValuationAssumptions`、`AdjustmentInputs`、`MethodChoices`或`MacroInputs`原字段默认改变；增加字段和缺值输出另计。原生数据库请求的手工无风险率默认4.25%也沿上游，不能当作最新人民币利率。来源关联、ERP解析和缺项拒绝的修复仍可能改变实际取到的输入，不能据此声称全部请求行为不变。

原应用默认包括前五年增长空值转0、利润率沿基期、销售/资本2.5、研发寿命5年、稳定期ROIC=WACC及Beta=1代理等。它们不是教材通用参数；保留用户输入功能也不代表自动经济校准已完成。US业务Beta可在可比条件下作为代理，但人民币现金流需人民币无风险率/债务成本及匹配风险暴露；接通人民币参考并未自动切换原生默认。原合成评级的研发分子、租赁分母和非正利息回退是继承问题，详见[组成审计](../valuation/native-cny-policy.md#利润利息与租赁组成审计)。

| 实际分支/边界 | 报告数 | 能说明什么 |
|---|---|---|
| 启用研发资本化 | 120 | 预测税务衔接有较大审阅范围；不等于120项已证实估值误差 |
| 执行亏损税盾WACC调整 | 28 | 新近似并非只存在于未用的专项分支 |

| 专项股权桥、额外租赁资本化、原合成评级 | 各0 | 不把其问题直接归到现行全部默认结果 |
| 显式期初NOL、逐年forecast覆盖 | 各0 | 默认没有提供这些公司条件，不代表事实余额或未来路径已核实 |

原始规则、公司经济依据和本地政策须分开。依据：[资本与折现率定义](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/definitions.html)、[增长价值驱动](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)、[稳定期回报与终值](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)。
