- 最近五年及当前TTM共288项收入、EBIT、研发、购建现金与前轮标准源证据逐项相同；重用源证据与消费对账，不冒称本轮独立重读全部TDX ZIP。
- 5份既有规范PDF相关页重提取与语义核对；下载／复制0。晶晨预告区间不取中点，“全年有望突破100亿元”保留原文的经营预估性质；自然年与下一TTM年按两个半年衔接。首次核验将百分号写在表内31.86数值后而失败，核对发现单位在列头后按实际版式修正，失败及原因留存，未改金额或放宽单位／期间。
- 20份完整原生结果经现有审阅器重放；11次现行8080完整API对照一致，临时会话全部释放。3次FCFF加100万元及5次错误PDF哈希均被现有审阅／证据入口拒绝。
- 条件及完整请求在修订计算前分别冻结，没有参数扫描或依据估值高低重选。阶段计算2.15秒，Python进程峰值RSS约90.52MiB；实际服务组硬限额1GiB，阶段串行。小样本不冒称全市场性能基线。
- 引擎文件、主库和财务SQLite哈希不变。未修改运行代码，未重跑无关Go／Python全套；这不是本轮全局代码验收声明。保留既有Starlette/httpx弃用提示。
