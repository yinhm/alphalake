# 预告经营期间与离线重解释修复

2026-10-17；不改财报、TTM、SQLite、故事条件或估值引擎。

## 行为

同为“第三季度”标题，国网信通快报正文为1–9月、源杰预告正文为7–9月。季度标签本身不能认证单季。两种来源解释器升为v3：明确月份、前三季度、半年、全年及无歧义Q1保留原定义；其余季度标题保留截止期，开始日未知，不丢公告、不统一改为累计。巨潮此类记录为partial，不能靠另一来源日期替PDF作主。

真实主库验收又检出：原离线流程插入新解释ID，却从不更新已有检查点，所以当前查询继续显示v2。已改为成员变化时原子发布新解释，沿用旧来源取得时间；成员相同不推进检查点。回归模拟旧分类器没有识别目标公告，再用完整归档恢复成员，核对零HTTP、来源时间不变及再重放不变。

## 实际结果

原4989家范围、2026Q3、公告窗口1月1日—10月17日；只使用本地完整归档，不在线抓取或下载PDF。

- 当前144家公司、266条观测不变：东财131、巨潮135，全部为v3。所有预测金额、单位、证券、公告日期和截止期逐项相同。
- 12条巨潮观测由单季改为开始日未知；valid 262→250、partial 4→16。真实单季也不能仅凭同名标题认证，不据此说其实际为累计；需要正文时按已存原文引用。
- 当前关联仍118对／236条linked观测；未知开始日不参与同期间关联。
- 再重放新增观测及关联均0，重开查询逐字节相同。v2观测和原始来源仍保留，新增解释ID不称新增公告。
- 两份真实PDF的规范对象哈希、页码和最短原文核对通过；固定测试证据见[JSON](../../internal/source/cninfo/testdata/guidance/operating-period-evidence.json)。未宣称通用PDF期间自动解析已实现。

来源收据`source_observed_at`全部不变；218条新解释引用了已归档的较后来源页，故新ID的`first_observed_at`与旧ID不同。新时间不晚于其归档来源取得时点；旧ID及其首次时间不改、同版重放稳定。不能无证据借旧解释的早日期回填新字段，更不能把重解释当本次取得上游最新。失败的“跨解释版本首次时间与引用必相同”验收预期已改正，不涉及金额容差或删除经济字段。
