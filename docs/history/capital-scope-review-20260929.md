# 近期债务与资本效率：核验及采用决策

2026-09-29，基于`8d7ec30`运行时、既有六家公司2024年报、当前主库及固定统一场景。只读批量导出六家公司2024年末至2026H1的相关标准列，没有扩展历史、下载新来源、写入审核零或发布新SQLite。当前入口见[资本效率](../valuation/capital-efficiency.md)。

## 决策

继续保留已批准行业倍率及债务代理，不自动以公司历史倍率替换。最新财年之前的资本余额仍有审核缺项；补齐2024年也最多增加一个可比观察年，且债务经济范围并未完整。通用规则应按负债性质分类，不能把长期应付款整项当有息债务。

达摩达兰的[债务定义](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/whatisdebt.htm)要求识别计息债务，区分经营性非计息负债，并一致处理租赁、现金和资本权重。报表科目名称及恒等式本身不能代替经济分类。

## 长期应付款的经济范围

航天原文[1222974273](https://static.cninfo.com.cn/finalpage/2025-04-01/1222974273.PDF)给出了此前未核实的证据：

- 167页明确“往来单位带息债务为长期债务且已约定利率”。150页长期应付款借款291,587,112.35元，专项应付款132,499,600.00元；合计424,086,712.35元。
- 159页关联方筹资借款期末4,352,628.60＋288,097,539.95，减149页已列流动部分863,056.20，恰为291,587,112.35。流动部分已进入现有债务代理，不重复加。
- TDX标准`long_term_payables`为424,086,720元，float32位对应原文总项；`special_payables`源位为零，实际PDF却有1.3250亿元。全584个位置按元/万元编码检查，未发现该两项分量的精确float32匹配；这只是本地该版本数值筛查，不证明所有上游版本都缺少。
- 因而不能从当前TDX标准值可靠拆出2.9159亿元，也不能把专项应付款的源零审核为真零。**融资性质已确认，结构化分拆缺口仍在。** 本轮仅把PDF分量用于显式敏感性，不入标准库、审核补充或网页快照。
- 原文筹资负债变动总额还比资产负债表口径少5,000,000元：表内银行借款40,000,000＋15,000,000，合并短期借款为60,000,000。关联借款分量闭合不等于整张债务变动表全部闭合；不为这项历史差额继续扩大取证。

其他公司的反例支持按经济性质分类：扬农160页长期应付款199,163,830.08元，主要是长期应付职工薪酬199,144,244.51元，仅19,585.57元为“融资租赁应付款及其他”；天富179页445,728,485.33元含政府专项拨款152,037,350.10元，其余又混合财政借款、融资租赁、国债资金及分期付款，不能整体计息化。扬农152—153页另披露供应商融资34,436,747.50元已重分类为短期借款，现有代理已经包含，不能再加一次。

## 重放与校验

原PDF路径及哈希、提取页、标准出口、源维护观察、七份候选输入/结果及日志在`workspace/derived/capital-scope-review/`。其标准出口使用原财务截止2026-09-27T08:12:14.060804+00:00；估值输入及参考沿用各基线文件，并保存基线SHA256，不冒称2024时点可得预测。生产数据未更新。

在独立且已核验1GiB硬限额的服务中执行以下Python即可复核关键证据和已保存候选（`PYTHONPATH=valuation/backend`，解释器`.venv/bin/python`，需既有pypdf）：

```python
import hashlib, json, re, struct
from decimal import Decimal
from pathlib import Path
from pypdf import PdfReader
from engine.data_dictionary import CompanyValuationInput
from engine.orchestrator import run_full_valuation
root = Path('workspace/derived/capital-scope-review')
for file in root.glob('*-pages.json'):
    meta = json.loads(file.read_text())
    assert hashlib.sha256(Path(meta['path']).read_bytes()).hexdigest() == meta['sha256']
meta = json.loads((root / '002025-pages.json').read_text())
pdf = PdfReader(meta['path'])
text = re.sub(r'\s+', '', pdf.pages[166].extract_text())
claim = '往来单位带息债务为长期债务且已约定利率'
assert claim in text
assert claim not in text.replace('往来单位带息债务', '往来单位无息债务')
assert Decimal('291587112.35') + Decimal('132499600') == Decimal('424086712.35')
rows = json.loads((root / 'source-zero-binding.json').read_text())['observations']
fields = {r['field']: r for r in rows if 'field' in r}
assert fields['special_payables']['source_evidence']['float32_bits'] == 0
bits = lambda x: struct.unpack('<I', struct.pack('<f', x))[0]
assert fields['long_term_payables']['source_evidence']['float32_bits'] == bits(424086712.35)
assert bits(424086712.35) != bits(291587112.35)
for file in root.glob('*-candidate.json'):
    saved = json.loads(file.read_text())
    result = run_full_valuation(CompanyValuationInput.model_validate(saved['inputs']))
    assert result.dcf.model_dump(mode='json') == saved['report']['dcf']
    assert result.final.model_dump(mode='json') == saved['report']['final']
print('证据及七份候选重放通过；没有批准或发布候选')
```
