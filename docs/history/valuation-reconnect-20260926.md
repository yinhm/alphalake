# 原生数据重新接入：已有值、派生值与尚未闭合范围

此前“缺现金、债务、投资、市值、五年研发”的说法混淆了源缺失、映射未实现、历史审核日期误用和市场价格尚未同步。本轮以标准事实为数值来源，保持原页面与模型公式，修正数据适配。SQLite契约更新为v4，旧快照显式重建，不保留兼容分支。

## 实际映射

| 原SQL列 | 本轮供给 | 准入含义 |
|---|---|---|
| 现金与短期投资 | 接入标准期末现金及现金等价物；附现金、金融资产等组成的标准事实引用 | `partial_target_scope`，不是包含所有短期投资的总额；不能直接送入估值 |
| 长期投资 | 接入标准长期股权投资，并提供其他金融投资的标准事实引用 | `partial_target_scope`，不是全部长期投资；不能把未分类部分当零 |
| 债务账面值 | 短期借款＋长期借款＋应付债券＋一年内到期非流动负债＋租赁负债；五项必须各有标准值 | 账面组成合计。未知不补零；保留到期项范围、其他融资与租赁重复资本化警告，不宣称逐公司CIQ认证 |
| 研发费用 | 官方利润表费用定义适用于已有历史；移除无依据的2025年样本审核起点 | 只扩大官方同一定义的标准映射范围；非零及公告、单位、期间校验保留，源总研发投入不冒充费用 |
| 股价／市值 | 批量读取已完成采集的TDX未复权日线；价格×标准报告期总股本÷百万 | `reported_share_price_proxy`，显式报告股本基期、交易日、运行和观察ID；已知存在流通B/H股时不计算单一A股价格代理 |

价格窗口固定为财务报告期末当日或此前14个自然日内最近一个合格收盘价，不使用财报期之后的价格。市值是该报告期价格/总股本代理，不是当前市值，也不认证未知的多股类范围。上市股价可独立供给；缺股数或已知多股类时仍保留价格证据但拒绝市值代理。信息截止控制日线观察与采集完成时间；盘中采集不会因后来查询自动变成完整收盘价。

原SQL金额以百万元、股数以百万股存储；标准事实保持元、股和源精度。`export_cells`记录组成、分量金额与状态，标准事实保留通用字段值；部分目标的原SQL总额列保持NULL，API以`available_component_value`展示已知金额，防止其他SQL消费者把分量误当总额。后端仍检查完整目标状态。原生成功路径不绕过该检查。

## 为什么两类投资范围不能靠改名解决

官方量化目录明确期末现金及现金等价物是时点余额；专业财务目录也明确资产负债表项目。它们足以支持标准字段接入，不能据此宣称“现金等价物＝现金及所有短期投资”或“长期股权投资＝全部长期投资”。

已有安克2026H1原文核验显示：交易性金融资产内包含1,890,858.07元未到期远期外汇合约；标准独立衍生金融资产另有约2.4930亿元。这两个分量并不相等，不能用独立衍生金融资产整桶扣掉交易性金融资产中的套期分量。现金等价物与货币资金的差额，也不能全当成受限资金。

因此，本轮先把能确认的数值和引用接通，剩余短期投资的性质、期限、受限与重叠，以及其他长期金融投资的分类单独保留。精确补齐需要复用已归档财报附注形成独立分类/调整证据；如涉及附注金额，则必须作为显式补充来源，不能宣称全是TDX数值。另一种路径是批准明确的简化账面场景，但那是模型假设，不能静默替换原SQL总额。本轮没有擅自实施这两种扩展。

依据：[TDX量化目录](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)、[专业财务目录](https://help.tdx.com.cn/gspt/docs/markdown/redword/Profinance/profinancedatalist.html)、[已有安克资产审核](../../valuation/research/company-inputs-20260917/README.md)、[达摩达兰现金与交叉持股章节](https://pages.stern.nyu.edu/adamodar/New_Home_Page/dam2ed.htm)。官方目录映射不冒充逐公司投资分类认证。

## 内存与验证

历史重算首次在256MiB DuckDB预算下拒绝分配，未发生系统OOM，主库未改动。根因是把所有财务包的身份关联同时聚合为签名列表；现改为同一连接逐包计算，签名内容和排序保持一致。没有提高数据库预算或1GiB进程硬限额，不通过反复重连隐藏问题。

审核收据、失败日志、重放与旧值比较、SQLite导出及网页复验均放在 `workspace/derived/valuation-reconnect-audit/`。生产主库须在候选重开及既有值/血缘检查通过后替换；旧派生副本验收后清理并保留哈希。
