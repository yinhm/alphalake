## 本轮范围与结果

固定原100家公司、报告期2026-06-30、信息截止2026-09-26T08:34:05.989815+00:00；重点处理其中21家、43个上市前年度。没有扩大证券分母，也没有重新选择估值政策。

- 43个年度均有本地TDX源记录：42个非零研发费用，1个源零待审。此前主要缺披露关联，不能称TDX缺数。
- 21家招股说明书全文已归档，37个年度研发费用完成合并范围、期间列、单位及金额精度核对。36个来自合并利润表；清研环境2021年1个来自招股说明书所载审计截止日后的年度审阅报告，明确不冒称审计值。
- schema53仅增加披露范围审核，不增加PDF数值主源。标准值从原TDX ZIP物化；主库标准值8,057,491→8,057,528，新增37，既有值更新/删除均为0。主库仍约329MiB，源记录定位、既有标准宽行及字段血缘全量比较无变化。
- SQLite契约仍为v6，标准事实25,093→25,130。原年度表只有37个研发费用单元格NULL→值；其他年度字段、季度表和公司表不变。
- 同一100家公司原生API由72成功/28拒绝变为**87成功/13拒绝**；原72家条件估值逐家完全一致。剩余12家缺研发、1家缺适用的经营利润。

新增可进入原生估值的15家：001378、301029、301030、301133、301210、301246、301288、301363、301589、605499、688073、688103、688226、688231、688653。

上述成功率只表示在当前代理口径、研发资本化选项及可编辑默认假设下可以计算，绝非估值准确率。API复验显式使用无风险利率0.0425这一测试假设，不称市场观察值；现金、长期投资与多股类市值的代理限制仍保留。

## 实现、验证和发布

机制及命令见[ADR021](../decisions/021-prospectus-disclosure-coverage.md)。招股书保留真实公告身份，无虚构年度公告；经审核的标准字段集合限定物化范围。正文范围撤销或变更会使相应归档内容签名失效；不改变其他归档签名，不新增逐字段源数值存储。

真实CNINFO查询暴露了一个检索问题：完整关键词“招股说明书”漏掉7家，改用“招股”并按正文标题分类后21家均取得全文。真实响应及正向/标题篡改回归已进Go测试。37个原文金额通过离线复验，原文两位小数舍入与TDX半ULP误差分别纳入界限；差异逐项留存。真实清单金额篡改+0.01原文单位被拒绝。

`go test ./...`、`go build ./cmd/alphalake`和16项相关Python回归通过。新增回归覆盖错误公司/哈希/期间/字段拒绝、披露日前不可见、未审核字段不放行、重放无变更、撤销删除及源零仍拒绝。37项真实PDF复验使用workspace证据，不在CI下载这些动态PDF；CI运行采集分类与审核物化回归、Python校验器的正负测试。

验收脚本首次Python回归未隔离归档环境且未设置项目Go缓存，修正运行环境后通过；失败日志保留。发布时还实际验证了回滚：临时systemd服务停止后需重新创建；随后验收脚本曾错误预期简写的blocked状态，修正为既有API完整状态枚举。两次失败均恢复原数据库及SQLite，未丢失候选或证据。

原始PDF与目录在`workspace/cninfo/`，全部本轮审核和结果在`workspace/derived/prelisting-rd-20260927/`：

- `source-audit.json`、`prospectuses.json`、`coverage-manifest.json`、`verified/`：源记录、公告身份、页码/年度列、审核输入及金额差异。
- `database-comparison.json`、`sqlite-comparison.json`、`materialize-replay.log`：全量既有标准宽行不变、37项新增及幂等重放。
- `api/summary.json`、`api-comparison.json`、`http.json`：固定100家原生API、旧72家不变及真实8080复核。
- `publication.json`、`cleanup.json`：发布哈希、备份轮转与临时文件清理。

唯一主库仍为`workspace/alphalake.duckdb`；8080读取`workspace/derived/valuation.sqlite`。仅保留最近一份主库和SQLite回滚副本，原始证据及审核记录保留。
