# 原生经营候选的经济输入审阅

> 历史阶段记录；其中的“当前”、命令、库版本和待办以当时提交为准。现行入口见[文档索引](../README.md)，不要直接作为日常操作手册。

本轮交付是可复用的输入审阅：从已保存的原生候选重放模型，解释收入规模、利润调整、再投资和终值。没有批准新的预测规则、修改网页默认或替换财务事实。固定样本仍为安克、茅台、苏泊尔、海尔和三一；海尔缺项保留在分母。

## 方法和停止条件

Damodaran的[增长与再投资](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/growth.htm)要求把增长与投入数量、未来投资回报相联系；历史资本平均效率不能直接证明新增投资效率，研发与租赁调整需要一致。[终值与超额回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)说明终值增长也有再投资代价。

因此审阅固定为三个问题：历史增速延续意味着多大的公司；报告利润到调整利润的桥接是什么；增长要求多少再投资、隐含回报及终期再投资率。近期同窗收入/报告EBIT只提供对照，不自动替换未来预测。无需增加阈值、寻找更接近股价的参数或重复扫描失败研究；本轮在固定五家公司和既有候选完成后停止，不扩大全市场DCF。

审阅不强制存量资本回报等于终值新增资本回报，也不据二者不同自动改公式。报告利润率与研发资本化后的利润率分开，不把调整当成主营盈利突然增长；保持调整后的利润率意味着研发费用、摊销与收入关系也需要前瞻解释。

## 系统交付

`tools.evaluate_native_policy`现在随每份成功候选保存`*-review.json`，复用共享引擎重放已有输入，结果不一致则拒绝。已有候选目录可独立审阅：

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.review_native_policy \
  workspace/derived/native-policy/final-five \
  workspace/derived/native-policy-review/final-five-review.json
```

输出文件必须不存在，不覆盖历史审阅。该命令是本地只读，不读取行情、抓PDF或修改SQLite。整体报告保存源文件哈希、原协议、当前后端版本、原分母及阻断原因；每家公司给出：

- 标准年度收入及相邻年度增速；模型内报告EBIT历史单列，缺EBIT裁掉的年份不误称标准收入缺失。
- 最近年度或同窗YTD收入增长、报告EBIT利润率；YTD按原生季度位置和报告日对齐，不使用季数据占位的`fiscal_year`猜期间。
- TTM报告EBIT、研发费用/摊销、租赁调整及调整后利润率。
- 逐年收入规模倍数、NOPAT、再投资、FCFF、再投资率与模型隐含账面ROIC；负现金流保留，非正NOPAT的再投资率留空。
- 实际终值增长、WACC、终值新增资本回报假设、再投资率及终值占比，存量隐含回报另列。

全部保持`automatic_adoption=false`。增长和利润率需要公司前瞻依据，行业资本倍率和参考WACC可作显式敏感性。历史FCFF或资本分量缺项不变成零，不用预测现金流倒推公司历史。这里的同引擎重放、哈希及数学恒等式均不代表独立来源核验。

安克近期增速与历史CAGR相近，但不能证明五年继续以28.89%增长；研发资本化净调整约23.78亿元也需要区分于原报告EBIT。茅台和苏泊尔近期增长低于历史CAGR，三一则高于历史CAGR；这些方向不同的变化说明统一机械外推缺少充分公司依据，不能以同一个事后折扣修补。

四家原生输入的历史FCFF均为空，折旧摊销及非现金营运资本变动未形成完整输入，历史调整ROIC序列也为空。进一步追到[`export_alphalake_sqlite.py`](../../valuation/backend/tools/export_alphalake_sqlite.py)：`FIELDS`没有`d_a`、`noncash_wc`及其变动的目标定义，`cell`对此返回`requires_separate_valuation_definition`；对应折旧与营运资本标准分量也不在本出口的`SOURCE_FIELDS`。**这是当前导出/口径缺口，不是断言TDX没有相关原始分量。**不能从这份SQLite反推上游缺数据，更不能把多个折旧项或全部流动资产减负债未经审核拼成目标。

历史ROIC还涉及原生税项定义：原目标是剔除特殊项目税前利润，不能把已有的报表利润总额直接填入；最近年度有效税率的独立派生不等于逐年该目标已补齐。原生v7已对此做过语义纠正，见[导出契约](../guides/valuation-sqlite-export.md)，本轮保持这条边界。

行业资本倍率仍只能作为敏感性代理，不能据此批准公司边际资本效率。安克候选第五年账面隐含ROIC约48.82%，终值存量隐含回报约42.44%，而新增投资回报假设为8.07%；须解释竞争优势、旧资本回报和新增投资的差异，不能把8.07%误称整个公司资本回报已经收敛。

## 预测再投资与历史核验的依赖（2026-09-28）

调用链现已核清：原生引擎 `module_3_cashflow` 用已调整资本开支、折旧及营运资本变动计算历史FCFF；`module_4_dcf` 用预测收入增量和销售资本比计算预测再投资，终值再投资率按增长/新增资本回报确定。**历史FCFF完整不是当前预测DCF的准入条件**，但历史证据不足会限制资本效率假设的可信度。这一结论不放宽收入、EBIT、研发或其他已有准入要求。

达摩达兰[增长公司的价值驱动](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)明确列出收入增量/销售资本比及投入领先收入的处理，并要求观察隐含资本回报；不是要求所有企业先还原完整历史FCFF。[增长与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)同时要求研发、租赁调整保持一致。现有模型的2.5空值默认只标为模型默认，不能由教材算例推导成全公司通用校准值。

现有审阅输出新增逐年 `capital_funding`：投入支持的收入年份、对应收入增量、所用销售资本比、复算再投资；超出预测期的收入明确标为按终值增长延伸。每行核对收入增量/倍率与模型再投资一致；不调用模型内部再投资函数冒充另一取数路径。高增长期后采用稳定期倍率，不误写成平滑插值。这里的总净再投资已涵盖资本需求，不能再额外扣一次营运资本变动或研发投入；这也不代表已有公司分量分类完成。

资本区另列预测方法、历史FCFF的核验作用、倍率显式输入/模型默认/继承关系。未新增预测政策或自动填入历史事实。

## 增长、税后利润率与增量回报核验

自动假设的下一道核验复用现有 `review_report`，不另建模型或按估值结果选参数。依据达摩达兰[增长的基本决定因素](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)区分新增投入与既有经营效率变化，以及[增长公司价值驱动](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)关于投资滞后和隐含回报的要求。

对第t年再投资，按原模型滞后L定位其对应收入年份u=t+L。设R为预测收入、N为预测NOPAT、m=N/R，输出以下精确分解：

- 收入贡献：`(R[u]−R[u−1]) × m[u−1]`。
- 税后利润率贡献：`R[u] × (m[u]−m[u−1])`。
- 两项合计必须等于 `N[u]−N[u−1]`；利润率贡献包含经营利润率、税率和亏损抵扣变化，不能全部解释为竞争力改善。
- 仅再投资为正时，分别输出总利润增量/该年投入、收入贡献/该年投入。前者混有既有业务利润率变化；后者只是恒定税后利润率下的模型隐含增量回报。二者均非已观察公司或项目ROIC，不用固定阈值自动批准。
