# 资本效率过渡条件情景

> 历史阶段记录；其中的“当前”、命令、库版本和待办以当时提交为准。现行入口见[文档索引](../README.md)，不要直接作为日常操作手册。

本轮聚焦当前预测，不扩展早年数据。复用既有12家固定名单和21个可计算场景，固定收入、利润率、税率、WACC、终值ROIC及股权/股本口径，只比较第六至十年的资本需求。

## 方法与契约

[达摩达兰增长和再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)允许以收入增量/销售资本倍率估计再投资，并要求检查回报；[终值再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)要求增长与资本回报配套。本轮不改这两个定义。

共享引擎新增后端输入`valuation_assumptions.annual_sales_to_capital`：每个预测投入年度一个正、有限倍率，长度必须等于预测年数；存在时覆盖两阶段倍率。没有该显式路径时，原两阶段方法和网页默认保持。年度路径不改变收入确认年份或投入滞后，零/负数/NaN/无穷及不完整路径拒绝。

固定情景`native-capital-transition-v1`：

1. 前五年保持基线各年倍率。
2. 第六至十年，在“每元收入所需资本”上从第五年水平线性过渡：`1 / S/C(t) = (1-w)/S/C(5) + w/S/C(10)`，`w=(t-5)/5`。
3. 终点取既有审阅计算的等价倍率，使同一终值年度、同一投入滞后下，倍率法与原`NOPAT×g/ROIC`给出相同再投资。没有正终值再投资或有效正倍率时，明确不适用，不填默认倍率。

五年起点和线性过渡均是事前固定的分析判断，不是教材规定或公司事实，不按结果调节。终点只是原终值政策的代数含义，并未独立证明终值ROIC合理。原终值无超额回报假设继续保留，不将新增投资回报和存量账面ROIC强制相等。

采用资本强度而不是倍率线性插值，是因为前者直接乘以收入增量得到再投资。更平滑不自动意味着更准确，也不保证现金流每年单调。市场空间、项目效率、过渡速度及原行业代理适用性仍须判断。

## 可重复入口

先用当前`tools.evaluate_native_policy --selection-policy`生成并保存完整基线目录，参见[统一情景](../valuation/native-uniform-scenarios.md)。冻结旧目录依原提交复验，不给旧运行时增加别名或静默兼容。

在已核验MemoryMax=1GiB的独立服务内串行执行：

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.compare_native_capital \
  workspace/derived/capital-transition/baseline \
  workspace/derived/capital-transition/result.json \
  --web http://127.0.0.1:8080
```

来源目录须先通过原选择、情景、预测诊断及报告重放检查；仅对已计算的`scenario_*`施加统一过渡。所有12家公司保留在分母，未获选或缺财务的公司保留来源状态、空情景，不另找替代公司。输出必须是workspace/derived内新文件，包含政策、来源哈希、完整前后输入/报告、年度倍率、年度再投资变化、终值衔接、引擎版本及run_id。

计算器强制核验：除年度资本倍率路径外其余输入一致；收入、EBIT、折现因子、终值和原财务/调整结果不变；再投资差额的折现和等于持续经营价值变化。失败概率及股权/期权调整仍由共享引擎执行，持续经营价值变化与叠加这些调整后的经营/每股价值变化分别报告，不自行线性换算。

该入口只生成显式条件结果，不自动选择或覆盖默认政策，不修改前端、主库或SQLite，不读取新增历史数据。
