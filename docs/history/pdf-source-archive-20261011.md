# PDF归档与跨语言复用（2026-10-11）

## 原因与改动

Python经营材料采集仅认清单中的本地路径或固定文件名；目录重采后本地路径为空，即使Go已归档同份公告仍会下载。故事运行又将每份PDF复制进每个输出目录。此前磁盘去重只处理了已有副本，未消除这两个写入路径。

现统一巨潮原文为`workspace/cninfo/objects/<摘要前2位>/<SHA-256>.pdf`，以`cninfo/documents/<官方URL日期>/<公告ID>.PDF`提供相对软链接，相邻JSON保存URL、摘要、原文路径及原始取得时间。Go公告、审核导入、股本／融资参考与Python研究共享逐URL锁和缓存收据；同一内容跨来源角色仅保留共享存储，主库来源角色及既有路径不改。其他官方来源仍按实际来源归档，不伪称巨潮。

下载前核对健康源版本、URL收据或已知哈希对象；缺少合格原文才请求官方URL。大小、PDF头、哈希、目录边界及原始取得时间校验保留。复用不更新时间或宣称上游最新，未知时间不从mtime推断，也不靠重复下载制造；主库要求原始取得记录的导入保留该缺项。内容摘要不等于独立语义核验。

经营采集升级为`narrative-document-collection-v2`，故事升级为`narrative-valuation-v2`。新故事只在`manifest.pdf_references`登记来源路径／摘要，报告直接链接原文；非PDF基线仍随运行归档。当前验证核对外部原文，缺失或篡改拒绝。没有改财务数值、估值参数、公式、引擎或网页；冻结v1按原提交复验，不给当前工具增加旧契约兼容。

## 验收及边界

真实离线验收重新校验全部688个共享URL引用；安克2026H1和茅台2025年报分别采集到两个输出目录，原文路径、哈希与原始取得时间一致，实际HTTP请求0、输出PDF副本0，文本及引用验证通过。收据为`replay-verification.json`，明细在同目录`replay/`。

回归覆盖：串行与并发采集仅下载一次、清单缺本地路径时复用、已知哈希对象复用、未知首次取得不制造、Go/Python双向共享、跨股本参考角色共享原文、故事不复制PDF、篡改拒绝及目录越界拒绝。Go默认回归与构建、选定`-tags=full`真实PDF／镜像审核／预告／跨语言来源回归均通过；Python默认563通过、4跳过、155个重型项目未选择，另有2条既有依赖弃用提示。执行记录在`regression.log`；均串行置于已核验1GiB硬限额服务，测试不继承真实归档环境，未将默认组称全局验收。

过程失败保留说明：新增测试最初误用仅full组定义的辅助类型，已改为本测试的HTTP拦截器；第一次目录验收另发现一个旧顶层软链接，登记到`legacy-link.json`后撤除，重复验收通过。都不是源PDF、财务或估值校验失败。systemd输出的部分峰值数值不能可靠代表整个测试组，故不作为进程RSS结论。
