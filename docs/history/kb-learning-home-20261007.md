# 知识库学习首页

2026-10-07按用户要求，将 `/knowledge` 从词条列表调整为默认学习首页。复用现有词条索引、文章页和搜索，不增加数据库、API、依赖或估值计算。

首页提供七课自学路线，六类主题导航（报表、现金流、增长与资本、风险、终值、股权）及六个专题入口（案例练习、经济策略、预测研究、系统初值、货币WACC、结果检查）。标题来自同版已发布词条，未发布ID不生成链接；列表与搜索仍最多十条。独立文章不重复展示首页导航，可返回首页；窄屏顺序排列，页首链接直接定位并聚焦搜索。

## 验收与发布

TypeScript／Vite构建、定向ESLint、匹配／缓存检查及20项浏览器回归通过，其中13项知识库交互、7项既有估值展示回归。新回归使用不完整的合成目录，验证缺失入口不生成链接、课程／主题／专题导航、键盘访问、返回首页、390px布局及目录外别名检索。

现有8080服务已加载新静态页面：553篇真实词库的33个首页链接逐项核对标题、详情及同版令牌，14个实际文章入口经浏览器打开与返回；十条上限、EBITDA精确匹配优先、搜索定位及390px首页／正文无水平溢出通过，无页面异常。新资源先落盘，HTML入口原子替换，保留旧资源供已有页面完成读取，无需重启后端。

词库仍为 `zh-valuation-learning-v7.7-r3-20261007`，内容令牌不变。财务DuckDB、财务SQLite、知识SQLite、编辑稿及16个引擎源码文件共20项摘要前后相同。Go默认整仓库测试及CLI构建通过；仅前端及文档变更，不执行未受影响的Go全局标签组或Python完整组；测试、构建与真实网页验收均串行使用独立1GiB服务。既有Summary合成测试仍有未模拟敏感性请求的Vite代理连接警告，测试断言通过，不称该请求为真实后端验收。

## 失败与修正

首轮浏览器检查误将搜索侧栏的学习链接也作为结果点击，产生选择器歧义；限定结果列表并移除首页重复学习入口后，20项全部通过。首次真实检查错误要求搜索“EBITDA”只有一条，实际词库有五个相关结果；改为验证十条上限及精确词条优先，未修改搜索规则。该次失败自动恢复旧HTML入口，摘要核对通过，随后重新发布并验收成功。

构建／失败日志、前后摘要、发布收据、实际链接检查和桌面／手机截图位于 `workspace/derived/knowledge-home/`。临时候选、检查脚本及回滚HTML在验收后清理，路径、摘要及原因留收据；故障日志和测试trace保留。阅读契约见[知识库指南](../guides/valuation-knowledge.md#阅读入口)，当前数量见[实现状态](../implementation-status.md#知识库)。
