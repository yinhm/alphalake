# 达摩达兰方法核对：净再投资与终值

本轮检查普通非金融FCFF路径：标准窗口→`build_book_dcf_inputs`→`compute_dcf`，历史增长与零增长显式政策共用该路径。结论是已检查的净再投资与终值公式一致，测试的一处弱断言已补强；另修正WACC代理分支错误继承的市场资本结构标签；不代表所有估值模型、公司WACC或全部默认参数完成核对。

方法依据：[达摩达兰增长与再投资说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/invfables/growthdeterminants.htm)、[终值中的超额回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)。增长、再投资与资本回报应联动，终值需要为稳定增长扣除相应再投资；是否存在超额回报决定增长对价值的影响。方法依据与公司预测实证分别记录。

| 检查项 | 当前普通FCFF实现 | 结论与边界 |
| --- | --- | --- |
| 净再投资 | 收入增量/收入资本比率；普通政策显式采用零年滞后 | 是净资本开支加经营营运资本投入的预测代理，不是现金购建支出 |
| FCFF | NOPAT−净再投资 | 未再额外扣除全部现金资本开支，避免将净额与毛额混用 |
| 终值投入 | 下一年NOPAT×g/ROIC | 已扣除增长对应的投入；g=0时净投入为0 |
| 终值折现 | 下一年NOPAT×(1−g/ROIC)/(WACC−g) | AlphaLake政策校验g<WACC及g<ROIC；现金流从预测期末再折现 |
| 无超额回报 | ROIC=WACC时，终值/下一年NOPAT=1/WACC | 新回归固定十年预测，跨三个g值检查这一关系；不是在改变下一年NOPAT时声称绝对价值完全不变 |
| 增长上限 | 共享引擎非显式覆盖路径以无风险利率限制终值增长 | 原测试仅检查正值，已改为完整结果与上限情景相等；低增长超额回报情景作对照 |
| 显式终值覆盖 | 普通政策显式给定g，绕过共享引擎默认上限 | 不代表g已获得经济长期增长依据；需要逐政策审阅币种、名义/实际及长期增长假设 |

安克两份普通政策的2%终值增长、10%WACC与10%终值ROIC仍为显式参数。零增长研究只支持两年/三年收入预测，不能用该研究替代终值参数依据。固定WACC对照也不等于公司市场WACC估计已完成。

回归检查了g=0、2%、4%，ROIC=WACC及ROIC>WACC两种情况。零增长的十年预测净再投资为0、FCFF为NOPAT，同时原输入仍保留正的历史现金资本开支和折旧；这用于锁定口径边界，不宣称历史输入就是未来维持性投入。

## 终值ROIC边界补验

在三年收入预测复验失败后，回到共享再投资链核对发现：`compute_dcf`原先对零、负数、NaN的终值ROIC使用零再投资率，无穷大也会令`g/ROIC`为零。通用`ValuationAssumptions`可接收这些值，普通AlphaLake政策的更严约束不能保护所有通用调用。

依据上方达摩达兰稳定增长再投资关系，当前稳定经营FCFF模型需要有限正值的终值资本回报；缺失/无效回报不能替换为零投入。现于解析终值ROIC后统一检查有限且严格为正，失败抛出既有`InvalidTerminalValue`，并移除零再投资率回退。未显式提供ROIC时仍沿用既有`ROIC=WACC`的无超额回报假设，并检查其解析后数值；这不是新增公司事实。未新增`ROIC>WACC`或`ROIC>g`的通用限制，不把价值毁损情景自动排除；零/负回报业务需要另行明确模型与经济解释，本模型直接拒绝。

修改前新增回归的四项全部失败（没有抛出异常），修改后通过；API回归同时覆盖原WACC错误和零ROIC错误，返回422、无效新请求不新增会话、无效覆盖保持原会话。已有零增长恒等式及NVIDIA Ginzu等回归继续检验有效情景；本次不改变负终值增长的既有处理或S/C默认政策，不能称全部再投资边界完成。

## 研发重分类的税项与期初资本

已修正共享引擎的本期研发重分类。依据[达摩达兰无形资产说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/intangiblevaluedriver.htm)：同一税项假设下，研发资本化对税后经营收益与净再投资作同额调整，纯重分类不改变历史现金流；回报率及增长则可能变化，不能把重分类当作现金创造。

旧M3对调整后EBIT全额乘税后系数，导致研发净加回60、税率20%时FCFF少12；净加回为负则反向虚增。新共享函数 `after_tax_operating_income` 保留原税项：先从M1的EBIT总调整中排除租赁调整，取研发净加回D；NOPAT＝调整后EBIT×(1−t)＋D×t。M3、公司ROIC与M5复用同一公式，EV/EBITDA也从同一NOPAT扣再投资得到分子，不再混用原始EBITDA推回的另一套经营利润。

这延续M1已有税项不变的分析重分类，不断言中国或境外税法允许全部当期扣除，不新增加计扣除、亏损抵税或递延税资产。M4未来利润率、税率及再投资仍是独立预测假设，本次未把历史重分类等同于未来研发投入预测。

本期M3期初研究资产改为“期末资产－当期新增＋当期摊销”；公司边际收入/资本比也扣回当期研发净增加，避免两期资本使用同一期末研发资产、使研发投入被抵消。M3本期ROIC使用期初资本，公司比较面板ROIC仍使用期末资本，分母定义保持区别。多年历史诊断随后已按下节重建逐年研发资产，不再复用当前资产；期初租赁PV仍有代理，完整历史经营资本和旧期源语义未闭合，不能将已修研发算法作为后续增长规则的有效性证据。

## 逐年研发资产与历史回报

历史诊断现在按各年度及此前的连续年度研发支出，复用M1直线摊销方法重建期末研究资产，并用同一税项不变函数计算年度NOPAT。历史利润率采用相应的研发调整后EBIT，ROIC的分母采用上一年末资本；不读取当前调整输入中的研发资产或当前研发金额代理过去。

期末研究资产只需要n个年度投入，因为第n个过往年度期末权重已为零；当年摊销需要当前加前n年，即n+1个年度。资产可算而摊销不足时，只保留资产相关资本比率，利润率及ROIC留空。缺失、负数、非有限研发、重复年份或非连续年份阻断相应窗口；显式原始财务输入零允许参与，但适配器仍不得把未解析的TDX零值当作已知零费用。

研发启用但年度诊断不完整时，编排报告增加明确提示。没有将缺研发的年度退回未调整利润/资本后混算平均值；收入增长仍独立计算。现有平均值仍是可用年度的平均，逐年空值必须一并查看，不能据平均值存在宣称三年/五年窗口完整。历史税率仍采用原有每年税费/税前利润及21%缺失代理，历史经营资本分类和租赁调整仍未完成，不能把这组诊断称为完整经济ROIC。
