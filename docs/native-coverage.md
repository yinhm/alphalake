# 原生估值缺口基线

本页区分标准财务覆盖、原生模型的数据准入和模型适用范围。当前只推进沪深非金融企业；金融专项、多市场暂停。100家是固定回归集合，不是总体覆盖率分母。本工具不运行DCF、不写标准事实、不发布网页。

## 可复验入口

`valuation/backend/tools/audit_native_coverage.py`复用现有`valuation-readiness`和原生`native_compatibility`，按实际必需/条件输入统计；不另建准入规则。先用[SQLite导出](valuation-sqlite-export.md)从同一主库导出候选，指定`--all`才是全部本地范围。工具要求SQLite记录的源库物理哈希与当前主库相同，期间和信息截止一致；已有网页快照不满足时重新导出候选，不能取消检查。

以下命令须在已核验`MemoryMax=1G`的独立systemd服务内串行执行，DuckDB预算512MiB、单线程，具体环境见[系统交付](system-delivery.md)。不要在交互终端直接运行全范围导出。

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.export_alphalake_sqlite \
  --database workspace/alphalake.duckdb \
  --output workspace/derived/native-coverage/full.sqlite --all \
  --period 2026-06-30 --as-of 2026-09-27T08:12:14.060804+00:00
PYTHONPATH=valuation/backend .venv/bin/python -m tools.audit_native_coverage \
  --source-database workspace/alphalake.duckdb \
  --database workspace/derived/native-coverage/full.sqlite \
  --output workspace/derived/native-coverage/full.json
```

输出拒绝覆盖已有报告。报告契约`alphalake-native-coverage-v1`，含逐公司缺项、范围依据、程序/源库/SQLite哈希、参考发布版本及观察日年龄。主库、候选在扫描前后均核对哈希；源变化即失败。审核完成后可删除可重建候选库，留下路径、哈希及原因。

范围政策`nonfinancial-tdx-damodaran-2026-v1`使用已核验Damodaran行业成员，并识别现有TDX申万金融节点的代码/名称对；不按公司名字猜行业。缺参考且无明确金融节点时保留范围待审；TDX明确金融而Damodaran非金融时保留冲突。非金融分类只是范围代理，不证明公司没有金融兼营。该政策不改变原生准入或既有100家集合。

## 参考供给边界与执行顺序

现有主库参考出口具有国家风险、Global行业Beta、国债曲线和信用利差版本。当前观察日距截止分别为88、265、18、269天；年龄不是自动过期判定，仍需消费政策。

原生网页默认US行业参考、国家边际税率不全在该出口中；公司行业选择需绑定主库版本，信用利差须与原生债务成本分支对齐，无风险利率须明确期限/方法/新鲜度。用户显式参数优先，不能静默以Global替换US。同步参考成功不代表网页WACC已接通。

后续顺序：

1. 批量定位行情及研发年度缺口的源/关联/物化原因，优先补通现有来源供给；不要先逐个追上市前个案。
2. 将已明确口径的主库参考接到原生实际输入；缺参考列明来源和方案，涉及新增来源/方法另行审批。
3. 复用ADR021补披露范围、零值和公告审核；随后审阅增长、利润率、资本效率。金融与多市场不开展。

快照不能证明哪些闭合来自自动同步、人工审核；本轮不虚报这两类完成数。后续须从审核事件及前后版本归因。

## 性能、证据和回归

动态证据在`workspace/derived/native-coverage/`。全范围导出77.74秒、峰值RSS514,932KiB；诊断39.96秒、峰值RSS390,084KiB。串行、1GiB进程组硬限额、512MiB DuckDB预算、单线程，已有文件缓存，非冷缓存基准。临时候选约1.1GiB，未发布到8080。复验后删除全范围及三家临时SQLite，释放1,122,025,472字节；路径、哈希和原因见`cleanup.json`，主库与现行网页快照哈希不变。

首次导出漏传`--all`被参数校验拒绝，日志保留`export-argument-failure*`；首次回归命令误用不存在的后端虚拟环境路径，日志保留`python-regression.log`。修正入口后相关Python15项通过（2条依赖弃用警告），Go全套与CLI构建通过；无OOM、未跳过失败。

固定100家对照见`sample-parity.json`，逐家准入及必需/条件缺项与现行网页SQLite比较，不重新算DCF。本轮不修改主库事实、现行网页SQLite或前端；原网页87准入/13阻断保持不变；100家范围分类为97家非金融、2家金融、1家待审，分类不改写原验收分母。单元回归包含范围外/待审保留、缺项按公司去重及身份/截止篡改拒绝。
