# 自动选择条件估值假设

## 达摩达兰方法核验

2026-09-28核验结论：**尚不能确认所有自动假设具有公司层面的经济依据，不能批准为自动合理估值。** 下述公式可用于条件情景，但数值有来源不等于预测合理；最近同比、持平利润率和行业倍率均不能由公式正确性获得背书。核验范围为当前 `select_native_assumptions.select` → `evaluate_native_policy.prepare` → 原生M4调用链，包括继承的WACC、税率及调整开关；不是对仓库所有专项模型重新认证。

| 自动选择/继承项 | 原始资料要求与允许方法 | 本项目结论及采用前缺口 |
|---|---|---|
| 最近可比同比作为未来增长 | [增长驱动](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)要求结合市场空间、竞争、公司历史及成熟同行，检查收入绝对规模 | 历史观测是真实输入，但直接外推仅是基线；缺公司增长空间与规模检验 |
| 一年后线性过渡、第十年进入终值 | 同上，增长持续期和衰减速度依公司特征 | 一年、十年及线性路径均为本地情景参数，不是理论统一规定；低于终值增长的公司实际会向上收敛，不能一概称“衰减” |
| 当前调整后TTM正利润率永久持平 | 同上，只有可持续时才能持平，目标和过渡需竞争及成本结构依据 | 正值不证明持续性；未完成调整口径一致的同行、历史及竞争优势核验 |
| Global行业销售资本比 | 同上，允许公司或行业倍率估计收入增量对应投入，需监测隐含资本回报 | 行业存量比率可作代理，不能认作公司新增资本效率；研发/租赁调整一致性和隐含ROIC仍需核验 |
| 一年投入滞后 | 同上，允许按投资到收入的时间差设置滞后 | 继承原引擎默认或显式覆盖；一年不是所有公司的通则，缺建设/周转周期依据 |
| 税率过渡 | [税率](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/taxrate.htm)允许有效税率渐变，但终值应使用适用边际税率 | 共享高增长期参数使税率也从第二年开始过渡，没有公司时间依据；现拒绝继承“永久保持不同于边际税率的有效税率”覆盖，不擅自改写用户税率 |
| 终值增长min(2%,人民币无风险率) | [稳定增长](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/stablegrowthrate.htm)要求币种/名义实际一致、长期经济约束；无风险率是实务上限参考 | 上限约束符合方法；2%不是指定值，也不保证公司具备该增长能力 |
| 终值ROIC=WACC、再投资率=g/ROIC | [终值超额回报](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)要求增长与再投资联动，允许竞争消除超额回报 | 公式有据，ROIC=WACC是无长期超额回报情景；并非所有公司必须相等，也不能单独证明整套估值保守 |
| Global无杠杆Beta、行业D/E、恒定WACC | [课程估值说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/eqUGemail.html)强调业务Beta和资本结构匹配 | 行业目标权重允许作为显式政策，但不等于公司市场权重；单行业、成熟期风险及目标杠杆未逐公司闭合 |
| 全中国风险暴露 | [国家风险暴露](https://pages.stern.nyu.edu/adamodar/New_Home_Page/valquestions/CountryRisk.htm)应考虑经营地域，不由注册/上市地点直接决定 | 仅是情景；尤其安克海外业务，不能据A股身份自动采用全中国暴露 |
| 统一BBB债务利差 | [合成评级](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/syntrating.htm)可用近期借款或财务比率估计信用风险 | 利差表有来源不证明公司是BBB；必须有适用评级或偿息能力/借款证据后才可作为公司参数 |
| 25%债务税盾 | 税率资料要求考虑可利用税盾及亏损抵扣；跨国业务可能有不同适用税率 | 统一25%是情景；不能由国家法定税率推出公司立即足额享受税盾 |
| 研发摊销、租赁、NOL、失败概率、现金/投资与股权桥接 | 沿用原生输入及已有[方法审计](damodaran-method-audit-20260911.md)、[输入审计](native-input-policy-audit.md) | 本选择器没有重新估计这些项目；五年研发寿命、无NOL/零失败概率等默认设置不证明实际状态。代理授权允许计算，不等于经济核验通过；每次完整请求保留这些输入 |
| 样本30、有效期370天、非负增长及正利润准入 | 数据治理和本工具能力边界 | 均非达摩达兰规定；他的方法可以处理收缩和亏损，拒绝仅表示本规则不会自动构造相应经营路径 |

当前审计输出增加 `economic_basis.status=not_established` 及八类未闭合依据，和 `predictive_validation` 分开。`selected_conditional` 只表示条件输入可生成，不能被解释为方法适用性通过；`automatic_adoption=false`保持。缺项不会被文字免责声明变成合理参数，现阶段只允许显式条件计算，不能自动发布为公司合理值。过去冻结结果按原提交复验，本次不修改其文件。

下一阶段先补增长/利润率持续性、资本口径与隐含回报、公司信用/经营地域/税盾的可计算判据，再进行事前固定的预测评价。不能只通过回测挑出一组数字就宣称遵循理论；也不为了本轮核验改网页、更新财务或重算一轮目标价。

本次核验回归：16项选择/原生桥接、51项现金流/DCF、Go全套（缓存）与构建通过；Python全套未重跑，既有弃用警告保留。1GiB隔离服务内串行执行，测试服务峰值613.8MiB。重放已存真实输入确认安克、茅台选出的完整请求数值不变，苏泊尔仍拒绝，三者均未获得经济依据通过状态；未重采数据或改网页。结果、日志及临时文件清理回执在 `workspace/derived/automatic-assumptions/method-audit/`。

## 计算前固定的规则

本轮只实现一组可解释的选择规则，不搜索阈值或按股价选参数。沿用安克、茅台、苏泊尔、海尔、三一五家及既有SQLite/参考截止；保留旧三年CAGR联合候选作对照，所有拒绝留在分母。停止条件是五家固定样本的选择、拒绝、模型传递及篡改校验完成；不打开历史研究留出集，不声称预测误差改善。

选择政策见[配置](../valuation/examples/native-assumption-selection.json)。这是本地明确政策，不是达摩达兰指定的统一参数。

- 增长起点：最新可比YTD收入同比；只有年度报告窗口才使用最近完整年度同比。季度窗口缺项时拒绝，不静默退回年度CAGR。起点为负需要复苏/收缩政策，本规则保留拒绝，不裁成零。
- 增长路径：高增长窗口一年，此后沿用原引擎向终值增长收敛至第十年；不把最近同比恒定延续五年。不证明公司衰减速度已校准。
- 利润率：明确采用当前已调整TTM正利润率持平情景，不混用未调整行业利润率；亏损需要扭亏路径，本规则拒绝。维持当前利润率仍是未经预测验证的假设。
- 资本：按原生公司已解析行业选Global销售资本比，要求样本不少于30、报告值有限且为正、来源日期与可用日期在参考截止内、观测不超过370天；无跨地区备用或2.5兜底。它是行业存量资本效率代理，不冒充公司新增资本效率。
- 终值：增长取2%与人民币无风险代理较低者；新增资本ROIC=WACC、不假设永久超额回报。沿用明确WACC情景（行业资本结构、BBB信用档和全中国暴露等仍非公司事实），政策边界必须随结果保留。

政策依据是达摩达兰的[增长、利润率和再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)与[终值再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)。原生引擎的现金流、折现及股权桥接公式保持不变。

自动选择不等于自动证明合理。输出须记录每项选择依据、明确政策、参考样本与缺项；未通过规则的不产生该候选。既有失败的增长研究继续有效，本轮不以机制通过或价格变化替代预测验证。

## 已接通的入口与适用边界

复用原生候选入口 `tools.evaluate_native_policy`，增加显式 `--selection-policy valuation/examples/native-assumption-selection.json`。其余数据库、参考、配方、标的和输出参数与原入口一致；可选 `--web http://127.0.0.1:8080` 验证完整输入API。原有折现率对照、CAGR联合候选保留作比较，新结果名为 `evidence_selected`，没有新估值引擎或前端。

在已核验硬限额的隔离服务中运行，例如：

```bash
PYTHONPATH=valuation/backend .venv/bin/python -m tools.evaluate_native_policy \
  --database workspace/derived/valuation.sqlite \
  --references workspace/derived/native-policy/final-five/references.json \
  --recipe valuation/examples/native-cny-candidates.json \
  --selection-policy valuation/examples/native-assumption-selection.json \
  --ticker SZSE:300866 --ticker SHSE:600519 \
  --output workspace/derived/automatic-assumptions/new-run
```

输出目录须不存在；示例使用既有本地参考证据，不代表上游最新状态。CLI不覆盖网页快照。需对未包含在SQLite中的公司估值时先定向导出，并保持截止与参考版本明确。

每家公司审计中新增 `selection`：增长、利润率、资本和终值各自的决定、值、依据和拒绝原因；选出时保存完整假设。总状态为 `selected_conditional` 或 `rejected`；自动选择为真、自动采用为假、预测有效性为未建立。这意味着程序已自动选值并可执行条件估值，但不能将规则输出包装成无需判断的合理目标价。

一年高增长阶段是原模型共享参数，除了增长，也使经营有效税率更早开始向边际税率过渡（除非已有显式不收敛覆盖）；不是只改变收入的单因素试验。WACC沿用显式人民币情景，两阶段倍率使用相同Global代理，当前利润率持平。每次请求保存全部输入差异及逐年再投资审阅，税率、资本结构和评级假设不冒充公司事实。

现有审阅工具会重新执行选择，比较政策、证据决定、原始请求及API返回输入；API自动更新的公司比较用资本成本单独核对为本次计算WACC，不把这项派生更新误当作用户输入篡改。原生目录查询404现归为 `outside_snapshot_scope`，与财务缺项区分。
