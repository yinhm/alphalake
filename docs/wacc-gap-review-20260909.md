本轮补齐安克合同债务期限的生产供给和现值区间计算，并核实茅台账面代理的原文依据。**仍不能把当前结果称为完全滚动到行情日的公允价值 WACC。** API 审计输出 `current_fair_value_complete=false` 和具体未闭合输入；该标志不阻止使用已明示的估计政策。

合同现金流含利息，浮息按报表日利率；不能再叠加TTM利息费用。四类账面合计与TDX及既有附注债务按float32精度界限核对。选择权不混入直债现金流，其既有账面调整仍是代理。

在非负年复利Kd下：

- PV上界：四桶分别按0、1、2、5年折现。
- PV下确界：前三桶按1、2、5年折现；开放的“5年以上”桶没有已证明的最迟付款日，正利率下其PV下确界为0；Kd为0时按全额计入。
- 新政策明确选择上界，不猜平均到期日。它不是WACC或每股值的“保守上界”，也不是被观察到的债务市价。
- 时间原点仍为六月末合同组合，利率取选定参考Kd；未掌握期后偿还、增借和浮息重设，不能将这组区间称为9月8日剩余债务现值区间。

## 验证
