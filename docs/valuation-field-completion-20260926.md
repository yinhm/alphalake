# 估值字段补齐：三个样本验收

本轮目标是字段供给与适用边界，以安克、贵州茅台、苏泊尔三个样本验收。没有批量运行DCF。数据金额仍来自TDX，CNINFO仅补公告身份和日期。

## 本轮交付

1. **年度会计有效税率接入原SQL字段。** 最近完整年度所得税费用除以利润总额，供给原`companies.effective_tax_rate`。缺项、来源冲突、非正分母、比例超出[0,1]均保留诊断和NULL，不截断、不用默认假设冒充公司事实。三个样本2025年度分别为10.4459%、25.6589%、19.0612%。安克两个源金额与已有原文台账按float32精度逐位一致；其他两家公司本轮验证标准事实到导出的比值，不冒称新增PDF审计。会计有效税率不是现金税率、边际税率或未来正常化税率，参见[达摩达兰税率说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/taxrate.htm)。
2. **补齐9个研发历史输入。** 缺项根因是没有关联的可用公告，不是已证实TDX无金额。定向补查两家公司2021年初至2025年6月末的目录，茅台新增28条、苏泊尔新增33条，另更新5条；无正文下载、无金额从PDF导入。沿原链路关联本地TDX并物化，茅台2020—2023年4项、苏泊尔2020—2024年5项研发费用补齐；三个样本原生默认研发调整的条件缺项均为0。
3. **财务值和血缘保留。** 主库7,958,031→7,960,220个标准值，新增2,189个；这是新关联期间的一组标准字段，不是2,189项不同指标。原有非空值、字段级运行血缘及快照身份/公告/运行元数据全部不变。最终重放新增、更新、删除均为0；源零与歧义拒绝仍保留。

## 尚不能称为估值数据完整

| 项目 | 三样本检查后的结论 |
| --- | --- |
| 现金及短期投资 | 已知组成有值；混合项目内期限、受限及经营属性未闭合，目标总额仍NULL |
| 长期投资 | 已知组成小计有值；范围和可加回部分未闭合，目标总额仍NULL |
| 价格与市值 | 安克本地已有合格价格和报告期市值代理；茅台、苏泊尔本地快照尚缺合格价格，是采集覆盖缺口，不是TDX字段不支持 |
| 总折旧摊销 | 三样本的来源报告EBITDA−EBIT与已知非使用权折旧摊销小计在源精度内吻合；仍有使用权折旧等范围问题，不能把差额直接认证为完整总额 |
| 剔除特殊项目税前利润 | 报表利润总额已有；调整后口径尚未闭合，二者不能直接等同 |
| 租赁承诺、期权、地理分部 | 仍缺对应披露，TDX余额不等于未来支付或期权数量；模型默认未启用不代表不存在 |

安克必需输入仍有两项资产范围阻断；茅台、苏泊尔各另缺一项市值供给。茅台兼营金融业务的模型适用边界独立保留，字段补齐不等于普通企业DCF获准。增长、利润率、资本效率和WACC仍是独立估值输入，不由财务字段齐全自动证明合理。
