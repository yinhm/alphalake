# AlphaLake 独立 DCF 校验

**只复用数据，独立建模。** 从 AlphaLake 取得事实与参考，以 Python 和 Excel 公式重新构建利润调整、税务、再投资、WACC、折现、终值及股权桥，用于校验现有 valuation 系统。现有引擎是被比较对象，不是本模型的计算器。

2026-10-11用户已明确授权独立校验及缺项PDF补证。范围限研究交付；不修改生产引擎、默认假设、主库事实或网页发布，不把校验条件自动采用为公司预测。

## 环境与独立性

- 默认Linux，使用已有 `.venv/bin/python`；已确认其他解释器时用 `ALPHALAKE_PYTHON`。定位会话已知仓库或 `ALPHALAKE_ROOT`，先读 `AGENTS.md`、`README.md`、`docs/implementation-status.md`。不硬编码本机路径，不使用Office JS或Windows操作。
- 数据含义查[数据契约](../../docs/valuation/data-contract.md)，计算读[独立模型说明](references/independent-model.md)。项目方法契约帮助理解被测行为，不能代替达摩达兰原始依据或独立推导。
- 使用标准库及已有 `openpyxl/pypdf`。不导入 `engine.*`，不调用原生DCF、WACC、研发／税务／索偿函数、模型类型、审阅器或导出器；也不能借用引擎目录之外实际执行这些计算的助手。
- 数据API、只读查询及原始文件可复用。TTM、利润调整、研发队列、Beta加杠杆、税务、再投资、折现及桥接独立推导；响应中的 `adjusted/dcf/cost_of_capital/final` 不作模型输入，也不抄入结果。
- 已有完整请求／故事中的**显式假设**可作为同条件对照读取，保留来源，不执行原故事生成／计算工具。普通原生估值用 `skills/alphalake-valuation/SKILL.md`，刷新和发布用 `skills/alphalake/SKILL.md`。
- 复用已确认条件并持续核验、交付，不逐表重复询问。真正缺必要信息或来源／方法冲突无法裁决时，指出具体问题再询问；本次PDF补证及独立计算不重复请求许可。

## 1. 冻结数据与校验问题

明确证券、币种、报告期、信息截止、报价日、股本基期，以及拟核对的原生运行或方法问题。主库 `workspace/alphalake.duckdb`、发布快照 `workspace/valuation.sqlite`；核对发布收据和元数据，保存哈希及参考版本，不把旧归档称最新。

按以下顺序取数：

1. 优先用 `export-financial-snapshot` 从DuckDB取得标准金额、期间、单位和来源，限定证券与实际消费字段。`GET /api/database/company/{ticker}` 及v13 SQLite只提供百万元/百万股年度、季度、TTM宽表和未展开的来源引用；不得假设仍有`standard_financials`或完整标准事实，独立TTM推导须用主库累计组成。
2. `GET /api/database/wacc-references`、主库及归档中的原始达摩达兰和人民币利率参考行。缺参考先查已接入数据，不从已算WACC倒推。
3. `export-financial-snapshot` 等只读标准出口，限定证券、期间及通用字段。接口为空时区分源缺失、未同步、未导出、未关联。
4. 已归档报告及论点／故事证据；仍缺事实时按下一节定向下载官方PDF。

`POST /api/valuation/from-database`会执行原引擎，不作为独立取数入口。原生兼容诊断仅说明被测入口的要求，不作为本模型准入门槛；不为单公司取数触发全市场估值或重建。

保存事实清单：标准名称、原值、单位、期间／范围、来源定位、哈希和转换公式。标准金额为人民币元、股数为股；模型统一百万元人民币、百万股、元／股及小数比例，保留源精度。

独立重算 `TTM = 最近完整全年 + 本期累计 − 上年同期累计`，余额不做TTM加总。半年不乘二，不伪造季度；同窗同比与全年同比分开。未来第1年明确日期区间，不将基期后12个月误写成完整日历年。

报价用快照已有最近合格完整交易日的未复权收盘价，股本按实际披露基期；多股类沿既有已批准A股市值代理时须标明。独立研究不因此隐式刷新行情、扩展多市场或将旧报价当实时价格。

## 2. 缺事实时允许官方PDF补证

先列缺项及影响：哪个计算需要、哪一期、哪个合并范围，是否仅可选诊断。优先本地PDF；不足时可直接尝试巨潮、交易所披露或公司投资者关系官网的年报、中报、招股书及正式附注，限定本公司及必要期间，不扩展成全市场取证。

PDF沿用[归档规则](../../docs/guides/workspace-layout.md#pdf归档与引用)。巨潮先在`data_sources.cninfo_documents.document_lock(url)`内调用`read_reference(url)`；已有哈希须匹配，合格原文直接复用。确无合格本地原文才下载官方URL，并在同一锁内以`publish_reference`登记唯一`cninfo/objects/<摘要前2位>/<SHA-256>.pdf`及日期／公告ID目录引用；已知哈希对象也先检查，不依赖固定文件名。研究清单只引用收据的`local_path`／`sha256`及页码，不复制PDF进模型目录。其他官方来源按实际来源子目录保存，不伪称巨潮；提取和本次收据放派生目录。

记录原URL、标题、原始取得与本次复用时间、SHA-256、报告期、PDF页码、项目标签、单位、合并／母公司及当期／比较列；原始取得未知留空，不借文件时间或重复下载制造。用 `pypdf` 提取，复杂表格或扫描页再视觉核验；文本能提取不等于金额语义正确。新取得资料不冒称旧快照截止时已留存；较晚披露或更新的材料作为新补证条件，公告日期未知也不伪造。

- 重点核对影响估值的收入／EBIT、债务、现金受限性、非经营投资、研发和D&A组成。
- 新补充列为 `pdf_supplement`，只进入独立模型工作输入，不冒充TDX或自动写主库。TDX有效值与PDF冲突保留两者、原披露／追溯调整原因，不静默覆盖。
- 真实零、明确不适用和未列报分开；未找到不补0。查最近年度补季度资料时保留原期间，只作显式估计，不标为已披露TTM。
- 补证改变原生可表达的事实时，单列“补证条件”；结果差异不直接归为引擎BUG。哈希、重复提取和恒等式各有边界。
- 无法取得或确认关键事实时保留失败及限制，交付可核验部分，不用默认税率、零研发、零债务或假设历史凑事实。

## 3. 事实、调整与预测分开

从公司经营机制形成具名条件，或复用已有用户完整路径。每项写明数值、依据、反例及适用条件；缺依据时标研究判断，不称经济参数自动选择或最可能预测。

| 事项 | 独立模型须明确的关系 |
|---|---|
| 收入／利润率 | 逐年绝对收入与增长；报表和经济EBIT分别列示；价格、销量、份额、成本怎样支持路径 |
| 研发 | 已费用化支出、历史队列、经济寿命、摊销及资产重新计算；已资本化开发支出不重复加入 |
| 经营税 | 报表税费、现金税、税基税率、税务扣除与可利用亏损分开；会计税率只能明示为代理 |
| 总净再投资 | 明细资本开支−D&A＋非现金营运资本变化，或显式资本倍率／完整总预算，互斥且不重复扣研发 |
| 风险／融资 | 原始参考、公司风险及代理条件分开；Beta、债务成本、市场权重重新计算；逐年和稳态条件分别留痕 |
| 终值 | 正常化利润、税务、增长、再投资、ROIC与WACC配套；研发／亏损过渡另计 |
| 股权桥 | 现金、非经营资产、债务、少数权益及其他索偿同范围；现有股数与权利扣减不重复摊薄 |

不强制十年历史；研发队列依经济寿命检查。历史FCFF明细缺项不阻止完整显式再投资条件下的预测，历史继续留空。周期、亏损、负投入、负股权保留并解释；金融、有限寿命或复杂困境不套通用永续FCFF凑结果。

## 4. 独立计算

按[独立模型说明](references/independent-model.md)从原始输入实现公式，保存逐年中间值。Python数值与Excel活公式分别构建并互核，不共用被测引擎代码。

临时分析脚本在系统临时目录执行；可复用工具需固化时放 `valuation/backend/tools/` 并保持独立，不把工具混入研究数据。模型定义、公式工作簿、输入和执行环境保留为交付证据。Skill不新增生产参数选择器或修改接口。

检查至少覆盖：

- 研发重分类同时调整利润、税务和投入；普通当期扣除下，重分类本身不创造FCFF。NOL按税基及可利用条件滚动，不自动即时退税。
- 不以净现金产生负债务权重；债务／权益、加杠杆Beta和现金桥一致。总ERP已含国家风险则不再加CRP；人民币现金流不直接套美元完整债务成本。
- 终值从正常化NOPAT及 `g/ROIC` 投入重新计算，要求WACC高于g、正ROIC及可持续终点；旧队列和剩余亏损不能消失。
- 折现时序明确；年末对照独立构建累计因子，年中条件另列并分别定义现金流和终值发生时点。
- 单位、符号、组成及非法条件有算例或断言。拒绝不变0，终值占比不设50%–70%硬门槛。

## 5. 敏感性与可编辑Excel

按[Excel建模说明](references/excel-delivery.md)独立生成核心 `DCF`、`WACC` 页，必要时另加来源／补证。预测、税务、折现、桥接、敏感性格使用活公式；只有事实、市场数据和显式条件硬编码并附批注，不用原生导出快照替代模型。

详细建模包含相关敏感性，通常5×5，中心精确等于本次条件，各格完整独立重算。WACC/g、增长/利润率、资本效率/利润率按实际路径选轴，保留必要联动；非法格说明原因，不按估值高低或接近股价选参数、赋概率。

`openpyxl`不执行公式。使用实际可用的Linux工具重算并核对；缺工具时仍交付独立Python数值与活公式工作簿，标明“Excel公式尚未执行核验”。不把空缓存当通过，不回退为静态原生结果，不引用不存在的工具路径。

## 6. 校验现有引擎与交付

先保存独立模型、条件及结果，再读取已有原生运行；需要新对照时仅为比较调用API，标明它是被测对象。不得看到目标每股值后调参、反推WACC或复制代码对齐。

对照分两类：

1. **同事实、同假设、同方法条件**：逐层比较TTM、利润调整、税基／现金税、研发、投入、WACC、年度FCFF、折现、终值、股权桥和股数。定位首次差异，保留金额差及明确绝对／相对容差，不只比较到分的价格。
2. **补证或经济／方法条件不同**：分别列PDF、经营范围、预测、税务、资本、融资／时序及索偿差异，再解释结果；不称同条件算术校验，差异不自动证明某模型错误。

只核有限模块就写“部分独立校验”。复杂税务尾部、转债或期权尚未实现时列未比较范围，不能删去或抄原生结果声称全模型通过。疑似BUG给最小输入和逐项反例，生产修正另走复现流程。

产物放 `workspace/derived/alphalake-dcf/<公司>/<本次标识>/`，旧证据保留，新运行不覆盖。交付事实／补证、显式条件、模型定义及实现签名、独立计算JSON、中文报告、公式Excel、敏感性和逐层对照；运行标识由独立执行程序产生，原生run ID另记。记录源、结果哈希和环境，主库及发布保持不变。

报告包含条件每股值／币种、各时点、关键假设、终值占比、缺项及对照结论。报价差为 `条件值/收盘价−1`；条件值不称认证目标价。独立算术、原生算术、事实证据、经济依据及预测有效性分开，未做的公式重算或完整比较如实说明。
