# 公司研究与可证伪论点

首次完整研究读取；只解释一个历史数值时不必执行。先确认范围和数据起点，再决定哪些经营证据值得展开。

## 从经济机制决定研究问题

回答“收入从哪里来、利润为什么留得住、增长要投入什么”，然后才选历史区间和可比公司。财务同比是结果，不能独自解释未来。

| 维度 | 必须解释的机制 | 可检验的反面 |
| --- | --- | --- |
| 增长 | 销量／价格／产品组合／客户／渗透率／渠道／产能，哪些主导；市场空间如何约束 | 份额上升但行业收缩、降价换量、渠道压货、集中客户流失 |
| 利润率 | 差异化、成本曲线、规模、竞争与周期；区分毛利率和经营利润率 | 毛利改善被销售／研发吞噬、一次性收益、周期高点、价格竞争 |
| 资本效率 | 研发、固定资产、库存与应收需求；轻资产、外包或预收款如何影响 | 增长需要更多存货／账期／资本开支，投入先行而收入滞后 |
| 风险与存续 | 币种、经营地区、融资／到期、控制权及经营寿命 | 杠杆、再融资、技术替代、资源枯竭与持续经营问题 |

业务分部、竞争对手只在改变这些判断时展开。消费品牌看产品／渠道／获客与复购，工业企业看产能／订单／交付及回款，软件／芯片看设计投入、产品周期与客户验证；不要求每家公司都算LTV/CAC或月度销量。不得从行业名称自动判周期；涉及周期，按[周期框架](../../../docs/valuation/cyclical-valuation.md)区分暴露、完整周期证据与条件正常化。

## 宏观证据按经营暴露选取

主库已有独立宏观域，按[来源与口径](../../../docs/guides/macro-data.md)先用`macro-series`找标准名称，再用`macro-data --series <标准名称>`读取有关期间。先读本地；仅需更新时沿`alphalake`既有手工入口，不在研究脚本另写抓取器。研究目录保存必要查询与引用，原文沿唯一来源归档。

需求可核对社零／出口／居民实际收入，周期可核对订单PMI／产能／地产，利润传导可核对出厂与购进价格，信用可核对社融组成及既有利率／汇率。说明公司是否暴露于这些市场以及为何可能偏离全国平均；不把宏观同比直接当公司增长，PMI不当增速，CPI不当预期通胀，GDP不自动当永续增长。统计期、实际／名义、原文发布时间、当前修订版本和取得时间分别写明，最新月与财报期不混称。

宏观用于研究正文中的支持／反证，当前没有自动故事绑定或参数选择，不新增证据枚举、不借Skill改变冻结引擎。未取得海外／商品统计时保留限制，不用国内总量替代全球终端需求。

## 首次覆盖要让读者认识公司

完整研究按下列问题展开成连贯解释，而非把清单复制成几句摘要。篇幅由业务复杂度和证据决定，不以管理层履历字数、固定同业数或图数凑深度。

| 模块 | 需要让读者理解什么 | 可交付的证据与估值连接 |
| --- | --- | --- |
| 公司与价值链 | 公司的产品实际解决什么问题；客户是谁、谁付款；设计、生产、分销、服务由谁完成 | 业务结构图或简表；规模、计费／成交方式、成本和现金的流向。只保留解释当前模式的关键历史转折 |
| 产品、地域与渠道 | 哪几项业务贡献收入和利润，成熟业务与新业务分别是什么；直销、经销与平台角色 | 同期业务表：规模／占比、增长、毛利或贡献（披露才填）、客户与渠道、未来驱动；地域与渠道是同一收入的不同切面，不相加 |
| 行业与市场机会 | 需求来自新增、替换、渗透还是价格周期；可服务范围和主要约束是什么 | 行业规模有出处和口径才引用；没有可靠TAM就用已有客户、份额、产能或产品范围检验远期收入，不编市场规模 |
| 竞争与优势 | 客户为什么选它、为何愿意继续付款；别人为何难复制，优势要付出什么成本 | 按重要业务挑有真实重叠的对手／替代品，比较定位、分销、成本、技术及转换成本；说明不可比处。高毛利、研发多或知名不单独证明护城河 |
| 经营与财务质量 | 增长是否转为可持续利润及现金，哪里提前投入或积累风险 | 按下表分析历史趋势及最近同期间；区别会计利润、经济调整、经营现金、模型FCFF，解释它们为何不同 |
| 管理层与资本配置 | 谁掌握资本决策，过去把钱投在哪里、兑现如何，对少数股东有什么影响 | 研发、扩产、并购、分红、回购、股权融资及关联交易的重大决策；能力判断以行动与结果为据，不据教育背景下结论 |
| 未来兑现条件 | 这家公司变得更大、更赚钱需要同时做到什么，最可能在哪个环节受限 | 把客户／产品／成本／投入机制接到收入、利润率、再投资、风险与持续期；再写可以推翻判断的观察 |

### 历史财务不能只是报数字

优先用现有最近3—5个完整年度及最近可比中期解释趋势；这是阅读窗口建议，不是估值准入门槛或继续扩采早年的要求。历史不足保留已有期间；TTM单独列，不把半年与全年连成增长趋势，不把半年乘二当全年。

| 观察 | 分析要回答的问题 | 取数与误区 |
| --- | --- | --- |
| 收入与毛利 | 哪些业务、量价或组合在贡献增长，涨价／份额／周期哪个解释更强 | 总收入沿标准事实；分部用现有披露补经营背景。只知道总收入时，量价拆分留未知 |
| EBIT、净利与费用 | 毛利能否覆盖销售、研发、履约及售后；投资收益、汇兑、税惠或一次性事项影响多少 | 报告EBIT与调整EBIT分别列，利润率必须同口径；未知调整金额不猜扣，毛利改善不等于经营优势增强 |
| CFO与利润 | 现金转换为何背离，是否由库存／应收／预付、预收／应付、税或一次性收支驱动 | 有调节表才精确归因；否则提出并核验解释。CFO不是FCFF，净利减CFO不自动等于营运资本变化 |
| 库存、应收与应付 | 占用是否跑赢销售，账期／减值／渠道压货风险如何；供应商融资能持续吗 | 余额变化和同比流量分开；周转指标使用同窗口及已知平均余额，不用两个期末数伪造完整现金循环 |
| 研发与资本开支 | 投入如何转为产品、产能或客户，失败的代价是什么 | 区分费用、资本化和真实现金；研发金额不证明商业回报，折旧也不自动等于维持性资本开支 |
| 债务与流动性 | 未来投入由利润、现金储备、借款还是股权承担，期限及限制是什么 | 现金是否受限、债务是否含租赁分别说明；合并金融资产不直接当作可自由分配净现金 |
| 资本回报 | 已有利润是否由足够资本支撑，回报能维持多久 | 优先读取已保存ROIC／资本审阅；范围或历史不足就留空，不在报告中另造ROIC或凭行业存量倍率断言新增效率 |

可用一张同口径历史表承载关键数字，正文选择最影响结论的变化展开。完整报告的基本面不能全部退到附件，术语首次出现可用一句解释或链接KB，但不把公司报告写成术语词典。

### 把事实推进成洞见

每个重要结论至少串起**观察、机制、替代解释、估值后果**。例如“库存增速快于收入”只是观察：它可能是新品备货，也可能是销售不畅；要再看销售周期、减值、折扣及后续回款。若只是备货，影响主要在现金占用及投入时点；若需降价去库，则收入、毛利和资本效率可能一起受损。缺少证据时把两种解释保留，不能直接将库存变化全归于增长或全归于经营恶化。

护城河同样要拆开：品牌溢价、渠道依赖、研发迭代速度和规模成本是不同机制，分别给支持证据及失效路径。公司自述先标明主体；重复公司愿景、写“行业领先／空间巨大／长期向好”而没有证据和估值含义，不算完成分析。

最近中报、预告、重大融资及监管／产品事件要进入经营判断，而不只出现在“资料来源”。注明本轮检查窗口及实际覆盖；新证据不一定改变数值，但须说明为什么维持或修订主张。预告不当正式事实，管理层目标不当订单或收入，未知共识不编超预期。

## 证据怎样进入判断

优先读已有标准经营证据、官方年报与最近中报、已有公司故事／论点。先核对缓存索引与共享PDF，规范路径及复用规则见[workspace指南](../../../docs/guides/workspace-layout.md#pdf归档与引用)。只补会影响一个明确决策的材料；目录、页码索引和摘要引用不等于读过原文。

- **财务事实**：标准期间、单位、合并范围及实际源版本；TDX主数值与原文冲突独列，不静默替换。
- **公司说法／计划**：谁在何时说、指向哪段期间、实现条件是什么；订单不等于收入，签约支出不等于本年支付。
- **参考／同业**：业务、地域、币种、规模、会计调整和周期位置是否可比；行业均值只作参照。
- **研究判断**：从哪些事实推向何种假设，缺哪一步证据；允许合理推断，明确尚未被事实证明。
- **用户条件**：保留原值与优先级；不把其批准计算解释为事实或概率认证。

每个用于改变假设的重要来源记录标题、主体、报告／公告时间、实际取得时点（已知才填）、文件相对路径或URL、SHA-256、页码／表格标签及证据角色。引用课程或方法不能替代公司证据。原文表述不确定时保留短引文与定位，不以哈希、重复提取或会计恒等式冒充独立语义核验。

同业分析用于检查机制和量级，不按当前估值／股价高低挑同业；缺共识预期时写“与本研究上一版条件比较”，不编造beat/miss或市场预期。

## 论点卡

围绕增长、利润率、资本投入至少覆盖这三个主题；只有证据支持时再增加。不要把报表复述当投资主张。

| 字段 | 要求 |
| --- | --- |
| 主张 | 一句可被未来证据推翻、带经营机制的陈述 |
| 当前证据 | 事实／公司计划／参考／判断分别列出，写期间与定位 |
| 反例与替代解释 | 已知不利证据、可能的会计／周期解释；不能只写“风险存在” |
| 对应参数 | 哪些收入、利润率、研发或资本路径受影响；未量化就写未量化 |
| 修订触发 | 可观察的事件／指标及检验方向；阈值若属研究选择，说明依据，不伪称理论要求 |
| 状态 | 支持、混合、证据不足、被反证；状态不是发生概率 |

例如“海外渠道扩展可持续提高销量”应同时问终端需求还是铺货、折扣与库存是否攀升；这些证据可能支持增长，也可能要求下调利润率并增加营运资本。不要把同一利好同时加到收入、利润率和资本效率却不说明机制。

已有`thesis-tracker`产物可直接读取并保留来源，**不要求再调用或安装该Skill**。落入故事文件时用既有`Evidence`／`Claim`字段：允许的证据种类是`snapshot_baseline`、`reported_fact`、`company_plan`、`reference`、`policy_proxy`、`research_judgment`；重要主张记录`evidence_state`、反例与修订。契约见[故事保存内容](../../../docs/valuation/narrative-valuation-plan.md#每个故事保存什么)，不能自创`company_guidance`种类或由Skill推断新后端能力。

## 什么时候停止搜集

已能区分关键机制、提出一套内部一致的显式条件，并解释最大证据缺口，就进入计算与交付。没有完整未来预算不妨碍使用已接通的销售资本倍率条件；未知事实不补零、未知未来不伪装成事实。若某资料只能丰富背景而不改变估值选择，记录为后续观察，不继续扩采。金融／多市场、短历史自动估计和更早历史不在当前扩展范围。
