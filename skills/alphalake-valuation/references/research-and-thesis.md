# 公司研究与可证伪论点

首次完整研究读取；只解释一个历史数值时不必执行。先确认范围和数据起点，再决定哪些经营证据值得展开。

## 从经济机制决定研究问题

回答“收入从哪里来、利润为什么留得住、增长要投入什么”，然后才选历史区间和可比公司。财务同比是结果，不能独自解释未来。

| 维度 | 必须解释的机制 | 可检验的反面 |
| --- | --- | --- |
| 增长 | 销量／价格／产品组合／客户／渗透率／渠道／产能，哪些主导；市场空间如何约束 | 份额上升但行业收缩、降价换量、渠道压货、集中客户流失 |
| 利润率 | 差异化、成本曲线、规模、竞争与周期；区分毛利率和经营利润率 | 毛利改善被销售／研发吞噬、一次性收益、周期高点、价格竞争 |
| 资本效率 | 研发、固定资产、库存与应收需求；轻资产、外包或预收款如何影响 | 增长需要更多存货／账期／资本开支，投入先行而收入滞后 |
| 风险与存续 | 币种、经营地区、融资／到期、控制权及经营寿命 | 杠杆、再融资、技术替代、资源枯竭与持续经营问题 |

业务分部、竞争对手只在改变这些判断时展开。消费品牌看产品／渠道／获客与复购，工业企业看产能／订单／交付及回款，软件／芯片看设计投入、产品周期与客户验证；不要求每家公司都算LTV/CAC或月度销量。不得从行业名称自动判周期；涉及周期，按[周期框架](../../../docs/valuation/cyclical-valuation.md)区分暴露、完整周期证据与条件正常化。

## 证据怎样进入判断

优先读已有标准经营证据、官方年报与最近中报、已有公司故事／论点。先核对缓存索引与共享PDF，规范路径及复用规则见[workspace指南](../../../docs/guides/workspace-layout.md#pdf归档与引用)。只补会影响一个明确决策的材料；目录、页码索引和摘要引用不等于读过原文。

- **财务事实**：标准期间、单位、合并范围及实际源版本；TDX主数值与原文冲突独列，不静默替换。
- **公司说法／计划**：谁在何时说、指向哪段期间、实现条件是什么；订单不等于收入，签约支出不等于本年支付。
- **参考／同业**：业务、地域、币种、规模、会计调整和周期位置是否可比；行业均值只作参照。
- **研究判断**：从哪些事实推向何种假设，缺哪一步证据；允许合理推断，明确尚未被事实证明。
- **用户条件**：保留原值与优先级；不把其批准计算解释为事实或概率认证。

每个用于改变假设的重要来源记录标题、主体、报告／公告时间、实际取得时点（已知才填）、文件相对路径或URL、SHA-256、页码／表格标签及证据角色。引用课程或方法不能替代公司证据。原文表述不确定时保留短引文与定位，不以哈希、重复提取或会计恒等式冒充独立语义核验。

同业分析用于检查机制和量级，不按当前估值／股价高低挑同业；缺共识预期时写“与本研究上一版条件比较”，不编造beat/miss或市场预期。

## 论点卡

围绕增长、利润率、资本投入至少覆盖这三个主题；只有证据支持时再增加。不要把报表复述当投资主张。

| 字段 | 要求 |
| --- | --- |
| 主张 | 一句可被未来证据推翻、带经营机制的陈述 |
| 当前证据 | 事实／公司计划／参考／判断分别列出，写期间与定位 |
| 反例与替代解释 | 已知不利证据、可能的会计／周期解释；不能只写“风险存在” |
| 对应参数 | 哪些收入、利润率、研发或资本路径受影响；未量化就写未量化 |
| 修订触发 | 可观察的事件／指标及检验方向；阈值若属研究选择，说明依据，不伪称理论要求 |
| 状态 | 支持、混合、证据不足、被反证；状态不是发生概率 |

例如“海外渠道扩展可持续提高销量”应同时问终端需求还是铺货、折扣与库存是否攀升；这些证据可能支持增长，也可能要求下调利润率并增加营运资本。不要把同一利好同时加到收入、利润率和资本效率却不说明机制。

已有`thesis-tracker`产物可直接读取并保留来源，**不要求再调用或安装该Skill**。落入故事文件时用既有`Evidence`／`Claim`字段：允许的证据种类是`snapshot_baseline`、`reported_fact`、`company_plan`、`reference`、`policy_proxy`、`research_judgment`；重要主张记录`evidence_state`、反例与修订。契约见[故事保存内容](../../../docs/valuation/narrative-valuation-plan.md#每个故事保存什么)，不能自创`company_guidance`种类或由Skill推断新后端能力。

## 什么时候停止搜集

已能区分关键机制、提出一套内部一致的显式条件，并解释最大证据缺口，就进入计算与交付。没有完整未来预算不妨碍使用已接通的销售资本倍率条件；未知事实不补零、未知未来不伪装成事实。若某资料只能丰富背景而不改变估值选择，记录为后续观察，不继续扩采。金融／多市场、短历史自动估计和更早历史不在当前扩展范围。
