# 从经营判断到显式假设

完整研究、单项假设研究与条件修订读取本页。方法以[方法契约](../../../docs/valuation/methodology-contract.md)、[显式政策](../../../docs/valuation/explicit-policy.md)及其中达摩达兰原始出处为准；本Skill不新增公式或合理参数选择器。

## 假设卡与来源层次

每个显著影响价值的假设给出：**值／年度路径、单位与实际消费字段；历史或参考锚点；公司经济依据；方法出处及本地选择；相互约束；反证与修订方向；状态**。一张表可容纳多张卡，不要求繁琐文件拆分。

状态要能区分已披露事实、参考代理、继承初始条件、用户覆盖、具名研究判断及未解决。来源初值来自历史或行业，仍不是公司预测。准备入口可能已填值，不能因此跳过论证；没有公司依据时保留原条件或提出可辨识的替代条件，不称“合理估值已完成”。

只用当前接口支持的路径，核对[数据契约](../../../docs/valuation/data-contract.md)与完整请求。`--prepare-inputs --ticker …`可配已确认的原生点路径`--overrides`；已有完整请求用互斥的`--explicit-input`。不手工拼缺失财务、不要求用户制作前端JSON，不混用BatchPolicy格式。实际`input_changes`与`dcf.forecast_parameters`优先于显示标签；显式0与空值不同。

## 参数之间的经济约束

| 参数 | 如何建立依据 | 联动和边界 |
| --- | --- | --- |
| 收入增长与持续期 | 可比同窗同比、量价／份额／产能和市场规模；历史CAGR是锚点而非答案 | TTM与年度／半年同比别混用；短期恢复不重复叠加正常增长。不机械将近期增长延续五年，或用同一持续期替所有公司作预测 |
| 经营利润率 | 当前**调整后**利润率、可比历史与竞争机制；说明目标为什么可持续 | 毛利率不是EBIT率；研发资本化、非经营收益剔除与税须同范围。历史／行业目标只作条件，不因“回归均值”自动合理 |
| 研发费用、资本化与税 | 现有队列、摊销寿命选择及未来费用／预算路径；普通扣除与税率分别说明 | 资本化不创造现金；总再投资已含资本化研发净额，不再额外加扣。保持绝对预算与保持收入费用率是不同条件 |
| 再投资与资本效率 | 现有销售资本倍率／年度倍率或显式年度总净预算，说明机制与领先期 | 历史存量倍率不自动是未来边际效率；收入增长、目标利润率与隐含回报互检。无详细预算时可用显式倍率，不新增普遍准入门槛 |
| 现金税与亏损 | 逐年经济利润、实际税基／普通扣除及已选NOL政策；长期税率需依据 | 税率不是统一21%／25%；实际税率、税基税率和现金税不同，不把全部研发自动加计扣除 |
| WACC与融资 | 同版CNY参考、无风险利率、ERP、Beta、债务成本／权重和代理 | 现金流与折现币种／名义口径一致；US行业不等于USD折现，不静默换Global，不重复叠国家溢价；正式信用与代理分开 |
| 终值 | 稳态增长、利润率、税、资本回报、竞争与风险相配 | g与币种长期经济一致并低于WACC，持续增长需要g/ROIC再投资；不强套固定g、TV占比上限或退出倍数 |
| EV到每股值 | 现金／投资／债务／少数权益／期权／转股权利及现有股数 | 利润剔除与资产加回同范围，不重复计数；代理市值与正式股类市值分开，不能扣权利后再全转股摊薄 |

不能只独立取“最好”：高增长要有市场和投入支撑，利润率上升要有成本或竞争解释，高资本效率要解释外包／预收等机制和风险。情景是一整套因果一致的条件，不是机械拼接参数高低值，也没有天然发生概率。

## 现有专项契约怎样使用

- **研发税务**：完整`research_tax`优先；需要对照才在具名入口加`--research-tax`。该条件是当前研发费用率及普通扣除，保留原基线，不改网页默认。读取`operating_tax_basis`、年度税基／现金税／NOL、`unused_nol_at_terminal`及`terminal_nol_treatment`。不能沿用旧“普通路径未计NOL”描述。比例／融资代理和抵亏到期／限额未核实部分要明说。
- **再投资**：读取`economic_checks.research_forecast`逐年费用率；改收入而绝对研发预算未变，不能称保持费用率。`capital_release`并列累计投入、释放与净额；零／负再投资可能有折旧、周转回收、处置或收缩解释，不自动拒绝或设下限，也不未经依据称已实现现金。
- **年度总预算**：`annual_net_reinvestment`是实际投资年、百万元报表币种的完整路径，与`annual_sales_to_capital`互斥；已含研发净投入及经营周转，不额外相加、不按销售领先期移动。末期核对g/ROIC与`terminal_transition`，不自动延长预算。无预算保留倍率路径。
- **税盾／未来融资**：读取`dcf.wacc_tax_shield_adjustments`、`tax_shield_basis`与`debt_tax_shield_spreads`。完整显式路径优先，未提供保留固定初始分量限制；整体WACC不能猜拆。报表信用条件只沿已批准`--reported-credit`及[人民币政策](../../../docs/valuation/native-cny-policy.md)，不用零利息或净财务费用推信用。
- **可转债**：按[市场索偿契约](../../../docs/valuation/methodology-contract.md#可转债索偿契约)读取`convertible_claim`的纯债B、权利O、含权M和原已扣账面额。主值扣纯债及权利一次后除现有股份；潜在股数仅诊断。缺报价／收益率／现金流说明无法完整定价，不恢复终局取低法。
- **周期／亏损**：只复用已批准[周期条件](../../../docs/valuation/cyclical-valuation.md)或既有显式恢复路径；五年平均不证明完整周期，负利润、释放和资源寿命保留。金融不靠补EBIT凑非金融DCF。

## 证据尚不足时的选择

保留继承基线，提出少量有机制差异的具名条件，解释它们需要什么成立；命名描述条件，不自动叫“最可能／保守／乐观”。用户已授权完整研究时可连续完成这些显式研究条件，不逐项再请求许可。需新公式、新输入、短历史估计或默认采用的提案，记TODO等待审批。

敏感性只用现有能力及获授权的明确变量变化：固定其他实际输入，保留拒绝；不拿高低值或接近股价选情景。资本效率用现有`tools.compare_native_capital`，限制见[资本效率](../../../docs/valuation/capital-efficiency.md)。统一候选用`tools.evaluate_native_policy --selection-policy`，但`selected_scenario=null`正常，历史均值及3／5／10年不是认证选择器。

## 公司证据的数量边界

补证先用`tools.review_operating_evidence`核对标准最近五年／TTM与SQLite，金额元。折旧及营运资本范围用`tools.derive_tdx_capital`，见[资本定义](../../../docs/valuation/native-capital-definition.md)。D&A空不代表TDX无分量；EBITDA−EBIT为0不证明无折旧，分量也可能合并列示，不能跨期固定相加。三项CFO调节不等于完整非现金营运资本。

报告`budget_review_index`只定位候选页；承诺、计划、付款及已完成投入不同，已签约／仅批准、建设／对外投资、合并／母公司须分开。自然年计划不等于下一TTM年总净预算，正承诺不单独反证负再投资；见[报告到预算](../../../docs/valuation/narrative-valuation-plan.md#从报告证据到资本预算)。

经营利润与资产成套剔除按[共同口径](../../../docs/valuation/valuation-book-proxies.md#显式共同口径交付)。标准EBIT优先直通；人工条件保留来源、基线与差异，不修改事实或自动启用旧公司专项。历史缺项、报表范围未闭合与未来预算未证实分别说明，不用一份PDF为整套DCF背书。

跨公司复验使用`tools.review_operating_constraints`，先按[约束契约](../../../docs/valuation/narrative-valuation-plan.md#经营证据到预测约束)冻结分母、观察值与三类参数卡。产量不是销量，分部毛利率不是调整EBIT率，半年投入比例不是TTM研发比例，签约承诺不是某年净预算。已有来源和公式只能建立条件关系，不能唯一选出未来数值；并列实际预测与原文条件桥的差额，保留TDX精度。首年可算不为后九年背书，未审核公司／参数照列，不将方向卡或定量关系卡称为机器经济认证。该入口不产生新默认或另一套DCF。
