# 北交所行业代理与自动估值

财务身份补证使北交所265家公司在已验收副本中拥有15项核心输入，但Damodaran公司名单的SHSE/SZSE部分不覆盖北京交易所；其中BSE标记指印度孟买，不能改当XBSE。TDX申万分类已为北京股票提供另一条来源证据。新映射只进入估值政策，保留TDX原分类，不向标准行业表写入“该公司属于Damodaran某行业”。

## 显式映射的依据

使用同一标准就绪度快照（2026H1，披露截止2026-09-10T04:42:23Z），选择同时拥有唯一TDX申万与唯一Damodaran行业的沪深股票，核对北京市场实际出现的128个TDX行业。得到3,029家沪深公司的分类共现，保存为 [`bse-shenwan-cohort-2026H1.csv`](../examples/bse-shenwan-cohort-2026H1.csv)。来源快照路径、SHA、范围和政策门槛见[元数据](../examples/bse-shenwan-proxies-2026H1.source.json)。这是本地已验证来源投影的分析摘录，CSV复算不等于重新独立解析全部原始源文件。

本轮明确采用“至少5家公司、最高共现分类占比至少80%、该代理在非金融目录准入清单内”的政策门槛，冻结48项映射；80项不满足者逐项留空并说明原因。完整清单见[代理CSV](../examples/bse-shenwan-proxies-2026H1.csv)。该门槛不是统计置信度，也不是北京公司的收入权重、经营地域或规模风险证明；沪深分类的一致性不能自动证明北京公司具有相同业务结构。

例：厨房小家电共现10家，其中9家归于Furn/Home Furnishings；清洁小家电7/7；仪器仪表50家中41家为Electronics (General)。仅凭中文行业名将它们直接放入Household Products或Machinery会偏离这些实际来源观察。相反，品牌消费电子、工业控制、其他专用设备等分类分散，本轮不强行指派单一全球行业。既有专门公司政策不因该跨市场代理而被改写。

获准映射同时选择同一全球行业的Beta、来源目标D/E和资本效率，继续沿用已有版本化经营预测、BBB信用利差及中国暴露情景。这些仍是条件估值假设，不是公司实际WACC，也不证明研发/租赁、周期及产品组合已经同口径调整。参考样本量、时效、财务符号、混合金融业务等既有门槛继续生效。

## 使用与边界

```bash
# 在 valuation/backend 下，展开原78行业政策并附加48条仅供XBSE使用的规则。
python -m tools.prepare_industry_policy \
  ../examples/a-share-nonfinancial-recipe-2026H1.json \
  --bse-crosswalk ../examples/bse-shenwan-proxies-2026H1.csv > ./data/combined-policy.json
```

生成结果直接交给既有 `batch_valuate_alphalake` 或 `refresh_valuate_alphalake --policy`。新规则要求标准证券的`exchange_mic=XBSE`，来源、分类体系、节点代码及名称全部匹配；还需满足观察/运行时点及年龄门槛。有效期内代码同名义改变时明确拒绝，不能悄悄套用旧政策；陈旧证据仍按原规则忽略。新增类别不会因源码目录扩充而自动获准。隔离类别及原因进入批次政策审计信息。

完整副本快照实测：5,223家非北京股票的原78行业路由逐条保持不变。346家北京股票中118家命中代理政策，其中89家核心输入齐全、22家缺输入、7家无标准事实；另外228家未命中，其中176家核心输入齐全，仍需进一步解决行业或业务拆分依据。命中政策不是估值成功数，实际运行结果见下节。

校验覆盖：冻结共现CSV重算准入/隔离、来源行业名称、仅XBSE路由、名称变化拒绝、陈旧证据排除、重复/未知代理/缺理由拒绝。Python全套237通过、4项既有跳过；Go全套与构建通过，未新增依赖。


## 副本实际批次验收

`workspace/bse-publication-20260910/batches/batch-3vthj_qr.json` 保持完整5,569证券分母，仅启用48条XBSE代理规则，以相同2026H1/04:42:23Z截止运行：118家命中者中，57家产出条件股权估值、30家输入/政策拒绝、31家缺输入；其他市场未启用政策，不能据此把它们记成估值执行失败。没有执行异常或公司遗漏。

57家中50家来自本轮235家新增核心输入齐全公司，7家原先即齐全。30项拒绝：收入/调整EBIT非正15、股权残值非正10、股本或账面索偿/现金符号不满足5。31项缺输入中，29家已有核心缺项；另2家虽具备15项核心输入，但不足两组同季度收入同比历史，不能硬造增长率。

这些仍为副本、报告日账面桥接及透明代理假设下的验证性结果；不称为57家公司已经逐份财报核对通过，也不称为市场目标价。原库78行业批次仍在运行，主库更新、合并范围的最终验收及剩余行业映射持续推进。
