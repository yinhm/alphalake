## 资本效率：不再对两家公司采用相同补证优先级

事前固定同一压力幅度：仅将收入资本比乘0.75或1.25。不是重新拟合，不是置信区间，不根据结果搜索倍率；不改变收入、利润、税率、WACC、终值ROIC及股权桥接。工具复用共享引擎，并对基线及两个资本情景作独立十进制复算。

## 重放与验证

实现放在`valuation/backend/tools/review_company_inputs.py`，本目录只保存台账及说明。Python使用项目backend依赖；原文验证另需pypdf。示例（已安装backend的Python环境）：

```bash
export PYTHONPATH=valuation/backend
export ALPHALAKE_VALUATION_RUN_DIR=workspace/company-input-review-runs
python -m tools.review_company_inputs valuation/research/method-closure-20260912/300866-request.json.gz --output valuation/research/company-inputs-20260917/300866.json.gz --check
python -m tools.review_company_inputs valuation/research/method-closure-20260912/002032-request.json.gz --output valuation/research/company-inputs-20260917/002032.json.gz --check
python -m pytest -q valuation/backend/tests/test_company_input_review.py valuation/backend/tests/test_method_closure.py
python internal/ingest/testdata/anker-valuation-2026/verify.py
```

压缩台账内包含基线run ID、资本情景run ID、十年FCFF/净投入、来源事实、参考及政策。资产单项压力只在内存中运行，附分量与结果，不冒称统一入口已批准的新政策或单独持久化运行。`--check`逐字节重建台账；引擎升级须审查差异再冻结，不能自动覆盖旧证据。
