# 当前财务契约输入

这12份输入用于当前回归和工具，全部为财务契约v2；由既有冻结证据一次性转换，当前代码不包含转换器，也不在读取时兼容旧契约。它们是输入，不是继承旧运行ID的估值结果。

`receipt.json` 逐文件记录原路径、原SHA-256、新路径和新SHA-256。转换实现为提交 `abe245a` 中的 `valuation/backend/tools/migrate_standard_contract.py`；需要重建时在该历史提交的独立工作区运行，不恢复到当前入口。原研究目录、来源文件及旧收据未改写。

- 命名由原输入已有的标准语义列确定；源编号独立保留为血缘，股本期间标签统一为instant。
- 标准历史五家公司及2025H1回溯只提取本轮需要的请求和实际快照；原报告用于数值交叉比较，不复制旧run ID为当前运行。
- 政策数值、事实值、单位、源位、窗口系数、输入期间和补充证据均保持。新契约改变证据哈希，新运行必须自行生成标识。
- CI全量pytest包含 `test_current_contract_evidence.py`，逐文件校验新旧哈希，并核对完整标准财务内容和政策参数；原文及源位核验仍由既有工具执行。

财务字段齐全或估值成功不表示公司政策获准，原有缺项、分类边界和条件估值限制不变。
