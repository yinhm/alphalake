# 多年增长路径复验

结论：提前收敛候选未通过采用门槛，不进入新增留出评分，不修改生产增长政策。协议在实现和评分前以3bf770f冻结；本轮使用原60家开发样本，并非新样本外验证。

[协议](protocol.json)、[完整结果](development-result.json)及[摘要](development-summary.json)分别保存；源快照沿用既有现金研究，并绑定文件哈希，不复制源解析或生产增长规则。

## 比较范围

共300个候选组合，202个可评价、98个拒绝；所有模型使用相同公司/起点/期限集合。2022H1和2023H1各看两年、三年，2024H1看两年，目标最晚为2026H1。公司跨起点/期限相关，不将202组当作202家独立公司。

原路径前五年沿用当前裁剪增速；候选第一年相同，第二至五年线性过渡到政策明确的2%稳定增速。零增长为独立基准。三个模型均保持当前调整EBIT利润率，未经利润校准；2%是冻结研究政策，不是公司事实或历史市场利率。候选使用现有引擎`_revenue_growth_path`，当前增速使用共享`historical_forecast`入口。

## 收入结果

指标：收入绝对误差占实际收入的均值（%），非估值误差。

| 合计 | 202/300 | 55.831385 | 40.435669 | 51.020439 |

提前收敛相对原路径主要误差改善约8.62%，收入WAPE 39.5034%→36.9138%，逐期限、逐起点/期限以及逐一删除公司后的门槛均通过；调整EBIT误差和WAPE也较原路径改善。然而零增长主要误差仅40.4357%，显著低于候选51.0204%，故零增长基准非劣门槛失败。零增长WAPE 37.6365%又略高于候选36.9138%；公司等权和规模加权指标存在取舍，不能只挑有利指标宣布获准。

两年集合122组：原路径42.6159%、候选40.9727%、零增长35.0805%；三年集合80组：原路径75.9851%、候选66.3433%、零增长48.6023%。总体有符号收入偏差仍明显为正，提前收敛并未解决所有过度外推问题。

这支持继续质疑近期增速的机械多年延续，但不自动批准零增长作为默认政策；如将零增长升级为正式候选，须另冻结比较和新的未接触留出，不能借本轮开发结果代替独立验证。当前证据只到两年/三年，不能称前五年路径已完整验证。
