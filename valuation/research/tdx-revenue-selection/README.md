# 历史误差选择收入规则：冻结协议

2026-09-11冻结，尚未实现或评分。继承[三年增长协议](../tdx-revenue-cagr/protocol.json)的600家开发名单、三起点、一年期限、源快照、信息/评价截止及两项收入对照。原三年增长候选已失败，本轮不调整它的窗口或门槛，不覆盖旧结果。

要检验的是：同一家公司已兑现的历史预测误差，能否帮助选择当前收入假设。只在短期同比与零增长之间选择，不新增增长公式，不按行业或月度经营细节分支。两项输入仍属情景假设，选择算法不冒称达摩达兰规定；估值方法、FCFF和再投资定义不变，方法边界沿用[准确度规范](../../../docs/valuation-accuracy.md)。

## 选择规则与时间顺序

对每个公司和当前起点Y年H1：

1. 当前短期同比及零增长按既有收入工具取数，利润不参与准入。短期基线不可用时保留阻断，不用选择器绕过原数据要求。
2. 只考察Y−3、Y−2、Y−1三个历史H1起点。每个历史预测只能用该年9月1日中国零点前可用的记录；各自预测次年H1。历史目标值只读**当前Y年9月1日**前可用的版本，不使用总研究评价截止补出后来才披露的结果。
3. 至少有两个两规则和历史目标都可评价的配对，才按各自平均绝对百分比误差选择较小者；精确相等选择零增长。少于两对则显式记录`insufficient_matured_history_use_baseline`，沿用短期基线，不删除公司。三年、两对及平局策略均为本项目事前选择，不作参数扫描。
4. 先保存所有公司当期预测、选择理由、历史预测/目标及来源，再读取Y+1年H1实际值评分。历史目标可以等于当前报告期，不能晚于当前期或当前信息截止。当前目标不可用于选择。

源文件后来取得、旧FN314不能排除后续修订，仍是简化TDX回溯，不是严格PIT。缺失、重复身份、日期非法和非正实际收入保留原因，不能算成零误差。未知历史可比性继续留痕，不以“有历史误差”替代业务证据。

## 采用门槛与交付

[协议](protocol.json)绑定父协议哈希。门槛继承其900组、300家、每起点200组、主误差至少改善5%、WAPE不劣、两项指标不劣于零增长、每起点最多退化5%、逐公司删除非劣约束；本轮额外要求候选保留短期基线可评价组合的100%。既有不足历史沿用基线是明确政策，须分别报告其覆盖、误差及实际切换数量，不能用大量沿用掩盖选择器本身的表现。

实现复用现有收入取数与短期公式，保持父协议及工具不变。测试须篡改当前目标收入、当前截止后日期及未来记录，证明选择与预测不变；缺历史触发有标签的沿用，历史配对不齐不混用不同分母；亏损/缺利润不影响选择；完整结果与手工重算的历史选择、误差和门槛核对。

开发不通过则保留结果、不进入新留出、不调参挽救。通过后先冻结选择，再核验全部已登记排除集合、固定新独立留出及其门槛，最后才评分。即使收入规则通过，也需进一步验证利润和再投资的联合效果，不能直接宣布完整DCF准确度提高。
