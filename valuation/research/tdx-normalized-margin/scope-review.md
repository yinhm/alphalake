# 正常化利润的适用范围与历史可比性复核

四个事后诊断案例均存在需要单独审核的业务变化证据；其中两家还确认了研究TDX收入沿用调整前口径。当前没有证据把“有五年数字”视为“业务成熟、完整周期、口径可比”。立即及渐进候选的失败结果继续保留，不据本次发现删公司、重调过渡年数或宣布新规则通过；原120家留出仍未提取或评分。

方法依据为[达摩达兰正常化利润原文](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)：正常化主要适用于成熟周期业务，历史应覆盖完整周期；利润率可以处理公司规模变化，但不能仅靠除以收入就证明业务组合和会计口径可比。这里对业务适用性的判断是本项目的证据分析，不是达摩达兰给这四家公司的结论。

## 如何选取与核对

复用已评分开发结果，对每家公司累加六窗口中可评价的“渐进候选绝对EBIT误差减基线绝对EBIT误差，再除以实际收入”；选退化贡献最大的两家及改善贡献最大的两家，同值按代码排序。[配置及证据定位](scope-review.json)、[完整125家公司排序与四例结果](scope-result.json)可重放。排序发生在已看过结果之后，属于目的明确的异常诊断，不是事前冻结的适用范围或独立验证。

原分母仍是240家公司、1,440组，995组基线可评价、578组共同可评价、125家公司。四例合计19个已评价窗口，不能由四例推断全体成熟周期公司的表现。选样跨窗口，计数分别为太阳能6、国科微4、九安医疗6、盛新锂能3；贡献按总和选取，没有冒充每家公司等权均值。

本轮定向取得四份2022年报，业务及可比性证据在文件载明的2023年披露，早于本研究最早2023年9月1日起点截止。取得发生在2026年，仍不证明历史当时留存或严格PIT。三份来自CNINFO，九安医疗使用东方财富托管的发行人原报告，未将镜像标作CNINFO归档。具体URL、取得时间、全文件SHA及workspace路径在配置中。

## 原披露与追溯调整的实际差异

单位：人民币元。2021的四季度FN230源位逐项求和，与2022年报披露的原口径及追溯后口径分别比较。

| 公司 | TDX四季收入加总 | PDF调整前收入 | PDF调整后收入 | 报表调整额 |
| --- | ---: | ---: | ---: | ---: |
| 000591 | 7,015,771,904.00 | 7,015,771,852.94 | 7,026,819,004.01 | 11,047,151.07 |
| 002240 | 2,934,272,416.00 | 2,934,272,468.13 | 3,017,155,553.58 | 82,883,085.45 |

两份年报均将变化归于解释第15号试运行销售相关会计政策。两组源加总与调整前差额分别51.06元和−52.13元，在四个独立float32季度的舍入界内；调整后差异远超该界。另核对四家公司2022年收入及另两家2021年收入，八个年度合计均与指定原披露金额在源精度界内相符。

这不是解析器把万元读成元，也不能据此认定源文件损坏；它证明这些历史季度并非2022年报提供的最新可比口径。尚未核对这些年度全部EBIT分量是否同时调整，故不宣称已定位某个年度内的利润/收入版本混用，也不据调整额直接修正利润率。

发现写入研究诊断，原TDX快照、原评分和生产标准事实不改。下一步需要对正常化所需的期间建立可比性证据，再决定显式调整或保留不可评价；不能静默用PDF覆盖TDX，也不要求所有公司重新全量抓CNINFO。

## 下一步的具体研究缺口

调用链为`backtest_tdx_normalized_margin.study`→`revenue_forecast`→生产`historical_forecast`：在尝试正常化前要求当前收入和EBIT为正。原445组基线阻断中，370组因当前收入/EBIT非正被拒绝；该理由合并两项，不能直接把370称为全部亏损公司。因而本轮没有评价起点亏损公司的恢复，这是达摩达兰正常化讨论中的重要情形。

后续应先在原开发样本中只读取起点信息，区分非正收入、经营亏损、历史均值不适用及历史不足，再冻结一项亏损恢复候选与覆盖门槛。需要保留零增长/当前利润的数学基线，并明确原生产模型拒绝范围；不能为凑共同样本只保留恢复成功者。业务周期和追溯调整证据应与此同步核对，原120家新留出在开发通过前继续不评分。该后续[亏损恢复开发试验](../tdx-loss-recovery/README.md)现已完成600家扩展，217组共同可评价但未通过，仍未进入留出。

## 可重复校验与范围

提交的是从四份原文抽取的15个完整PDF页面（派生证据，保留页面映射），合计约1.5MB；没有把抽页文件冒充全份原始文件。准备时逐页比对完整原文与抽页文本；全份哈希及重提取再次通过，见[本地全归档验收](scope-evidence/archive-check.json)。全份原文仍保存在回执中的workspace。

默认CLI和CI直接解析提交的PDF页面，核对47个金额及业务锚点，并将八个年度收入与既有TDX源快照逐位读取结果对账。抽取按物理页、固定章节/标签、出现序与金额列序；删除空白用于还原九安医疗等表格的跨行金额，不做模糊数值搜索。太阳能p15“太阳能发电”前有两处公司名称、随后两处收入构成行，毛利率表使用第5次出现；盛新锂能p23新能源收入从“分行业”起定位。特例只用于固定证据，不推广为通用财报解析器。

在`valuation/backend`执行：

```bash
python -m tools.audit_tdx_normalized_scope ../research/tdx-normalized-margin/scope-review.json
python -m tools.audit_tdx_normalized_scope ../research/tdx-normalized-margin/scope-review.json --raw-dir ../../workspace/tdx-normalized-margin-scope-20260911
python -m pytest tests/test_tdx_normalized_scope.py -q
```

`--raw-dir`额外强制校验全份原文SHA及抽页文字一致；缺文件会失败，不静默跳过。默认不声称已核对本地全归档。回归包含独立从预测与实际值重建125家公司排序、金额加0.01拒绝、调整后金额冒充原值拒绝、源绑定及PDF篡改拒绝。使用既有pypdf依赖，CI既有pytest入口覆盖，未新增依赖；本轮未核对四家公司所有历史EBIT或研发资本化，不能声称完整达摩达兰估值已验证。
