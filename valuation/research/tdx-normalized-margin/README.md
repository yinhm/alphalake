# 五财年利润率代理的历史验证

立即正常化与五年渐进正常化两轮开发比较均未通过，候选不采用、不进入新留出。五财年利润率均值不能机械替代所有公司的当前利润率；这不否定达摩达兰按业务与周期选择正常化依据的方法。后续[四例适用范围复核](scope-review.md)已确认业务变化和两处调整前收入沿用，进一步限制将该结果解释为同口径周期正常化效果。

方法参照[达摩达兰正常化利润说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)：以历史利润率估计正常化盈利；周期公司应覆盖完整周期，通常5—10年。本候选使用五个完整财年的等权平均利润率，属于待验证输入代理，不声称五年已覆盖每家公司周期。

[协议](protocol.json)冻结后先为[开发名单](development-study.json)提取来源。240家开发来自已有登记样本，120家新留出按固定SHA256顺序排除所有既有研究名单；未按完整度或结果选择。开发通过门槛前不提取新留出。三起点六窗口：2023H1到未来1/2/3年、2024H1到未来1/2年、2025H1到未来1年；实际值版本截止2026-09-10中国零点，起点信息截止为当年9月1日中国零点。

零增长加当前利润率为基线，零增长加五财年平均利润率为唯一候选，原生产增长加当前利润率为额外比较。主指标为EBIT绝对误差/实际收入的均值，要求改善至少5%，EBIT WAPE与原生产比较不退化，各期限不退化，每窗口容忍最多5%退化，逐公司删除后不退化。财年缺失或平均利润率不在(0,1]时保留阻断；历史单年亏损不删除、不归零。分母同时报告基线可评价与候选可评价，公司适用范围依完整历史限制，不承诺全市场覆盖。

已完成开发评分。原2021年以来档案不足以提供2023起点的五财年历史，已补取2018—2020季度包并复用现有Go解析；TDX源值不发布为标准事实，不回写主库。严守后来取得版本及FN314不等于严格PIT的边界，不以盈利预测准确度代替FCFF或完整估值有效性。

开发评分实现复用现有TDX期间、FN314可用性和经营利润计算；正向模拟已验证五年等权均值保留单年亏损，未来实际值变动不影响起点预测，缺季度及晚于起点的年度证据保持候选阻断。该模拟不代替真实来源验收。当前CLI只开放开发评分，留出评分须开发通过后再冻结实现与选择。

开发实现全套检查：Python298通过、4项既有上游测试数据缺失跳过；Go全套及构建通过，无新增依赖。该阶段只覆盖开发实现；随后真实来源与评分结果见下文，不能将测试通过当成预测有效性通过。对2018—2020字段口径的研究外推不扩大生产映射审核有效期，新增年包记录也不替代缺失季度证据。

经营利润继续采用基线的TDX财务/投资调整代理，保持比较口径一致；未因此证明每家公司已完成研发资本化、全部租赁和兼营业务经济调整。即便预测门槛通过，也需单独核对这些达摩达兰估值适用条件后才能进入公司估值政策。

## 实际开发结果

冻结顺序为协议`8c54a8c`、开发实现`fdd1482`、评分前源快照`318df0a`，之后才评分。[源回执](source-receipt.json)记录34个包、240家公司、7,400条源记录；原22个包及取得时间保持原版本，新增12个旧季度包采用当次TDX清单MD5/大小逐一核验。首次下载在2020Q1超时，未发布成功清单；失败归档保留，重试逐文件保存取得时间、失败记录和完成清单后才生成完整快照。取得时间描述本次下载，不冒称历史当时已留存。

[完整结果](development-result.json)及[摘要](development-summary.json)：240家公司、六窗口共1,440组；995组基线可评价，候选共同可评价578组、涉及125家公司，占基线可评价的58.09%。445组基线阻断保留；另417组候选阻断包含324组年度证据不全、93组平均利润率不在(0,1]。原120家新留出没有提取或评分。

## 五年渐进正常化复验

先冻结[渐进协议](gradual-protocol.json)（`5926e7d`），再提交实现与未来值隔离检查（`93c724d`），之后评分。复用现有AlphaLake历史年度政策，第一至第三年分别调整当前利润率与历史均值差额的20%、40%、60%，第五年到达历史均值；收入保持零增长。五年线性过渡是显式输入假设，不是达摩达兰对所有公司的规定，也不代表已识别每家公司的完整周期。本次只评价一至三年，未验证第四、第五年预测。
