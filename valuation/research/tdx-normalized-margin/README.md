# 五财年利润率代理的历史验证

方法参照[达摩达兰正常化利润说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)：以历史利润率估计正常化盈利；周期公司应覆盖完整周期，通常5—10年。本候选使用五个完整财年的等权平均利润率，属于待验证输入代理，不声称五年已覆盖每家公司周期。

[协议](protocol.json)冻结后先为[开发名单](development-study.json)提取来源。240家开发来自已有登记样本，120家新留出按固定SHA256顺序排除所有既有研究名单；未按完整度或结果选择。开发通过门槛前不提取新留出。三起点六窗口：2023H1到未来1/2/3年、2024H1到未来1/2年、2025H1到未来1年；实际值版本截止2026-09-10中国零点，起点信息截止为当年9月1日中国零点。

零增长加当前利润率为基线，零增长加五财年平均利润率为唯一候选，原生产增长加当前利润率为额外比较。主指标为EBIT绝对误差/实际收入的均值，要求改善至少5%，EBIT WAPE与原生产比较不退化，各期限不退化，每窗口容忍最多5%退化，逐公司删除后不退化。财年缺失或平均利润率不在(0,1]时保留阻断；历史单年亏损不删除、不归零。分母同时报告基线可评价与候选可评价，公司适用范围依完整历史限制，不承诺全市场覆盖。

当前仅冻结设计，未评分。原2021年以来档案不足以提供2023起点的五财年历史，接下来补取2018—2020季度包并复用现有Go解析；TDX源值不发布为标准事实，不回写主库。严守后来取得版本及FN314不等于严格PIT的边界，不以盈利预测准确度代替FCFF或完整估值有效性。

开发评分实现复用现有TDX期间、FN314可用性和经营利润计算；正向模拟已验证五年等权均值保留单年亏损，未来实际值变动不影响起点预测，缺季度及晚于起点的年度证据保持候选阻断。该模拟不代替真实来源验收。当前CLI只开放开发评分，留出评分须开发通过后再冻结实现与选择。
