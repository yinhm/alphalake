# 研发费用、总投入与开发支出余额

金迪克两期原文与TDX桥接确认：**FN304是费用化研发，FN34是期末开发支出余额；两者都不能直接代替本期研发总投入。** 本轮只核对已暴露公司的输入范围，不新增预测规则、估值或标准映射，不改变既有失败回测。

## 两期数值

金额单位为人民币元。同比使用同份报告上年同期比较列，不将后来取得的比较值冒称历史起点已留存。

| 项目 | 2023全年 | 2024上半年 |
| --- | ---: | ---: |
| 费用化研发投入 | 15,471,820.82 | 12,791,059.40 |
| 费用化研发同比 | −52.26% | +98.40% |
| 资本化研发投入 | 15,990,870.05 | 7,907,105.73 |
| 研发总投入 | 31,462,690.87 | 20,698,165.13 |
| 总投入同比 | −31.81% | +34.49% |
| 开发支出期末余额 | 42,174,450.66 | 50,081,556.39 |
| 总投入中的折旧及摊销费 | 9,048,215.83 | 4,493,307.03 |

2023年报物理第20页、2024半年报第12页的研发投入表，分别与第198页、第148–149页研发附注交叉一致；同一报告内交叉一致不是第二条独立来源。两期费用化金额另与合并利润表一致，转float32后分别为15,471,821和12,791,059，与FN304逐位相同。合并资产负债表开发支出转float32后为42,174,452和50,081,556，与FN34逐位相同。保留源精度，不恢复小数。

两期开发支出滚动表分别满足：26,183,580.61＋15,990,870.05＝42,174,450.66；42,174,450.66＋7,907,105.73＝50,081,556.39。这里余额差恰好等于内部开发增加，**不能据此把所有公司的FN34差分当作资本化投入**：表内另设其他增加、转无形资产、转损益等列，本样本这些列未列金额，不是通用零值规则。

2024半年报第96页还说明，自主研发形成的无形资产摊销计入研发费用。报告研发总投入包含折旧及摊销，因此既不是研发现金支付，也不是可以直接全部叠加到现有资本开支的“新增现金再投资”；不能将全部折旧摊销都认作研发资产摊销并扣掉。费用化/资本化分配、既有无形资产摊销及现金流分类仍须另行识别。

调用链上，[M1](../../backend/engine/module_1_adjustments.py)开启研发调整后会把当前研发输入加回EBIT，并按历史序列增加研究资产。因此不能仅将该输入换成“研发总投入”：已资本化部分本就未作为当期研发费用扣除，账面已有资产也不能重复追加。总投入可以作为另一项研究特征，替换会计调整输入则需要完整的既有资本化及摊销桥接，本轮不作这种替换。

## 对预测研究的约束

[既有研发利润候选](../tdx-rd-profit/README.md)检验的是FN304费用序列及显式五年寿命政策，并未声称使用研发总投入。本次发现不推翻其失败结果，也不证明改用总投入就会有效。费用化同比98.40%与总投入同比34.49%的差异说明，后续不能把FN304变化直接解释成研发投入增速或未来收入增速。

现有600家48字段快照没有资本化研发流量；本次只增加两条独立研究记录的FN34/FN304核对，不扩大600家的完整输入覆盖。后续候选必须分别声明使用费用化研发还是总投入，列明资本化范围与摊销重复风险；没有流量来源时保留缺项。商业化滞后与新增资本回报尚未检验，不能通过删掉高研发费用率公司代替这些输入。
