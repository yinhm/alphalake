# 中国天楹：债券零值与额外融资款核验

六家定向候选中完成首家000035的2021/2022年末核验。两份完整年报来自CNINFO：[2021](https://static.cninfo.com.cn/finalpage/2022-03-31/1212745954.PDF)、[2022](https://static.cninfo.com.cn/finalpage/2023-04-29/1216697044.PDF)。URL、实际下载时刻及SHA见[evidence.json](evidence.json)。没有把URL路径日期当作独立公告目录证据；这里只用于已授权简化历史研究，不生成标准PIT事实。

## 债券零值

两年原始合并资产负债表的“应付债券”行均空白（物理p153/p108），各自债券章节均勾“不适用”（p145/p101）；把其他列示的非流动负债逐项加总，精确等于相应合计。2021原始期末列与2022期初比较列逐项一致。

这支持两期期末债券余额为零，但证据性质是**报表空白、章节适用性及合计勾稽共同支持的零**，不是原文打印数字0，也不能证明报告期内没有任何融资行为。保留TDX FN56原始零位，不覆盖源数据，不把此结论推广到其余源零。

原三起点“所有分量非零”的33/37/33统计原样保留；它是源形态盘点，不是经济完整率。本轮完成候选6家中的1家、12个债券期末槽位中的2个证据核验，另外5家仍待核验，不改全市场覆盖率。

## 源值与到期拆分

FN41、FN55、FN52、FN439各两期，共8个源值与2022合并主表对应列匹配。FN439保留万元两位小数后编码float32的观察结果（9488.76 / 3473.55），原文元金额与源金额差异保留在[result.json](result.json)，不恢复损失精度。其余三字段按元float32比较。源记录须唯一、包报告期一致、FN314在2023-09-01中国零点前可用；没有把研发研究的输入改成新标准事实。

2022年报p192的一年内到期负债分为借款、长期应付款、租赁负债，两列分量合计均精确闭合FN52对应原文总额。p193的长期融资应付款扣减到期部分，精确等于非流动长期应付款。不能把“含到期部分的融资款总额”再全额加到FN52之上。

## 五项常见债务之外

2022年末另有：

| 原文项目 | 元 | 位置 |
| --- | ---: | --- |
| 非流动长期融资应付款 | 1,093,896,222.71 | p193 |
| 其他应付款中的第三方借款 | 179,399,509.17 | p191 |
| 其他应付款中的供应商融资 | 89,999,999.91 | p191 |
| 合计 | 1,363,295,731.79 | Decimal加总 |

供应商融资附注明确支付义务对手方转移到融资资金提供方。以上是相对“五项常见债务”的额外融资性款项清单，不是完整债务估计或最终Damodaran债务政策；承兑票据、其他非流动负债等仍待分类。它直接说明不能仅因补齐债券零就声称债务完整。

p192另显示合并其他流动负债涉及B&I保险合同准备金，不能把公司当前行业标签当作没有金融业务的证据；未去合并保险业务，经营资本、完整再投资及ROIC继续留空。没有生成估值或更改生产准入。

## 重放与拒绝

在仓库根目录，使用项目Python环境：

```sh
cd valuation/backend
python -m tools.verify_cnty_debt
python -m pytest tests/test_cnty_debt.py -q
```

[验证器](../../../backend/tools/verify_cnty_debt.py)沿用已安装Poppler逐页提取与标准库Decimal/float32核对，无新增依赖。两份PDF、最小源记录及台账均自包含入库，既有Python CI已安装poppler-utils并自动发现新增回归。

[source.json.gz](source.json.gz)由已核对34包的原600家公司源快照筛选两条完整记录，保留源包元数据和父快照SHA；本地逐条复核与原快照一致，不另造解析器。每次校验锁定源与PDF哈希、合并范围/单位/财年、两期原文列、到期及融资拆分和源位；篡改原文台账0.01元、FN52一位、FN56零位，或替换成同样有债券空白的母公司页均拒绝。

金额提取和恒等式验证不能替代独立语义复核；这里的融资分类依据保留在原文附注。剩余五家不因本样本通过而自动视为通过。
