## 关键反例：FN56为零不等于没有债券

湖北宜化[2021年原始年报](https://static.cninfo.com.cn/finalpage/2022-04-09/1212858037.PDF)物理p113的债券章节为“适用”，列有中期票据；p195的到期负债附注明确列示：

| 2021年末一年内到期负债构成 | 元 |
| --- | ---: |
| 长期借款 | 4,174,967,040.00 |
| 应付债券 | 20,000,000.00 |
| 长期应付款 | 346,874,390.98 |
| 租赁负债 | 1,000,000.00 |
| 应付利息 | 12,169,734.67 |
| 合计 | 4,555,011,165.65 |

五分量精确等于合并主表FN52对应总额。债券章节的金额跨行打印，已目视核对；金额机器断言取p195正常金额行，不拼接其他列。**FN56对应非流动部分，债券移入一年内到期后仍然是债务；如果已加整个FN52，不能再加一次到期债券。** 也不能把所有FN52分量简单标为不含利息的贷款本金。

另外九份年报的债券章节均“不适用”。这与相应主表源零相互支持，但空白仍保留为报表列示证据，不说原文打印0。全批十个FN56源零中只有青岛双星2021期末明确打印0.00。

结合此前中国天楹，原六家共12个年度槽位的FN56对应列已核验，48个非零债务源值已匹配；其中湖北宜化2021必须保留“到期债券仍存在”的反例。原145家候选池及600家开发分母没有变化，不能推断其余源零或全市场完成率。
