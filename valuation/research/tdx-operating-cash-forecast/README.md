# 报表经营现金流预测复验

当前开发164/180、预留120家公司331/360个组合均通过冻结门槛；留出OCF误差改善6.84%，现金代理误差改善6.09%，尚未替换生产DCF政策；已接入统一入口的显式现金交叉检查。上轮存货调节预测未胜过零贡献基准；本轮回到可逐期核对的报表OCF目标。生产DCF以收入增量÷资本效率预测总再投资，而报表OCF减资本开支仍包含经营税、融资/投资收益及其他分类差异，不等于FCFF；本研究不以现金代理替代完整估值准确度验收。

[协议](protocol.json)在评分前固定原60家开发公司及资本开支/营运现金研究中仍未评分的120家公司留出，三个起点2023H1、2024H1、2025H1。候选将当前与上年同期的TTM经营现金流率等权平均，乘当前TTM收入；收入固定不增长，不借用未来收入，不裁剪负现金流。对照为沿用当前OCF，另设零OCF基准。所有模型共用沿用最近资本开支，额外检验OCF减资本开支预测的误差是否恶化，避免只改善一个分量。

采用门槛：至少80组合，OCF主要误差较沿用改善至少5%，OCF WAPE及零OCF两指标不恶化，各起点主要误差不超过沿用的105%，逐公司剔除仍不劣于沿用；现金代理的主要误差和WAPE也不得恶化。开发失败不打开留出，不搜索平滑权重；缺项与拒绝保留完整分母。

源数据仍是后来取得的TDX版本，FN314仅作用户授权的简化回溯时间约束，不称严格PIT；当前证券和行业抽样保留幸存者偏差。无需全量CNINFO，新异常才定向原文核验。

这条链只检验报表经营现金流及现金代理，不产出实际FCFF。完整总再投资仍需非现金投入、经营/非经营资产范围及税项桥接；后续即使留出通过，也只能以有版本和适用边界的现金预测输出供估值分析，不能直接替换DCF再投资项。

OCF WAPE为47.983706%→44.491254%，现金代理WAPE为80.190337%→77.162692%。主指标分别改善6.84%与6.09%；三个起点均改善，但2024起点OCF改善仅约1.04%，不称各年均改善5%。331是同一批公司跨期组合数，不是331家独立公司或统计显著性证明。归档代码与现时名单造成的版本/幸存者偏差仍在。

120家名单至此已对现金预测研究公开结果：资本开支和存货候选自身仍未评分，但今后不能再次把同一名单称为未接触的新留出。后续改规则须另保留样本或新披露期间，不能使用这批结果调参后重复宣称独立验证。

通过的是报表现金预测：OCF包含财报自身的经营现金分类，资本开支仍是沿用当前现金金额，未预测收购、资产处置和租赁非现金投入。它可以成为估值的现金合理性检查，但不直接生成历史FCFF或替换生产总再投资。下一步将其与生产估值输出并列、暴露现金口径差额，再决定需要原文核验的桥接分量；不把差额自动解释为模型误差。

验收：Python 3.12后端全套279项通过、4项既有上游TEST_DATA缺失跳过；随后新增留出回归，与本轮开发/负向回归一起3项通过（新增1项未包含在前述279项内）。锁定源位模式不变、Decimal独立误差复算、未来/留出数值隔离、负值与真实零保留、截止拒绝、伪造开发回执拒绝，以及OCF改善但现金代理恶化时拒绝采用。测试在既有后端pytest CI路径中；Go全套测试、构建、vet、两份回执哈希、文档链接及`git diff --check`通过。无新依赖、生产政策或主库变更。
