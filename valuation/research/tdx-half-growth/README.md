# 半量增长与首年半量增长复验

持续半量候选开发失败；首年半量候选开发通过，但新120家独立留出仍有一项门槛失败，均未采用。首年半量在留出六窗口的收入主误差均优于原规则，整体改善13.55%，但收入WAPE 20.9701%仍略高于零增长20.7345%。不因差异小而事后取消门槛，也不把有改善的指标说成毫无价值。

两项都是增长输入假设，不修改达摩达兰估值公式；50%不是达摩达兰对公司的统一建议。保留他的[增长、再投资与资本回报关系](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/invfables/growthdeterminants.htm)及公司适用条件，预测系数只在研究层检验，不把统计改善等同于FCFF或完整DCF准确度。

## 定义及冻结顺序

[持续半量协议](protocol.json)在`4b969d8`提交：把已限幅在−10%至20%的生产增长率乘0.5，即−5%至10%，逐年复利，当前利润率不变。固定50%，不搜索其他系数。开发600家公司、六窗口及实际值版本完全复用[上轮冻结结果](../tdx-zero-growth-horizons/development-result.json.gz)，预测只读起点收入、利润率和已限幅增长率。`55dad56`提交实现和正负回归后才评分。

持续半量整体收入主误差26.2519%，低于原规则30.6478%，但高于零增长25.6100%；WAPE亦劣于零增长，未通过额外对照门槛。结果显示一年期半量19.8673%优于原规则21.2469%和零增长20.2537%，但把增长继续累积到二/三年拖累整体；只支持设计后续开发候选，不是留出验证。

`a363bd0`保存[持续半量失败结果](development-result.json.gz)及[摘要](development-summary.json)，同时冻结[首年半量协议](first-year-protocol.json)：只在第一年采用半量增长，第二、第三年增长为零，保持第一年收入水平。比如基期收入100、原增长20%，新收入路径为110、110、110，不是110、100、100，也不是110、121、133.1。`5311df7`提交该规则；`ce4ec20`冻结留出入口及预测实现版本检查；开发数值重放不变后，`9c1922f`提交[通过的选择](first-year-selection.json)与[完整开发结果](first-year-development.json.gz)。

两项开发均为2,527/3,600组可评价、507家公司，1,073组阻断保留；源数据及缺项分母不因候选改变。首年半量没有把亏损研究的范围混入本次，仍沿用原生产正收入、正EBIT及同比季度要求，未来亏损不因亏损而剔除。

## 留出与门槛

新120家按既有SHA256排序，从固定总体中排除已登记的1,220家公司后选择，完全不复用上轮已评分120家。持续半量未提取/评分这批；首年半量在开发选择提交后才执行现有Go工具，从相同34个TDX版本提取3,684条源记录。`152aca5`提交[快照](first-year-holdout-snapshot.json)及[源回执](first-year-source-receipt.json)，之后才独立评分。这批现已暴露，下一项新规则须另留样本。

沿用原零增长的开发120组/30家公司、留出240组/60家门槛；收入主误差改善至少5%，收入WAPE及两项EBIT误差不劣于原规则，各期限收入主误差不劣于原规则，各窗口最多5%退化，逐公司删除后收入主误差不劣于原规则。**新增的额外门槛**在首次评分前冻结：整体收入主误差及WAPE均不得劣于零增长。对零增长未设逐窗口或EBIT不退化门槛，不能事后扩大通过声明。

同一600家开发资料在多个试验中反复使用，只是开发，不是独立证据。源为后来取得的TDX历史文件，FN314保守取中国次日零点，不是严格PIT。起点截止为当年9月1日中国零点，实际值版本截止2026-09-10中国零点；原始业务、会计可比性及幸存者偏差边界不变。
