# 同六份研报的资本开支口径检查

沿用既定两家公司、2023/2024/2025三个起点及同六份PDF，不新增报告或更换券商。本轮检查直接预测能否替代机械现金资本开支输入，未重新扫描已失败的平滑、趋势或在建工程候选。结论：**18个预测位置均保留，但0个获得FN114口径准入，不计算预测误差或发布DCF政策。**这不是说报告没有数字，而是未证明这些数字对应同一现金项目。

## 发现及决策

六份报告均只标“资本开支”或“资本支出”，未将该预测行明确拆成购建长期资产现金、处置回款、并购或其他投入。为避免把现金支出方向的负号当差异，下表仅比较历史金额的绝对数值；印刷正负号完整保存在[证据](capex-scope.json)，绝对值比较不构成科目语义认证。

单位：百万元。斜线分隔同一历史年度对应的印刷数值和TDX FN114购建现金（后者仅在表中舍入至整数，证据保留源位金额）。

| 公司/报告起点 | 印刷历史年度 | 印刷绝对值 / FN114 | 结论 |
| --- | --- | --- | --- |
| 安克2023 | 2020、2021、2022 | 30 / 冻结切片缺失；207 / 207；1144 / 1144 | 两项数值匹配仍不足以确认预测定义 |
| 安克2024 | 2022、2023 | 1144 / 1144；70 / 70 | 两项数值匹配仍不足以确认预测定义 |
| 安克2025 | 2023、2024 | 0 / 70；1544 / 429 | 两项不匹配 |
| 苏泊尔2023 | 2021、2022 | 225 / 228；160 / 165 | 两项不匹配 |
| 苏泊尔2024 | 2023 | 135 / 137 | 不匹配 |
| 苏泊尔2025 | 2022、2023、2024 | 160 / 165；135 / 137；199 / 208 | 三项不匹配 |

合计13个印刷历史单元格：4个仅数值匹配、8个不匹配、1个在冻结资本快照中缺失。不因已有另一份2020营业利润源切片而声称同时补齐了FN114；也不新增下载来追查这一项，因为即便补齐，仍不能建立预测科目定义。

安克2025报告的2024历史“资本开支”15.44亿元，与已核验购建现金4.2888亿元差距较大。这足以否定直接按同口径接入，但**不证明券商数字错误，也不证明差额必然来自并购、处置或非现金投资**。苏泊尔较小差异同样不反推归因。不得为了得到可评分结果，把它们一律改称“净资本开支”，或事后仅选数值匹配的报告。

因此本轮收口：不采用研报资本开支行替代FN114，不用它补完整FCFF，也不把收入、营业利润预测的局部改善延伸为资本需求已改善。已有标准输入、主估值及所有历史预测不变。后续若要改变这项决策，需要来源对购建/处置/并购等范围作出明确分解；仅更多同标签数字不增加准入证据。保留既有现金资本开支基线，其预测有效性不因本轮拒绝而获得背书。
