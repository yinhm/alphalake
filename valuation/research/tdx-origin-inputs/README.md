## 对下一步的约束

当前证据说明正利润门槛会漏掉大量可计算经营代理，不说明应把亏损公司直接送进现有DCF。另一方面，最近五年齐备的1,205组仍全部缺少已确认的业务可比性，不能机械套五年正常化后声称符合达摩达兰。

下一步候选须解决通用输入问题：先区分历史经营代理可计算与预测假设充分，再冻结可验证的利润率/增长路径；若采用资本回报驱动增长，先证明对应再投资及资本口径可用。不得用本诊断构造事后筛选、删除亏损与未知组合来挽救已失败的半量增长或正常化规则。本轮没有新规则评分，也没有新的估值数值。
