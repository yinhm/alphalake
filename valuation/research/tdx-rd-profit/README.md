# 研发重分类与下一年经营利润预测

状态：新候选在评分前[冻结协议](protocol.json)，开发复验未通过，不进入新留出、不更改生产规则。本600家公司已有其他研究结果暴露，仅作开发，不冒称新留出。

采用2022/2023/2024三个完整财年为起点，分别于次年5月1日中国零点预测下一财年；预测期内部分季度可能已经披露，本规则主动只用起点及以前年度/季度，所有对照一致。窗口与此前H1研究不同，不能把两者误差直接横比。样本、源版本、截止、缺项处理与通过门槛均已冻结，旧数据含后来修订的可能性仍保留。

令当期收入R、原经营利润代理E、费用化研发D，A为过去五年研发直线摊销。按[达摩达兰研发重分类](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/R%26D.htm)，调整后利润为E+D−A。本研究假设下一年收入和调整后利润率不变，下一年研发预算为最近两年研发费用率均值×R；下一年摊销由已知年度投入向前滚动一年，随后以“调整后利润−研发预算＋下一年摊销”还原到原经营利润代理口径评分。没有使用目标年实际研发作预测输入。

五年是既有模型政策，不是已经证明的行业受益寿命。收入不变、利润率不变和两年费用率预算是待检验假设，不能称达摩达兰给出了这条预测公式。研发资本化本身不会创造现金流，本实验也不证明研发对增长的因果作用；未补造完整资本回报、再投资或历史FCFF。

对照包括：原利润不变、短期收入规则×原利润率，以及仅调整研发预算而不做资本化的利润预测。最后一项用于判断是否只是预算变化产生效果。缺六年正值研发、上年收入或时点不满足时沿用原利润基线，并单列原因；源零不当成真实无研发。亏损和拒绝公司保留全部分母。短期收入对照不可用时也显式沿用平利润，不删除该公司。

开发至少900组、300家公司，各起点至少200组可评价且至少100组候选输入齐全，主误差（绝对经营利润误差/实际收入）改善至少5%；WAPE、短期对照、预算对照、逐起点及逐公司删除共同检查。仅全部通过后才进入排除所有已暴露公司的新留出；不按评分调整寿命、阈值或窗口。

## 开发结果

600家、三个起点共1,800组，1,704组可评价，涉及589家公司；95组起点阻断、1组实际值阻断保留，其中408组当前经营利润非正但仍参与评价。这里评价的是统一经营利润源代理，未逐公司证明经营范围或历史业务可比；当前行业分层也不冒称历史行业身份。

| 规则 | 利润主误差 | 利润WAPE |
| --- | ---: | ---: |
| 原利润不变 | 11.8341% | 44.5863% |
| 研发重分类候选 | 11.9366% | 45.2715% |
| 只改研发预算 | 11.8977% | 44.9798% |
| 短期收入×原利润率 | 12.0108% | 47.2796% |

主候选没有达到5%改善，绝对误差和WAPE都更差，也未胜过仅改预算的对照；逐公司删除仍不满足非劣要求。与较差的短期收入对照相比更好，不足以通过原利润不变基线。完整结果及门槛见[结果](development-result.json.gz)和[摘要](development-summary.json)。

| 起点财年 | 可评价/600 | 候选输入齐全/600 | 其中可评价 | 基线主误差 | 候选主误差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2022 | 540 | 110 | 109 | 12.6147% | 12.5262% |
| 2023 | 576 | 486 | 486 | 11.7873% | 11.9953% |
| 2024 | 588 | 529 | 529 | 11.1632% | 11.3375% |

候选起点输入共1,125组齐全，其中1,124组实际可评价。其余有基线的580组显式沿用基线：482组研发零/负值、80组上年经营窗口缺失/重复、17组研发年度缺失/重复、1组上年收入非正。未把这些情况都算作“无研发”。最早起点覆盖低，主要受六年研发史及5月1日截止约束，不事后改成9月1日补覆盖。

在1,124组真正改变预测的样本中，844组上调利润，只有490组绝对利润误差改善。该子组平均有符号误差从−0.7599%升至0.0206%（均按实际收入归一），但平均绝对误差仍退化；偏差接近零不代表逐公司预测更准确。该拆解属于评分后诊断，不用于事后筛掉退化样本或修改已冻结规则。

## 结论与下一步约束

保留研发资本化作为利润和资本口径一致性调整，但本结果不支持将“固定调整后利润率＋平滑研发预算”升级为通用增长预测。连同此前[研发净投入收入选择失败](../tdx-rd-growth/README.md)，目前没有实证支持这两条简化规则；不能推导为研发没有经济价值，也不能通过扫描摊销寿命来挽救结果。

下一步增长规则仍须由可比较的再投资与新增回报共同支撑；未闭合时保留显式情景及已验证范围内的基线。研发预算和资本化重分类不能替代商业化回报证据。[后续两期原文桥接](../tdx-capital-inputs/rd-scope.md)确认FN304费用增速可能显著偏离研发总投入增速，且总投入含折旧摊销；本候选的费用序列范围不因此改写。本轮不输出新DCF值，不回写历史事实，不将失败结果改成“基本有效”。
