# 研发重分类与下一年经营利润预测

状态：新候选在评分前[冻结协议](protocol.json)，尚未完成开发复验；不更改生产规则。本600家公司已有其他研究结果暴露，仅作开发，不冒称新留出。

采用2022/2023/2024三个完整财年为起点，分别于次年5月1日中国零点预测下一财年；预测期内部分季度可能已经披露，本规则主动只用起点及以前年度/季度，所有对照一致。窗口与此前H1研究不同，不能把两者误差直接横比。样本、源版本、截止、缺项处理与通过门槛均已冻结，旧数据含后来修订的可能性仍保留。

令当期收入R、原经营利润代理E、费用化研发D，A为过去五年研发直线摊销。按[达摩达兰研发重分类](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/R%26D.htm)，调整后利润为E+D−A。本研究假设下一年收入和调整后利润率不变，下一年研发预算为最近两年研发费用率均值×R；下一年摊销由已知年度投入向前滚动一年，随后以“调整后利润−研发预算＋下一年摊销”还原到原经营利润代理口径评分。没有使用目标年实际研发作预测输入。

五年是既有模型政策，不是已经证明的行业受益寿命。收入不变、利润率不变和两年费用率预算是待检验假设，不能称达摩达兰给出了这条预测公式。研发资本化本身不会创造现金流，本实验也不证明研发对增长的因果作用；未补造完整资本回报、再投资或历史FCFF。

对照包括：原利润不变、短期收入规则×原利润率，以及仅调整研发预算而不做资本化的利润预测。最后一项用于判断是否只是预算变化产生效果。缺六年正值研发、上年收入或时点不满足时沿用原利润基线，并单列原因；源零不当成真实无研发。亏损和拒绝公司保留全部分母。短期收入对照不可用时也显式沿用平利润，不删除该公司。

开发至少900组、300家公司，各起点至少200组可评价且至少100组候选输入齐全，主误差（绝对经营利润误差/实际收入）改善至少5%；WAPE、短期对照、预算对照、逐起点及逐公司删除共同检查。仅全部通过后才进入排除所有已暴露公司的新留出；不按评分调整寿命、阈值或窗口。
