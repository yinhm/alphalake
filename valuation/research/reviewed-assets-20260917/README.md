# 已审核资产进入统一估值入口

本轮交付三项目标中的第一项生产能力：`nonfinancial-reviewed-history-fcff-v1`在既有历史FCFF政策之上，显式采用经审核的标准金融资产，FN19/FN431支持单独审核的受限分量扣除。仍由统一公司CLI/API、同一共享引擎及原生股权桥接计算，不改变默认行业政策。

财务期2026-06-30，审核/信息时点2026-09-17T00:00:00Z，有效期至2026-10-17T00:00:00Z。**WACC显式固定为旧参考结果8.075367197%，不是9月17日市场WACC**；行业资本效率仍2.483535697458，未改增长、利润率、税率、终值或其他桥接。此验收只证明已批准资产可以进入生产计算，不是当前目标价、完整股权估值或公司资本效率闭合。旧归档运行保持不变。

联营投资的账面金额已经代表集团拥有的权益，不再乘一次持股比例；经营EBIT已剔除投资收益，单独桥接避免遗漏。账面价值仅为政策代理，未估计各被投企业市场价值，也未对套期、混合科目或未审核资产自动加回。方法依据：[达摩达兰每股价值](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/valuepershare.htm)对非合并持股单独计值的要求，不能据此把账面值称为公允价值。

## 审核契约

公司政策绑定代码、报告期、审核开始/截止时间；每项规则绑定源包哈希、补充导入哈希和完整导出证据内容哈希。仅允许FN9/FN19/FN25/FN430/FN431/FN433；默认整项，FN19/FN431允许从标准总额扣除同期间、同原文且单独绑定哈希的受限分量，再乘回收率。负受限额、超过原文总额或标准总额、缺少分量、分类与分量不匹配均拒绝；重复字段或复用分量证据拒绝；FN25只接受非合并权益投资分类。证券/期间不一致、缺证、单位错误、金额不符、PDF或TDX修订、未来审核及过期均拒绝，不回退旧政策。

补充证据须来自同一公告、同一PDF哈希/URL，且与标准源金额按float32精度相符。数值仍从TDX标准事实读取；PDF核验完整组成及金额，受限分量作为显式附注补充，不覆盖TDX总额。内容哈希只锁版本，分类正确性靠原文和审核，不用哈希替代语义判断。政策中`recovery`与账面代理是显式假设，补充表不存估值假设。

生产导入格式见[补充记录](../../../internal/ingest/testdata/reviewed-assets-2026/supplements.json)，现有命令为`alphalake import-supplements <db> <json>`；先归档并关联对应公告，不能仅传PDF URL绕过原文门槛。之后用标准导出生成审核绑定，参考[独立公司政策示例](../../examples/batch-reviewed-assets-20260917.json)。该示例限定隔离验收的证据版本，不可直接换库沿用。
