# 研发净投入与收入规则选择

状态：协议在分组评分前冻结，开发复验未通过，不进入新留出。沿用600家开发样本、2023/2024/2025H1三起点、一年收入预测和原实际值版本，原结果只复用短期基线与零增长，旧CAGR是否可算不作为准入。

主候选固定五年寿命：上一完整年度研发费用减此前五年均值为非正时选择零收入增长，否则沿用短期规则；历史不足、歧义零等情况仍沿用基线并单列缺项。三年仅敏感性，不以评分较好为由改成主候选。源输入与既有预测均已冻结，所有选择在读取目标实际值之前完成。

研发资产收缩不等于公司总再投资为负，也不必然意味着收入不增长。这是受[达摩达兰再投资与回报框架](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)启发、尚无效性证据的经验收入选择规则，不是他的经营利润增长公式，不改FCFF/ROIC/WACC定义或估值方法。五年取自现有模型默认政策，不称通用最优寿命。

[协议](protocol.json)保留原样本/覆盖门槛、至少5%主误差改善、WAPE与零增长双对照、各起点和逐公司删除检查。仅主候选通过开发门槛才进入新的独立留出；本600家已有其他研究结果曝光，不算新留出。失败不改阈值，不删除亏损、缺研发或表现不好的公司。

## 开发结果

600家、三个历史起点，共1,800组；1,726组可评价，72组基线阻断、2组实际值阻断全部保留。金额计算沿用百万元人民币，主误差为逐公司期间绝对百分比误差均值，WAPE按实际收入加权。

| 规则 | 主误差 | WAPE |
| --- | ---: | ---: |
| 短期基线 | 23.2921% | 15.1425% |
| 五年研发主候选 | 23.3415% | 15.1374% |
| 零增长对照 | 21.8877% | 14.2102% |
| 三年研发敏感性 | 23.2035% | 14.9741% |

五年候选全分母中1,006组净投入正、219组非正、575组研发历史不可用；共同可评价组实际改变218条预测。主误差改善、零增长对照和逐公司删除门槛失败。三年只改变399条共同预测，不能事后晋升主候选。结论只针对此收入选择规则，不证明研发无效，也不能据此调整DCF增长或研发寿命。

## 对下一步的约束

回到达摩达兰的完整投入/回报框架：在回报稳定的条件下，经营利润增长由再投资率和新增投资回报共同决定，存量效率改善另算；研发只是一部分再投资。需要先补齐经营资本分类、研发受益寿命及资本化研发防重复口径，再检验投入到回报的时间关系。不能因这一候选失败而在相同开发结果上反复挑研发阈值，也不能把收入增长直接等同经营利润增长。
