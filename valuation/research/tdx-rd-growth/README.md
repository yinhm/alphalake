# 研发净投入与收入规则选择

状态：协议已在分组评分前冻结，尚无结果。沿用600家开发样本、2023/2024/2025H1三起点、一年收入预测和原实际值版本，原结果只复用短期基线与零增长，旧CAGR是否可算不作为准入。

主候选固定五年寿命：上一完整年度研发费用减此前五年均值为非正时选择零收入增长，否则沿用短期规则；历史不足、歧义零等情况仍沿用基线并单列缺项。三年仅敏感性，不以评分较好为由改成主候选。源输入与既有预测均已冻结，所有选择在读取目标实际值之前完成。

研发资产收缩不等于公司总再投资为负，也不必然意味着收入不增长。这是受[达摩达兰再投资与回报框架](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)启发、尚无效性证据的经验收入选择规则，不是他的经营利润增长公式，不改FCFF/ROIC/WACC定义或估值方法。五年取自现有模型默认政策，不称通用最优寿命。

[协议](protocol.json)保留原样本/覆盖门槛、至少5%主误差改善、WAPE与零增长双对照、各起点和逐公司删除检查。仅主候选通过开发门槛才进入新的独立留出；本600家已有其他研究结果曝光，不算新留出。失败不改阈值，不删除亏损、缺研发或表现不好的公司。
