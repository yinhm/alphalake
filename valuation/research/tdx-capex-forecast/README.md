# 资本开支现金预测复验

当前三轮开发的四条候选均未通过，新增120家留出未评分，未改变生产政策。

本研究检验FN114购建长期资产支付现金的下一年TTM预测，不把它视为净再投资、完整FCFF或生产估值准入。当前生产历史DCF使用显式资本效率政策；这里的“沿用最近金额”是新研究的朴素基线，不冒称生产已有独立资本开支预测。

## 固定范围与首轮结果

`f0ec051`在提取及评分前冻结[协议](protocol.json)：保留原60家开发公司，从既有4,833家当前非金融行业抽样总体按原SHA256排序取第241–360名作为新增120家验证公司，与前几轮选中公司不重叠。三个起点为2023H1、2024H1、2025H1，目标分别为下一年H1 TTM；仍有当前上市/行业筛选的幸存者偏差，不称无偏全市场样本。

[源快照](snapshot.json)复用22个不可变TDX包及各自清单，Go准备工具重新校验MD5/大小并保留源float32位。所有规则要求当前TTM、最近两个完整年度的共同历史窗口；缺期保留拒绝。亏损不剔除，资本开支真实源零在此口径保留，负累计组合拒绝。报告发布日期按FN314研究规则使用，后来取得的版本不冒称严格PIT或主库标准事实。

候选为三窗口金额中位数，以及三窗口资本开支/收入比中位数乘当前TTM收入。没有使用目标期收入进行预测；实际收入只用于评价误差。预测先固定后取目标期，目标缺失仍保留预测和拒绝原因。

[开发结果](development-summary.json)：60×3=180个候选组合中158个可评价，22个拒绝。指标为公司期间等权的绝对资本开支误差除以实际收入：

| 规则 | 主要误差指标 | 资本开支WAPE |
| --- | --- | --- |
| 沿用最近TTM金额 | 4.5261% | 32.7109% |
| 三窗口金额中位数 | 5.1491% | 37.7113% |
| 三窗口收入比中位数 | 4.7474% | 37.6752% |

两个候选均未通过5%改善、WAPE不退化、逐起点及逐公司删除检查，**不采用，新增验证集未评分**。历史平滑在本开发集反而更差，不能因为直觉上“更稳健”而替换规则。所有结果按同一共同可评价集合比较，不表示基线在缺少更早历史时也无法计算。

复现（后端目录）：

```bash
python -m tools.backtest_tdx_capex ../research/tdx-capex-forecast/protocol.json ../research/tdx-capex-forecast/snapshot.json --phase development
```

留出阶段必须提供有通过候选的开发回执；CLI核对协议、快照、代码/共享解析器哈希，并重算开发选择，未通过不能打开留出。相关回归覆盖抽样排名、真实开发结果、留出数值不影响开发、未来目标不改变预测、零资本开支保留和负值/重复身份拒绝。

## 滞后偏差校准仍未通过

`0cdae69`在开发评分前冻结[协议v2](protocol-v2.json)，复用原始快照与同一共同集合。只检验一个候选：以上一历史起点的开发公司“实际资本开支/沿用最近金额预测值”加权中位数作为尺度，权重为预测资本开支/实际收入，尺度限定0.5–1.5后半量应用。最低30个有效训练组合，预测为零的训练比例不定义，保留拒绝；评价中的零资本开支仍可参与。

训练基期输入按当年的预测截止读取，实际标签按下一年、也就是当前起点截止读取；例如2023起点的校准训练为2022H1→2023H1，两个截止分别是2022和2023年9月1日中国零点，不能用标签截止放宽基期可用时间。三个起点的训练量为52、55、58，最终倍率约0.87445、0.87994、0.93247。

[开发v2结果](development-v2-summary.json)：158/180个组合与首轮相同，主要误差4.5261%→4.3703%，改善约3.44%，未达5%门槛；资本开支WAPE32.7109%→33.0123%，亦未通过。逐起点及逐公司删除检查通过，但不能掩盖整体失败，候选不采用，新增120家验证公司仍未评分。

原首轮失败、旧代码哈希与回执保留。CLI用`protocol-v2.json`重放开发阶段；v2显式绑定原协议和快照哈希，未重新下载或替换源包。下一轮按预先冻结的公司自身近期趋势继续开发检验，结果见下文；多轮开发试验不称多次独立验证。

## 公司近期趋势也未通过

`787c15b`在开发评分前冻结[协议v3](protocol-v3.json)，只检验`max(0, 2×当前TTM资本开支−最近年度资本开支)`。两个窗口相隔半年，将窗口差额年化后半量外推，不增加网格参数，仍在同一158/180共同集合比较。

[开发v3结果](development-v3-summary.json)：主要误差升至5.6779%，资本开支WAPE升至36.7915%，各效果门槛均未通过；新增120家验证公司仍未评分。至此三轮共四条候选都不支持替代“沿用最近TTM金额”的简单研究基线。基线在开发集合中相对更好，不等于已证明其预测有效性，更不等于生产资本效率政策已获验证。

本轮停止继续搜索平滑/倍率参数，保留新增留出供后续有不同经济依据的候选使用；先研究项目及支出驱动信息，不能为了通过门槛反复观察留出或降低标准。代码提供开发选择重算及哈希约束；伪造失败候选为通过时，在进入留出评价前拒绝。

三个协议共享一个不可变源快照，v2/v3显式绑定原协议和快照；历史回执代码哈希保留。CLI替换为对应协议即可复算各轮开发结果；旧回执若需用于CLI验证，先用当前实现重跑开发，不修改旧记录。研究配置和证据保存在本目录，工具实现在`valuation/backend/tools/backtest_tdx_capex.py`。
