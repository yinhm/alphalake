# 营运现金调节预测复验

当前首轮开发未通过采用门槛，120家留出未评分，未改变生产政策。目标是判断FN146–FN148报表调节贡献能否预测下一年，并不将其反号后直接作为完全分类营运资本变动或FCFF。

## 固定样本与口径

`7a44850`在提取、评分前冻结[协议](protocol.json)。沿用资本开支研究的60家开发公司，以及SHA256排序第241–360名的120家留出公司；后者在资本开支四轮中均未评分。三个起点2023H1、2024H1、2025H1，目标各为次年H1 TTM。保留当前上市/行业选择的幸存者偏差，后来取得的TDX版本与FN314日期仅用于用户授权的简化研究，不称严格PIT；2025年前字段不扩展生产映射生效范围。

[源快照](snapshot.json)重新从同一22个不可变归档提取，核验原清单MD5/大小。开发公司既有源值与[再投资覆盖快照](../tdx-growth-expanded/snapshot-reinvestment.json)逐位一致。原文语义依据沿用[ADR013](../../../docs/decisions/013-cashflow-research-fields.md)及[中邮科技三期现金核验](../tdx-growth-expanded/depreciation-review-688648/cash-evidence.json)，没有新增来源解释或PDF数值覆盖。

FN146为存货减少、FN147为经营性应收减少、FN148为经营性应付增加，均为人民币元、年初累计，负数保留。每个分量按年度＋当期半年−上年同期半年组合；各源分量的零仍是歧义拒绝，但三个非零分量相抵后形成的真实合计零允许参与。收入只用FN230四季度加总，实际收入只作评价分母，不参与预测。缺期、身份重复、非有限值、晚于截止或零歧义均保留拒绝，不删除亏损公司。

## 候选和结果

研究基线为沿用最近TTM净贡献，唯一候选为其一半；另设置显式的“预测净贡献为零”对照。这个零是预测假设，不是对缺失源数值的填补。生产历史DCF并无此独立净贡献预测，所以不冒称替换了现有生产营运资本政策。

[开发结果](development-summary.json)：180个公司期间组合中167可评价、13拒绝，三个起点分别53/60、57/60、57/60。

| 规则 | 平均绝对误差/实际收入 | 现金调节WAPE |
| --- | --- | --- |
| 沿用最近TTM | 15.0370% | 115.0105% |
| 预测净贡献为零 | 10.3356% | 100.0000% |
| 半量沿用 | 11.5082% | 97.4642% |

WAPE分母是实际净贡献绝对值之和，避免正负抵消；因此零预测的WAPE恒为100%（分母非零时），不能单凭这个指标声称零预测有效。半量候选相对沿用的主要误差改善约23.5%，但仍劣于零贡献对照，预先要求的对照门槛未通过，**不采用，留出未评分**。最新起点半量WAPE也达到104.10%，不同期间及不同加权指标没有一致优势。

该结果只支持本开发样本中“净贡献简单延续不可靠”的判断，不证明所有公司营运资本变动应预测为零。下一步须区分存货、应收和应付的变化来源及其经济驱动；不通过降低门槛或观察留出寻找倍率。完整经营分类、税费、再投资及DCF有效性仍待闭合。

```bash
python -m tools.backtest_tdx_working_cash ../research/tdx-working-cash-forecast/protocol.json ../research/tdx-working-cash-forecast/snapshot.json --phase development
python -m pytest tests/test_tdx_history.py -k working_cash
```
