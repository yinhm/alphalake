由此可以确认，极端预测不只是一个待“修正”的源值：在收入基期很小、历史经营内容或合并范围改变时，固定存货/收入比例外推会放大。2023起点已有土地开发属性可见，但不能将2024年末业务剥离倒填为2023年的已知事件；未来规则须区分当时可见事实和后来发生的事件。
