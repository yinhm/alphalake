# 零增长多年预测独立验证

零增长候选通过预先冻结的采用门槛；支持本样本范围的两年/三年收入和经营利润预测改进，已接入显式安克估值对照，未改默认政策，不证明完整DCF准确度。

正式候选为零增长，对照为当前前五年平增速；提前收敛只作诊断比较，没有在留出结果上择优。原60家开发结果已观察，不能称独立验证。新120家名单按既有总体和固定SHA256顺序，在排除980个既有研究/抽样排除代码后取排名961—1080；不按财务完整度或误差筛选。此“新”限于历史预测研究样本，不声称从未读取这些公司的其他信息。

冻结顺序：协议及名单`49ae3e9` → 校验代码及通过的开发选择`b4f5c41` → 新名单源快照`87d5864` → 留出评分。见[协议](protocol.json)、[开发选择](development-selection.json)、[源回执](source-receipt.json)、[源快照](snapshot.json)、[留出摘要](holdout-summary.json)和[完整结果](holdout-result.json)。源快照复用22个既有TDX归档，共180家公司、3,803条记录，不下载新版本，不改数据库。

## 结果

开发60家、300组中202组可评价，涉及50家公司，98组拒绝保留。收入主要误差55.8314%→40.4357%，全部开发门槛通过后才提取新留出。

留出120家、600个公司/窗口组合中406组可评价，涉及103家公司；194组阻断仍计入分母：111组起点收入或EBIT不满足正值规则、70组缺历史期间、13组缺至少两个同期收入增速。17家公司没有可评价组合。源实际值固定截至2026-09-10中国零点；预测起点信息截止均为对应年份9月1日中国零点。

| 留出指标 | 当前平增速 | 零增长 |
| --- | ---: | ---: |
| 收入平均绝对百分比误差 | 33.6535% | 27.2236% |
| 收入WAPE | 17.7936% | 13.8299% |
| EBIT绝对误差/实际收入均值 | 10.5914% | 9.2206% |
| EBIT WAPE | 82.0754% | 69.6364% |

收入主要误差相对改善19.11%，EBIT主要误差改善12.94%。两年、三年整体及逐公司删除后的收入主要误差均不劣于基线，满足预定样本量、5%主指标改善和其他门槛。

| 起点→实际期 | 可评价/分母 | 当前收入误差 | 零增长收入误差 |

最后一个窗口主要误差退化约3.19%，仍在事前5%容忍范围内；其收入WAPE也由9.4140%升至11.5629%。不能声称每个年份或所有指标改善；`each_window_nonworse`这一代码键实际按协议检查不超过基线1.05倍。两年整体收入中位绝对百分比误差也由18.9507%升至19.5759%，中位数不是本轮采用门槛。

## 重放与边界

从仓库根目录使用已安装项目依赖的Python解释器；以下模块命令在`valuation/backend`执行：

```bash
python -m tools.validate_tdx_zero_growth ../research/tdx-zero-growth-validation/protocol.json --phase development
python -m tools.validate_tdx_zero_growth ../research/tdx-zero-growth-validation/protocol.json --phase holdout --snapshot ../research/tdx-zero-growth-validation/snapshot.json --selection ../research/tdx-zero-growth-validation/development-selection.json
python -m pytest tests/test_tdx_zero_growth.py tests/test_tdx_multiyear_growth.py -q
```

校验器在打开留出快照前核验开发选择，分别检查名单、源版本及共享开发记录。默认Python测试包含完整留出重放、Decimal独立误差聚合、修改未来实际期源值不影响起点预测、伪造选择及源绑定拒绝。复用多年工具增加显式阶段，旧开发结果数值完整重放不变；旧回执代码哈希保留当时版本。

这是用户授权的简化回溯：后来取得的TDX源数值及FN314日期不构成严格PIT；当前存续证券抽样有幸存者偏差，窗口重叠也不等于406个独立实验。未做逐公司CNINFO原文全量核验。起点利润率固定，未来亏损保留；两年/三年结果不能外推成五年或十年有效性，所有历史FCFF仍为空。

已完成[显式估值桥接](../../../docs/zero-growth-valuation-20260911.md)，安克同标准快照92.1504→42.2846元，首年收入增量再投资归零而FCFF上升，下一步检验再投资分类与规则；终值、WACC和股权桥接继续保留各自假设。不能因收入预测改善就声称零增长加零再投资的DCF更准确，也不自动替换市场默认政策。
