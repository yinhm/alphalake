# 高权重训练输入：利润主表与附注复核

状态：两家公司各五期、六个利润分量的主表核对完成；50个明确金额与TDX逐位匹配，10处主表空白对应源零，不能据此确认经济零。四个TTM源代理复算一致。发现海航四个利息源零被附注反证，以及年度利息范围、担保损失符号的变化；**完整可比经营EBIT仍未闭合**，未修改源事实、标准映射或生产估值。

海航窗口为2021H1/FY、2022H1/FY、2023H1；金迪克为2022H1/FY、2023H1/FY、2024H1。新增六份CNINFO原始报告见[清单](manifest.json)，另复用[此前四份原文](../source-review/manifest.json)。[台账](ledger.json)锁定各报告SHA-256、合并主表六行、单位、期间及21项附注行；[检查结果](checks.json)保存源位、差异状态与机械敏感性。

## 海航：主表空白不能解释为没有利息

两期合并主表的“其中：利息费用/利息收入”均空白，TDX的FN305/FN306均为零，但附注66披露：

| 报告 | 原文页 | 借款利息支出（元） | 利息收入（元，经济方向） |
| --- | ---: | ---: | ---: |
| 2021H1 | 135 | 1,058,958,000 | 87,410,000 |
| 2022H1 | 101 | 5,370,000 | 73,948,000 |

附注以千元列示。2021H1收入行原文为“减：利息收入 −87,410”，2022H1为“减：利息收入 73,948”；展示符号分开留痕，不能直接照打印符号作为利润表利息收入。这里确认的是主表源零未覆盖附注金额，不是TDX二进制解码或元/万元倍率错误。

2021FY主表p90的利息费用为976,333千元，与TDX匹配；附注p183明确这只是借款利息，另有租赁负债利息43,247千元。2022FY主表p74及附注p147的2021比较列为1,019,580千元，恰好等于上述两项之和。不能把不同年份同名FN305无条件视为相同的含租赁口径。

即使改用三期附注的“借款利息支出”，2022H1 TTM算式仍为5,370＋976,333−1,058,958＝−77,255千元。后续[公司回复及会计师说明](../closing-review/README.md)确认关账时存在收入/财务费用重分类，但没有提供利息子项的完整桥接。这个负数是**跨期可比性待查的算术结果**，不作为真实负借款成本、补齐后的EBIT或允许自动替换源值的依据。

## 担保损失：先校准符号，再做TTM

原研究利润代理为`FN86＋FN305−FN306−FN83−FN82−FN301`。FN301是资产处置收益，公式没有扣除“其他收益”，也未单独正常化财务担保损失。

附注71的五期担保损失行及合计均已核对。前三期附注按损失正数列示，后两期按收益方向列示；每期以附注合计对上合并主表信用减值损失，锁定对应符号：

| 期间 | 附注担保损失打印值（千元） | 对利润贡献（千元） |
| --- | ---: | ---: |
| 2021H1 | 48,135 | -48,135 |
| 2021FY | -1,709,995 | 1,709,995 |
| 2022H1 | 6,425 | -6,425 |
| 2022FY | -6,425 | -6,425 |
| 2023H1 | 7,836 | 7,836 |

据此，2022H1 TTM担保项目对利润的贡献为1,751,705,000元，2023H1 TTM为7,836,000元；不能将整笔2021年度转回直接当成2022H1 TTM调整。2021年报保留审计意见的边界仍保留，不把加总对账当成担保估计已获独立证明。

为说明量级，检查结果另列“从原源代理扣除担保贡献”和“再机械代入已披露利息”的敏感性。2022H1原源代理2,784,612,936元，扣除担保贡献后1,032,907,936元；机械利息替换差额为−1,040,126,000元，合并算式变成−7,218,064元。**这不是修正后的经营利润**：年度利息包含范围、负借款利息TTM及其余经营分类未解决，`full_normalized_ebit_cny`保持空值。金迪克两期源代理亦不自动升级为完全正常化利润。

## 对训练质量与后续工作的影响

在原600家开发集合三个起点的已准入训练池中，涉及任意FN305/FN306源零的条目分别为66/407、44/432、40/433；检查同时覆盖滞后预测输入及截至该起点已知的训练实际值。这里计数的是**源零暴露**，不是已确认缺数的公司数，真实无利息的公司也可能被包含。

已据此在评分前冻结并执行[通用利息源零过滤复验](../training-quality.md)，完整评价分母保留；规则未通过，不进新留出、不改生产。数据质量筛查与预测改进是两个独立结论。下一步应核对旧期利息重分类与可比期间，确定能够规模化提供的利润输入；不得把清理后仍有缺口的利润代理用作研发回报的经济真值。
