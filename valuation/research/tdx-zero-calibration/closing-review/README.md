## 已闭合：季度收入差异的原因

公司原回复p13说明，编制2021Q3时使用英迈管理层报表；编制年报时进行了英迈年末关账调整，涉及现金折扣导致的收入与财务费用重分类、总额法确认销售收入和收入截止调整等。

补充回复p3进一步明确：因处置英迈发生在第三季度，为避免读者误解第四季度海运收入，年报季度数据将收入差异调整到第三季度。普华永道说明p8–9列出相同说明，并表示其核查未发现与取得证据及管理层解释存在重大不一致。会计师说明不是我们另行获得的完整调整分录，也不等于每个金额都有第二条独立取数链。

原2021Q3报告p1以千元列示当季收入3,846,448，与TDX FN230逐位匹配。结合已归档年报p8：

| 数据 | 金额（元） |
| --- | ---: |
| 原Q3报告收入 | 3,846,448,000 |
| 年报季度表Q3收入 | 3,699,614,000 |
| 两个报表值的差额 | 146,834,000 |
| 年报季度表Q4收入 | 41,745,000 |
| 年报Q4减去上述差额 | -105,089,000 |
| TDX Q4源值 | -105,089,000 |

公司回复按万元整数列示Q3的384,645与369,961及差额14,684；与千元表格精确差额相差6,000元，落在两个端点按万元舍入的累计范围内。保留两种披露精度，不强行改成完全相等。

TDX数值关系与“前三季保留原披露、Q4承接全年差额”一致；这是对数值关系的判断，未取得TDX内部算法，不能把推断当作供应商实现说明。原Q3源float32舍入与两季合计的128元差额继续保留，不用PDF恢复源精度。

## 尚未闭合：利息子项的跨期比较

三份回复确认收入/财务费用存在重分类，却没有提供将2021H1借款利息1,058,958千元与2021FY借款利息976,333千元桥接到可比期间的完整分录。不能把全部收入调整额都加到利息，也不能仅因两者同属财务费用就声称负的借款利息TTM已解释。

此前[利息源零、租赁范围及担保贡献](../earnings-review/README.md)的核验仍有效；完整可比经营EBIT保持缺失，机械替换敏感性不升级为估值输入。本轮不继续为该单家公司推测缺少的分量，后续增长/研发回报研究须显式保留此不可比状态。

## 对通用预测的约束

- 不能把来源一致、全年加总正确等同于各季度经济含义一致。单季增速、利润率与训练权重仍可能受跨期调整影响。
- 2022H1 TTM同时包含2021Q3、Q4，两季差额在源精度内抵消；只包含其中一季的滚动窗口不享有这个性质，不能泛称TTM不受影响。
- 发现负季度收入应保留待查；金迪克年报Q3本身就是负值，所以“负数即错误、直接删除”不是通用规则。
- 不据本例静默重写TDX，也不把公司回复里的粗精度金额做全市场自动补差。旧研究、过滤失败结论及生产政策保持原样。
