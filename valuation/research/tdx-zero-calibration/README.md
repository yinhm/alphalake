# 零增长与一年期利润校准的组合复验

状态：评分前[冻结协议](protocol.json)，开发复验未通过，不改生产、不进入新留出。沿用已暴露的600家公司，2023/2024/2025H1三起点及当年9月1日中国零点，预测下一年H1经营利润代理；全1,800组保留。

[零增长两／三年验证](../tdx-zero-growth-validation/README.md)与[一年利润校准](../../../docs/forecast-calibration.md)有各自范围及后续反证：零增长后来的一至三年联合验证未通过一年门槛，利润校准2025时间复验效果也减弱。组合不是既有验证结论，现有生产政策仍禁止直接把校准与未经验证的增长改动叠加。

对照为零收入增长、短期收入规则（缺同期历史时显式沿用零增长），都保持当前经营利润率。两种基线各自拟合上一年已经兑现的误差：以前一年H1为预测起点，前一年9月1日为预测信息截止，以本次起点截止可用的本年H1实际为训练标签。系数使用既有加权中位数算法，权重为预测利润/实际收入，原始比例为实际利润/预测利润，截到[0.5,1.5]后只应用一半，即倍率(1+截断比例)/2。不把短期基线系数直接套到零增长基线。

每家目标公司在拟合自己的系数时从训练池中移除；池中至少30家公司，历史预测利润为正，实际利润允许亏损。当前预测利润非正时保留原预测并注明不适用乘性校准，不删除公司；正利润但训练不足时校准预测留空，不默认为倍率1。短期基线的缺历史回退在训练和预测中均明确记录，它不是未经改变的生产准入规则。

主候选是零增长＋半量校准，要求相对未校准零增长的利润主误差至少改善5%，WAPE非劣，且不劣于短期及短期校准两个对照；至少900组、300家公司，每起点至少200组共同可评价、100组实际应用校准，基线覆盖保留90%。各起点最多退化5%，另逐一删除评价公司检查整体非劣。目标公司从训练中移除与删除评价公司是两项不同检查，不声称已做所有训练同业逐一剔除后重拟合。

全部预测完成后再读取下一年目标结果。不新增自由调参，不挑行业或删除亏损来挽救结果；后来取得的TDX与FN314仅作简化源回溯，业务可比性未知，不是严格PIT、完整FCFF或估值准确率。开发全部门槛通过后，才可定义排除所有已暴露公司的新留出。

## 开发结果

1,726/1,800组共同可评价，涉及589家公司；72组基线阻断、2组实际值阻断保留。基线可评价组合全部保留，没有发生训练不足；起点应用校准1,289组，其中1,288组可评价，另438组可评价的非正利润保持未校准。不能将保留未校准的亏损公司说成乘性校准已适用于它们。

| 规则 | 利润主误差 | 利润WAPE |
| --- | ---: | ---: |
| 零增长 | 13.2080% | 43.6590% |
| 零增长＋半量校准 | 12.9344% | 45.3320% |
| 短期收入或零增长回退 | 13.2996% | 44.7062% |
| 短期基线＋重新拟合的半量校准 | 12.7715% | 44.2982% |

主候选的主误差相对改善2.0719%，不足预定5%；WAPE退化，也未胜过短期校准对照。逐起点和删除评价公司检查通过，不能抵消三个失败门槛。完整[结果](development-result.json.gz)保留预测、训练证据、每家公司独立系数及实际值，[摘要](development-summary.json)保留全部指标、缺项和哈希。

| 起点 | 可评价/600 | 当期训练池准入/600 | 起点应用校准/600 | 零增长主误差 | 组合主误差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2023H1 | 554 | 407 | 433 | 17.1501% | 16.6186% |
| 2024H1 | 583 | 432 | 433 | 10.2641% | 10.0925% |
| 2025H1 | 589 | 433 | 423 | 12.4142% | 12.2820% |

训练池准入后还会按目标代码移除该公司，所以某家公司的实际训练数可能少一。零增长校准倍率区间分别为0.8130–0.8420、0.8361–0.8562、0.9336–0.9370；短期基线各自重新拟合，区间分别0.7922–0.8178、0.7990–0.8326、0.9098–0.9106。固定使用同一个旧系数会混淆两种基线的预测误差。

即使只观察1,288组实际适用校准的正利润组合，主误差8.7368%→8.3700%，改善约4.20%，仍不足5%；WAPE35.8426%→37.7443%仍退化。这是按既有适用状态展示的诊断，不是删掉亏损后重新宣布通过。

[评分后集中度诊断](diagnosis.json)显示，移除目标公司前，零增长训练池最大单家公司权重占比分别16.84%（海航科技）、13.68%（金迪克）、1.48%（振华风光）。这说明不同年份的权重分布不同，不证明单家公司决定了加权中位数。组合相对零增长的全样本绝对利润误差净增加171.3290亿元（跨三个窗口合计），增加最多的五家公司为华能水电、山东黄金、中信特钢、上港集团和新集能源，分别37.0386、24.9648、21.7469、19.6178、13.4080亿元。训练集中度与评价误差是两项不同诊断，不能据此直接宣布因果关系；这些公司也没有被排除或用于修改规则。

后续定向核对两个高权重训练样本：海航科技2022H1→2023H1的收入源代理3,803.27→247.55百万元、利润代理2,784.61→−157.59百万元；金迪克2023H1→2024H1分别429.23→10.74、90.55→−179.41百万元。当前仅确认这是本次源研究使用的数值，尚未核对其原文及业务可比性，不先认定源错误或直接调整权重；选择依据是训练池集中度，不是把未来评价误差大的公司删掉。

## 结论

不采用组合，不进入新留出，也不改变现有校准政策的叠加限制。两项规则有过各自限定范围的正面证据，组合仍需独立验证；本次已排除一个未经验证的直接叠加方案。较好的短期校准对照也不事后升格为通过的新候选，扩大训练集或适用范围仍须另行冻结并验证。

本600家为已有开发集合，训练规模、目标排除及短期缺项回退与原60家政策研究有差异，不能将新对照的数字当作原生产校准政策的同口径更新。收入、利润代理、DCF和股价贴合程度仍分别评价。

后续[训练剔除敏感性](training-exclusions.md)已完成：评价分母不变，分别及同时剔除两家高权重公司均未挽救组合；[原文复核](source-review/README.md)已定位季度收入差异、担保转回及研发资本化范围，后续[十期利润主表](earnings-review/README.md)已核对，利息范围和完整经营分类仍未闭合。该剔除诊断是事后研究，不是新的独立验证。随后事前冻结的[利息源零训练过滤](training-quality.md)开发也未通过，不进入新留出、不改变生产。
