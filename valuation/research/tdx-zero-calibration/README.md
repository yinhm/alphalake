# 零增长与一年期利润校准的组合复验

状态：评分前[冻结协议](protocol.json)，尚未完成开发，不改生产或进入新留出。沿用已暴露的600家公司，2023/2024/2025H1三起点及当年9月1日中国零点，预测下一年H1经营利润代理；全1,800组保留。

[零增长两／三年验证](../tdx-zero-growth-validation/README.md)与[一年利润校准](../../../docs/forecast-calibration.md)有各自范围及后续反证：零增长后来的一至三年联合验证未通过一年门槛，利润校准2025时间复验效果也减弱。组合不是既有验证结论，现有生产政策仍禁止直接把校准与未经验证的增长改动叠加。

对照为零收入增长、短期收入规则（缺同期历史时显式沿用零增长），都保持当前经营利润率。两种基线各自拟合上一年已经兑现的误差：以前一年H1为预测起点，前一年9月1日为预测信息截止，以本次起点截止可用的本年H1实际为训练标签。系数使用既有加权中位数算法，权重为预测利润/实际收入，原始比例为实际利润/预测利润，截到[0.5,1.5]后只应用一半，即倍率(1+截断比例)/2。不把短期基线系数直接套到零增长基线。

每家目标公司在拟合自己的系数时从训练池中移除；池中至少30家公司，历史预测利润为正，实际利润允许亏损。当前预测利润非正时保留原预测并注明不适用乘性校准，不删除公司；正利润但训练不足时校准预测留空，不默认为倍率1。短期基线的缺历史回退在训练和预测中均明确记录，它不是未经改变的生产准入规则。

主候选是零增长＋半量校准，要求相对未校准零增长的利润主误差至少改善5%，WAPE非劣，且不劣于短期及短期校准两个对照；至少900组、300家公司，每起点至少200组共同可评价、100组实际应用校准，基线覆盖保留90%。各起点最多退化5%，另逐一删除评价公司检查整体非劣。目标公司从训练中移除与删除评价公司是两项不同检查，不声称已做所有训练同业逐一剔除后重拟合。

全部预测完成后再读取下一年目标结果。不新增自由调参，不挑行业或删除亏损来挽救结果；后来取得的TDX与FN314仅作简化源回溯，业务可比性未知，不是严格PIT、完整FCFF或估值准确率。开发全部门槛通过后，才可定义排除所有已暴露公司的新留出。
