# 高权重训练样本的业务与源精度复核

四份CNINFO原始PDF及下载URL、取得时间、SHA-256见[清单](manifest.json)。`archive_path_date`仅为归档路径日期，不作为逐记录公告时间；历史研究沿用原TDX/FN314时点。原文为本次后来取得，不冒称当时已归档或严格PIT。

本轮完成八个单季度收入对照（六个float32位匹配、两个差异保留）、两个TTM收入复算，以及业务说明定位；**未完成两家公司全部TTM经营利润分量核验**，没有修正源值、删除标准事实或把报表归母净利润当作经营利润。

## 海航科技：季度分配差异、业务出表与担保转回

2021年报p3说明2021年7月2日完成GCL IM股权交割，此后不再持有股权；p14说明交割后不再合并英迈收入。2022H1训练输入的收入窗口为2021Q3至2022Q2，跨越该交割事件。

年报p8季度表以**千元人民币**列示，换算后与各自季度包FN230比较：

| 期间 | 年报季度表（元） | TDX源值（元） | 结果 |
| --- | ---: | ---: | --- |
| 2021Q3 | 3,699,614,000 | 3,846,448,128 | 单季不同 |
| 2021Q4 | 41,745,000 | -105,089,000 | 单季不同，连符号也不同 |
| 两季合计 | 3,741,359,000 | 3,741,359,128 | 差128元，在源舍入范围内 |

2023H1报告p6比较列的2022H1收入为61,910千元。加上上述年报两季得到2022H1 TTM收入3,803,269,000元；原训练输入为3,803,269,128元，差128元，小于四季度源float32累计半ULP界限135元。比较列不代替2022H1原始报告；本轮不能确定单季差异具体由哪次修订引起。四季合计能闭合，也不意味着短期单季增长可以直接互换口径。

2021年报p3及p184另说明，财务担保合同损失准备转回1,709,995千元；p57保留意见说明涉及该转回的审计证据限制。原研究经营利润代理公式只剔除指定的投资、公允价值和其他收益等字段，**没有按附注单独正常化财务担保损失**。这构成利润可持续性复核线索；不能直接从2022H1 TTM利润扣掉整笔2021年度转回，尚须闭合半年分量及相关项目。

2023H1本期收入同比反而增长162.53%，报告p6解释为新船增加运力。TTM训练收入大幅下降与当前半年收入增长可以同时发生，不能把前者直接解释成新业务持续衰退。

## 金迪克：低收入分母与研发总投入范围

2023年报p9披露7月暴雨导致临时停产，12月18日恢复疫苗销售，错过部分销售旺季。2024H1报告p7解释半年收入同比下降97.41%还受2023年一季度接种需求高基数及2024年疫情较平稳影响，不能把全部变化归因于停产。

2023年报四季度收入与TDX逐位匹配，其中Q3为负值−6,299,040.71元；保留负数。用年报Q3、Q4及2024H1收入重建TTM为10,736,784.63元，原研究四季源值合计10,736,784.75元，差0.12元，在累计半ULP界限1.0625元内。

2024H1报告p12还提供了研发线索：

| 当期投入 | 金额（元） |
| --- | ---: |
| 费用化研发 | 12,791,059.40 |
| 资本化研发 | 7,907,105.73 |
| 合计 | 20,698,165.13 |

合计同比增长34.49%，同时当期收入同比下降97.41%。这不是研发无效的因果证据，但说明仅用研发/收入比例容易混入收入分母坍缩；评价研发总投入也不能只取代表费用化研发的FN304。资本化新增、开发支出余额及摊销属于不同期间/存量概念，不能相加冒充同一投入。本轮只核对该表原文与加总，未新增其TDX标准映射，也不将投入直接转为未来增长率。

## 剔除的适用边界

两家公司由上一轮训练权重集中度定位，均不是随机抽样。原文支持定向核查，但尚未形成跨公司通用的事前剔除标准。[训练剔除敏感性](../training-exclusions.md)保留评价分母，结果不能用来宣称已验证一条自动异常值规则。尤其2024年报告不能作为2023年起点剔除金迪克的当时已知证据。
