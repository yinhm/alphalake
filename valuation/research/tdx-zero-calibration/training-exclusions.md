# 高权重公司的训练剔除敏感性

按用户建议，对既有600家、三个历史起点进行事后诊断：从训练池分别剔除海航科技、金迪克，再同时剔除。评价集仍为原1,800组，1,726组可评价（589家公司），72组基线阻断、2组实际值阻断及438组当前经营利润非正全部保留；这两家公司仍参与评价。完整结果见[training-exclusions.json](training-exclusions.json)，原文见[四份报告复核](source-review/README.md)。

选样已受既有训练权重和历史研究结果影响；按公司代码跨起点剔除只是敏感性分析，并不是可部署的事前异常规则。没有新留出、没有采用门槛，也不将本次较好的指标追认成通过验证。

## 结果

下表为零增长＋半量利润校准组合，主误差是逐公司绝对经营利润误差/实际收入的均值，WAPE以实际经营利润绝对值加权。

| 训练处理 | 主误差 | WAPE |
| --- | ---: | ---: |
| 原组合，不额外剔除 | 12.9344% | 45.3320% |
| 剔除海航科技 | 12.9857% | 44.7420% |
| 剔除金迪克 | 12.9389% | 44.7344% |
| 同时剔除两家 | 12.9898% | 44.1504% |
| 未校准零增长基线 | 13.2080% | 43.6590% |

三种剔除均令主误差比原组合更差，WAPE改善但仍劣于未校准基线；同时剔除后的主误差相对未校准基线改善约1.65%，仍不足原5%门槛。短期增长＋半量校准对照也没有同时改善两项指标：两家剔除后主误差12.7715%→12.8467%，WAPE44.2982%→43.7811%。**不能通过删除这两家公司挽救组合规则，生产限制不变。**

2023H1训练池原本同时包含两家；2024H1只包含金迪克；2025H1均不在原正预测利润训练池。因此同时剔除对应三个起点实际移除2/1/0条，不是每期都删除两条。共改变866个组合预测；当前非正利润仍不缩放，评价实际值不参与重拟合，原目标公司自排除和至少30条训练要求继续生效。

## 后续行动

后续已完成[十期利润主表及担保贡献对账](earnings-review/README.md)，发现利息源零和包含范围问题；[通用利息源零训练过滤](training-quality.md)开发亦未通过。海航单季收入修订及完整可比经营EBIT仍待追踪，不支持先删公司再把改善解释为预测能力。若后续研究通用异常规则，应只依赖该起点可取得的业务/财务信息，事前固定阈值，单列剔除数量并在完整评价集报告误差；针对研发需同时考虑资本化投入、商业化滞后和低收入分母，不能直接按研发强度高低删样本。
