# 非正起点EBIT的恢复预测复验

开发候选未通过，不进入新留出、不修改生产估值政策。600家公司、三起点六窗口共3,600组，834组非正EBIT基线可评价，217组候选共同可评价、涉及82家公司。候选主误差16.7680%→17.2520%（退化2.89%）；虽然WAPE改善，仍劣于盈亏平衡对照。数据齐全和公式复算通过不等于恢复预测有效。

本轮补上[此前正常化试验](../tdx-normalized-margin/README.md)经生产正EBIT门槛后遗漏的亏损起点。依据[达摩达兰正常化说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)，负的当前盈利可能需要正常化，但需判断业务成熟、周期及恢复时间。本文只检验“当前非正EBIT、过去五财年均值为正”的输入代理，不声称这些公司均是成熟周期业务。前轮发现的[业务变化及追溯调整](../tdx-normalized-margin/scope-review.md)风险仍然适用，不因需要样本而忽略。

## 事前定义与数据

原240家开发样本的起点信息盘点（未评分本候选）共有720个公司/起点：505个当前EBIT为正、98个历史均值不适用、44个亏损但历史不足、23个起点源窗口阻断，只有50个公司/起点满足候选，涉及38家公司。最多93个预测窗口，达不到原120组开发门槛，因此未降低门槛，按既有SHA256排序取已登记1100家公司中的前600家开发，包含原240家。600家中的历史结果在其他研究中已有暴露，本轮明确只作开发。原120家新留出名单保持不变，不按未来恢复与否选取。

[协议](protocol.json)与[开发采集定义](development-study.json)在`79b4286`提交后，复用现有Go工具解析34个原始包，得到18,418条源记录、600家公司。[源回执](source-receipt.json)确认全部原240家公司7,400条记录逐项相同，源清单、文件版本及取得时间一致；没有新下载、标准事实或主库变更。TDX FN314只是简化可用性代理，后来取得的源版本不是严格PIT，也不保证已按起点最新追溯口径重列。

首次评分前已经生成源快照、完成实现及模拟正负回归，但提交实现的命令因工作目录错误失败，评分仍执行；`5891811`是评分后的补记提交，不冒称它证明了评分前Git冻结。评分回执中的实现与源哈希同该提交一致；评分后未改候选、名单或门槛。本轮属于开发，未因此声称独立留出验证。

## 比较规则

只用起点可用数据：当前TTM收入为正、调整EBIT非正；过去五个完整财年须各有四季收入及年度EBIT，保留单年亏损，五年等权平均利润率须在(0,1]。当前正EBIT列为范围外，源缺失、历史均值不适用各自保留；候选历史不足时仍评价可计算的非正EBIT基线。未来仍亏损也进入评价，217组共同样本中150组未来EBIT非正，67组转正。

- 基线：收入零增长、保持当前利润率，因此保持当前负/零EBIT。这是数学预测基线，不是生产DCF准入。
- 唯一候选：收入零增长，利润率按`当前利润率 + (五财年平均利润率 − 当前利润率) × 年数/5`过渡，评价第1/2/3年，第5年到达均值。
- 额外对照：收入仍相同、EBIT为零的盈亏平衡预测，不把零当实际缺项补值。

过渡速度沿用此前已定义的五年政策形式，未搜索其他年数；当前生产预测拒绝非正EBIT，因此只在独立研究层实现，不放松生产准入。这个线性过渡不是达摩达兰对所有公司的规定，也未验证第4/5年或终值。财务/投资调整EBIT代理尚不等于全部研发、租赁等经济调整后的经营盈利，历史FCFF仍为null。

沿用开发120组/30家公司、留出240组/60家门槛；主指标为EBIT绝对误差/实际收入的平均值，须改善至少5%，WAPE不退化；对额外盈亏平衡模型的主指标与WAPE均不得退化；各期限不退化，每窗口最多5%退化，逐公司删除后不退化。协议`require_production_comparator_nonworse`保留了共享门槛的旧键名，但本协议显式`comparator=zero_ebit`，结果使用`breakeven_comparator_nonworse`，不冒称存在生产亏损预测。

## 实际结果

[摘要](development-summary.json)与[无损压缩完整结果](development-result.json.gz)：2,588组当前正EBIT列为范围外，178组源/实际窗口阻断，617组候选历史阻断（417组均值不在范围、200组季度缺失），217组共同可评价。834组基线可评价中候选覆盖26.02%，不隐藏缺历史或经营长期亏损公司。
