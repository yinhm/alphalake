# 起点前误差范围的开发试验

[协议](protocol.json)先于评分冻结。现有600家已暴露开发公司按固定哈希排序分300家误差校准、300家评价，公司不重叠但不是新留出。三个起点仅用前一已成熟的一年窗口估计误差范围，不用下一年实际值决定区间。收入和EBIT代理各取历史标准化有符号误差5%/95%最近秩分位数；名义各90%不等于联合90%，也没有未来概率保证。

每起点至少80个校准/评价组合；任一变量任一起点覆盖低于90%即停止这个固定候选，不扫描分位数或扩大带宽救结果。通过也只允许进入新的公司验证，不自动发布。报告带宽和联合覆盖，点预测保持当前规则，真实负利润保留，收入下限取零不修改实际值。

依据达摩达兰[概率方法章节](https://pages.stern.nyu.edu/~adamodar/pdfiles/val3ed/c33.pdf)对历史/横截面分布、结构变化和相关性的讨论；本文分位数与停止门槛为显式研究政策，不是其指定公式。不是蒙特卡洛估值或完整DCF置信区间。尚未评分。
