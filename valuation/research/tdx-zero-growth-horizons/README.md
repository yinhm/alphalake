# 零增长一至三年统一窗口复验

开发通过，独立留出未通过，不能采用为统一一至三年预测规则。新120家公司720组中493组可评价、涉及101家公司，227组阻断保留；收入平均绝对百分比误差改善15.94%，但一年期合计略退化，2024/2025起点一年窗口分别退化约6.53%/6.85%，超过事前5%容忍。此前另一批120家两年/三年通过的结果仍成立，但不能外推到一年期。

本轮是收入输入假设检验，不修改达摩达兰FCFF、净再投资、ROIC或WACC定义。方法参考[增长基本决定因素](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/invfables/growthdeterminants.htm)，零增长是显式待验证输入，不是达摩达兰对上市公司的统一建议。公司经营、会计可比性与幸存者偏差仍存在，不能把经营预测误差当成完整DCF误差。

## 规则与事前门槛

基线复用生产同季同比收入中位数，按政策限制在−10%至20%，保持起点利润率。候选只将收入增长置零，利润率相同；均评价同一实际TTM收入及调整EBIT。原提前收敛路径只保留诊断，不参与选择。适用范围沿用生产历史预测的正收入/正EBIT、足够同比季度等准入；不要求五财年利润率齐全，不用未来亏损与否删样本。

复用此前零增长门槛：开发至少120组/30家公司、留出至少240组/60家公司；收入主误差改善至少5%，收入WAPE不退化、EBIT主误差与WAPE不退化，每个期限收入主误差不退化，各起点/期限最多容忍5%退化，逐公司删除后收入主误差不退化。门槛在评分前固定，不因一年期失败而只报告两/三年。
