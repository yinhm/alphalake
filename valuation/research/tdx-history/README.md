# TDX简化历史预测复验

研究层实验，不写标准事实或主库，不要求全量CNINFO核验。以固定20家公司评价2025H1起点至2026H1的一年TTM收入和调整经营利润预测；`study.json`在计算前提交冻结，12家开发、8家留出，人工分层不冒称标准行业身份。

## 数据与计算

2024Q1—2026H1共10个季度：FN230是单季度收入；FN86/305/306/83/82/301按累计口径组合，金额以源float32为准。FN314按YYMMDD解释，在中国次日零点可用；非法日期、早于或等于报告期、晚于取得日期、超过研究截止均不能成为该时点的输入。缺项不填零，重复代码/期间不任选一条。

起点固定2025-09-01中国零点，评价截止2026-09-10中国零点。输入只使用起点可用记录，实际值另按评价截止读取；后来下载包内的修订仍可能造成前视偏差。2024语义是对已审核后续期间映射的研究外推，不扩展生产映射有效期，也不代表20家公司已逐份原文核验。

收入TTM取连续四季之和，累计字段取上年全年＋当年同期−上年同期。调整EBIT沿用通用模型六分量公式；预测调用生产入口共享的`historical_forecast`纯函数，未修改增长假设。固定对照为零增长、基期利润率不变；没有用留出结果调参。

这是非金融主业固定样本的经营预测子规则实验，不进行完整DCF准入。非正基期收入/EBIT仍按规则拒绝。当前v2将全部19家可评价公司的合并调整EBIT代理纳入误差评价，并按金融字段信号分别输出13家未命中组、6家命中组；不因财务公司等业务字段非零就把主营公司归为金融行业。

FN506/509/510的TTM或FN413期末非零只产生`financial_scope_flags`及`profit_scope=financial_fields_present`研究分组，零字段不证明没有兼营。这6家是茅台、伊利、双汇、美的、格力、三一；它们的代理利润仍包含未拆分金融业务，`profit_basis=consolidated_adjusted_ebit_proxy`不代表纯实业EBIT，不推广为银行/保险公司的模型。分组依据含起点与实际期字段，是回溯评价信号，不是当时已知的行业分类。

## 复现

已有依赖的Python，在`valuation/backend`运行：

```bash
python -m tools.backtest_tdx_history ../research/tdx-history/study.json \
  ../research/tdx-history/snapshot.json > /absolute/result.json
```

源码快照保存源位及原包哈希，供离线回归；金额与零值均来自TDX，未由PDF补填。快照完整原包保存在本地研究归档，未将全市场包提交仓库。快照与归档核对的边界是二进制解析，不是独立财报语义校验。

重新取数时，先下载所需专业财务包和对应`gpcw.txt`清单；中断下载可续传，完整大小和MD5通过前不得发布快照。可复用已归档包，但必须使用与该版本对应的原清单和原取得时间，不用新清单覆盖旧版本身份。

准备来源清单JSON数组，每项为`file`（如gpcw20240331.zip）、`path`（已下载原包路径）、`list`（对应原gpcw.txt路径）、`fetched_at`（带时区的真实取得时间）。路径相对执行目录或使用绝对路径。在仓库根目录：

```bash
go run ./valuation/research/tdx-history/prepare.go \
  valuation/research/tdx-history/study.json /absolute/source-manifest.json \
  /absolute/new-archive-directory
```

目录必须不存在；研究准备器核验清单、大小/MD5及包头报告期，复用现有Go解析器提取指定公司的源位，保留原包、源清单、研究配置与SHA256；失败保留不完整目录，不生成最终snapshot.json，不修改已有归档。随后将新snapshot路径传给回溯命令。结果为`tdx-history-backtest-v2`，退出0仅表示处理完成，必须读取拒绝分母；请求错误退出1。

## 评价边界

- 分别输出总体、开发/留出及人工分层的分母、拒绝、收入中位绝对百分比误差、平均有符号百分比偏差、收入加权绝对误差，以及利润率百分点绝对误差和利润绝对误差/实际收入。
- 实际利润非正仍可评价；不对利润做易失真的百分比误差。没有可评价样本时指标为空，不返回零误差。
- 一年期结果不能证明前五年增长延用合理，更不能证明全DCF、每股值或投资收益准确。只有一个历史起点，目的抽样有幸存者偏差；留出公司不等于未来时间样本外。
- 不输出统计置信区间或胜出政策，不因样本误差较小自动修改生产参数。

这条基线没有一致支持当前规则胜出：总体收入指标较好，留出指标有好有坏；也没有检验五年增长持续性。未修改生产政策，不推导合理股价。下一步优先增加历史起点，观察增长/利润率偏差在不同期间是否持续；已经看过的留出结果不能重新宣称为未接触的验证数据。
