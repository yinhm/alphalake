# 扩展样本的经营预测规则研究

当前结论：经过六轮开发试验，滞后半量乘性利润校准通过开发门槛；首次留出有改善但样本不足，随后固定同一规则的120家公司独立复验通过。证据支持原两个历史起点的一年期利润预测改善；追加2025起点仍改善约1.9%，但未达到预定5%门槛，已接入[显式一年期政策](../../../docs/forecast-calibration.md)并完成安克主库对照，不等于完整DCF准确度提升。

## 抽样与源数据

[抽样名单](sampling-universe.json)来自2026-09-10本地主库就绪度导出，仅保留身份唯一的沪深证券、已有78个非金融政策行业中的唯一Damodaran行业，排除此前研究的20家公司。共4,833家公司；不按财务完整率、利润或历史表现筛选。

对六位代码计算`SHA256("alphalake-growth-v3:" + code)`并升序排列，取前120家，偶数索引60家开发、奇数索引60家留出。名单及[初始协议](protocol.json)在`21b82ec`评分前冻结；回归测试重建抽样并检查与旧样本无交集。当前身份/行业只用于抽样，不进入历史预测；本研究仍有当前上市名单的幸存者偏差，不代表无偏历史市场样本，也不覆盖北交所。

复用2022Q1—2026H1的18个TDX原包，按各自取得版本的清单核验大小/MD5，再调用生产二进制解析器生成[2,121条源记录快照](snapshot.json)，保留原始float32位。新增公司未逐一核验PDF；映射沿用已审核语义属于简化研究假设。后来取得的版本与FN314不能证明严格历史PIT，不新增标准事实。

## 开发结果与决策

两个一年窗口：2023H1→2024H1、2024H1→2025H1。60家公司共120个组合，44+42=86个可评价；34个拒绝中25个因起点不满足正收入/正EBIT规则，其余9个缺期间或足够同比输入。拒绝不被替补，也不计零误差。亏损实际仍保留，只在起点遵循生产模型准入。

| 试验 | 收入WAPE | 利润绝对误差/实际收入的等权均值 | 结果 |
| --- | --- | --- | --- |
| 当前规则 | 11.8893% | 5.2303% | 基线 |
| 零增长、当前利润率 | 16.6690% | 5.2028% | 对照 |
| 增长乘0.75 | 12.1872% | 5.1750% | 利润改善不足、收入恶化 |
| 增长乘0.50 | 13.4821% | 5.1304% | 利润改善不足、收入恶化 |
| 当前/上一全年利润率各半 | 11.8893% | 6.1036% | 利润恶化 |
| 上一全年利润率 | 11.8893% | 7.2685% | 利润恶化 |
| 延续利润率变化，限2个百分点 | 11.8893% | 5.1946% | 改善不足、剔除公司后不稳健 |
| 延续利润率变化，限5个百分点 | 11.8893% | 5.1260% | 改善不足、剔除公司后不稳健 |

增长试验保持当前利润率；其余试验保持当前增长。利润率趋势为`当前TTM利润率 + clip(0.5 × (当前TTM利润率 − 上一全年利润率), ±变化上限)`，仅在研究工具支持；变化上限是绝对百分点，不是相对比例。允许预测负利润，不用零截断掩盖损失。

每轮先冻结协议再评分：初始增长试验后，`014e589`冻结[利润率回归协议](protocol-v2.json)，`d75fa74`冻结[限幅趋势协议](protocol-v3.json)。后两轮属于开发结果指导的迭代，不称独立预注册初始假设。门槛保持至少80个可评价组合、利润误差改善至少5%、收入WAPE不变差、分起点及逐公司剔除稳健性。前三轮六个候选全部未通过，当时不打开留出、不挑第二名、不放宽门槛。后续试验及首次打开留出的顺序见下文。

三份开发摘要分别为[增长](development-summary.json)、[利润率回归](development-v2-summary.json)、[限幅趋势](development-v3-summary.json)，包含各起点、金融业务信号分组和全部准入判据。

## 复现与覆盖

在后端环境运行：

```bash
cd valuation/backend
python -m tools.backtest_tdx_origins ../research/tdx-growth-expanded/protocol-v3.json ../research/tdx-growth-expanded/snapshot.json --phase development > /tmp/alphalake-expanded-development.json
python -m pytest tests/test_tdx_history.py -q
```

前两轮分别替换为`protocol.json`和`protocol-v2.json`。回归锁定抽样、源哈希、86/120分母、三轮决策、变化限幅和非法参数拒绝；篡改留出公司的源利润不会改变开发输出。旧多起点结果继续精确复现。新增的是研究计算能力，不是生产预测政策。

前三轮结果促使后续检查误差的共同偏差，再预先固定校准规则。未继续微调限幅追逐总分；后续拟合保留时间隔离、开发与留出隔离。完整DCF还需再投资、WACC及终值验证，当前一年期经营预测不能替代它们。

开发集还出现方向性偏差：当前规则2023起点44个可评价组合中30个高估利润，2024起点42个中24个高估；以实际收入标准化的有符号利润误差均值分别为+4.0072、+2.9801个百分点，中位数为+2.1908、+0.7688个百分点。这只是开发诊断，不能用同一期间误差校准后自称提升。据此开展下文的滞后校准：补2021源包，以起点前已可评价的更早窗口估计偏差，并验证训练标签的可用时间，不从目标期实际值拟合校正量。


## 滞后校准与独立复验

`704ca9c`先冻结[滞后校准v4](protocol-v4.json)，再取得2021四个TDX包。新增[22包快照](snapshot-v4.json)保持此前18包的源记录与归档元数据不变；2023预测的训练窗口为2022H1→2023H1，2024预测为2023H1→2024H1。训练实际按当前起点当年9月1日中国零点截断，只用60家开发公司，分别36、44个可评价训练组合；留出公司及未来目标实际不参与校准。

| 开发试验 | 利润误差指标 | 决策 |
| --- | --- | --- |
| v4：上一窗口利润率误差中位数，半量/全量，限3个百分点 | 5.1113% / 5.0881% | 改善不足5% |
| v5：按主指标加权的加性利润校准，半量/全量，限3个百分点 | 5.0607% / 5.1223% | 未通过 |
| v6：乘性利润校准，半量/全量 | 4.7893% / 5.2824% | 仅半量通过 |

[v5协议](protocol-v5.json)在`1d8c44f`冻结，[v6协议](protocol-v6.json)在`b36bb2a`冻结。所有候选增长保持不变，开发基线为5.2303%；此前失败结果不覆盖。摘要为[v4](development-v4-summary.json)、[v5](development-v5-summary.json)、[v6](development-v6-summary.json)。

乘性方法在过去窗口计算`实际EBIT / 原预测EBIT`，权重为`原预测EBIT / 实际收入`，取加权中位数并限定在[0.5,1.5]；这对应过去训练集按实际收入标准化的绝对利润损失最小化。半量模型的预测EBIT乘以`(1+系数)/2`，收入完全不变。加权损失断点枚举回归验证公式最优性，不冒称独立财务取数核验。

2023、2024起点系数分别为0.5、0.782955459563529，即最终利润倍率0.75、0.8914777297817645。2023原始估计为0.05312018276175804，触及事先规定的下限，九安医疗从高利润回落对训练权重有明显影响；不删除该公司，不把边界截断称为数据事实。预定逐公司剔除门槛是评价集合稳健性；另做的训练公司删除重拟合诊断见下文。

`48dfd47`冻结实现及开发选择后首次打开原60家留出：[v6结果](holdout-v6-summary.json)75/120组合可评价，利润误差7.5186%→6.7384%（改善约10.4%）；所有误差与剔除门槛通过，但未达到80组合，整体保持未通过。

`8efd080`随后冻结[独立复验协议v7](protocol-v7.json)：原4,833家公司同一哈希排序第121—240名，共120家新留出。训练公司、源值、拟合结果、模型、80组合及改善5%等门槛均不变；不与旧留出拼接凑数、不根据结果继续加样本。`f194174`锁定[独立复验快照](snapshot-v7.json)及[不变的开发选择](development-v7-summary.json)后评分。

| --- | --- | --- | --- |
| 2023H1→2024H1 | 85/120 | 8.3780% | 7.3481% |

## 追加2025起点：改善幅度未达门槛

`885d2b6`在评分前冻结[协议v8](protocol-v8.json)，`8483ee3`锁定[不变的开发选择](development-v8-summary.json)后评估2025H1→2026H1。同一120家验证公司的旧窗口已经使用，本次只增加时间窗口，不称另一批新公司独立验证；候选仍固定半量乘性规则，不据此调参。

[时间复验结果](holdout-v8-summary.json)：85/120个组合可评价，35个拒绝保留。利润误差指标由7.740288%降至7.591722%，改善约1.92%；仅`primary_improvement`未通过，其他预定门槛均通过。收入WAPE保持12.171552%，本窗口当前增长规则优于零增长13.593286%，与原两个窗口的表现不同，提示跨期表现不能概括为始终胜出。

训练严格为2024H1→2025H1，按2025-09-01中国零点核验标签可用性，共42个训练组合；尺度0.907113572390187，最终利润倍率0.9535567861950935。新目标期2026H1实际没有进入该校准，也未用于重新选择候选。

原v7独立复验通过的历史判定保留；追加窗口的整体判定为未通过，不拼接旧结果掩盖效果门槛失败。三个时间起点的改善方向一致，幅度不稳定。显式一年期政策仍只作为限定采用的研究校准，不扩大自动默认范围；下一步需检查现金流层面的可比取值及误差，不能仅凭利润误差改善宣称FCFF或完整估值准确度提升。

复现：在后端目录按前述命令将协议换成`protocol-v8.json`，保持`snapshot-v7.json`，先重新生成开发选择文件再运行holdout。原始摘要代码哈希保留，不改写历史记录。


## 现金流诊断取值准备

[现金代理协议](protocol-cash-proxy.json)在读取新增字段前冻结，使用原验证公司、三个已观察的利润窗口和固定模型，不作为新独立验证或参数选择。`cmd/prepare-tdx-history`现接受研究JSON中的可选`additional_source_fields`；默认仍为原12个字段，非法/重复字段在创建归档前拒绝。

[新增快照](snapshot-cash-proxy.json)在原22包、3,861条记录上追加FN234和FN114；旧字段、原包及清单引用逐项不变，[来源摘要](cash-source-summary.json)锁定内容哈希。真实`annual-2025`切片回归核对已审核Q4现金流原文金额的float32位，重复请求字段及清单MD5篡改均拒绝。

FN234按四季度求和；FN114按年度＋当期累计−上年同期累计。两者之差仅为报表现金代理，无法单独识别完整FCFF、并购/非现金再投资或全部经营营运资金。当前完成源字段提取，现金距离评分尚未运行；不改变标准映射历史有效期或主库事实。
